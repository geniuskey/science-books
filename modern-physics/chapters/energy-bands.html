Chapter 12

결정 속 전자와 에너지 띠

실리콘 결정 1 cm³에는 원자가 5×10²²개 있다. 그런데 그 속의 전자는 원자 하나하나에 부딪히며 비틀거리지 않고, 마치 거의 자유로운 입자처럼 수백 nm를 미끄러져 간다. 비밀은 주기성이다. 완전히 규칙적인 퍼텐셜 속에서 전자의 파동은 산란되지 않는 블로흐 파가 되고, 그 대가로 에너지는 허용된 띠와 금지된 띠 간격으로 갈라진다. 이 장은 양자역학에서 반도체 소자로 넘어가는 다리다. 아래 화면에서 결정 속 전자의 파동과 그 에너지 띠를 먼저 보자.

E(k)를 눌러 상태 선택
  • 결정의 격자·단위 세포·격자 상수를 설명하고, 실리콘(다이아몬드 구조, \(a = 0.543\) nm)의 원자 밀도를 계산한다.
  • 블로흐 정리 \(\psi_k = u_k(x)e^{ikx}\)의 의미와 결정 운동량 \(\hbar k\), 브릴루앙 영역을 설명한다.
  • 크로니히–페니 모형의 분산 관계 \(\cos kd = f(E)\)로 허용 띠와 띠 간격을 구하고, 띠 간격이 영역 경계의 브래그 반사에서 생긴다는 것을 보인다.
  • 강결합 띠 \(E = E_0 - 2t\cos ka\)로 띠 폭과 유효 질량을 계산하고, 전자 수로 금속·반도체·절연체를 가른다.
  • 군속도 \(v = \hbar^{-1}dE/dk\), 유효 질량 \(m^* = \hbar^2/(d^2E/dk^2)\), 준고전 운동 \(\hbar\,dk/dt = -qF\), 정공의 개념을 쓴다.
  • 실리콘의 6개 Δ 계곡(\(m_l, m_t\)), 무거운·가벼운 정공, 직접·간접 띠 간격과 그 온도 의존을 소자와 연결한다.

결정과 주기 퍼텐셜

결정은 같은 원자 배열이 3차원으로 끝없이 되풀이되는 고체다. 되풀이의 뼈대가 되는 점들의 집합을 격자(lattice), 각 격자점에 붙는 원자 묶음을 기저(basis)라 한다. 결정 전체를 빈틈없이 채우며 반복되는 가장 작은 덩어리가 기본 단위 세포(primitive cell)이고, 대칭을 보기 쉽게 고른 더 큰 덩어리가 관습적 단위 세포(unit cell)다. 단위 세포 한 변의 길이가 격자 상수(lattice constant) \(a\)다.

실리콘·저마늄·다이아몬드는 다이아몬드 구조(diamond structure)를 가진다. 면심 입방(FCC) 격자의 각 점에 원자 두 개(하나는 \((0,0,0)\), 다른 하나는 \((\tfrac14,\tfrac14,\tfrac14)a\))를 붙인 꼴이다. GaAs는 같은 뼈대에 두 자리를 Ga와 As가 나눠 앉은 섬아연석 구조다. 11장에서 본 sp³ 혼성 오비탈이 정사면체 결합 네 개를 만드는 이유가 바로 이 구조다.

전자가 느끼는 퍼텐셜 에너지는 원자핵과 다른 전자들이 만드는 평균 퍼텐셜이다. 원자가 주기적으로 늘어서 있으므로 퍼텐셜도 주기 함수다.

$$V(x + a) = V(x) \qquad (\text{3차원: } V(\vec r + \vec R) = V(\vec r),\ \vec R = n_1\vec a_1 + n_2\vec a_2 + n_3\vec a_3)$$
\(\vec R\)은 격자 벡터. 결정 속 전자 하나의 문제는 "이 주기 퍼텐셜 속의 1전자 슈뢰딩거 방정식"으로 바뀐다(다른 전자의 영향은 평균장에 넣는다).

원자들이 멀리 떨어져 있으면 각 원자의 깊은 우물 사이에 높은 장벽이 있어 전자는 자기 원자에 묶인다(5장의 유한 우물). 원자를 가까이 모으면 이웃 퍼텐셜이 겹쳐 장벽이 낮아지고, 바깥 껍질 전자는 장벽을 터널링하거나 아예 넘어 결정 전체로 퍼진다. 아래 미니 실험으로 이 변화를 보자.

블로흐 정리

퍼텐셜이 주기 \(a\)로 반복되면, 결정을 \(a\)만큼 옮겨도 물리는 똑같다. 따라서 전자를 찾을 확률도 \(|\psi(x+a)|^2 = |\psi(x)|^2\)이어야 하고, 파동함수 자체는 기껏해야 크기 1인 위상 인자만큼 달라질 수 있다. 그 위상을 \(e^{ika}\)로 쓰면 결정 속 고유 상태의 모양이 정해진다.

블로흐 정리

주기 퍼텐셜 \(V(x+a) = V(x)\) 속 슈뢰딩거 방정식의 고유 상태는 다음 꼴로 쓸 수 있다.

$$\psi_{nk}(x) = u_{nk}(x)\,e^{ikx}, \qquad u_{nk}(x+a) = u_{nk}(x) \quad\Longleftrightarrow\quad \psi_{nk}(x+a) = e^{ika}\psi_{nk}(x)$$

\(k\)는 결정 운동량(crystal momentum) \(\hbar k\)를 정하는 파수, \(n\)은 띠 번호다.

블로흐 함수(Bloch function)는 자유 전자의 평면파 \(e^{ikx}\)에 격자와 같은 주기로 출렁이는 함수 \(u_k\)를 곱한 것이다. 평면파 부분은 전자가 결정 전체에 퍼져 있다는 것을, \(u_k\) 부분은 원자 근처에서 파동이 원자 오비탈처럼 일그러진다는 것을 담는다. \(|\psi|^2 = |u_k|^2\)은 모든 단위 세포에서 똑같다 — 완전한 결정 속 블로흐 전자는 산란되지 않는다. 저항은 주기성을 깨는 것(격자 진동, 불순물, 결함)에서만 생긴다.

k는 어디까지 의미가 있나: 브릴루앙 영역

\(k\)에 \(G = 2\pi/a\)를 더해도 \(e^{i(k+G)a} = e^{ika}\)이므로 블로흐 조건은 그대로다. 실제로 \(\psi = u_k e^{ikx} = (u_k e^{-iGx})e^{i(k+G)x}\)로 고쳐 쓰면 괄호 안도 주기 함수이므로, \(k\)와 \(k+G\)는 같은 상태를 두 가지로 이름 붙인 것에 불과하다. 그래서 \(k\)는 길이 \(2\pi/a\)인 구간 하나만 보면 충분하고, 보통 원점을 중심으로

$$-\frac{\pi}{a} < k \le \frac{\pi}{a} \qquad (\text{제1 브릴루앙 영역})$$
\(G = 2\pi n/a\)를 역격자 벡터(reciprocal lattice vector)라 한다. 영역 경계 \(k = \pm\pi/a\)가 뒤에서 띠 간격이 열리는 자리다.

\(\hbar k\)는 진짜 운동량이 아니다(블로흐 함수는 운동량 연산자의 고유 함수가 아니다). 하지만 외력에 대해 운동량처럼 반응하므로 결정 운동량이라 부른다. 길이 \(L = Na\)인 결정에 주기 경계 조건 \(\psi(x+L) = \psi(x)\)를 주면 \(k = 2\pi m/(Na)\)로 띄엄띄엄해지고, 영역 안에 정확히 \(N\)개의 \(k\)가 들어간다. 즉 띠 하나에는 단위 세포 수만큼의 궤도 상태, 스핀까지 \(2N\)개의 자리가 있다.

크로니히–페니 모형

블로흐 정리는 상태의 모양만 알려 준다. 에너지를 구하려면 실제 퍼텐셜을 넣어 풀어야 한다. 1931년 크로니히와 페니는 원자 하나를 폭 \(a\)인 우물(퍼텐셜 0), 원자 사이를 폭 \(b\), 높이 \(V_0\)인 장벽으로 바꾼 사각 퍼텐셜을 골랐다. 구간마다 해가 단순한 지수 함수라서(5·6장) 손으로 끝까지 풀 수 있는 가장 간단한 결정이다.

미지수 \(A, B, C, D\) 네 개에 경계 조건 네 개(우물–장벽 경계에서 \(\psi, \psi'\) 연속, 장벽–다음 우물 경계에서 블로흐 조건을 쓴 \(\psi, \psi'\) 연속)가 걸린다. 자명하지 않은 해가 있으려면 4×4 행렬식이 0이어야 하고, 정리하면 놀랍도록 깔끔한 결과가 나온다.

$$\cos kd = f(E) \equiv \cos\alpha a\,\cosh\beta b + \frac{\beta^2-\alpha^2}{2\alpha\beta}\sin\alpha a\,\sinh\beta b \qquad (0 < E < V_0)$$
\(E > V_0\)이면 \(\beta \to i\beta'\), \(\beta' = \sqrt{2m(E-V_0)}/\hbar\): \(f = \cos\alpha a\cos\beta' b - \dfrac{\alpha^2+\beta'^2}{2\alpha\beta'}\sin\alpha a\sin\beta' b\). 왼쪽 \(\cos kd\)는 −1과 1 사이에만 있을 수 있다.

이 식이 띠 구조의 전부다. 에너지 \(E\)를 하나 고르면 오른쪽 \(f(E)\)가 계산된다. \(|f(E)| \le 1\)이면 실수 \(k = \cos^{-1}f/d\)가 있어 블로흐 파가 결정 전체에 퍼질 수 있다 — 허용 띠(allowed band). \(|f(E)| > 1\)이면 \(k\)가 복소수가 되어 파동이 셀마다 지수적으로 커지거나 줄어든다. 무한 결정에서는 그런 상태가 있을 수 없으므로 그 에너지 구간은 띠 간격(band gap), 금지 띠다.

델타 함수 극한

장벽을 얇고 높게(\(b\to0\), \(V_0\to\infty\)) 하되 \(V_0 b\)를 유지하면 \(f(E) = \cos\alpha d + P\,\dfrac{\sin\alpha d}{\alpha d}\), \(P = \dfrac{mV_0 b\,d}{\hbar^2}\)가 된다. \(P = 0\)이면 \(f = \cos\alpha d\)라 모든 에너지가 허용되고 \(k = \alpha\) — 자유 전자다. \(P\)가 커질수록 \(\alpha d = n\pi\) 바로 위에서 \(|f| > 1\)인 구간, 즉 띠 간격이 넓어진다. \(P\to\infty\)이면 허용 띠가 \(\alpha d = n\pi\)의 점으로 줄어들어 무한 우물(5장)의 준위가 된다.

장벽 높이 \(V_0\)를 0으로 내리면, 환원 영역(\(-\pi/d \le k \le \pi/d\))에 그린 \(E(k)\)는 어떤 모양이 될까?

\(V_0 = 0\)이면 \(f(E) = \cos\alpha d\)이므로 \(k = \alpha\) (+ 역격자 벡터의 배수). 포물선 \(E = \hbar^2k^2/2m\)을 \(2\pi/d\) 간격으로 잘라 제1 영역에 겹쳐 놓은 그림이 된다. 아래 시뮬레이터에서 장벽을 0으로 끌어내려 확인하라.

같은 \(E(k)\)를 그리는 방법이 셋 있다. 띠 \(n\)을 \(n\)번째 영역(\((n-1)\pi/d < |k| \le n\pi/d\))에 두면 자유 전자 포물선과 비교하기 쉬운 확장 영역(extended zone) 표시가 된다. \(k\)와 \(k + 2\pi/d\)가 같은 상태이므로 각 조각을 역격자 벡터만큼 옮겨 제1 영역에 모으면 환원 영역(reduced zone) 표시 — 반도체 띠 구조 그림은 모두 이것이다. 환원 영역 그림을 \(2\pi/d\)마다 되풀이하면 반복 영역 표시다.

우물 폭 \(a = 0.40\) nm, 장벽 폭 \(b = 0.10\) nm, 장벽 높이 \(V_0 = 2.0\) eV인 크로니히–페니 결정(자유 전자 질량)에서 (a) \(E = 1.0\) eV는 허용 에너지인가? 그렇다면 \(k\)는? (b) \(E = 1.8\) eV는?

풀이 보기
전략 \(\alpha = \sqrt{E/0.0381}\), \(\beta = \sqrt{(V_0-E)/0.0381}\) (nm⁻¹)을 구해 \(f(E)\)를 계산하고 \(|f| \le 1\)인지 본다.
풀이 (a) \(\alpha = \beta = 5.123\) nm⁻¹(\(E = V_0/2\)라 같다). \(\alpha a = 2.049\), \(\beta b = 0.512\). \(\beta^2 - \alpha^2 = 0\)이라 둘째 항이 사라져 \(f = \cos(2.049)\cosh(0.512) = (-0.460)(1.134) = -0.522\). 허용. \(k = \cos^{-1}(-0.522)/d = 2.120/0.50 = 4.24\) nm⁻¹ \(= 0.675\,\pi/d\).

띠 간격의 두 얼굴: 브래그 반사와 강결합

거의 자유로운 전자: 영역 경계의 브래그 반사

왜 하필 \(k = n\pi/a\)에서 간격이 열릴까? X선 회절의 브래그 조건(Bragg condition) \(2a\sin\theta = n\lambda\)를 1차원(\(\theta = 90^\circ\))에 쓰면 \(\lambda = 2a/n\), 즉 \(k = 2\pi/\lambda = n\pi/a\)다. 이 파수의 전자 파동은 원자마다 조금씩 반사된 파동들이 모두 같은 위상으로 더해져 강하게 되돌아온다. 오른쪽으로 가는 \(e^{i\pi x/a}\)와 반사된 \(e^{-i\pi x/a}\)가 같은 크기로 섞이면 진행하지 않는 두 정상파가 된다.

$$\psi_+ = \sqrt2\cos\frac{\pi x}{a}, \qquad \psi_- = \sqrt2\,i\sin\frac{\pi x}{a} \qquad\Rightarrow\qquad E_\mp = \frac{\hbar^2}{2m}\left(\frac{\pi}{a}\right)^2 \mp |V_G|, \quad E_g = 2|V_G|$$
\(V_G\)는 퍼텐셜의 푸리에 성분 \(V(x) = \sum_G V_G e^{iGx}\) 가운데 \(G = 2\pi/a\) 성분. \(\psi_+\)는 전자를 양이온 위(퍼텐셜이 낮은 곳)에 모아 에너지가 내려가고, \(\psi_-\)는 이온 사이에 모아 올라간다.

두 정상파의 \(|\psi|^2\)는 같은 \(k\)인데 퍼텐셜을 정반대로 샘플링한다. 그 에너지 차이가 띠 간격이다. 퍼텐셜이 약할 때 \(E_g\)가 \(|V_G|\)에 정비례한다는 이 그림을 거의 자유 전자 모형(nearly free electron model)이라 한다. 영역 경계에서 군속도 \(dE/dk\)가 0이 되는 것도 같은 이유다 — 정상파는 움직이지 않는다.

퍼텐셜의 푸리에 성분이 \(|V_G| =\) 0.56이면 거의 자유 전자 모형의 띠 간격은 \(E_g = 2|V_G| =\) 이고, 이 간격을 건너뛰는 광자의 파장은 \(hc/E_g =\) 다.

\(a = 0.500\) nm, \(V(x) = -2U\cos(2\pi x/a)\), \(U = 0.300\) eV인 1차원 결정이 있다. (a) 퍼텐셜이 없을 때 \(k = \pi/a\)의 자유 전자 에너지는? (b) 퍼텐셜이 있을 때 두 정상파의 에너지와 띠 간격은? 어느 쪽이 아래 띠의 꼭대기인가?

풀이 보기
전략 이 퍼텐셜의 푸리에 성분은 \(V_{\pm G} = -U\)이다. 1차 섭동으로 \(E_\mp = E_0 \mp U\).
풀이 (a) \(E_0 = 0.0381\times(\pi/0.500)^2 = 1.504\) eV. (b) \(\psi_+\propto\cos(\pi x/a)\): \(\langle V\rangle = -2U\langle 2\cos^2(\pi x/a)\cos(2\pi x/a)\rangle = -U\) → \(E = 1.204\) eV. \(\psi_-\propto\sin\): \(\langle V\rangle = +U\) → 1.804 eV. \(E_g = 2U = 0.600\) eV.
(a) 1.50 eV (b) cos 정상파 1.20 eV(아래 띠 꼭대기), sin 정상파 1.80 eV(위 띠 바닥), E_g = 0.600 eV

강하게 묶인 전자: 원자 준위가 넓어진 띠

반대쪽 극한에서 출발해도 같은 결론에 이른다. 11장에서 원자 \(N\)개를 사슬로 이으면 원자 준위 \(E_0\) 하나가 \(N\)개로 갈라지는 것을 보았다. 이웃 오비탈 사이의 겹침(호핑 적분(hopping integral)) \(t\)만 남기는 강결합 근사(tight-binding approximation)에서, 블로흐 정리를 만족하는 원자 오비탈 \(\phi\)의 조합

$$\psi_k(x) = \frac{1}{\sqrt N}\sum_n e^{ikna}\,\phi(x - na) \qquad\Rightarrow\qquad E(k) = E_0 - 2t\cos ka$$
띠 폭 \(W = 4t\). 바닥(\(k = 0\))은 모든 오비탈이 같은 위상인 결합 상태, 꼭대기(\(k = \pi/a\))는 이웃끼리 부호가 엇갈리는 반결합 상태다(11장의 σ, σ* 오비탈).

원자 사이 겹침이 작은 깊은 내각 준위는 \(t\)가 작아 거의 평평한 좁은 띠가 되고, 겹침이 큰 바깥 껍질 준위는 수 eV 폭의 넓은 띠가 된다. 서로 다른 원자 준위에서 나온 띠들 사이의 빈 공간이 띠 간격이다. 실리콘에서는 sp³ 결합 오비탈들이 가전자대, 반결합 오비탈들이 전도대를 이루고, 둘 사이가 1.12 eV의 띠 간격이다.

거의 자유 전자 (위에서 내려옴)

자유 전자 포물선에서 출발. 약한 주기 퍼텐셜이 영역 경계에서 간격 \(2|V_G|\)를 연다. 넓은 띠, 가벼운 유효 질량 — 금속의 s·p 전자, 반도체 전도대.

고립 원자 준위에서 출발. 이웃 겹침 \(t\)가 준위를 폭 \(4t\)의 띠로 넓힌다. 좁은 띠, 무거운 유효 질량 — 전이 금속의 d 전자, 절연체의 가전자대.

풀이 보기
전략 바닥 근처에서 \(\cos ka \approx 1 - (ka)^2/2\) → \(E \approx E_0 - 2t + t a^2k^2\). 이것을 \(\hbar^2k^2/2m^*\)과 비교한다.

띠 채움: 금속·반도체·절연체

띠 구조를 알았으니 전자를 채우자. 앞 절에서 띠 하나에는 기본 단위 세포 수 \(N\)만큼의 \(k\) 상태, 스핀까지 \(2N\)개의 자리가 있다고 했다. 기본 단위 세포마다 전자가 \(Z_c\)개 있다면 바닥부터 파울리 원리대로 채워 \(Z_c/2\)개의 띠가 찬다. 마지막으로 채워진 준위가 페르미 준위 \(E_F\)이고(10장), 그 위치가 고체의 성격을 정한다.

  • 페르미 준위가 띠 한가운데: 바로 위에 빈 상태가 무수히 있어, 아주 약한 전기장으로도 전자 분포가 \(k\) 공간에서 한쪽으로 쏠린다 → 전류 → 금속(metal). 셀당 전자 수가 홀수이면 반드시 이렇다.
  • 띠가 꽉 차고 위 띠와 사이에 간격: 꽉 찬 띠는 \(+k\)와 \(-k\) 상태가 짝지어 모두 차 있어 전류를 나르지 못한다(뒤의 정공 절). 간격이 작으면(대략 \(E_g \lesssim 3\)–4 eV) 상온에서 일부 전자가 열로 올라가는 반도체(semiconductor), 크면 절연체(insulator).
  • 짝수 전자인데 띠가 겹침: 위·아래 띠가 에너지에서 겹치면 둘 다 일부만 차서 금속이 된다(Mg, Ca 같은 2족 금속).

유효 질량, 군속도, 정공

이제 결정 속 전자를 움직여 보자. 전자는 블로흐 파들을 겹친 파속이고, 파속은 군속도로 움직인다(2장). 결정 속 전자의 군속도는 분산 관계의 기울기다.

$$v_g = \frac{d\omega}{dk} = \frac{1}{\hbar}\frac{dE}{dk}$$
자유 전자라면 \(E = \hbar^2k^2/2m\) → \(v = \hbar k/m\). 띠의 바닥·꼭대기·영역 경계에서는 \(dE/dk = 0\)이라 전자가 멈춰 있다(정상파).

준고전 운동 방정식

외부 전기장 \(\mathcal{E}\)(이 책에서는 \(F\)로 쓴다)가 전자에 힘 \(-qF\)를 주면, 시간 \(dt\) 동안 한 일 \((-qF)v_g\,dt\)가 전자의 띠 에너지 변화 \(dE = (dE/dk)\,dk\)가 된다. \(v_g = \hbar^{-1}dE/dk\)를 넣고 정리하면

$$\hbar\frac{dk}{dt} = -qF \qquad (\text{외력만 들어간다: 격자의 힘은 } E(k) \text{ 안에 이미 있다})$$
결정 운동량 \(\hbar k\)는 뉴턴 법칙의 운동량처럼 외력에만 반응한다. 이온들이 주는 엄청난 주기 힘은 띠 구조에 다 흡수되어 있다.

가속도는 \(\dfrac{dv_g}{dt} = \dfrac{1}{\hbar}\dfrac{d^2E}{dk^2}\dfrac{dk}{dt} = \dfrac{1}{\hbar^2}\dfrac{d^2E}{dk^2}(-qF)\)이다. 이것을 \(a = F_\text{ext}/m\)과 비교하면 결정 속 전자는 다음 질량을 가진 입자처럼 행동한다.

유효 질량

$$m^* = \frac{\hbar^2}{d^2E/dk^2}, \qquad \text{띠 바닥 근처: } E(k) \approx E_c + \frac{\hbar^2(k-k_0)^2}{2m^*}$$

유효 질량(effective mass)은 곡률이 크면(뾰족한 띠) 가볍고, 평평한 띠에서는 무겁다. 띠 꼭대기 근처에서는 곡률이 음수라 \(m^* < 0\)이다.

띠 꼭대기 바로 아래(\(k\)가 영역 경계 근처)에 있는 전자에 오른쪽으로 힘을 준다. 전자의 속도는 어떻게 변할까?

\(\hbar\,dk/dt = F_\text{ext}\)이므로 \(k\)는 오른쪽으로 늘어나지만, 꼭대기 근처에서는 \(k\)가 늘수록 기울기 \(dE/dk\)가 줄어든다. 속도가 힘과 반대로 변한다 — 영역 경계로 다가가는 파동이 브래그 반사로 되튀는 것이다. 아래에서 점을 꼭대기 근처로 끌어 \(m^*\)의 부호를 확인하라.

블로흐 진동

산란이 전혀 없다면 일정한 전기장 속 전자의 \(k\)는 \(k(t) = k_0 - qFt/\hbar\)로 영역을 가로질러 경계에 닿고, \(k\)와 \(k + 2\pi/a\)가 같은 상태이므로 반대편 경계에서 다시 나타난다. 속도 \(\hbar^{-1}dE/dk\)는 부호를 바꾸며 진동하고, 전자는 직류 전기장 속에서 제자리를 왕복한다. 주기는 \(k\)가 \(2\pi/a\)만큼 변하는 시간이다.

$$T_B = \frac{2\pi\hbar}{qFa} = \frac{h}{qFa}, \qquad \text{진폭 } \frac{W}{qF}$$

이 블로흐 진동(Bloch oscillation)은 1992년 반도체 초격자에서 처음 관측되었다. 보통 결정에서는 아래 예제처럼 한 주기가 지나기 훨씬 전에 전자가 산란되어 볼 수 없다.

정공: 꽉 찬 띠에서 하나가 빠지면

꽉 찬 띠는 전류를 나르지 못한다. \(E(k) = E(-k)\)이므로 \(v(-k) = -v(k)\)이고, 모든 \(k\)가 차 있으면 속도의 합이 0이다. 전기장이 모든 전자의 \(k\)를 똑같이 밀어도 꽉 찬 띠는 꽉 찬 채로 남는다. 이제 전자 하나를 \(k_e\)에서 빼내자.

정공

거의 꽉 찬 띠의 빈 상태 \(k_e\)는 다음 성질을 가진 입자처럼 행동한다: 전하 \(+q\), 파수 \(k_h = -k_e\), 에너지 \(E_h = -E_e\)(아래로 갈수록 정공 에너지가 크다), 속도 \(v_h = v_e(k_e)\), 유효 질량 \(m_h^* = -m_e^*(k_e) > 0\). 운동 방정식은 \(\hbar\,dk_h/dt = +qF\) — 양전하 입자의 뉴턴 법칙이다.

실제 반도체의 띠 구조

3차원 결정에서 \(k\)는 벡터가 되고 브릴루앙 영역은 다면체다. FCC 격자(Si, Ge, GaAs)의 영역은 깎은 팔면체이고, 중심을 \(\Gamma\), [100] 방향 경계를 \(X\)(\(|k| = 2\pi/a\)), [111] 방향 경계를 \(L\)이라 부른다. 띠 구조도는 \(E(\vec k)\)를 이 대칭점들을 잇는 선 위에서 그린 것이다. 1차원 모형에서 배운 것 — 영역 경계의 간격, 곡률이 정하는 유효 질량, 꼭대기의 정공 — 이 그대로 적용된다.

실리콘의 전도대: 6개의 Δ 계곡

실리콘 전도대의 가장 낮은 점은 \(\Gamma\)가 아니라 \(\Gamma\)에서 \(X\)로 가는 Δ 선 위, \(X\)까지의 85% 지점(\(k_0 \approx 0.85\times2\pi/a\))에 있다. 입방 대칭 때문에 \(\pm k_x, \pm k_y, \pm k_z\) 여섯 방향에 똑같은 바닥이 있어 계곡(valley)이 6개다. 각 계곡 근처의 에너지는 축 방향과 수직 방향의 곡률이 달라

$$E(\vec k) = E_c + \frac{\hbar^2}{2}\left[\frac{(k_l - k_0)^2}{m_l} + \frac{k_{t1}^2 + k_{t2}^2}{m_t}\right], \qquad m_l = 0.98\,m_e,\ m_t = 0.19\,m_e$$
\(m_l\): 세로(longitudinal) 질량, \(m_t\): 가로(transverse) 질량. 등에너지면은 계곡 축 방향으로 길쭉한 회전 타원체다(반축 \(\propto\sqrt{m}\)).

방향마다 질량이 다르면 "전자의 질량"을 한 숫자로 쓸 수 없다. 용도에 따라 두 가지 평균을 쓴다. 상태 밀도(10장의 \(N_c\))에는 계곡 수까지 넣은 상태 밀도 유효 질량(density-of-states effective mass), 전류(이동도)에는 세 방향 \(1/m\)의 평균인 전도도 유효 질량(conductivity effective mass)을 쓴다.

$$m_{dn} = g_v^{2/3}\,(m_l m_t^2)^{1/3} = 1.08\,m_e \ (g_v = 6), \qquad \frac{1}{m_c} = \frac13\left(\frac{1}{m_l} + \frac{2}{m_t}\right) \Rightarrow m_c = 0.26\,m_e$$

가전자대 꼭대기는 \(\Gamma\)에 있고 세 띠가 모인다. p 오비탈에서 나온 띠라서 곡률이 서로 다르다: 무거운 정공(heavy hole) \(m_{hh} \approx 0.49\,m_e\), 가벼운 정공(light hole) \(m_{lh} \approx 0.16\,m_e\), 그리고 0.044 eV 아래의 갈라진 띠(split-off). 정공 상태 밀도 질량은 \(m_{dp} = (m_{hh}^{3/2} + m_{lh}^{3/2})^{2/3}\)이다.

직접 띠 간격과 간접 띠 간격

GaAs는 전도대 바닥과 가전자대 꼭대기가 모두 \(\Gamma\)(\(k = 0\))에 있는 직접 띠 간격(direct band gap) 반도체이고, Si와 Ge는 둘의 \(k\)가 다른 간접 띠 간격(indirect band gap) 반도체다. 이 차이가 결정적인 이유는 운동량 보존이다. 띠 간격 크기의 광자가 가진 파수 \(2\pi/\lambda \approx 2\pi/1000\ \text{nm}\)는 영역 크기 \(2\pi/a \approx 2\pi/0.5\ \text{nm}\)의 1/2000밖에 안 된다. 광자를 흡수하거나 내는 전이는 \(k\)가 거의 변하지 않는 수직 전이뿐이다. 간접 간격을 건너려면 결정 운동량 \(\Delta k\)를 격자 진동(포논, 7장)이 대신 내줘야 하는 3체 과정이 되어 확률이 크게 떨어진다.

핵심 정리

  1. 결정의 퍼텐셜은 주기 함수 \(V(x+a) = V(x)\)이고, 그 고유 상태는 블로흐 함수 \(\psi_{nk} = u_{nk}(x)e^{ikx}\)이다. \(k\)와 \(k + 2\pi/a\)는 같은 상태이므로 제1 브릴루앙 영역 \(-\pi/a < k \le \pi/a\)만 보면 된다. 띠 하나에는 스핀 포함 \(2N\)개의 자리가 있다.
  2. 크로니히–페니 모형의 분산 관계 \(\cos kd = f(E)\)에서 \(|f| \le 1\)인 에너지만 허용된다. 장벽이 0이면 자유 전자, 장벽이 클수록 띠 간격은 넓어지고 띠는 좁아진다.
  3. 띠 간격은 영역 경계 \(k = n\pi/a\)의 브래그 반사로 생긴다. 두 정상파가 퍼텐셜을 다르게 느껴 \(E_g = 2|V_G|\)가 된다. 강결합 그림에서는 원자 준위가 폭 \(4t\)의 띠 \(E_0 - 2t\cos ka\)로 넓어진다.
  4. 셀당 전자 수와 띠 구조가 금속(띠 일부만 참, 또는 띠 겹침)·반도체(작은 \(E_g\))·절연체(큰 \(E_g\))를 가른다. Si는 셀당 8개 → 가전자대 4개가 꽉 차고 \(E_g = 1.12\) eV.
  5. 군속도 \(v_g = \hbar^{-1}dE/dk\), 준고전 운동 \(\hbar\,dk/dt = -qF\), 유효 질량 \(m^* = \hbar^2/(d^2E/dk^2)\). 띠 꼭대기에서는 \(m^* < 0\)이고, 산란이 없으면 블로흐 진동(\(T_B = h/qFa\))이 일어난다.
  6. 거의 꽉 찬 띠의 빈 상태는 전하 \(+q\), 양의 질량 \(m_h^* = -m_e^*\)인 정공처럼 움직인다.
  7. Si 전도대 바닥은 \(0.85X\)의 6개 Δ 계곡(\(m_l = 0.98\), \(m_t = 0.19\), \(m_{dn} = 1.08\), \(m_c = 0.26\,m_e\))이고, 가전자대는 \(\Gamma\)의 무거운·가벼운 정공 띠다. Si·Ge는 간접, GaAs는 직접 띠 간격이며, 간격은 온도가 오르면 줄어든다(\(E_g^{\text{Si}}(300\ \text{K}) = 1.12\) eV).

연습문제

\(\hbar^2/2m_e = 0.0381\) eV·nm², \(\hbar = 6.582\times10^{-16}\) eV·s, \(h = 4.136\times10^{-15}\) eV·s, \(hc = 1239.8\) eV·nm, \(m_e = 9.109\times10^{-31}\) kg. 답이 ±1% 이내면 정답이다.

저마늄은 실리콘과 같은 다이아몬드 구조이고 격자 상수가 0.5658 nm이다. 원자 밀도는?

단위 세포에 원자 8개. \(a^3 = (0.5658\times10^{-7})^3 = 1.811\times10^{-22}\) cm³ → \(n = 8/a^3 = 4.42\times10^{22}\) cm⁻³.

GaAs의 격자 상수 0.5653 nm를 주기로 하는 1차원 사슬의 제1 브릴루앙 영역 경계 \(\pi/a\)는?

\(\pi/0.5653 = 5.56\) nm⁻¹.

주기 \(a\)인 퍼텐셜 속 블로흐 상태 \(\psi_k\)에 대해 옳은 것은?

블로흐 상태는 한 셀 옮길 때 위상 \(e^{ika}\)만 바뀐다(\(|\psi|^2\)는 주기적). \(\psi\) 자체가 주기적인 것은 \(k = 0\)일 때뿐이다. \(\hbar k\)는 결정 운동량이다.

델타 함수 극한의 크로니히–페니 모형 \(f(E) = \cos\alpha d + P\sin(\alpha d)/(\alpha d)\)에서 \(P = 3.0\)이다. \(\alpha d = \pi/2\)인 에너지에서 \(f\)의 값은? 이 에너지는 허용되는가?

\(f = \cos(\pi/2) + 3.0\times1/(\pi/2) = 0 + 1.91 = 1.91\). \(|f| > 1\)이므로 금지(띠 간격 안). \(P = 3\)이면 첫 허용 띠가 \(\alpha d \approx 2.2\)–\(\pi\) 사이로 밀려 올라간다.

격자 상수 0.300 nm인 1차원 결정에서 \(k = \pi/a\)인 자유 전자의 에너지는?

\(E = 0.0381\times(\pi/0.300)^2 = 0.0381\times109.7 = 4.18\) eV.

호핑 \(t = 0.80\) eV, 격자 상수 \(a = 0.40\) nm인 1차원 강결합 띠의 폭과 띠 바닥의 유효 질량은?

바닥 근처 \(E \approx E_0 - 2t + ta^2k^2\).

\(W = 4t = 3.20\) eV. \(m^*/m_e = 0.0381/(ta^2) = 0.0381/(0.80\times0.16) = 0.298\).

바르시니 식(Si: \(E_g(0) = 1.170\) eV, \(\alpha = 4.73\times10^{-4}\) eV/K, \(\beta = 636\) K)으로 400 K(전력 소자 동작 온도)에서 실리콘의 띠 간격을 구하라.

\(E_g = 1.170 - (4.73\times10^{-4})(400)^2/(400 + 636) = 1.170 - 75.68/1036 = 1.170 - 0.0731 = 1.097\) eV ≈ 1.10 eV. 300 K보다 28 meV 작아 \(n_i\)가 크게 늘어난다.

어떤 반도체의 전도대 바닥을 측정했더니 \(E - E_c = (0.147\ \text{eV·nm}^2)\,k^2\)이었다. 유효 질량은 자유 전자 질량의 몇 배인가?

\(\hbar^2/2m^* = 0.147\) → \(m^*/m_e = 0.0381/0.147 = 0.259\). 실리콘 전도도 유효 질량과 비슷하다.

\(E(k) = E_0 - 2t\cos ka\), \(t = 1.0\) eV, \(a = 0.30\) nm인 띠에서 \(ka = \pi/2\)인 전자의 군속도는?

\(v = \hbar^{-1}dE/dk = 2ta\sin(ka)/\hbar = 2(1.0)(0.30\times10^{-9})/(6.582\times10^{-16}) = 9.12\times10^5\) m/s. 이 띠에서 가장 빠른 전자다.

GaAs/AlGaAs 초격자의 주기가 \(d = 10.0\) nm이다. 전기장 \(F = 10\) kV/cm에서 블로흐 진동 주기는? 결정 격자 상수(0.565 nm)를 주기로 쓸 때보다 몇 배 짧은지도 생각해 보라.

\(T_B = h/(qFd)\), \(qFd\)를 eV로.

\(qFd = 10^6\ \text{V/m}\times10^{-8}\ \text{m} = 10^{-2}\) eV. \(T_B = 4.136\times10^{-15}/10^{-2} = 4.14\times10^{-13}\) s = 0.414 ps. 주기가 약 18배 길어 \(T_B\)가 18배 짧아졌고, 운동량 완화 시간(~ps)과 비슷해져 관측이 가능하다.

GaAs의 기본 단위 세포에는 Ga 원자 1개와 As 원자 1개가 있다. 원자가 전자(Ga 4s²4p¹, As 4s²4p³)로 채우면 꽉 차는 띠는 몇 개인가?

셀당 전자 3 + 5 = 8개, 띠 하나에 셀당 2개 → 띠 4개가 꽉 찬다. 실리콘(4 + 4)과 같은 전자 수라서 같은 꼴의 가전자대를 가진다(등전자 계열).

기본 단위 세포에 원자가 하나인 결정 가운데, 띠 구조를 몰라도 반드시 금속이라고 말할 수 있는 것은?

셀당 전자가 홀수(1개)이면 띠 하나가 반만 차 페르미 준위가 띠 안에 있다 → 금속. 짝수이면 띠 겹침 여부에 따라 다르다(Mg는 겹쳐서 금속이지만 띠 구조를 알아야 판단할 수 있다).

Si(\(a = 0.5431\) nm)의 간접 전이에서 포논이 공급해야 하는 결정 운동량 \(\Delta k\)(Γ → 0.85X)와, \(E_g = 1.12\) eV 광자의 파수와 \(\Delta k\)의 비를 구하라.

\(\Delta k = 0.85\times2\pi/0.5431 = 9.83\) nm⁻¹. \(k_\text{ph} = 2\pi\times1.12/1239.8 = 5.68\times10^{-3}\) nm⁻¹ → 비 \(5.77\times10^{-4}\).

실리콘 가전자대의 무거운 정공 \(m_{hh} = 0.49\,m_e\), 가벼운 정공 \(m_{lh} = 0.16\,m_e\)이 \(\Gamma\)에서 겹쳐 있다. 두 띠의 상태 밀도를 더한 정공 상태 밀도 유효 질량 \(m_{dp} = (m_{hh}^{3/2} + m_{lh}^{3/2})^{2/3}\)은?

3차원 상태 밀도는 \(m^{3/2}\)에 비례하므로 두 띠의 상태 밀도를 더하면 \(m^{3/2}\)끼리 더해진다.

\(0.49^{1.5} = 0.343\), \(0.16^{1.5} = 0.064\) → 합 0.407 → \(0.407^{2/3} = 0.549\). 무거운 정공이 상태 밀도의 84%를 차지한다. (교재 값 0.81은 온도 효과와 비포물선성을 넣은 값이다.)

실리콘 전도대 계곡의 \(m_l = 0.98\,m_e\), \(m_t = 0.19\,m_e\), 계곡 수 6이다. 상태 밀도 유효 질량 \(m_{dn}\)과 전도도 유효 질량 \(m_c\)를 구하라.

\(m_{dn} = 6^{2/3}(0.98\times0.19^2)^{1/3} = 3.302\times0.3283 = 1.08\,m_e\). \(1/m_c = (1/0.98 + 2/0.19)/3 = (1.020 + 10.53)/3 = 3.849\) → \(m_c = 0.260\,m_e\). 상태 밀도는 무거운 \(m_l\)과 계곡 수 때문에 크고, 전류는 가벼운 \(m_t\)가 주도한다.

개념 확인 퀴즈

주기 \(a\)인 결정에서 파수 \(k\)인 블로흐 상태와 \(k + 2\pi/a\)인 블로흐 상태(같은 띠)는?

\(e^{i(k+G)a} = e^{ika}\)이고 \(u\)를 다시 정의하면 같은 함수다. 그래서 제1 브릴루앙 영역만 보면 된다.

1차원 결정에서 띠 간격은 어떤 파수에서 열리는가?

\(\lambda = 2a/n\)인 파동은 모든 원자에서 같은 위상으로 반사되어 정상파가 되고, 두 정상파의 에너지 차가 간격이다.

기본 단위 세포당 전자 수가 홀수인 결정(띠 겹침과 상관관계 효과 무시)은?

띠 하나는 셀당 2개를 담으므로, 홀수 전자면 마지막 띠가 반만 찬다.

띠 꼭대기 근처 전자의 유효 질량이 음수라는 말의 의미는?

\(dv/dt = F_\text{ext}/m^*\)에서 \(m^* < 0\). 영역 경계로 다가가며 브래그 반사되는 효과가 질량에 담긴 것이다. 그런 빈 상태를 정공으로 보면 질량은 양수가 된다.

실리콘으로 효율 좋은 LED를 만들기 어려운 근본 이유는?

전도대 바닥(0.85X)과 가전자대 꼭대기(Γ)의 \(k\)가 달라, 광자만으로는 운동량을 맞출 수 없다. 흡수는 포논 도움으로 일어나 Si 광검출기는 잘 작동한다.
