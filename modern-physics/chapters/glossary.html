용어집과 종합 문제

1–13장 본문에서 처음 정의한 용어를 모았다. 설명은 본문의 정의를 한두 문장으로 정리한 것이며, 링크를 누르면 그 용어가 처음 나온 절로 이동한다. 뒤의 종합 문제는 장마다 계산 문제를 2–3개씩 내고, 상당수는 EUV 노광, 전자 현미경, 나노시트 채널, 게이트 절연막, 도핑, LED처럼 반도체 현장의 숫자로 묻는다. ‘종합’ 표시가 붙은 문제는 여러 장의 도구를 함께 써야 풀린다. 마지막에는 각 장의 개념 퀴즈를 무작위로 섞어 낸다. 상수는 CODATA 2018 값, \(hc = 1239.84\ \text{eV}\cdot\text{nm}\), \(\hbar^2/2m_e = 0.0381\ \text{eV}\cdot\text{nm}^2\), 300 K에서 \(kT = 25.85\ \text{meV}\)를 쓴다.

MRAM 셀의 두 강자성 전극의 스핀 분극률이 모두 \(P = 0.60\)이다. 줄리에르 모형의 TMR과, 평행 저항이 2.00 kΩ일 때의 반평행 저항은?

\(\text{TMR} = 2P_1P_2/(1 - P_1P_2)\), \(R_{AP} = R_P(1 + \text{TMR})\).

\(\text{TMR} = 2(0.36)/(1 - 0.36) = 1.125 = 113\%\). \(R_{AP} = 2.00(2.125) = 4.25\ \text{k}\Omega\).

10장 양자 통계본문 →

실리콘 칩의 온도가 300 K에서 400 K로 오른다. \(n_i \propto T^{3/2}e^{-E_g/2kT}\)이고 띠 간격이 \(E_g(T) = 1.17 - 4.73\times10^{-4}T^2/(T + 636)\ \text{eV}\)를 따를 때, 진성 캐리어 농도는 몇 배가 되는가?

\(E_g(300) = 1.1245\ \text{eV}\), \(E_g(400) = 1.0969\ \text{eV}\). \(k = 8.617\times10^{-5}\ \text{eV/K}\).

\((400/300)^{3/2} = 1.540\). 지수: \(\dfrac{1.1245}{2k(300)} - \dfrac{1.0969}{2k(400)} = 21.750 - 15.912 = 5.838\) → \(e^{5.838} = 343\). 곱하면 \(1.540\times343 = 528\)배. 확산 누설(\(\propto n_i^2\))은 28만 배가 된다.

배선 금속 구리의 자유 전자 밀도는 \(8.47\times10^{28}\ \text{m}^{-3}\)이다. 자유 전자 모형의 페르미 에너지는?

\(E_F = \dfrac{\hbar^2}{2m}(3\pi^2n)^{2/3}\).

\((3\pi^2n)^{1/3} = 1.359\times10^{10}\ \text{m}^{-1} = 13.59\ \text{nm}^{-1}\), \(E_F = 0.0381(13.59)^2 = 7.03\ \text{eV}\) — \(kT\)의 270배이므로 상온에서도 전자 기체는 깊이 축퇴되어 있다.

300 K에서 페르미 준위보다 0.10 eV 위에 있는 상태가 전자로 채워져 있을 확률은?

\(f = 1/(e^{0.10/0.02585} + 1) = 1/(47.9 + 1) = 0.0205\). 볼츠만 근사 \(e^{-3.87} = 0.0209\)와 2% 차이다.

11장 분자와 화학 결합본문 →

실리콘은 격자 상수 \(a = 0.5431\ \text{nm}\)의 다이아몬드 구조로, 각 원자가 sp³ 혼성 오비탈로 이웃 넷과 결합한다. Si–Si 결합 길이와 원자 밀도를 구하라.

최근접 이웃은 입방체 대각선의 1/4만큼 떨어져 있다: \(d = \sqrt3a/4\). 단위 입방 세포에 원자 8개.

\(d = \sqrt3(0.5431)/4 = 0.235\ \text{nm}\). \(n = 8/(0.5431\times10^{-7}\ \text{cm})^3 = 4.99\times10^{22}\ \text{cm}^{-3}\) ≈ \(5\times10^{22}\) — 도핑 \(10^{16}\ \text{cm}^{-3}\)은 원자 500만 개에 하나다.

같은 원자 4개가 일렬로 놓이고 이웃끼리만 결합한다(이웃 결합 적분 \(|t| = 2.0\ \text{eV}\)). 강결합 근사의 준위는 \(E_j = \varepsilon - 2|t|\cos\dfrac{j\pi}{N+1}\) (\(j = 1,\dots,N\))이다. 가장 낮은 준위와 가장 높은 준위의 간격은? 원자 수가 아주 많아지면 이 폭은 얼마로 가는가?

\(N = 4\): \(\cos(\pi/5) = 0.809\), \(\cos(4\pi/5) = -0.809\) → 간격 \(4|t|(0.809) = 6.47\ \text{eV}\). \(N \to \infty\)이면 \(\cos\)가 ±1에 가까워져 띠 폭 \(4|t| = 8.0\ \text{eV}\)로 수렴한다 — 준위가 늘어도 폭은 결합 세기가 정한다.

12장 결정 속 전자와 에너지 띠본문 →

어떤 직접 띠 간격 반도체의 전도대 바닥 근처에서 \(k = 0.50\ \text{nm}^{-1}\)인 상태의 에너지가 띠 가장자리보다 0.100 eV 높다. 포물선 띠 \(E = \hbar^2k^2/2m^*\)로 보고 유효 질량을 구하라.

\(m^*/m_e = (0.0381\ \text{eV}\cdot\text{nm}^2)\,k^2/E\).

\(m^*/m_e = 0.0381(0.25)/0.100 = 0.0952\). 곡률이 클수록(띠가 가파를수록) 유효 질량이 작다. InP(0.08)·GaAs(0.067)와 같은 가벼운 전자다.

격자 상수 0.50 nm의 1차원 결정에서 첫 브릴루앙 영역 경계의 파수와, 그 파수를 가진 자유 전자의 에너지는? (이 에너지 근처에서 띠 간격이 열린다.)

경계: \(k = \pi/a\) — 브래그 조건 \(2a = \lambda\).

\(k = \pi/0.50 = 6.28\ \text{nm}^{-1}\). \(E = 0.0381(6.283)^2 = 1.50\ \text{eV}\). 주기 퍼텐셜의 푸리에 성분 \(U\)가 있으면 이 점에서 에너지가 \(1.50 \pm U\)로 갈라진다.

13장 빛과 물질의 상호작용본문 →

띠 간격 근처에서 발광한다고 할 때 GaAs(\(E_g = 1.42\ \text{eV}\))와 GaN(\(E_g = 3.4\ \text{eV}\)) LED의 발광 파장은?

\(\lambda\,[\text{nm}] = 1239.84/E_g\,[\text{eV}]\).

GaAs: \(1239.84/1.42 = 873\ \text{nm}\) (근적외선). GaN: \(1239.84/3.4 = 365\ \text{nm}\) (근자외선). 청색 LED는 GaN에 In을 섞어 띠 간격을 2.7 eV 근처로 줄인 InGaN 우물을 쓴다.

850 nm 광통신용 실리콘 포토다이오드의 외부 양자 효율이 0.80이다. 응답도(빛 1 W당 광전류)는?

\(R = \eta\,e/h\nu = \eta\,\lambda[\text{nm}]/1239.84\ \text{A/W}\).

\(R = 0.80(850)/1239.84 = 0.548\ \text{A/W}\). 광자 하나의 에너지가 1.46 eV이므로 1 W는 초당 \(4.28\times10^{18}\)개의 광자이고, 그 80%가 전자 하나씩을 회로로 보낸다.

녹색광(약 550 nm)에 대한 실리콘의 흡수 계수를 \(\alpha = 1.0\times10^4\ \text{cm}^{-1}\)로 잡는다. 표면 반사를 무시할 때 입사광의 90%를 흡수하려면 이미지 센서 포토다이오드는 얼마나 깊어야 하는가?

비어–람베르트: \(I(x) = I_0e^{-\alpha x}\). 남는 빛 10%.

\(e^{-\alpha d} = 0.1\) → \(d = \ln10/\alpha = 2.303/(1.0\times10^4\ \text{cm}^{-1}) = 2.30\times10^{-4}\ \text{cm} = 2.30\ \mu\text{m}\). 간접 띠 간격이라 흡수가 약한 적색·근적외선은 훨씬 깊은 포토다이오드가 필요하다.
