Chapter 05

양자 우물과 구속

전자를 좁은 공간에 가두면 에너지가 띄엄띄엄한 값만 허용된다. 가둔 폭이 좁을수록 준위 사이가 벌어지고, 그 간격이 열에너지 \(k_BT \approx 26\) meV를 넘는 순간 구속은 소자 특성에 그대로 드러난다 — 두께 5 nm의 나노시트 채널, 1 nm 두께의 반전층, 지름 몇 nm의 양자점이 모두 그렇다. 아래 우물에서는 두 정상 상태가 겹친 전자가 좌우로 출렁인다. 오른쪽 벽을 끌어 우물을 넓혀 보자.

오른쪽 벽(흰 원)을 끌어 폭을 바꾸고, 빈 곳을 누르면 겹친 상태가 바뀐다
  • 무한 사각 우물의 \(E_n = n^2\pi^2\hbar^2/2mL^2\)과 \(\psi_n\)을 유도하고, 마디 수·기댓값·직교성을 계산한다.
  • 유한 사각 우물의 짝·홀 상태를 그래프 풀이로 구하고, 속박 상태 수와 장벽 속 침투 깊이를 어림한다.
  • 유효 질량과 띠 오프셋으로 GaAs/AlGaAs 양자 우물과 실리콘 나노시트의 구속 에너지를 계산한다.
  • 삼각 우물의 에어리 해로 MOSFET 반전층의 준위와 두께를 구하고, 전기적 산화막 두께가 늘어나는 이유를 설명한다.
  • 2·3차원 상자의 준위와 축퇴를 세고, 양자점의 크기가 발광색을 정하는 원리를 설명한다.

무한 사각 우물

가장 단순한 구속은 폭 \(L\)인 상자 속 입자다. 상자 안(\(0 < x < L\))에서는 퍼텐셜이 0이고 벽은 무한히 높아 입자가 절대 넘어가지 못한다. 이것을 무한 사각 우물(infinite square well)이라 부른다. 벽 밖에서 \(\psi = 0\)이고 파동함수는 연속이어야 하므로 \(\psi(0) = \psi(L) = 0\)이 경계 조건이 된다. 4장의 시간 독립 슈뢰딩거 방정식은 상자 안에서

$$-\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} = E\psi \quad\Rightarrow\quad \psi = A\sin kx + B\cos kx,\qquad k = \frac{\sqrt{2mE}}{\hbar}$$
\(\psi(0) = 0\)에서 \(B = 0\), \(\psi(L) = 0\)에서 \(\sin kL = 0\) → \(kL = n\pi\) (\(n = 1, 2, 3, \dots\)). \(n = 0\)은 \(\psi \equiv 0\)이라 입자가 없는 것과 같으므로 제외한다.

\(k_n = n\pi/L\)을 \(E = \hbar^2k^2/2m\)에 넣고, \(\int_0^L|\psi|^2dx = 1\)로 \(A = \sqrt{2/L}\)을 정하면

$$E_n = \frac{n^2\pi^2\hbar^2}{2mL^2} = n^2\,\frac{0.376\ \text{eV}}{(m/m_e)\,(L/\text{nm})^2},\qquad \psi_n(x) = \sqrt{\frac{2}{L}}\sin\frac{n\pi x}{L}$$
유용한 조합 \(\hbar^2/2m_e = 0.0381\) eV·nm², \(\pi^2\hbar^2/2m_e = 0.376\) eV·nm². 에너지는 \(n^2\)에 비례하고 \(1/L^2\), \(1/m\)에 비례한다. 바닥 상태도 \(E_1 > 0\)이다 — 이것이 영점 에너지(zero-point energy)로, 불확정성 원리 \(\Delta x \lesssim L\) → \(\Delta p \gtrsim \hbar/L\)의 결과다.

질량 1.00인 입자를 폭 1.0의 무한 우물에 가두면 \(E_1\) = , \(E_2\) = 이다. 2 → 1 전이로 나오는 광자의 파장은 이고, 준위 간격은 실온 열에너지의 배다.

우물 폭 \(L\)을 두 배로 넓히면 바닥 상태 에너지 \(E_1\)은 어떻게 될까?

\(E_n \propto 1/L^2\)이다. 아래에서 벽을 끌어 \(L\)을 2 nm에서 4 nm로 바꾸고 오른쪽 사다리의 \(E_1\)을 읽어 보라. 파장이 두 배가 되면 운동량이 절반, 운동 에너지는 1/4이 된다.

기댓값과 직교성

\(|\psi_n|^2\)은 좌우 대칭이므로 \(\langle x\rangle = L/2\)이고, 적분하면 \(\langle x^2\rangle = L^2\left(\tfrac13 - \tfrac{1}{2n^2\pi^2}\right)\)이다. 운동량은 \(+\hbar k_n\)과 \(-\hbar k_n\)인 두 진행파의 겹침이라 \(\langle p\rangle = 0\), \(\langle p^2\rangle = (n\pi\hbar/L)^2 = 2mE_n\)이다.

$$\Delta x = L\sqrt{\frac{1}{12} - \frac{1}{2n^2\pi^2}},\qquad \Delta p = \frac{n\pi\hbar}{L},\qquad \Delta x\,\Delta p = \frac{\hbar}{2}\sqrt{\frac{n^2\pi^2}{3} - 2} \;\ge\; 0.568\,\hbar$$
바닥 상태에서도 \(\hbar/2\)보다 크다 — 불확정성 원리를 만족한다.

서로 다른 상태는 직교(orthogonal)한다: \(\int_0^L\psi_m\psi_n\,dx = \delta_{mn}\). 이는 에르미트 연산자(해밀토니안)의 서로 다른 고유값에 속한 고유함수가 늘 갖는 성질이며, 임의의 파동함수를 \(\Psi = \sum c_n\psi_n\)으로 전개하고 \(|c_n|^2\)을 "\(E_n\)을 측정할 확률"로 읽을 수 있게 해 준다. 머리 그림의 출렁임이 바로 \(c_1 = c_2 = 1/\sqrt2\)인 겹침이며, 주기는 \(T = h/(E_2 - E_1)\)이다.

폭 1.00 nm인 무한 우물에 자유 전자가 있다. \(E_1, E_2, E_3\)과, \(n = 2 \to 1\) 전이에서 나오는 광자의 파장을 구하라.

유한 사각 우물

실제 벽은 무한히 높지 않다. GaAs 양자 우물의 장벽은 0.2–0.3 eV, Si/SiO₂ 계면의 장벽은 3.1 eV다. 깊이 \(V_0\), 폭 \(L\)인 유한 사각 우물(finite square well)을 우물 가운데를 원점으로 놓고 풀자(\(|x| < L/2\)에서 \(V = 0\), 밖에서 \(V = V_0\)). 속박 상태(\(0 < E < V_0\))에서 장벽 속은 고전적으로 금지된 영역이라 해가 진동하지 않고 지수적으로 줄어든다.

$$|x| < \tfrac L2:\ \psi'' = -k^2\psi,\quad k = \frac{\sqrt{2mE}}{\hbar}; \qquad |x| > \tfrac L2:\ \psi'' = \kappa^2\psi,\quad \kappa = \frac{\sqrt{2m(V_0 - E)}}{\hbar}$$
밖의 해는 \(e^{-\kappa|x|}\)(무한대에서 발산하는 \(e^{+\kappa|x|}\)은 버린다). 퍼텐셜이 좌우 대칭이므로 해는 짝 상태(even) \(\cos kx\) 또는 홀 상태(odd) \(\sin kx\)로 나뉜다.

경계 \(x = L/2\)에서 \(\psi\)와 \(\psi'\)이 연속이어야 한다. 두 조건을 나누면(\(\psi'/\psi\) 연속) 진폭이 사라지고 에너지에 대한 조건만 남는다.

$$\text{짝:}\ k\tan\frac{kL}{2} = \kappa, \qquad \text{홀:}\ -k\cot\frac{kL}{2} = \kappa, \qquad k^2 + \kappa^2 = \frac{2mV_0}{\hbar^2}$$
무차원 변수 \(\xi = kL/2\), \(\eta = \kappa L/2\)를 쓰면 \(\eta = \xi\tan\xi\)(짝), \(\eta = -\xi\cot\xi\)(홀), \(\xi^2 + \eta^2 = z_0^2\), \(z_0 = \dfrac{L}{2}\dfrac{\sqrt{2mV_0}}{\hbar}\). 초월 방정식이라 대수적으로 풀리지 않는다.

같은 폭의 무한 우물과 비교하면 유한 우물의 바닥 상태 에너지는?

파동함수가 장벽으로 스며들어 실효 폭이 \(L\)보다 넓어진 것처럼 행동한다. 넓은 상자일수록 에너지가 낮다. 아래에서 ‘무한 우물 준위’를 켜고 비교하라.

그래프 풀이와 속박 상태 수

\(\xi\)–\(\eta\) 평면에 짝 곡선 \(\eta = \xi\tan\xi\), 홀 곡선 \(\eta = -\xi\cot\xi\), 그리고 반지름 \(z_0\)인 원을 그리면 교점이 곧 고유 상태다. 각 곡선 가지는 \(\xi = 0, \pi/2, \pi, 3\pi/2, \dots\)에서 0으로 출발하므로, 원의 반지름이 \(\pi/2\)를 넘을 때마다 상태가 하나씩 생긴다.

$$N = \left\lceil \frac{2z_0}{\pi} \right\rceil = \left\lceil \frac{L\sqrt{2mV_0}}{\pi\hbar} \right\rceil, \qquad E = \frac{\hbar^2}{2m}\left(\frac{2\xi}{L}\right)^2$$
\(\lceil\ \rceil\)은 올림. \(z_0 \to 0\)이어도 짝 곡선 첫 가지와 원은 늘 만나므로 상태가 적어도 하나 있다. \(n\)번째 상태가 막 생기는 문턱 \(z_0 = (n-1)\pi/2\)에서 \(V_0\)는 같은 폭 무한 우물의 \(E_{n-1}\)과 같다.

장벽으로 스며드는 꼬리

장벽 속 파동함수는 \(e^{-\kappa x}\)로 줄어든다. 진폭이 \(1/e\)로 줄어드는 거리를 침투 깊이(penetration depth) \(\delta = 1/\kappa = \hbar/\sqrt{2m(V_0 - E)}\)라 한다. 확률 \(|\psi|^2\)은 \(\delta/2\)마다 \(1/e\)로 준다. 고전 입자는 결코 들어갈 수 없는 곳에 양자 입자가 있을 확률이 0이 아니라는 사실이 6장 터널링의 출발점이다.

유효 질량과 반도체 양자 우물

결정 속 전도대 전자는 주기 퍼텐셜 속을 움직이지만, 띠 바닥 근처에서는 질량만 바뀐 자유 입자처럼 행동한다: \(E = E_c + \hbar^2k^2/2m^*\). 이 \(m^*\)가 유효 질량(effective mass)이다(12장에서 띠 구조로 유도). 따라서 결정 위에 원자 수십 층 크기로 덧씌운 "느린" 퍼텐셜은 \(m \to m^*\)로 바꾼 슈뢰딩거 방정식으로 다룰 수 있다 — 포락 함수 근사(envelope function approximation).

띠 간격이 다른 두 반도체를 원자층 단위로 쌓은 것을 이종 구조(heterostructure)라 한다. 대표가 GaAs와 AlxGa1−xAs다. 격자 상수가 거의 같아(차이 0.1% 미만) 결함 없이 쌓이고, AlGaAs의 띠 간격이 더 넓다. 얇은 GaAs를 AlGaAs 사이에 끼우면 띠 간격 차이 \(\Delta E_g\)가 전도대와 가전자대로 나뉘어 전자와 정공 모두를 가두는 우물이 된다. 이 나뉨이 띠 오프셋(band offset)이다.

$$E_g(\text{Al}_x\text{Ga}_{1-x}\text{As}) \approx 1.424 + 1.247x\ \text{eV}\ (x < 0.45), \qquad \Delta E_c \approx 0.65\,\Delta E_g,\quad \Delta E_v \approx 0.35\,\Delta E_g$$
질량: GaAs 전자 \(m_e^* = 0.067m_e\), 무거운 정공 \(m_{hh}^* \approx 0.5m_e\)(대표값). 발광 에너지 \(\approx E_g(\text{GaAs}) + E_{e1} + E_{hh1}\) (엑시톤 결합 약 8 meV는 무시).

삼각 우물과 MOSFET 반전층

MOSFET 게이트에 문턱 이상의 전압을 걸면 산화막 아래 실리콘 표면에 전자가 모인다(반전층(inversion layer)). 이때 전도대는 계면에서 아래로 휘고, 전자는 한쪽은 산화막 장벽(3.1 eV), 다른 쪽은 휘어 오르는 전도대로 막힌 좁은 우물에 갇힌다. 계면 근처의 전도대는 거의 직선이므로 \(V(z) = qFz\) (\(z > 0\)), \(z < 0\)은 무한 벽인 삼각 우물(triangular well)로 근사할 수 있다. \(F\)는 계면의 실리콘 쪽 전기장이다.

삼각 우물의 해는 에어리 함수(Airy function) \(\psi_n(z) \propto \mathrm{Ai}\!\left(z/z_F - a_n\right)\)이며(\(z_F = (\hbar^2/2mqF)^{1/3}\)), 벽 조건 \(\psi(0) = 0\)이 \(\mathrm{Ai}(-a_n) = 0\)을 요구해 \(a_n\) = 2.338, 4.088, 5.521, …이 정해진다. WKB 근사(6장)는 거의 같은 값을 간단한 식으로 준다.

$$E_n = \left(\frac{\hbar^2}{2m}\right)^{1/3}(qF)^{2/3}\,a_n \;\approx\; \left(\frac{\hbar^2}{2m}\right)^{1/3}\left[\frac{3\pi}{2}\left(n - \frac14\right)qF\right]^{2/3},\qquad \langle z\rangle_n = \frac{2E_n}{3qF}$$
\(n = 1, 2, 3, \dots\). WKB 식의 계수 \([\tfrac{3\pi}{2}(n - \tfrac14)]^{2/3}\) = 2.320, 4.082, 5.517은 정확한 \(a_n\)과 1% 안에서 맞는다. \(m\)은 구속 방향(계면에 수직) 유효 질량, \(\langle z\rangle\) 관계는 비리얼 정리에서 나온다. 에너지는 \(F^{2/3}\), 두께는 \(F^{-1/3}\)로 변한다.

2·3차원 상자와 양자점

변의 길이가 \(a, b, c\)인 3차원 상자에서는 퍼텐셜이 \(x, y, z\)로 나뉘므로 변수 분리(separation of variables) \(\psi = X(x)Y(y)Z(z)\)가 된다. 각 방향이 독립적인 1차원 우물이라 에너지는 세 우물 에너지의 합이다.

$$E_{n_xn_yn_z} = \frac{\pi^2\hbar^2}{2m}\left(\frac{n_x^2}{a^2} + \frac{n_y^2}{b^2} + \frac{n_z^2}{c^2}\right),\qquad \psi = \sqrt{\frac{8}{abc}}\sin\frac{n_x\pi x}{a}\sin\frac{n_y\pi y}{b}\sin\frac{n_z\pi z}{c}$$
양자수 세 개가 모두 1 이상이다. 정육면체(\(a = b = c = L\))에서는 \(E = E_0(n_x^2 + n_y^2 + n_z^2)\), \(E_0 = \pi^2\hbar^2/2mL^2\).

정육면체에서는 \((2,1,1), (1,2,1), (1,1,2)\)처럼 다른 상태가 같은 에너지를 갖는다. 이를 축퇴(degeneracy)라 하고, 같은 에너지의 상태 수를 축퇴도라 한다. 축퇴는 대칭의 결과다 — 변의 길이가 달라지면 대칭이 깨지고 준위가 갈라진다. 실리콘 나노시트에서 여섯 계곡의 축퇴가 깨진 것과 같은 이야기다.

차원을 줄이면: 우물·선·점

한 방향만 가두면 양자 우물(quantum well, 2D), 두 방향을 가두면 양자선(quantum wire, 1D), 세 방향 모두 가두면 양자점(quantum dot, 0D)이다. 갇힌 방향의 에너지는 띄엄띄엄하고 남은 방향은 연속이라, 에너지당 상태 수(상태 밀도, 10장)의 모양이 차원에 따라 달라진다. 양자점은 원자처럼 날카로운 준위만 가져 "인공 원자"라 불린다.

양자점과 크기 따라 바뀌는 색

CdSe나 InP 나노 결정(지름 2–8 nm)은 전자와 정공을 세 방향 모두에서 가둔다. 반지름 \(R\)인 구 우물의 바닥 상태 에너지는 \(\pi^2\hbar^2/2m^*R^2\)이므로, 전자–정공 쌍을 만드는 에너지(곧 발광 에너지)는 벌크 띠 간격보다 크다. 브루스가 쿨롱 인력까지 넣어 얻은 근사식은

$$E \approx E_g + \frac{\pi^2\hbar^2}{2R^2}\left(\frac{1}{m_e^*} + \frac{1}{m_h^*}\right) - 1.786\,\frac{e^2}{4\pi\varepsilon_0\varepsilon_r R}$$
브루스 식(Brus equation). CdSe: \(E_g = 1.74\) eV, \(m_e^* = 0.13\), \(m_h^* = 0.45\), \(\varepsilon_r = 10.6\), \(e^2/4\pi\varepsilon_0 = 1.440\) eV·nm. 구속 항은 \(1/R^2\), 쿨롱 항은 \(1/R\)이라 작은 점에서는 구속이 이긴다. 무한 장벽을 가정해 작은 점의 에너지를 과대평가한다.

CdSe 양자점을 더 작게 만들면 발광색은 어느 쪽으로 움직일까?

작은 상자일수록 구속 에너지가 커져 띠 간격이 넓어진다: 지름 2 nm 근처는 파랑, 6–7 nm는 빨강이다. 아래에서 점을 끌어 확인하라.

양자점 디스플레이와 이미지 센서

QD-OLED·QD 필름 디스플레이는 청색 빛을 녹색(약 530 nm)·적색(약 630 nm) 양자점에 흡수시켜 다시 내보낸다. 크기만 바꿔 색을 고르고, 크기 분포가 좁으면 발광 폭이 20–30 nm로 좁아 색 재현 범위가 넓다. 카드뮴 규제 때문에 상용 제품은 InP/ZnSe/ZnS 코어–셸 점이 주류다. 같은 원리로 PbS 양자점은 띠 간격을 1–2 μm 단파 적외선에 맞춰 실리콘이 못 보는 빛을 찍는 센서가 된다. 디스플레이 색, OLED, 보이지 않는 빛 센서.

핵심 정리

  1. 무한 우물: \(E_n = n^2\pi^2\hbar^2/2mL^2 = n^2(0.376\ \text{eV})/(m^*L^2)\) [L in nm], \(\psi_n = \sqrt{2/L}\sin(n\pi x/L)\). \(n\)번째 상태의 마디는 \(n-1\)개, 상태들은 서로 직교한다.
  2. 구속 에너지는 \(1/L^2\), \(1/m^*\)에 비례한다. 바닥 상태도 0이 아닌 영점 에너지를 가지며 \(\Delta x\Delta p \ge 0.568\hbar\)이다.
  3. 유한 우물: 짝 \(k\tan(kL/2) = \kappa\), 홀 \(-k\cot(kL/2) = \kappa\). 그래프 풀이에서 반지름 \(z_0 = (L/2)\sqrt{2mV_0}/\hbar\)인 원과의 교점이 상태이고, 상태 수는 \(\lceil 2z_0/\pi\rceil\)(최소 1개).
  4. 파동함수는 장벽 속으로 \(\delta = \hbar/\sqrt{2m(V_0 - E)}\) 깊이만큼 스며들어, 준위가 같은 폭 무한 우물보다 낮다.
  5. 반도체 이종 구조는 띠 오프셋으로 우물을 만들고, 유효 질량으로 계산한다. 폭으로 발광 파장을, 계곡별 질량 차이로 Si 채널의 계곡 분리를 정한다.
  6. 삼각 우물: \(E_n \approx (\hbar^2/2m)^{1/3}[\tfrac{3\pi}{2}(n - \tfrac14)qF]^{2/3}\), \(\langle z\rangle = 2E/3qF\). MOSFET 반전층 중심이 계면에서 약 1 nm 떨어져 CET가 EOT보다 0.3–0.4 nm 두껍다.
  7. 3차원 상자는 변수 분리로 풀리고, 대칭이 축퇴를 만든다. 양자점은 크기로 띠 간격을 바꿔 작을수록 파란 빛을 낸다.

연습문제

필요하면 \(\hbar^2/2m_e = 0.0381\) eV·nm², \(\pi^2\hbar^2/2m_e = 0.376\) eV·nm², \(hc = 1239.8\) eV·nm, \(k_BT(300\ \text{K}) = 25.9\) meV를 쓴다. 답이 ±1% 이내면 정답이다.

폭 0.500 nm인 무한 우물 속 자유 전자의 바닥 상태 에너지는?

\(E_1 = 0.376/(0.500)^2 = 1.50\) eV.

폭 10.0 nm GaAs 층(\(m^* = 0.067m_e\))을 무한 우물로 보면 전자의 바닥 준위는 몇 meV인가?

\(E_1 = 0.376/(0.067\times100) = 0.0561\) eV = 56.1 meV.

폭 1.00 nm 무한 우물 속 전자가 \(n = 2\)에서 \(n = 1\)로 떨어질 때 내는 광자의 파장은?

\(\Delta E = (4 - 1)(0.376) = 1.128\) eV, \(\lambda = 1239.8/1.128 = 1.10\times10^3\) nm.

무한 우물의 바닥 상태 입자가 \(0 < x < L/4\)에서 발견될 확률은?

\(\int_0^{L/4}\tfrac2L\sin^2\tfrac{\pi x}{L}dx = \tfrac14 - \tfrac{1}{2\pi}\sin\tfrac{\pi}{2}\).

\(P = 1/4 - 1/(2\pi) = 0.250 - 0.159 = 0.0908\). 고전값 0.25보다 훨씬 작다 — 벽 근처는 \(\psi\)가 작다.

폭 2.00 nm 무한 우물의 바닥 상태에서 위치의 불확정성 \(\Delta x\)는?

\(\Delta x = L\sqrt{1/12 - 1/2\pi^2} = 2.00\times0.1808 = 0.362\) nm.

같은 폭이라면, 깊이 \(V_0\)인 유한 우물의 바닥 상태 에너지 \(E_1^{\text{유한}}\)과 무한 우물의 \(E_1^{\text{무한}}\)의 관계로 옳은 것은?

파동함수가 장벽으로 스며들어 실효 폭이 넓어지므로 에너지는 항상 더 낮다. \(V_0 \to \infty\)일 때 두 값이 같아진다.

깊이 0.300 eV, 폭 5.00 nm인 GaAs 우물(\(m^* = 0.067m_e\))에 전자의 속박 상태는 몇 개인가?

\(z_0 = 2.50\sqrt{0.067\times0.300/0.0381} = 1.82\), \(2z_0/\pi = 1.16\) → 2개(짝 하나, 홀 하나). 에너지는 약 89.6, 287 meV.

GaAs 우물의 전자(\(m^* = 0.067m_e\))가 장벽 꼭대기보다 0.200 eV 아래에 묶여 있다. 장벽 속 침투 깊이 \(\delta = 1/\kappa\)는? (장벽에서도 같은 질량)

\(\delta = \sqrt{0.0381/(0.067\times0.200)} = \sqrt{2.84} = 1.69\) nm.

폭 4.00 nm GaAs 우물(\(m^* = 0.067m_e\))이 전자 속박 상태를 2개 이상 갖기 위한 최소 깊이 \(V_0\)는?

둘째 상태는 \(z_0 = \pi/2\)일 때 생긴다.

\(\tfrac L2\sqrt{m^*V_0/0.0381} = \pi/2\) → \(V_0 = \pi^2(0.0381)/(m^*L^2) = 0.376/(0.067\times16.0) = 0.351\) eV. 같은 폭 무한 우물의 \(E_1\)과 같다.

두께 6.00 nm인 (100) 실리콘 나노시트를 무한 우물로 보면 Δ4(\(m_t = 0.19\))와 Δ2(\(m_l = 0.98\)) 계곡의 첫 준위 차이는?

\(\Delta E = \tfrac{0.376}{36.0}\left(\tfrac{1}{0.19} - \tfrac{1}{0.98}\right) = 0.01045\times4.243 = 0.0443\) eV = 44.3 meV (1.7\(k_BT\)).

(100) Si 반전층의 계면 전기장이 0.500 MV/cm일 때 Δ2 계곡(\(m_\perp = 0.98\))의 첫 부띠 에너지를 에어리 정확해(\(a_1 = 2.338\))로 구하라.

\(qF = 0.0500\) eV/nm, \((0.0381/0.98)^{1/3} = 0.3388\), \((0.0500)^{2/3} = 0.1357\) → \(E_1 = 0.3388\times0.1357\times2.338 = 0.1075\) eV ≈ 108 meV.

계면 전기장 1.50 MV/cm의 Si 반전층(Δ2, \(m_\perp = 0.98\))에서 전자 중심 거리 \(\langle z\rangle\)에 의한 CET 증가 \(\langle z\rangle(3.9/11.7)\)는?

\(E_1\)을 먼저 구하고 \(\langle z\rangle = 2E_1/3qF\).

\(qF = 0.150\) eV/nm, \(E_1 = 0.3388\times(0.150)^{2/3}\times2.338 = 0.2236\) eV. \(\langle z\rangle = 2(0.2236)/(0.450) = 0.994\) nm → \(0.994/3 = 0.331\) nm.

정육면체 상자에서 \(E = 14E_0\)인 준위의 축퇴도는?

\(14 = 3^2 + 2^2 + 1^2\)뿐이고, 세 수가 모두 달라 순열 \(3! = 6\)개: (321), (312), (231), (213), (132), (123).

지름 6.00 nm CdSe 양자점의 발광 파장을 브루스 식으로 어림하라(\(E_g = 1.74\) eV, \(m_e^* = 0.13\), \(m_h^* = 0.45\), \(\varepsilon_r = 10.6\), \(e^2/4\pi\varepsilon_0 = 1.440\) eV·nm).

\(R = 3.00\) nm. 구속 \(0.376(9.915)/9.00 = 0.414\) eV, 쿨롱 \(1.786(1.440)/(31.8) = 0.0809\) eV → \(E = 2.073\) eV, \(\lambda = 598\) nm.

폭 10.0 nm GaAs 우물을 무한 우물로 근사해(전자 0.067, 무거운 정공 0.50) e1 + hh1 전이의 파장을 구하라(\(E_g = 1.424\) eV). 유한 장벽으로 푼 예제 값 848 nm와 비교하라.

e1 = 56.1 meV, hh1 = 0.376/(0.50×100) = 7.52 meV → \(h\nu = 1.4876\) eV, \(\lambda = 833\) nm. 무한 장벽 근사는 에너지를 과대평가해 파장을 15 nm 짧게 예측한다.

개념 확인 퀴즈

무한 우물의 \(n = 4\) 상태 파동함수에는 (벽을 빼고) 마디가 몇 개 있는가?

\(n\)번째 상태에는 반파장이 \(n\)개 들어가고, 그 사이 마디는 \(n - 1\)개다. 마디가 많을수록 곡률이 커서 운동 에너지가 크다.

우물을 넓히면 준위들은 어떻게 되는가?

\(E_n \propto n^2/L^2\). 아주 넓어지면 간격이 \(k_BT\)보다 작아져 연속(벌크)처럼 보인다.

대칭인 1차원 유한 우물이 아주 얕고 좁을 때 속박 상태는?

그래프 풀이에서 짝 곡선의 첫 가지는 원점에서 출발하므로 반지름이 아무리 작아도 원과 만난다. (3차원 구 우물은 다르다 — 문턱 깊이가 있다.)

MOSFET의 CET가 EOT보다 두껍게 측정되는 양자역학적 이유는?

\(\psi(0) = 0\)인 삼각 우물 바닥 상태의 중심은 \(\langle z\rangle = 2E_1/3qF \approx 1\) nm. 그 실리콘 층이 직렬 커패시턴스로 더해진다. (폴리 게이트 공핍도 CET를 늘리지만 양자 효과는 아니고, 금속 게이트에는 없다.)

2차원 정사각형 상자에서 (1,2)와 (2,1) 상태가 같은 에너지를 갖는 근본 이유는?

90° 회전·대각선 반사 대칭이 두 상태를 서로 옮긴다. 직사각형으로 늘이면 대칭이 깨져 갈라진다(미니 실험).
