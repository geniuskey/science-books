단위 환산: 광자와 전자

광자 하나의 에너지는 파장·진동수·파수·온도 어느 것으로도 나타낼 수 있다. 분광학에서는 파수(cm⁻¹), 광학과 리소그래피에서는 파장(nm), 소자 물리에서는 eV, 열 문제에서는 \(E/k_B\)(K)를 쓴다. 관계식은 모두 하나다.

$$E = h\nu = \frac{hc}{\lambda} = hc\,\tilde\nu = k_BT_{\text{eq}},\qquad \lambda\,[\text{nm}] = \frac{1239.84}{E\,[\text{eV}]},\qquad \tilde\nu\,[\text{cm}^{-1}] = 8065.5\,E\,[\text{eV}]$$

전자의 운동 에너지와 드브로이 파장

전자를 전압 \(V\)로 가속하면 운동 에너지 \(K = eV\)를 얻는다. 수 keV 이하에서는 \(\lambda = h/\sqrt{2m_eK}\)로 충분하지만, 투과 전자 현미경(100–300 kV)에서는 \(K\)가 \(m_ec^2 = 511\ \text{keV}\)에 견줄 만해 상대론 식을 써야 한다.

$$\lambda = \frac{hc}{\sqrt{K(K + 2m_ec^2)}} \;\xrightarrow{K\ll m_ec^2}\; \frac{h}{\sqrt{2m_eK}} = \frac{1.226\ \text{nm}}{\sqrt{K\,[\text{eV}]}}$$

게이트 절연막과 EOT

MOS 소자의 게이트 절연막은 두 가지로 평가한다. 정전 용량을 정하는 비유전율 \(\varepsilon_r\)과, 누설 전류를 정하는 장벽 높이(실리콘 전도대와의 오프셋 \(\Delta E_c\))와 막 속 터널링 유효 질량 \(m_{ox}\)이다. 유전율이 큰 막일수록 띠 간격과 장벽이 낮아지는 경향이 있어, 둘 사이에서 타협한다(6장).

$$\text{EOT} = \sum_i t_i\,\frac{3.9}{\varepsilon_{r,i}},\qquad C_{ox} = \frac{3.9\,\varepsilon_0}{\text{EOT}},\qquad T_{\text{WKB}} \approx \exp\!\Big(-2\sum_i \kappa_i t_i\Big),\quad \kappa_i = \sqrt{\frac{m_{ox,i}\,\Delta E_{c,i}}{0.0381\ \text{eV}\cdot\text{nm}^2}}$$

45 nm 노드의 HKMG 전환

SiO₂(질화 SiON) 게이트는 1.2 nm 근처에서 직접 터널링 누설이 100 A/cm²를 넘어 더 얇아질 수 없었다. 2007년 45 nm 노드에서 HfO₂ 기반 high-k와 금속 게이트(HKMG)로 바꾸면서, 물리 두께는 2 nm 이상으로 늘리고 EOT는 1 nm 아래로 낮췄다. 위 계산기에서 같은 EOT의 누설이 수 자릿수 줄어드는 것이 그 이유다. 남은 병목인 계면 SiO₂를 얇게 하는 '계면층 스캐빈징'이 이후 노드의 과제가 되었다 — MOS 구조, 스케일링.

표 읽기 확인 문제

이 부록의 표와 계산기만으로 풀 수 있다. 특별한 말이 없으면 표의 300 K 대표값을 쓴다.

EUV 노광 광원(13.5 nm)과 ArF 엑시머 레이저(193 nm) 광자 하나의 에너지를 각각 구하라.

\(E = 1239.84/\lambda\).

\(1239.84/13.5 = 91.8\ \text{eV}\), \(1239.84/193 = 6.42\ \text{eV}\). EUV 광자 하나가 약 14배의 에너지를 지니므로, 같은 선량에서 광자 수는 1/14 — 확률적 결함(stochastics)의 근원이다.

실리콘과 GaN이 흡수할 수 있는 가장 긴 파장(흡수 끝)은 각각 얼마인가?

\(\lambda_g = 1239.84/E_g\): Si \(1239.84/1.12 = 1107\ \text{nm}\), GaN \(1239.84/3.4 = 365\ \text{nm}\). Si 이미지 센서는 1.1 μm 너머를 보지 못하고, GaN은 가시광에 투명한 자외선 검출기가 된다.

200 kV로 가속한 TEM 전자의 드브로이 파장을 상대론 식으로 구하라(pm 단위).

\(\lambda = hc/\sqrt{K(K+2m_ec^2)}\), \(K = 2\times10^5\ \text{eV}\), \(m_ec^2 = 510\,999\ \text{eV}\).

\(\sqrt{2\times10^5\times(2\times10^5 + 1.022\times10^6)} = 4.944\times10^5\ \text{eV}\), \(\lambda = 1239.84/4.944\times10^5 = 2.51\times10^{-3}\ \text{nm} = 2.51\ \text{pm}\). 비상대론 식은 2.74 pm(9% 과대).

계면 SiO₂ 0.5 nm 위에 HfO₂ 2.0 nm를 쌓은 게이트 절연막의 EOT는?

\(\text{EOT} = 0.5 + 2.0\times3.9/25 = 0.5 + 0.312 = 0.812\ \text{nm}\). 물리 두께 2.5 nm의 1/3이지만, 그중 60%가 계면층에서 온다.

GaAs(\(m^* = 0.067\), \(\varepsilon_r = 12.9\))의 얕은 주개 결합 에너지와 유효 보어 반지름을 수소 모형으로 구하라.

\(E_b = 13.606\times0.067/12.9^2 = 5.48\ \text{meV}\), \(a_B^* = 0.05292\times12.9/0.067 = 10.2\ \text{nm}\). 상온 \(k_BT\)(25.9 meV)보다 훨씬 작아 주개는 거의 모두 이온화된다.

에너지 1 eV인 전자가 높이 3.1 eV, 두께 1 nm인 사각 장벽(막 속 유효 질량 0.42)을 지나갈 확률을 정확한 식으로 구하라.

\(\kappa = \sqrt{0.42\times2.1/0.0381} = 4.81\ \text{nm}^{-1}\), \(\sinh(4.81) \approx 61.6\).

\(T = [1 + 3.1^2\sinh^2(4.812)/(4\times1\times2.1)]^{-1} = [1 + 9.61\times3795/8.4]^{-1} = 2.31\times10^{-4}\). 지수 근사 \(16(1)(2.1)/3.1^2\cdot e^{-9.62} = 2.3\times10^{-4}\)도 잘 맞는다(계산기의 '자유' 질량 대신 0.42를 넣어 확인).

실리콘의 \(n_i = 1.0\times10^{10}\ \text{cm}^{-3}\)(300 K)에서 출발해, \(E_g = 1.12\ \text{eV}\)가 변하지 않는다고 보고 400 K의 \(n_i\)를 구하라.

\(n_i \propto T^{3/2}e^{-E_g/2k_BT}\)의 비를 쓴다.

\(\frac{n_i(400)}{n_i(300)} = (4/3)^{1.5}\exp\!\big[\frac{1.12}{2\times8.617\times10^{-5}}(\frac1{300} - \frac1{400})\big] = 1.540\times e^{5.416} = 346\). 따라서 \(n_i = 3.46\times10^{12}\ \text{cm}^{-3}\). 띠 간격의 온도 감소까지 넣으면(계산기) 조금 더 커진다.

표의 물질 중 효율 좋은 발광 소자(LED, 레이저)를 만들 수 있는 직접 띠 간격 반도체끼리 묶은 것은?

GaAs·GaN·InP는 전도대 바닥과 가전자대 꼭대기가 같은 k(Γ점)에 있어 포논 없이 광자를 낸다. Si·Ge·4H-SiC는 간접이다(12장, 13장).
