공식과 물성 자료

본문 16개 장에서 쓴 공식과 재료 값을 한곳에 모았다. 좌표계별 미분 연산, 맥스웰 방정식과 경계 조건, 대표 구조의 정전 용량·인덕턴스·특성 임피던스는 표로 정리하고, 표마다 같은 식을 쓰는 계산기를 붙였다. 계산기는 이 책의 계산 엔진 EM.*을 그대로 부르므로 본문 시뮬레이터와 같은 값을 낸다. 재료 표는 머리글을 눌러 정렬하고 검색 칸으로 거른다. 값은 특별한 말이 없으면 상온·저주파 대표값이다. 문제를 풀 때는 문제에 주어진 값을 먼저 쓰고, 없을 때 이 표를 쓴다.

  • 직교·원통·구 좌표의 기울기·발산·회전·라플라시안 공식을 찾고, 점과 벡터 성분을 좌표계 사이에서 바꾼다.
  • 맥스웰 방정식의 미분형·적분형·페이저형과 경계 조건, 매질별 평면파 상수를 한 표에서 확인한다.
  • 평행판·적층막·동축·두 선·배선 구조의 정전 용량, 솔레노이드·고리·나선의 인덕턴스, 동축·마이크로스트립의 특성 임피던스를 계산기로 구한다.
  • 공정 재료의 유전율·전도도·투자율·굴절률을 표에서 찾고, 표피 깊이·도파관 차단 주파수·데시벨 단위를 바로 환산한다.

표 찾아 쓰기 연습

필요한 값은 모두 이 부록의 표와 계산기에 있다. 문제에 값이 주어지면 그 값을 쓴다. 상수는 ε₀ = 8.854 × 10⁻¹² F/m, μ₀ = 4π × 10⁻⁷ H/m, c = 2.998 × 10⁸ m/s.

계면 SiO₂ 1.0 nm 위에 HfO₂(εr = 22) 2.5 nm를 올린 게이트 스택의 EOT와 단위 넓이 정전 용량을 구하라.

EOT = Σ di × 3.9/εri, C/A = 3.9ε₀/EOT.

\(\text{EOT} = 1.0 + 2.5\times3.9/22 = 1.0 + 0.443 = 1.443\ \text{nm}\). \(C/A = 3.9\times8.854\times10^{-12}/1.443\times10^{-9} = 2.39\times10^{-2}\ \text{F/m}^2 = 23.9\ \text{fF}/\mu\text{m}^2\). 물리 두께 3.5 nm인데도 SiO₂ 1.44 nm와 같은 용량이다.

신호 발생기 출력 13 dBm은 몇 mW인가? 50 Ω 부하에 걸리는 실효 전압은?

\(P = 10^{13/10} = 19.95\ \text{mW}\). \(V_{\text{rms}} = \sqrt{PR} = \sqrt{0.01995\times50} = 0.999\ \text{V}\). 진폭(피크)은 \(\sqrt2\)배인 1.41 V다.

RG-58 동축 케이블은 안 도체 반지름 a = 0.455 mm, 유전체 바깥 반지름 b = 1.475 mm, 폴리에틸렌 εr = 2.25다. 특성 임피던스와 단위 길이 정전 용량을 구하라.

\(Z_0 = (60/\sqrt{\varepsilon_r})\ln(b/a)\), \(C' = 2\pi\varepsilon/\ln(b/a)\).

\(\ln(b/a) = \ln 3.242 = 1.176\). \(Z_0 = (60/1.5)\times1.176 = 47.0\ \Omega\)(정확히는 \(\eta_0/2\pi = 59.96\)). \(C' = 2\pi\times2.25\times8.854\times10^{-12}/1.176 = 1.06\times10^{-10}\ \text{F/m} = 106\ \text{pF/m}\). 사양서의 "50 Ω, 100 pF/m"와 맞는다(실제 안 도체는 꼬임선이라 실효 반지름이 약간 다르다).

구리(σ = 5.96 × 10⁷ S/m)의 표피 깊이를 13.56 MHz와 2.45 GHz에서 구하고, 13.56 MHz의 표면 저항을 구하라.

\(\delta = 1/\sqrt{\pi f\mu_0\sigma}\). 13.56 MHz: \(\pi\times1.356\times10^7\times4\pi\times10^{-7}\times5.96\times10^7 = 3.19\times10^9\), \(\delta = 17.7\ \mu\text{m}\). 2.45 GHz: \(\delta = 17.7\times\sqrt{13.56/2450} = 1.32\ \mu\text{m}\). \(R_s = 1/(\sigma\delta) = 1/(5.96\times10^7\times1.77\times10^{-5}) = 9.48\times10^{-4}\ \Omega = 0.948\ \text{m}\Omega\)(Ω/□).

WR-340 도파관(a = 86.36 mm, b = 43.18 mm, 공기)의 TE10 차단 주파수와 2.45 GHz에서의 도파 파장을 구하라.

\(f_c = c/2a = 2.998\times10^8/(2\times0.08636) = 1.736\ \text{GHz}\). \(\lambda = c/f = 122.4\ \text{mm}\), \(\lambda_g = 122.4/\sqrt{1 - (1.736/2.45)^2} = 122.4/0.7058 = 173\ \text{mm}\). 다음 모드 TE20·TE01은 3.47 GHz라 2.45 GHz에서는 TE10만 전파한다.

점 (x, y, z) = (3, 4, 12)에서 단위 벡터 \(\mathbf A = \hat{\mathbf z}\)의 구 좌표 성분 \(A_r\), \(A_\theta\)를 구하라.

\(\hat{\mathbf z} = \cos\theta\,\hat{\mathbf r} - \sin\theta\,\hat{\boldsymbol\theta}\).

\(r = 13\), \(\cos\theta = 12/13\), \(\sin\theta = \rho/r = 5/13\). \(A_r = 12/13 = 0.923\), \(A_\theta = -5/13 = -0.385\), \(A_\phi = 0\). 좌표 변환기에 넣어 확인할 수 있다.

\(\mathbf F = r^2\,\hat{\mathbf r}\)의 발산을 r = 3 m에서 구하라. 반지름 3 m 구면을 나가는 선속이 \(\int\nabla\cdot\mathbf F\,dV\)와 같은지도 확인하라.

\(\nabla\cdot\mathbf F = \dfrac{1}{r^2}\dfrac{d}{dr}(r^4) = 4r = 12\). 선속 \(4\pi r^2\cdot r^2 = 4\pi\cdot81 = 1018\), 부피 적분 \(\int_0^3 4r\cdot4\pi r^2dr = 16\pi\cdot81/4 = 4\pi\cdot81\). 같다(발산 정리).

FR-4(εr = 4.4) 기판에서 50 Ω 마이크로스트립의 w/h와 유효 유전율을 해머스타드 식으로 구하라(u ≥ 1 식을 쓰고 반복으로 푼다).

u = 2에서 Z₀를 계산해 50 Ω보다 큰지 작은지 보고 u를 조정한다. 계산기의 "마이크로스트립"으로 확인할 수 있다.

u = 2: \(\varepsilon_{\text{eff}} = 2.7 + 1.7/\sqrt{1 + 6} = 3.343\), \(Z_0 = 377/(\sqrt{3.343}\,[2 + 1.393 + 0.667\ln 3.444]) = 377/(1.828\times4.218) = 48.9\ \Omega\) — 약간 작으니 u를 줄인다. u = 1.93에서 \(\varepsilon_{\text{eff}} = 3.33\), \(Z_0 = 50.0\ \Omega\). 1.6 mm 기판이면 w = 3.08 mm, 지연 \(\sqrt{3.33}/c = 6.09\) ps/mm.

사각 평면 나선 인덕터: 감은 수 n = 4, 바깥 지름 250 μm, 안 지름 110 μm. 수정 휠러 식(K₁ = 2.34, K₂ = 2.75)으로 L을 구하라.

마그네트론 타깃 표면의 자기장이 300 G다. 이것은 몇 mT인가? 진공(플라스마 영역)에서 이 B에 해당하는 H는 몇 A/m인가?

1 G = 10⁻⁴ T이므로 300 G = 0.03 T = 30 mT. \(H = B/\mu_0 = 0.03/(4\pi\times10^{-7}) = 2.39\times10^4\ \text{A/m}\) = 300 Oe.

진성 실리콘(εr = 11.7, σ = 4.4 × 10⁻⁴ S/m)의 1 GHz 손실 탄젠트와 정전 완화 시간 ε/σ를 구하라.

\(\omega\varepsilon = 2\pi\times10^9\times11.7\times8.854\times10^{-12} = 0.651\ \text{S/m}\), \(\tan\delta = 4.4\times10^{-4}/0.651 = 6.76\times10^{-4}\). \(\tau = 1.036\times10^{-10}/4.4\times10^{-4} = 2.35\times10^{-7}\ \text{s}\). 이 기판은 1 GHz에서 저손실 유전체다. 1 Ω·cm(σ = 100 S/m)로 도핑하면 tan δ ≈ 150으로 손실이 커진다.

선폭 20 nm Cu 배선의 저항을 표의 벌크 비저항(1.68 μΩ·cm)으로 계산했다. 실제 측정값과 비교하면?

선폭이 Cu의 평균 자유 행로(약 39 nm)보다 좁아 표면·결정립계 산란이 늘고, 장벽층이 도체 단면을 줄인다. 그래서 실효 비저항이 벌크의 2–4배가 된다. 직류 측정에서도 마찬가지이므로 주파수 문제가 아니다.
