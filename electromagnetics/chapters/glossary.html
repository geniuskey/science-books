Appendix B

용어집과 종합 문제

1–16장 본문에서 처음 정의한 용어를 모았다. 설명은 본문의 정의를 한두 문장으로 정리한 것이며, 링크를 누르면 그 용어가 처음 나온 절로 이동한다. 검색창에 한국어나 영어를 넣거나 장을 골라 목록을 좁힐 수 있다. 뒤의 종합 문제는 장마다 3–5문제씩 계산 문제와 선택형 문제를 섞어 내고, 대부분 high-k 게이트, 배선 저항과 수명, 홀 측정, ICP 코일, 플라스마 차단 밀도, 박막 두께, RF 정합기, TDR과 전원망, 마이크로파 도파관, EMI 차폐, 리소그래피 시뮬레이션처럼 반도체 현장의 숫자로 묻는다. 풀이 끝의 링크는 그 문제가 기대는 절로 돌아간다. 마지막에는 각 장의 개념 퀴즈를 무작위로 섞어 낸다. 상수는 CODATA 2018 값(\(\varepsilon_0 = 8.854\times10^{-12}\ \text{F/m}\), \(\mu_0 = 1.2566\times10^{-6}\ \text{H/m}\), \(\eta_0 = 376.7\ \Omega\))을 쓰고, 시간 조화장은 \(e^{j\omega t}\) 관례를 따른다. 공식과 물성 값은 부록 A에 모여 있다.

스칼라장 \(f = x^2y + 3yz\)의 점 \((1, 2, -1)\)에서 최대 변화율 \(|\nabla f|\)와, 방향 \((2, -1, 2)\)으로의 변화율(방향 도함수)을 구하라.

\(a = b/e = 1.84\ \text{mm}\)에서 \(a\ln(b/a) = a = b/e\). \(V_{max} = E_{bd}b/e = 3\times10^6(5\times10^{-3})/2.718 = 5.52\ \text{kV}\). 이때 \(Z_0 = 60\ \Omega\)으로, 50 Ω 동축선이 내전압 최적(60 Ω)과 손실 최적(77 Ω) 사이의 절충이라는 말이 여기서 나온다. → 3장 절연 파괴

접지된 도체 평면 위 2.0 cm에 점전하 1.0 nC이 있다. 전하가 받는 힘의 크기와, 전하 바로 아래 평면의 유도 면전하 밀도는?

금속–실리콘(\(\varepsilon_r = 11.7\)) 쇼트키 접합의 계면 전기장이 \(1.0\times10^5\ \text{V/cm}\)이다. 영상력 때문에 장벽이 낮아지는 양은?

\(\Delta\phi = \sqrt{(1.602\times10^{-19})(10^7)/(4\pi\times11.7\times8.854\times10^{-12})} = \sqrt{1.231\times10^{-3}} = 0.0351\ \text{V}\), 즉 35.1 meV. 열전자 방출 전류가 \(e^{\Delta\phi/kT} \approx 3.9\)배 커진다 — 역방향 누설이 전압과 함께 늘어나는 까닭이다. → 4장 영상법

에폭시 몰드(\(\varepsilon_r = 4\)) 속에 작은 구형 공기 기포가 있다. 기포에서 먼 곳의 장이 균일한 \(E_0\)일 때 기포 안의 장은 \(E_0\)의 몇 배인가?

유전율 \(\varepsilon_1\)의 구가 \(\varepsilon_2\) 속에 있을 때 안의 장은 \(3\varepsilon_2E_0/(\varepsilon_1 + 2\varepsilon_2)\)(르장드르 \(l = 1\) 해).

한 변을 \(M = 100\)칸으로 나눈 정사각 격자에서 라플라스 방정식을 이완법으로 푼다. 최적 SOR 계수와, 야코비 반복으로 오차를 \(10^{-6}\)배로 줄이는 데 드는 반복 수는?

배선의 전류 밀도가 2배가 되고 동작 온도가 105 °C에서 125 °C로 오른다. 블랙 식 \(\text{MTF} = AJ^{-n}e^{E_a/k_BT}\)(\(n = 2\), \(E_a = 0.9\ \text{eV}\))로 수명은 몇 분의 1이 되는가?

서로 수직인 균일한 \(\mathbf E\)와 \(\mathbf B\) 속에 전자와 \(\text{Ar}^+\) 이온이 정지 상태에서 놓였다. 오래 지난 뒤 두 입자의 평균 이동(안내 중심 표류)은?

\(SE \approx 20\log(\lambda/2L) = 20\log(0.30/0.06) = 14.0\ \text{dB}\). 판 자체는 100 dB를 넘어도 외함은 가장 긴 틈이 정한다. 틈을 개스킷으로 막거나 짧은 구멍 여럿으로 나눈다. → 15장 차폐

격자 간격 \(h\), \(h/2\), \(h/4\)로 푼 정전 용량(정규화)이 1.0480, 1.0120, 1.0030이다. 수렴 차수와 리처드슨 외삽값은?

\(p = \log_2[(u_h - u_{h/2})/(u_{h/2} - u_{h/4})]\), 가장 촘촘한 두 값으로 \(u^* \approx u_{h/4} + (u_{h/4} - u_{h/2})/(2^p - 1)\).

\(p = \log_2(0.0360/0.0090) = 2.00\). \(u^* = 1.0030 + (1.0030 - 1.0120)/3 = 1.000\). 2차 수렴이 확인되면 외삽 하나로 격자를 몇 번 더 나눈 정확도를 얻는다. → 16장 유한 차분과 수렴

ArF(193 nm) 리소그래피의 레지스트 패턴을 3차원 FDTD로 푼다. 균일 격자 \(\Delta = 10\ \text{nm}\)에서 안정한 최대 시간 간격과, 레지스트(\(n = 1.7\)) 속 파장당 칸 수는?

\(\Delta t \le \Delta/(c\sqrt3) = 10^{-8}/(2.998\times10^8\times1.732) = 1.93\times10^{-17}\ \text{s} = 19.3\ \text{as}\). 매질 속 파장 \(193/1.7 = 113.5\ \text{nm}\) → 11.4칸. 수치 분산을 줄이려면 파장당 15–20칸이 바람직해 격자를 더 줄여야 하고, 그러면 \(\Delta t\)도 함께 준다. → 16장 FDTD

두께 10칸(\(\Delta = 10\ \text{nm}\))의 PML에 3차 다항식 손실 분포(\(m = 3\))를 쓴다. 수직 입사 반사를 \(10^{-6}\)으로 만드는 최대 전도도는?

\(R(0) = \exp[-2\sigma_{max}d/((m+1)\varepsilon_0c)]\).

\(\sigma_{max} = -(m+1)\varepsilon_0c\ln R/(2d) = 4(8.854\times10^{-12})(2.998\times10^8)(13.82)/(2\times10^{-7}) = 7.33\times10^5\ \text{S/m}\). 사입사에서는 \(\cos\theta\)만큼 흡수가 약해지고, 너무 급한 분포는 이산화 반사를 만든다. → 16장 흡수 경계

주기 500 nm인 격자에 633 nm 빛이 공기 쪽에서 수직 입사한다. 공기 쪽으로는 0차만 반사되는데, 석영 기판(\(n = 1.46\)) 쪽으로 투과하는 1차 회절의 각은?

공기: \(\sin\theta_1 = 633/500 = 1.27 > 1\) → 소산. 기판: \(1.46\sin\theta_1 = 1.266\) → \(\sin\theta_1 = 0.867\), \(\theta_1 = 60.1^\circ\). RCWA는 이런 전파·소산 차수를 모두 플로케 고조파로 담아 푼다. → 16장 RCWA

갤러킨 유한 요소법으로 같은 전극의 정전 용량을 점점 촘촘한 메시로 계산할 때 값은 보통 어떻게 수렴하는가?

전위 고정 문제에서 참 해가 에너지 \(\tfrac12\int\varepsilon|\nabla V|^2\)를 최소로 하고, 유한한 기저 공간의 해는 그보다 큰 에너지를 갖는다. \(W = \tfrac12CV^2\)이므로 \(C\)가 위에서 수렴한다. → 16장 유한 요소법
