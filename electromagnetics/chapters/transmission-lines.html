Chapter 12

전송선

10–11장의 평면파는 끝없는 공간을 달렸다. 실제 신호와 전력은 두 도체가 나란히 놓인 길, 곧 전송선을 따라 간다. 동축 케이블, PCB의 마이크로스트립, 칩 안 배선, 플라스마 장비의 RF 케이블이 모두 그렇다. 선의 길이가 파장에 견줄 만해지면 "도선 = 같은 전위"라는 회로 이론의 약속이 깨지고, 선 위의 전압은 위치마다 다른 크기와 위상을 갖는 파동이 된다. 끝에서 임피던스가 맞지 않으면 파동 일부가 되돌아와 정재파를 만들고, 그만큼 전력이 부하에 닿지 못한다. 이 장은 짧은 선 조각의 회로(RLGC)에서 출발해 전신 방정식, 특성 임피던스, 반사 계수와 정재파비, 입력 임피던스, 스미스 차트를 거쳐 임피던스 정합까지 간다. 마지막에는 식각·증착 장비의 13.56 MHz RF 정합기가 플라스마라는 까다로운 부하를 50 Ω으로 바꾸는 과정을 직접 조정해 본다. 먼저 오른쪽 스미스 차트의 점을 끌어 부하를 바꿔 보자.

스미스 차트의 점을 끌어 부하를 바꾼다
  • 선 길이가 파장의 약 1/10을 넘으면 분포 정수 모형이 필요한 이유를 설명하고, RLGC 사다리에서 전신 방정식과 파동 해 \(V(z) = V_0^+e^{-\gamma z} + V_0^-e^{\gamma z}\)를 유도한다.
  • 특성 임피던스 \(Z_0 = \sqrt{(R + j\omega L)/(G + j\omega C)}\)와 전파 상수 \(\gamma = \alpha + j\beta\)를 계산하고, 저손실 근사와 무왜곡 조건, 동축·평행 2선·마이크로스트립의 \(Z_0\) 공식을 쓴다.
  • 반사 계수 \(\Gamma_L = (Z_L - Z_0)/(Z_L + Z_0)\), 정재파비 \(S = (1 + |\Gamma|)/(1 - |\Gamma|)\), 반사 손실, 부하 전달 전력 \(1 - |\Gamma|^2\)을 구하고 전압 최대·최소의 위치를 찾는다.
  • 입력 임피던스 공식으로 단락·개방 스터브가 인덕터·커패시터로 보이는 길이, λ/4 반전과 λ/2 반복, 손실 선의 입력 임피던스를 계산한다.
  • 스미스 차트에서 임피던스·어드미턴스를 읽고, 발전기 쪽으로 이동(시계 방향 회전)과 정재파비 원을 써서 부하를 찾는다.
  • L 정합 회로, 단일 스터브, λ/4 변성기로 임의의 부하를 \(Z_0\)에 정합하고 소자 값과 대역폭을 계산한다.
  • 플라스마 부하(수 Ω − j100 Ω 안팎)를 13.56 MHz에서 50 Ω으로 바꾸는 L형 RF 정합기의 tune·load 콘덴서 값과 자동 정합 원리를 설명한다.

분포 정수 모형과 전신 방정식

회로 이론은 도선의 모든 점이 같은 순간 같은 전위에 있다고 가정한다. 신호가 도선을 따라 퍼지는 시간이 주기보다 훨씬 짧을 때만 맞는 근사다. 신호는 길이 \(\ell\)인 선을 \(\ell/v_p\)만에 건너고, 그동안 위상이 \(2\pi\ell/\lambda\)만큼 돈다. 경험적으로 \(\ell \gtrsim \lambda/10\)이면(위상 차 36° 이상) 선 위치마다 전압이 달라져 선 자체를 회로 소자로 다뤄야 한다. 60 Hz 송전선의 파장은 5000 km라 수백 km 선로에서야 문제가 되지만, 13.56 MHz에서 폴리에틸렌 동축 케이블 속 파장은 약 15 m라 수 m 케이블이 이미 "길다". 1 GHz면 PCB 위 파장이 15 cm 남짓이라 몇 cm 배선부터 전송선이다.

두 도체가 나란히 놓인 구조를 전송선(transmission line)이라 한다. 두 도체에 반대 방향 전류가 흐르면 그 사이에 자기장이 쌓이고(인덕턴스), 두 도체 사이 전압은 전기장을 만든다(정전 용량). 이 에너지 저장이 선 전체에 고르게 퍼져 있다는 것이 핵심이다. 그래서 선을 짧은 조각 \(\Delta z\)로 나눠 조각마다 작은 회로를 붙인다 — 분포 정수 모형(distributed-element model)이다. 단위 길이당 네 상수가 선을 완전히 기술한다: 두 도체의 저항 \(R\)(Ω/m), 자기 인덕턴스 \(L\)(H/m), 절연체의 누설 컨덕턴스 \(G\)(S/m), 정전 용량 \(C\)(F/m).

단계 4의 두 식이 전신 방정식(telegrapher's equations)이다. 1880년대 헤비사이드가 대서양 전신 케이블의 신호 왜곡을 설명하려고 정리했다. 한 식을 \(z\)로 한 번 더 미분해 다른 식을 넣으면 \(V\)와 \(I\)가 각각 따로 파동 방정식을 만족한다.

$$\frac{d^2V}{dz^2} = \gamma^2V,\qquad \frac{d^2I}{dz^2} = \gamma^2 I,\qquad \gamma = \alpha + j\beta = \sqrt{(R + j\omega L)(G + j\omega C)}$$
\(\gamma\): 전파 상수(propagation constant), \(\alpha\): 감쇠 상수(Np/m, 1 Np = 8.686 dB), \(\beta\): 위상 상수(rad/m), 위상 속도 \(v_p = \omega/\beta\), 파장 \(\lambda = 2\pi/\beta\). 평면파의 \(\gamma = \sqrt{j\omega\mu(\sigma + j\omega\varepsilon)}\)(10장)와 꼴이 같다.

일반해는 \(+z\)로 가는 파동과 \(-z\)로 가는 파동의 합이다. 전류는 첫째 전신 방정식 \(I = -(dV/dz)/(R + j\omega L)\)에서 나온다.

$$V(z) = V_0^+e^{-\gamma z} + V_0^-e^{+\gamma z},\qquad I(z) = \frac{V_0^+}{Z_0}e^{-\gamma z} - \frac{V_0^-}{Z_0}e^{+\gamma z}$$
특성 임피던스(characteristic impedance)

한 방향으로만 진행하는 파동의 전압과 전류의 비. 선의 단면(재료와 모양)만으로 정해지며 선의 길이와 무관하다. 무한히 긴 선의 입력 임피던스이기도 하다.

$$Z_0 = \frac{V_0^+}{I_0^+} = -\frac{V_0^-}{I_0^-} = \sqrt{\frac{R + j\omega L}{G + j\omega C}}\ \xrightarrow{\ R = G = 0\ }\ \sqrt{\frac{L}{C}},\qquad v_p = \frac{1}{\sqrt{LC}}$$
반대로 가는 파동은 전류 부호가 바뀐다(\(-V_0^-/I_0^- = Z_0\)). \(Z_0\)은 저항처럼 Ω 단위지만 에너지를 소모하지 않는다. 진행파가 전력을 앞으로 실어 나를 뿐이다. 무손실 TEM 선에서는 늘 \(LC = \mu\varepsilon\)이므로 \(v_p = 1/\sqrt{\mu\varepsilon} = c/\sqrt{\varepsilon_r}\)로 단면 모양과 상관없다.

저손실 선과 무왜곡 선

실제 선은 대부분 \(R \ll \omega L\), \(G \ll \omega C\)인 저손실 선이다. \(\gamma\)를 1차까지 전개하면

$$\alpha \approx \frac{R}{2Z_0} + \frac{GZ_0}{2},\qquad \beta \approx \omega\sqrt{LC},\qquad Z_0 \approx \sqrt{L/C}$$
첫 항은 도체 손실, 둘째 항은 유전체 손실이다. 고주파에서 \(R\)은 표피 효과로 \(\sqrt f\)에 비례해 늘고(10장), \(G = \omega C\tan\delta\)는 \(f\)에 비례한다. 그래서 GHz 대역 PCB 손실은 유전체 손실 탄젠트가 좌우한다.

손실이 있어도 \(R/L = G/C\)이면 \(\gamma = \sqrt{RG} + j\omega\sqrt{LC}\)가 되어 \(\alpha\)는 주파수와 무관하고 \(v_p\)도 일정하다. 모든 주파수 성분이 같은 비율로 줄고 같은 속도로 가므로 펄스 모양이 그대로 유지된다 — 무왜곡 선로(distortionless line). 헤비사이드는 전화선이 \(R/L \gg G/C\)라는 데 착안해 선에 일정 간격으로 코일을 달아 \(L\)을 키우자고 제안했다(장하 코일).

반사 계수와 정재파비

무손실 선(\(\gamma = j\beta\)) 끝 \(z = 0\)에 부하 \(Z_L\)을 달자. 부하에서는 전압과 전류가 옴의 법칙 \(V(0) = Z_LI(0)\)을 만족해야 한다. 진행파 하나만으로는 \(V/I = Z_0\)이므로 \(Z_L \ne Z_0\)이면 이 조건을 맞출 수 없다. 그래서 되돌아오는 파동 \(V_0^-\)이 생겨 경계 조건을 맞춘다. 일반해를 넣으면 \(V_0^+ + V_0^- = Z_L(V_0^+ - V_0^-)/Z_0\)이고, 이로부터

$$\Gamma_L = \frac{V_0^-}{V_0^+} = \frac{Z_L - Z_0}{Z_L + Z_0} = \frac{z_L - 1}{z_L + 1},\qquad z_L = \frac{Z_L}{Z_0}$$
\(\Gamma_L\): 부하의 전압 반사 계수(reflection coefficient), 일반적으로 복소수. 수동 부하(\(\text{Re}\,Z_L \ge 0\))면 \(|\Gamma_L| \le 1\). 정합 \(Z_L = Z_0\): \(\Gamma = 0\). 단락: \(\Gamma = -1\). 개방: \(\Gamma = +1\). 순수 리액턴스: \(|\Gamma| = 1\). 11장의 수직 입사 \(\Gamma = (\eta_2 - \eta_1)/(\eta_2 + \eta_1)\)과 같은 꼴이다.

부하에서 발전기 쪽으로 거리 \(d\)(\(z = -d\))인 곳의 전압은 입사파와 반사파의 합이다.

$$V(d) = V_0^+e^{j\beta d}\left[1 + \Gamma_Le^{-j2\beta d}\right] = V_0^+e^{j\beta d}\left[1 + \Gamma(d)\right],\qquad \Gamma(d) = \Gamma_Le^{-j2\beta d}$$
\(\Gamma(d)\): 그 위치에서 부하 쪽을 볼 때의 반사 계수. 크기는 그대로이고 위상만 \(2\beta d\)만큼 돈다. \(|V(d)| = |V_0^+|\,|1 + \Gamma_Le^{-j2\beta d}|\)은 \(\lambda/2\)마다 되풀이된다.

두 파동이 겹쳐 생기는 무늬가 정재파(standing wave)다. \(\Gamma(d)\)가 양의 실수일 때 두 파동이 같은 위상으로 더해져 \(|V|_{max} = |V_0^+|(1 + |\Gamma|)\), 음의 실수일 때 \(|V|_{min} = |V_0^+|(1 - |\Gamma|)\)이다. 두 값의 비가 정재파비(voltage standing-wave ratio, VSWR)다.

$$S = \frac{|V|_{max}}{|V|_{min}} = \frac{1 + |\Gamma|}{1 - |\Gamma|},\qquad |\Gamma| = \frac{S - 1}{S + 1},\qquad d_{max} = \frac{\theta_\Gamma}{4\pi}\lambda + n\frac\lambda2,\quad d_{min} = d_{max} \pm \frac\lambda4$$
\(\theta_\Gamma\): \(\Gamma_L\)의 위상각. 전류의 최대는 전압의 최소 자리에 있다. 1 ≤ \(S\) < ∞. 정합이면 \(S = 1\)(정재파 없음), 단락·개방·리액턴스면 \(S = \infty\)(최소점 전압 0).

전력과 반사 손실

무손실 선에서 부하로 가는 평균 전력은 입사 전력에서 반사 전력을 뺀 것이다.

$$P_L = \frac{|V_0^+|^2}{2Z_0}\left(1 - |\Gamma_L|^2\right),\qquad \text{RL} = -20\log_{10}|\Gamma|\ \text{dB},\qquad \text{ML} = -10\log_{10}\left(1 - |\Gamma|^2\right)\ \text{dB}$$
반사 손실(return loss) RL: 반사파가 입사파보다 몇 dB 작은가(클수록 좋다). 부정합 손실(mismatch loss) ML: 반사 때문에 부하가 덜 받는 비율. 측정기에서 \(S_{11}\)(dB) \(= -\text{RL}\)로 표시한다.

입력 임피던스

발전기는 선과 부하를 하나로 묶어 그 입구의 임피던스만 본다. 부하에서 거리 \(\ell\)인 곳의 전압과 전류의 비를 입력 임피던스(input impedance)라 한다. \(V(d)\)와 \(I(d)\)를 나누고 \(\Gamma_L\)을 \(Z_L\)로 바꾸면

$$Z_{in} = Z_0\frac{1 + \Gamma_Le^{-j2\beta\ell}}{1 - \Gamma_Le^{-j2\beta\ell}} = Z_0\frac{Z_L + jZ_0\tan\beta\ell}{Z_0 + jZ_L\tan\beta\ell}\qquad\left(\text{손실 선: } Z_0\frac{Z_L + Z_0\tanh\gamma\ell}{Z_0 + Z_L\tanh\gamma\ell}\right)$$
\(\beta\ell = 2\pi\ell/\lambda\): 선의 전기적 길이. 선 하나가 부하 임피던스를 길이에 따라 다른 값으로 "변환"한다. \(\lambda/2\)마다 같은 값이 되풀이된다.

단락 끝 (\(Z_L = 0\))

\(Z_{in} = jZ_0\tan\beta\ell\). 순수 리액턴스. \(\ell < \lambda/4\)이면 양(인덕터), \(\lambda/4\)에서 무한대(개방), \(\lambda/4\)–\(\lambda/2\)에서 음(커패시터).

개방 끝 (\(Z_L = \infty\))

\(Z_{in} = -jZ_0\cot\beta\ell\). \(\ell < \lambda/4\)이면 커패시터, \(\lambda/4\)에서 0(단락). 짧은 개방선은 \(C\ell\)짜리 커패시터다.

λ/4와 λ/2

\(\ell = \lambda/4\): \(Z_{in} = Z_0^2/Z_L\)(임피던스 반전). \(\ell = \lambda/2\): \(Z_{in} = Z_L\)(그대로 되풀이). \(Z_L = Z_0\)이면 어느 길이에서도 \(Z_{in} = Z_0\).

단락·개방 끝의 짧은 선 조각을 스터브(stub)라 한다. 마이크로파 회로에서는 집중 소자 인덕터·커패시터 대신 스터브를 쓴다. 칩 인덕터는 GHz 대역에서 자기 공진과 손실이 문제가 되지만, 스터브는 PCB 패턴만으로 만들 수 있고 값도 길이로 정확히 정해진다.

끝을 단락한 50 Ω 선의 길이가 정확히 λ/4다. 입구에서 들여다본 임피던스는?

\(Z_{in} = jZ_0\tan(\pi/2) \to \infty\). 단락에서 λ/4 떨어진 곳은 전압이 최대, 전류가 0인 자리다. 아래에서 길이를 λ/4 근처로 끌어 확인하라. 이 성질 때문에 λ/4 단락 스터브는 DC 바이어스 경로를 주면서 RF는 막는 "RF 초크"로 쓰인다.

스미스 차트

입력 임피던스 공식은 복소수 계산이 번거롭다. 그런데 반사 계수로 보면 선을 따라 움직이는 일은 아주 단순하다. \(\Gamma(d) = \Gamma_Le^{-j2\beta d}\)는 크기가 그대로이고 각만 돈다. 1939년 벨 연구소의 필립 스미스는 이 사실을 이용해 \(\Gamma\) 평면(단위 원) 위에 정규화 임피던스 \(z = r + jx\)의 눈금을 그렸다. 이것이 스미스 차트(Smith chart)다. 회로 시뮬레이터와 네트워크 분석기 화면에 지금도 그대로 쓰인다.

$$\Gamma = \frac{z - 1}{z + 1} = \Gamma_r + j\Gamma_i\quad\Longrightarrow\quad\left(\Gamma_r - \frac{r}{1 + r}\right)^2 + \Gamma_i^2 = \left(\frac{1}{1 + r}\right)^2,\qquad(\Gamma_r - 1)^2 + \left(\Gamma_i - \frac1x\right)^2 = \left(\frac1x\right)^2$$
\(r\)가 일정한 곡선은 중심 \((r/(1+r), 0)\), 반지름 \(1/(1+r)\)인 원(모두 \(\Gamma = 1\)에서 접한다). \(x\)가 일정한 곡선은 중심 \((1, 1/x)\), 반지름 \(1/|x|\)인 원호. 위쪽 반은 유도성(\(x > 0\)), 아래쪽 반은 용량성.

차트 읽기 규칙

  • 선을 따라 이동: 발전기 쪽으로 \(d\)만큼 가면 중심을 축으로 시계 방향으로 \(2\beta d = 4\pi d/\lambda\)만큼 돈다(부하 쪽은 반시계). 바깥 테두리에 "파장 수" 눈금이 있어 한 바퀴 = 0.5λ다.
  • 정재파비 원: 무손실 선 위의 모든 점은 중심이 같은 반지름 \(|\Gamma_L|\)의 원 위에 있다. 이 원이 오른쪽 실수축과 만나는 점의 \(r\) 값이 곧 VSWR이고(전압 최대 자리), 왼쪽 실수축과 만나는 점은 \(1/S\)(전압 최소 자리)다.
  • 어드미턴스: \(y = 1/z\)는 \(\Gamma \to -\Gamma\), 곧 중심에 대해 180° 돌린 점이다. λ/4 선이 임피던스를 반전하는 것과 같은 이야기다. 그래서 같은 차트를 어드미턴스 차트(\(g + jb\))로도 읽을 수 있다. 병렬 소자를 다룰 때 쓴다.
  • 손실 선: \(\Gamma_{in} = \Gamma_Le^{-2\alpha\ell}e^{-j2\beta\ell}\)이므로 원이 아니라 중심으로 감겨 드는 나선이 된다.

임피던스 정합

부하를 선에 정합(impedance matching)한다는 것은 부하와 선 사이에 무손실 회로를 넣어 선이 보는 임피던스를 \(Z_0\)으로 만드는 일이다. 이유는 셋이다. ① 반사가 없으면 발전기가 낼 수 있는 전력이 모두 부하에 간다. ② 반사파가 발전기로 돌아가 출력단을 상하게 하거나 출력을 불안정하게 하지 않는다. ③ 선 위에 정재파가 없으니 전압 최대점의 절연 파괴와 전류 최대점의 과열이 없고 선 손실도 최소다.

Z₀ 정합

부하 쪽에서 선이 \(Z_0\)을 보게 한다. 선 위 \(\Gamma = 0\), 정재파 없음. 선 길이와 무관하게 발전기도 \(Z_0\)을 본다.

켤레 정합(conjugate matching)

발전기 내부 임피던스 \(Z_g\)에 대해 \(Z_{in} = Z_g^*\)이면 부하 전력이 최대(\(|V_g|^2/8R_g\)). 발전기가 \(Z_g = Z_0\)(실수)이면 두 조건이 같아진다. 그래서 RF 시스템은 모두 50 Ω에 맞춘다.

L 정합 회로

가장 단순한 정합 회로는 리액턴스 소자 두 개(직렬 하나, 병렬 하나)로 된 L 정합 회로(L-network)다. 스미스 차트에서 보면 직렬 리액턴스 \(jx\)를 더하면 점이 \(r\) 일정 원을 따라 움직이고, 병렬 서셉턴스 \(jb\)를 더하면 \(g\) 일정 원을 따라 움직인다. 두 번 움직여 중심에 닿으면 된다. 부하 저항이 \(Z_0\)보다 크면 부하에 병렬 소자를 먼저, 작으면 직렬 소자를 먼저 단다.

$$R_L > Z_0:\ B = \frac{X_L \pm\sqrt{R_L/Z_0}\sqrt{R_L^2 + X_L^2 - Z_0R_L}}{R_L^2 + X_L^2},\quad X = \frac1B + \frac{X_LZ_0}{R_L} - \frac{Z_0}{BR_L}$$ $$R_L < Z_0:\ X = \pm\sqrt{R_L(Z_0 - R_L)} - X_L,\quad B = \pm\frac{1}{Z_0}\sqrt{\frac{Z_0 - R_L}{R_L}}$$
\(X > 0\)이면 직렬 인덕터 \(L = X/\omega\), \(X < 0\)이면 직렬 커패시터 \(C = -1/\omega X\). \(B > 0\)이면 병렬 커패시터 \(C = B/\omega\), \(B < 0\)이면 병렬 인덕터 \(L = -1/\omega B\). 해가 둘이라 소자 종류(저역·고역 통과)를 고를 수 있다.

500 MHz에서 \(Z_L = 120 - j40\) Ω인 안테나를 50 Ω 선에 L 정합 회로로 정합하라. 두 해의 소자 값을 모두 구하라.

단일 스터브 정합

집중 소자를 쓰기 어려운 마이크로파 대역에서는 선과 스터브만으로 정합한다. 단일 스터브 정합(single-stub matching)은 부하에서 거리 \(d\)인 곳에 길이 \(\ell\)인 단락(또는 개방) 스터브를 병렬로 단다. 차트에서는 두 단계다. ① 선을 따라 \(d\)만큼 가서(정재파비 원을 시계 방향으로) 어드미턴스가 \(y = 1 + jb\)가 되는 곳(\(g = 1\) 원과의 교점)을 찾는다. ② 그곳에 서셉턴스 \(-jb\)인 스터브를 달아 \(b\)를 지운다. 단락 스터브의 어드미턴스는 \(-j\cot\beta\ell\)이다.

λ/4 변성기와 대역폭

실수 부하 \(R_L\)은 길이 λ/4, 특성 임피던스 \(Z_1\)인 선 하나로 정합할 수 있다. λ/4 선의 반전 성질 \(Z_{in} = Z_1^2/R_L\)을 \(Z_0\)과 같게 하면 된다. 이것이 λ/4 변성기(quarter-wave transformer)다. 11장의 반사 방지막(굴절률 \(\sqrt{n_1n_2}\), 두께 λ/4)과 같은 원리다.

$$Z_1 = \sqrt{Z_0R_L},\qquad \frac{\Delta f}{f_0} = 2 - \frac4\pi\cos^{-1}\left[\frac{\Gamma_m}{\sqrt{1 - \Gamma_m^2}}\,\frac{2\sqrt{Z_0R_L}}{|R_L - Z_0|}\right]$$
정확히 λ/4가 되는 주파수 \(f_0\)에서만 완전 정합이다. \(\Gamma_m\): 허용 반사 계수, \(\Delta f/f_0\): \(|\Gamma| \le \Gamma_m\)인 상대 대역폭(TEM 선). 50 → 100 Ω, \(\Gamma_m = 0.1\)(VSWR 1.22)이면 \(Z_1 = 70.7\) Ω, 대역폭 36.7%. 부하 비가 클수록 좁다. 넓히려면 여러 단을 이어 임피던스를 조금씩 바꾼다(이항·체비쇼프 다단 변성기).

100 부하를 50 Ω에 λ/4 변성기로 정합하려면 \(Z_1 =\) 인 선이 필요하다. 주파수 2.4, 유효 유전율 3.0이면 길이는 이고, VSWR 1.5 이하인 대역폭은 다.

플라스마 장비의 RF 정합기

용량 결합 플라스마(CCP) 식각기와 PECVD 장비는 13.56 MHz(산업·과학·의료용 ISM 주파수) RF 전원으로 플라스마를 만든다. 발전기는 50 Ω 출력에 50 Ω 동축 케이블로 연결되지만, 전극 너머의 플라스마는 50 Ω과 거리가 멀다. 플라스마 몸체는 전도도가 큰 저항이고, 전극 앞의 시스(sheath)는 이온만 남은 얇은 층이라 커패시터처럼 행동한다. 그래서 전극에서 본 부하는 대개 "작은 저항 + 큰 용량성 리액턴스", 예를 들어 \(Z_p \approx 2\)–\(15\ \Omega - j(60\)–\(150)\ \Omega\)이다. 이대로 연결하면 \(|\Gamma| > 0.9\)라 전력의 80% 이상이 되돌아온다.

그래서 발전기와 전극 사이에 정합기(matching network, matcher)를 둔다. 가장 흔한 꼴은 L형이다. 발전기 쪽에 병렬로 단 load 콘덴서 \(C_L\), 플라스마 쪽에 직렬로 단 tune 콘덴서 \(C_T\)와 고정 인덕터 \(L_s\)다. 콘덴서는 수 kV, 수십 A를 견디는 진공 가변 콘덴서(vacuum variable capacitor)이고 스텝 모터가 돌린다. 부하 저항이 50 Ω보다 작으므로 앞 절의 "직렬 → 병렬" 해(\(R_L < Z_0\))에 해당한다.

13.56 MHz에서 플라스마 부하가 \(Z_p = 5 - j100\) Ω이다. 정합기의 직렬 가지는 \(L_s = 2.0\) µH와 tune 콘덴서 \(C_T\)이고, 발전기 쪽 병렬 가지는 load 콘덴서 \(C_L\)이다. 50 Ω 정합을 이루는 \(C_T\)와 \(C_L\)은?

풀이 보기

자동 정합

플라스마 임피던스는 점화 순간, 압력·전력·기체가 바뀌는 레시피 단계마다, 챔버 벽이 오염되며 천천히 변한다. 정합기 입구의 센서가 전압·전류의 크기 비와 위상차(또는 입구 어드미턴스의 실수부·허수부)를 재고, 두 오차 신호로 두 모터를 돌린다. 이 장의 시뮬레이터는 입구 어드미턴스 \(y_{in} = g + jb\)를 쓴다: 허수부 \(b\)는 병렬 \(C_L\)이 지우고, 실수부 오차 \(g - 1\)은 직렬 \(C_T\)가 줄인다. 콘덴서가 움직일 수 있는 범위가 유한하므로 정합기마다 맞출 수 있는 부하의 영역(정합 범위)이 정해져 있다.

정합이 완벽하던 중 압력 단계가 바뀌어 플라스마 저항 \(R_p\)가 5 Ω에서 10 Ω으로 커졌다(리액턴스는 그대로). 정합기가 반응하기 전, 발전기 쪽에서 보는 \(|\Gamma|\)는?

L 회로는 5 Ω을 50 Ω으로 10배 키우도록 맞춰져 있다. \(R_p\)가 10 Ω이 되면 직렬 가지의 컨덕턴스 \(R/(R^2 + X_s^2)\)가 0.020 S에서 0.031 S로 늘고 load 콘덴서가 지우던 서셉턴스도 어긋나, 입구 임피던스가 약 \(27 - j12\) Ω, \(|\Gamma| \approx 0.33\)(반사 전력 11%)이 된다. 아래 시뮬레이터에서 "레시피 B"를 눌러 반사 전력이 튀는 것과 자동 정합이 따라가는 것을 보라. Q가 높은(\(R_p\)가 작은) 부하일수록 정합이 예민하다.

왜 하필 50 Ω인가

1930년대 공기 동축선을 연구하던 벨 연구소는 바깥 지름을 고정했을 때 두 기준이 서로 다른 \(Z_0\)을 고른다는 것을 알았다. 도체 손실 \(\alpha_c \propto (1/a + 1/b)/\ln(b/a)\)는 \(b/a = 3.59\), 곧 \(Z_0 = 76.7\) Ω에서 최소이고, 절연 파괴 전기장으로 정한 최대 전력 \(\propto a^2\ln(b/a)\)는 \(b/a = 1.65\), \(Z_0 = 30\) Ω에서 최대다. 두 값 사이의 절충이 50 Ω이다(산술 평균 53, 기하 평균 48). 폴리에틸렌(\(\varepsilon_r = 2.25\))을 채우면 손실 최소점이 76.7/1.5 = 51 Ω으로 내려온다는 점도 한몫했다. 전력이 아닌 신호만 보내는 케이블 TV는 손실 최소에 가까운 75 Ω을 쓴다. 전송선의 시간 영역 이야기 — 계단파의 반사, 바운스, TDR, 누화 — 는 13장에서 이어진다.

핵심 정리

  1. 선 길이가 λ/10을 넘으면 분포 정수 모형이 필요하다. 단위 길이 \(R, L, G, C\)의 사다리에서 전신 방정식 \(-dV/dz = (R + j\omega L)I\), \(-dI/dz = (G + j\omega C)V\)와 파동 해 \(V = V_0^+e^{-\gamma z} + V_0^-e^{\gamma z}\)가 나온다.
  2. \(Z_0 = \sqrt{(R + j\omega L)/(G + j\omega C)}\), \(\gamma = \alpha + j\beta = \sqrt{(R + j\omega L)(G + j\omega C)}\). 무손실이면 \(Z_0 = \sqrt{L/C}\), \(v_p = 1/\sqrt{LC} = c/\sqrt{\varepsilon_r}\). 저손실 \(\alpha \approx R/2Z_0 + GZ_0/2\), 무왜곡 조건 \(R/L = G/C\). 동축 \(Z_0 = (60/\sqrt{\varepsilon_r})\ln(b/a)\).
  3. \(\Gamma_L = (Z_L - Z_0)/(Z_L + Z_0)\), \(\Gamma(d) = \Gamma_Le^{-j2\beta d}\). VSWR \(S = (1 + |\Gamma|)/(1 - |\Gamma|)\), 최대·최소는 λ/4 간격, 무늬는 λ/2 주기. 부하 전력 비율 \(1 - |\Gamma|^2\), 반사 손실 \(-20\log|\Gamma|\).
  4. \(Z_{in} = Z_0(Z_L + jZ_0\tan\beta\ell)/(Z_0 + jZ_L\tan\beta\ell)\). 단락 \(jZ_0\tan\beta\ell\), 개방 \(-jZ_0\cot\beta\ell\)(스터브 = L 또는 C), λ/4 반전 \(Z_0^2/Z_L\), λ/2 반복. \(Z_0 = \sqrt{Z_{sc}Z_{oc}}\). 긴 손실 선은 \(Z_0\)으로 보인다.
  5. 스미스 차트는 \(z\)를 \(\Gamma = (z - 1)/(z + 1)\)로 단위 원에 그린 지도다. 발전기 쪽 이동 = 시계 방향 회전(λ/2에 한 바퀴), VSWR 원의 오른쪽 교점 = \(S\), 어드미턴스 = 180° 회전.
  6. 정합: L 회로(직렬 소자는 \(r\) 원, 병렬 소자는 \(g\) 원을 따라 이동, \(R_L\)과 \(Z_0\)의 대소로 순서 결정), 단일 스터브(\(g = 1\) 원까지 \(d\) 이동 후 \(-jb\) 상쇄), λ/4 변성기 \(Z_1 = \sqrt{Z_0R_L}\)(부하 비가 클수록 대역 좁음, 다단으로 확장).
  7. 플라스마 부하는 "작은 \(R_p\) + 시스 커패시턴스"다. L형 정합기의 직렬 tune(\(C_T\) + \(L_s\))이 실수부를, 병렬 load(\(C_L\))가 허수부를 맞추어 13.56 MHz에서 50 Ω을 만든다. 낮은 \(R_p\)일수록 정합이 예민하고, 자동 정합기가 레시피 단계마다 따라간다. 50 Ω은 손실 최소(77 Ω)와 전력 최대(30 Ω)의 절충이다.

연습문제

\(\varepsilon_0 = 8.854\times10^{-12}\) F/m, \(\mu_0 = 4\pi\times10^{-7}\) H/m, \(c = 2.998\times10^8\) m/s, \(\eta_0 = 376.7\) Ω. 따로 말이 없으면 선은 무손실이고 \(Z_0 = 50\) Ω이다. 답이 ±1% 이내면 정답이다.

안 도체 반지름 0.50 mm, 바깥 도체 안 반지름 1.75 mm, PTFE(\(\varepsilon_r = 2.1\)) 절연 동축 케이블의 특성 임피던스는?

\(Z_0 = \dfrac{\eta_0}{2\pi\sqrt{\varepsilon_r}}\ln\dfrac ba = \dfrac{376.7}{2\pi(1.449)}\ln 3.5 = 41.37\times1.2528 = 51.8\) Ω(\(60/\sqrt{\varepsilon_r}\) 근사로도 51.9 Ω).

단위 길이 인덕턴스 300 nH/m, 정전 용량 120 pF/m인 무손실 선의 특성 임피던스와 위상 속도는?

\(Z_0 = \sqrt{300\times10^{-9}/120\times10^{-12}} = \sqrt{2500} = 50\) Ω. \(v_p = 1/\sqrt{LC} = 1/\sqrt{3.6\times10^{-17}} = 1.67\times10^8\) m/s(\(\varepsilon_r = 3.24\)에 해당).

50 Ω 선에 75 Ω 부하(비디오 장비 입력)를 연결했다. 반사 계수, VSWR, 반사 손실은?

\(\Gamma = (75 - 50)/(75 + 50) = 0.2\), \(S = 1.2/0.8 = 1.5\), RL \(= -20\log 0.2 = 13.98\) dB.

RF 발전기가 정방향 100 W를 보내는데 케이블에서 잰 VSWR이 2.0이다. 반사 전력과 반사 손실은?

\(|\Gamma| = (S - 1)/(S + 1)\).

\(|\Gamma| = 1/3\). \(P_r = |\Gamma|^2P_f = 100/9 = 11.1\) W. RL \(= -20\log(1/3) = 9.54\) dB. 부하에는 88.9 W가 들어간다.

길이 λ/8인 50 Ω 단락 스터브의 입력 리액턴스는(유도성을 양수로)?

\(Z_{in} = jZ_0\tan(\pi/4) = j50\) Ω. \(X_{in} = +50\) Ω(인덕터).

λ/4 길이의 50 Ω 선 끝에 20 Ω 저항이 달려 있다. 입력 임피던스는?

\(Z_{in} = Z_0^2/Z_L = 2500/20 = 125\) Ω.

무손실 선 한 토막의 입력 임피던스를 쟀더니 끝을 단락했을 때 \(j40\) Ω, 개방했을 때 \(-j62.5\) Ω이었다. 특성 임피던스와 전기적 길이 \(\beta\ell\)(도, 0–90° 사이)는?

\(Z_0 = \sqrt{Z_{sc}Z_{oc}}\), \(\tan\beta\ell = \sqrt{-Z_{sc}/Z_{oc}}\).

\(Z_{sc}Z_{oc} = (j40)(-j62.5) = 2500\) → \(Z_0 = 50\) Ω. \(\tan\beta\ell = \sqrt{40/62.5} = 0.8\) → \(\beta\ell = 38.7°\)(0.107λ).

50 Ω 선에서 VSWR이 3.0, 부하에서 가장 가까운 전압 최소점이 \(0.10\lambda\)에 있다. 부하 임피던스 \(R_L + jX_L\)은?

\(z_L = (1 - jS\tan\beta d_{min})/(S - j\tan\beta d_{min})\), \(\beta d_{min} = 36°\).

\(t = \tan 36° = 0.7265\). \(z_L = \dfrac{1 - j2.180}{3 - j0.7265} = 0.481 - j0.610\). \(Z_L = 24.1 - j30.5\) Ω. 확인: \(|\Gamma_L| = 0.5\) → \(S = 3\) ✓. 스미스 차트에서는 최소점 \(\Gamma = -0.5\)에서 부하 쪽(반시계)으로 72° 돌린 점이다.

2.4 GHz에서 12.5 Ω 부하를 50 Ω 마이크로스트립에 λ/4 변성기로 정합한다. 변성기 선의 특성 임피던스와 길이는? 변성기 선의 유효 유전율은 3.0이다.

\(Z_1 = \sqrt{50\times12.5} = 25\) Ω. \(\lambda = c/(f\sqrt{\varepsilon_{\text{eff}}}) = 2.998\times10^8/(2.4\times10^9\times1.732) = 72.1\) mm, \(\ell = \lambda/4 = 18.0\) mm.

50 Ω 선에 100 Ω 부하가 있다. 병렬 단락 스터브로 정합할 때 부하에 가장 가까운 해의 스터브 위치 \(d\)와 스터브 길이 \(\ell\)(파장 단위)은?

\(y_L = 0.5\). 선을 따라가며 \(y(d) = 1 + jb\)인 곳을 찾는다: \(\tan\beta d = \pm\sqrt{2}\)(부하 \(R_L\)이 실수이면 \(\tan\beta d = \sqrt{R_L/Z_0}\)).

\(\tan\beta d = \sqrt{2}\) → \(\beta d = 54.7°\) → \(d = 0.152\lambda\). 그곳에서 \(y = 1 + j0.707\). 스터브는 \(-j0.707\)을 내야 한다: \(-j\cot\beta\ell = -j0.707\) → \(\tan\beta\ell = 1.414\) → \(\ell = 0.152\lambda\). (둘째 해: \(d = 0.348\lambda\), \(\ell = 0.348\lambda\).)

100 MHz에서 10 Ω 저항 부하를 50 Ω에 정합한다. 부하에 직렬 인덕터, 그다음 발전기 쪽에 병렬 커패시터를 다는 L 회로의 소자 값은?

\(R_L < Z_0\): \(X = \sqrt{10\times40} = 20\) Ω → \(L = 20/(2\pi\times10^8) = 31.8\) nH. \(B = \sqrt{40/10}/50 = 0.04\) S → \(C = 0.04/(2\pi\times10^8) = 63.7\) pF. 확인: \(1/(10 + j20) = 0.02 - j0.04\), \(+j0.04\) → 0.02 S = 1/50 ✓.

13.56 MHz에서 플라스마 부하가 \(3 - j60\) Ω이다. L형 정합기(부하 쪽 직렬 리액턴스, 발전기 쪽 병렬 콘덴서)에서 부하에 직렬로 더해야 할 리액턴스(유도성 해)와 병렬 load 콘덴서의 용량은?

직렬 가지 전체의 리액턴스는 \(+\sqrt{R(Z_0 - R)}\)이어야 한다.

\(X_s = \sqrt{3\times47} = 11.87\) Ω이 되어야 하므로 더할 리액턴스는 \(11.87 - (-60) = 71.9\) Ω. \(B = \sqrt{47/3}/50 = 0.0792\) S, \(C_L = B/\omega = 0.0792/(8.520\times10^7) = 929\) pF. 예제(5 Ω, 704 pF)보다 \(R_p\)가 작으니 더 큰 \(C_L\)이 필요하다.

손실이 1.0 dB인 케이블 끝을 단락하고 입구에서 반사를 쟀다. 입구에서 보이는 반사 계수 크기와 반사 손실은?

반사파는 케이블을 왕복하므로 2 dB 줄어든다. RL = 2 dB, \(|\Gamma_{in}| = 10^{-2/20} = 0.794\). 완전 반사인 단락이 "꽤 정합된 것처럼" 보이는 이유다. 부하 측정은 케이블 손실을 보정(교정)한 뒤 해야 한다.

스미스 차트에서 부하 점을 찍은 뒤 선을 따라 발전기 쪽으로 λ/8만큼 이동했다. 점은 어떻게 움직이나?

\(\Gamma(d) = \Gamma_Le^{-j2\beta d}\), \(2\beta d = 4\pi(1/8) = \pi/2\). 크기는 그대로, 시계 방향 90°. 한 바퀴는 λ/2다.

RF 시스템 표준 임피던스가 50 Ω이 된 이유로 가장 알맞은 것은?

TEM 선의 위상 속도는 \(c/\sqrt{\varepsilon_r}\)로 \(Z_0\)과 무관하다. 손실과 전력 용량이 \(b/a\)에 따라 반대로 움직여 그 사이 값이 표준이 되었다. 반사가 0인 것은 "부하 = 선의 \(Z_0\)"일 때일 뿐 50이라는 숫자 자체와는 관계없다.

개념 확인 퀴즈

같은 PCB 배선이 1 MHz에서는 그냥 도선이지만 5 GHz에서는 전송선으로 다뤄야 하는 이유는?

단위 길이 \(L\), \(C\)는 주파수와 거의 무관하다. 바뀌는 것은 파장 대비 길이다. 5 GHz, \(\varepsilon_{\text{eff}} = 3\)이면 파장이 3.5 cm라 몇 mm 배선부터 위상 차가 무시할 수 없게 된다.

끝이 개방된 무손실 선의 부하 위치에서 옳은 것은?

\(\Gamma = +1\)이라 반사 전압파가 입사파와 같은 위상으로 더해지고, 전류는 부호가 반대라 상쇄된다. 개방 끝에서 전류가 흐를 곳이 없다는 경계 조건 그대로다.

VSWR 측정값이 무한대에 가까웠다. 이 부하에 대해 말할 수 있는 것은?

\(|\Gamma| = 1\)이면 \(S = \infty\)이고 \(1 - |\Gamma|^2 = 0\)이다. 어느 것인지는 최소점의 위치(\(d_{min}\))를 봐야 안다. 손실이 큰 선은 오히려 VSWR을 작게 보이게 한다.

길이 λ/2인 선을 부하와 측정기 사이에 끼워도 측정되는 임피던스가 변하지 않는다. 그런데 주파수를 10% 올리면?

λ/2 반복은 한 주파수에서만 성립한다. 전기적 길이 \(\beta\ell\)이 주파수에 비례하기 때문이다. λ/4 변성기의 대역폭이 유한한 것도 같은 이유다. 정합 부하(\(Z_L = Z_0\))만 길이·주파수와 무관하다.

플라스마 식각기의 정합기가 레시피 단계가 바뀔 때마다 콘덴서를 다시 움직이는 근본 이유는?

발전기와 케이블은 50 Ω으로 고정이다. 바뀌는 것은 챔버 안 부하다. 정합 회로는 한 부하에 대해서만 \(\Gamma = 0\)을 만들므로 부하가 바뀌면 다시 맞춰야 한다. 주파수 튜닝 발전기는 콘덴서 대신 주파수를 조금 바꿔 같은 일을 한다.
