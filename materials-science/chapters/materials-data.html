재료 물성 자료와 계산기

본문 18개 장에서 쓴 재료 자료·계산·공식을 한곳에 모았다. 표는 이 책의 계산 엔진 Mat.*에 들어 있는 자료를 페이지를 열 때 그대로 읽어 그린 것이라, 본문 시뮬레이터·예제와 같은 숫자를 낸다. 물성 표는 검색·정렬·분류 필터가 되고, 줄을 누르면 두 재료 비교기에 들어간다. 성질 지도는 두 축을 골라 그리고, 선택선을 끌어 성능 지수로 재료를 거른다. 이어지는 계산기는 이론 밀도부터 셰러 결정립 크기까지 학부 시험과 현장에서 자주 하는 계산을 한 칸씩 맡는다. 값은 Callister·Ashby·ASM·CRC 핸드북 수준의 상온 대표값이다. 같은 재료라도 조성·열처리·결정립·두께에 따라 수 %에서 몇 배까지 달라지고, 특히 박막은 공정에 따라 크게 다르다. 문제를 풀 때는 문제에 주어진 값을 먼저 쓰고, 없을 때 이 표를 쓴다.

  • 응력·파괴 인성·저항률·열팽창·열전도·활성화 에너지 단위를 바로 바꾸고, wt%와 at%를 오간다.
  • 물성 표에서 밀도·탄성률·강도·파괴 인성·열팽창·열전도·저항률·유전율을 찾고 정렬하며, 두 재료를 성질별 배수로 비교하고, 성질 지도에서 성능 지수 선으로 후보를 거른다.
  • 금속 결정·이온 반지름·입방정 탄성 상수·확산·홀–페치·배선 금속·필링–베드워스·유리 점도·셀마이어·압전·특성 X선·XPS 결합 에너지·상태도 핵심 점을 표에서 찾는다.
  • 이론 밀도, 공공 농도, D(T)와 확산 거리, 탄성 상수 변환, 주응력·폰 미제스, 스토니 휨, 열응력, 홀–페치·테일러, 임계 균열, 와이블 크기 효과, 파리스 수명, 라슨–밀러, 지렛대 규칙, JMAK, 혼합 법칙, EOT, 블랙 가속 계수, 셰러 크기를 계산기로 구하고 손 계산과 맞춰 본다.
  • 장별 공식 모음에서 식을 찾고, 그 식을 유도한 본문 절로 바로 간다.

자료표·계산기 활용 연습

필요한 값은 모두 이 부록의 표와 계산기에 있다. 문제에 값이 주어지면 그 값을 쓴다. 손으로 푼 뒤 해당 계산기에 넣어 같은 답이 나오는지 확인하자. \(R = 8.314\) J/(mol·K), \(k = 8.617\times10^{-5}\) eV/K, \(N_\mathrm A = 6.022\times10^{23}\) mol⁻¹. 따로 말이 없으면 답이 ±1 % 이내면 정답이다.

물성 표의 E와 ρ로 비강성 \(E/\rho\)를 비교하라. 다음 중 \(E/\rho\)가 가장 큰 것은?

\(E/\rho\)[GPa/(g/cm³)]: Al 6061 69/2.70 = 25.6, Ti-6Al-4V 114/4.43 = 25.7, 4340 207/7.85 = 26.4, Si 165/2.329 = 70.8. 흔한 구조용 금속 셋은 비강성이 거의 같다(약 26) — 가벼운 금속은 탄성률도 그만큼 작다. 공유 결합 세라믹·반도체가 비강성에서 한 단계 위에 있다. 성질 지도(가로 ρ, 세로 E, 기울기 1)에서 확인할 수 있다.

구리(FCC, R = 0.1278 nm, A = 63.55 g/mol)의 이론 밀도를 구하라.

FCC는 단위정에 원자 4개, \(a = 2\sqrt2R\).

\(a = 2\sqrt2(0.1278) = 0.3615\) nm, \(V_\mathrm C = a^3 = 4.724\times10^{-23}\) cm³. \(\rho = \dfrac{4\times63.55}{4.724\times10^{-23}\times6.022\times10^{23}} = 8.94\) g/cm³. 실측 8.96과 0.3 % 차이다(이론 밀도 계산기, 금속 결정 표).

1000 °C 구리의 평형 공공 밀도를 구하라. \(Q_\mathrm v = 0.90\) eV, 1000 °C의 밀도 8.40 g/cm³, A = 63.5 g/mol, 엔트로피 항은 무시한다.

\(N = N_\mathrm A\rho/A\)를 m⁻³으로(1 cm³ = 10⁻⁶ m³).

\(N = \dfrac{6.022\times10^{23}\times8.40}{63.5}\times10^6 = 7.97\times10^{28}\) m⁻³. \(kT = 8.617\times10^{-5}\times1273.15 = 0.1097\) eV, \(N_\mathrm v/N = e^{-0.90/0.1097} = 2.74\times10^{-4}\). \(N_\mathrm v = 2.18\times10^{25}\) m⁻³(캘리스터 예제 4.1).

0.20 wt% C 강을 1000 °C에서 표면 농도 1.20 wt% C로 10 h 침탄한다. 확산 자료표의 C in γ-Fe 값으로 \(D\)를 구하고, 깊이 0.5 mm의 탄소 농도를 구하라.

\(D_0 = 2.3\times10^{-5}\) m²/s, \(Q_\mathrm d = 148\) kJ/mol. \(\dfrac{C_x - C_0}{C_\mathrm s - C_0} = 1 - \operatorname{erf}\dfrac{x}{2\sqrt{Dt}}\).

\(D = 2.3\times10^{-5}\exp\!\left(-\dfrac{148000}{8.314\times1273.15}\right) = 1.95\times10^{-11}\) m²/s. \(\sqrt{Dt} = \sqrt{1.95\times10^{-11}\times36000} = 8.38\times10^{-4}\) m, \(z = \dfrac{0.5\times10^{-3}}{2\times8.38\times10^{-4}} = 0.298\), \(\operatorname{erf}(0.298) = 0.327\). \(C = 0.20 + 1.00\times(1 - 0.327) = 0.873\) wt% C.

구리의 E = 110 GPa, ν = 0.34에서 전단 탄성률 G와 체적 탄성률 K를 구하라.

\(G = \dfrac{110}{2(1.34)} = 41.0\) GPa, \(K = \dfrac{110}{3(1 - 0.68)} = \dfrac{110}{0.96} = 115\) GPa. 탄성 상수 변환 계산기에서 "G, K"로 되돌려 넣으면 E, ν가 돌아온다.

평면 응력 \(\sigma_x = 120\), \(\sigma_y = -40\), \(\tau_{xy} = 50\) MPa(σz = 0)에서 주응력 σ₁, σ₂와 폰 미제스 등가 응력을 구하라. Al 6061-T6(σy = 276 MPa)이면 안전 계수는 얼마인가(서술)?

중심 \(c = 40\), 반지름 \(R = \sqrt{80^2 + 50^2} = 94.34\). σ₁ = 134.3, σ₂ = −54.3 MPa. \(\sigma_\text{VM} = \sqrt{\sigma_1^2 - \sigma_1\sigma_2 + \sigma_2^2} = \sqrt{18047 + 7300 + 2953} = 168\) MPa. 안전 계수 276/168 = 1.64. 주축 각 \(\theta_\mathrm p = \tfrac12\tan^{-1}(100/160) = 16.0°\).

지름 300 mm, 두께 775 µm인 Si(100) 웨이퍼에 500 nm 막을 증착했더니 막 쪽이 오목하게 휨 높이 30 µm가 생겼다. 이축 탄성률 \(E_\mathrm s/(1-\nu_\mathrm s) = 180.3\) GPa로 막 응력을 구하라(인장 +).

\(\kappa = 8\delta/D^2\).

\(\kappa = 8(30\times10^{-6})/0.3^2 = 2.667\times10^{-3}\) m⁻¹ (R = 375 m). \(\sigma_\mathrm f = \dfrac{180.3\times10^3\times(775\times10^{-6})^2\times2.667\times10^{-3}}{6\times500\times10^{-9}} = 96.3\) MPa. 막 쪽이 오목하므로 인장이다.

400 °C에서 무응력으로 증착한 구리 막을 Si 기판 위에서 25 °C로 식혔다. 물성 표의 값(Cu: E = 110 GPa, ν = 0.34, α = 17.0 ppm/K; Si: α = 2.6 ppm/K)으로 막의 탄성 열응력을 구하라. 이 값이 실제로 남을 수 있는가(서술)?

\(\sigma_\mathrm f = \dfrac{110\times10^3}{1 - 0.34}(2.6 - 17.0)\times10^{-6}\times(25 - 400) = 166667\times(-14.4\times10^{-6})\times(-375) = +900\) MPa(인장). 괴상 구리의 항복 강도(69 MPa)는 물론 박막 구리의 항복 강도(수백 MPa)보다도 커서, 식는 도중 소성 변형으로 응력이 풀린다. 실측 상온 응력은 보통 수백 MPa 인장이다.

홀–페치 표의 α-Fe 계수(σ₀ = 70 MPa, k = 0.74 MPa·√m)로 결정립 10 µm의 항복 강도를 구하고, 항복 강도 400 MPa에 필요한 결정립 크기를 구하라.

\(\sigma_\mathrm y = 70 + 0.74/\sqrt{10^{-5}} = 70 + 234 = 304\) MPa. \(d = \left(\dfrac{0.74}{400 - 70}\right)^2 = (2.242\times10^{-3})^2 = 5.03\times10^{-6}\) m = 5.03 µm.

알루미나(물성 표의 KIC)에 가장자리 균열(Y = 1.12)이 있다. 인장 200 MPa에서 임계 균열 깊이를 구하고, 균열 깊이가 20 µm이면 파괴 응력이 얼마인지 구하라.

\(K_\mathrm{IC} = 4.2\) MPa·√m. \(a_\mathrm c = \dfrac1\pi\left(\dfrac{4.2}{1.12\times200}\right)^2 = \dfrac{(0.01875)^2}{\pi} = 1.12\times10^{-4}\) m = 112 µm. \(\sigma_\mathrm f = \dfrac{4.2}{1.12\sqrt{\pi\times20\times10^{-6}}} = 473\) MPa.

와이블 계수 m = 10인 세라믹 막대 시편의 중앙 강도가 400 MPa였다. 응력이 걸리는 부피가 1000배인 부품의 같은 파괴 확률 강도는?

\(\sigma_2 = \sigma_1(V_1/V_2)^{1/m} = 400\times1000^{-0.1} = 400\times0.501 = 200\) MPa. 큰 부품일수록 큰 결함을 품을 확률이 커서 강도가 떨어진다(와이블 미니 실험).

강판(C = 10⁻¹² m/cycle·(MPa·√m)⁻³, m = 3, Y = 1)에 Δσ = 100 MPa가 반복된다. 임계 균열 ac = 10 mm일 때 초기 균열 1 mm와 0.5 mm의 피로 수명을 각각 구하라.

\(m = 3\)이면 \(N_\mathrm f = \dfrac{2(a_0^{-1/2} - a_\mathrm c^{-1/2})}{C(Y\Delta\sigma\sqrt\pi)^3}\).

\(C(Y\Delta\sigma\sqrt\pi)^3 = 10^{-12}\times(177.2)^3 = 5.568\times10^{-6}\). a₀ = 1 mm: \(2(31.62 - 10.00)/5.568\times10^{-6} = 7.77\times10^6\). a₀ = 0.5 mm: \(2(44.72 - 10.00)/5.568\times10^{-6} = 1.25\times10^7\). 검출 한계를 절반으로 줄이면 수명이 61 % 는다 — 수명 대부분을 균열이 작을 때 쓰기 때문이다.

Pb–40 wt% Sn 합금에 대해 (가) 150 °C에서 α상의 질량 분율(α 11 wt% Sn, β 99 wt% Sn)과 (나) 공정 온도 바로 아래에서 초정 α의 질량 분율(α 최대 고용 18.3, 공정 61.9 wt% Sn)을 구하라.

(가) \(W_\alpha = \dfrac{99 - 40}{99 - 11} = 0.670\). (나) \(W_\text{초정}\alpha = \dfrac{61.9 - 40}{61.9 - 18.3} = 0.502\), 공정 조직은 0.498. 지렛대 규칙 계산기에서 상태점을 (40, 150)과 (40, 184)에 놓고 확인한다.

구리 배선 일렉트로마이그레이션 시험을 2 MA/cm², 250 °C에서 했더니 MTTF가 200 h였다. 사용 조건 1 MA/cm², 105 °C에서 블랙 식(n = 2, Ea = 0.85 eV)으로 가속 계수와 사용 MTTF(년, 1년 = 8766 h)를 구하라.

전류 항 \(2^2 = 4\). 온도 항 \(\exp\!\left[\dfrac{0.85}{8.617\times10^{-5}}\left(\dfrac1{378.15} - \dfrac1{523.15}\right)\right] = \exp(9.864\times10^3\times7.330\times10^{-4}) = e^{7.230} = 1380\). AF = 5520, 사용 MTTF = 200 × 5520 = 1.10 × 10⁶ h = 126년. \(E_\mathrm a\)가 0.1 eV 크면 AF가 2.3배 커진다 — 외삽은 \(E_\mathrm a\) 추정에 민감하다.
