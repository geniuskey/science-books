Chapter 08

각운동량

현대물리학에서는 수소 원자를 풀다가 각운동량이 \(L^2 = l(l+1)\hbar^2\), \(L_z = m\hbar\)로 양자화된다는 사실을 미분 방정식의 경계 조건에서 얻었다. 이 장은 같은 결과를 교환 관계 세 줄에서 다시 얻는다. 미분 방정식을 하나도 풀지 않고 사다리 연산자만으로 고유값이 나오고, 그 대수가 곧 회전의 대수라는 것을 보게 된다. 아래 곡면은 구면 조화 함수 \(Y_l^m\)이다. 중심에서의 거리가 \(|Y_l^m|\), 색이 복소 위상이다. \(m \ne 0\)이면 색이 \(z\)축 둘레를 \(m\)번 감는다 — 그것이 \(L_z = m\hbar\)의 모습이다.

끌어서 돌려 보세요
  • \(\hat{\mathbf L} = \hat{\mathbf r}\times\hat{\mathbf p}\)에서 교환 관계 \([\hat L_i, \hat L_j] = i\hbar\,\varepsilon_{ijk}\hat L_k\), \([\hat L^2, \hat L_i] = 0\)을 유도하고, 각운동량 성분 사이의 불확정성 관계를 계산한다.
  • 사다리 연산자 \(\hat J_\pm\)만으로 \(\hat J^2\), \(\hat J_z\)의 고유값 \(j(j+1)\hbar^2\), \(m\hbar\)와 \(2j\)가 정수라는 조건, 행렬 원소 \(\hbar\sqrt{j(j+1)-m(m\pm1)}\)을 얻는다.
  • 구면 조화 함수를 \(\hat L_+ Y_l^l = 0\)과 \(\hat L_-\)로 만들고, 직교성·패리티·실수 오비탈(\(p_x\), \(d_{xy}\) …)과의 관계를 쓴다.
  • 벡터 모형으로 \(|\mathbf L|\), \(L_z\), \(\langle L_x^2\rangle\)를 해석하고, 임의의 축으로 각운동량을 잴 때의 확률 \(|d^{\,l}_{m'm}(\theta)|^2\)을 계산한다.
  • 회전 연산자 \(e^{-i\alpha\,\hat{\mathbf n}\cdot\hat{\mathbf J}/\hbar}\)와 위그너 \(D\)·\(d\) 행렬로 상태와 오비탈을 돌린다.
  • 강체 회전자 \(E_J = hcBJ(J+1)\)로 이원자 분자의 회전 스펙트럼(선 간격 \(2B\))과 온도에 따른 선 세기를 계산하고, 스펙트럼에서 결합 길이와 회전 온도를 구한다.

궤도 각운동량 연산자와 교환 관계

고전 역학의 각운동량은 \(\mathbf L = \mathbf r\times\mathbf p\)이다. 양자역학에서는 위치와 운동량을 연산자로 바꾸면 된다. 곱의 순서가 걱정되지만 \(\hat L_x = \hat y\hat p_z - \hat z\hat p_y\)에서 \(\hat y\)와 \(\hat p_z\)는 서로 다른 좌표라 교환하므로 순서는 문제가 되지 않고, 세 성분 모두 에르미트 연산자다.

$$\hat L_x = \hat y\hat p_z - \hat z\hat p_y,\qquad \hat L_y = \hat z\hat p_x - \hat x\hat p_z,\qquad \hat L_z = \hat x\hat p_y - \hat y\hat p_x$$
이것이 궤도 각운동량(orbital angular momentum) 연산자다. 위치 표현에서는 \(\hat p_x = -i\hbar\,\partial/\partial x\) 등을 넣는다. 기본 재료는 정준 교환 관계 \([\hat x_i, \hat p_j] = i\hbar\,\delta_{ij}\) 하나뿐이다.

세 성분의 교환자를 계산해 보자(예제 8.1). 결과는 놀랄 만큼 간단하다.

$$[\hat L_x, \hat L_y] = i\hbar\hat L_z,\quad [\hat L_y, \hat L_z] = i\hbar\hat L_x,\quad [\hat L_z, \hat L_x] = i\hbar\hat L_y \;\;\Longleftrightarrow\;\; [\hat L_i, \hat L_j] = i\hbar\,\varepsilon_{ijk}\hat L_k$$
\(\varepsilon_{ijk}\)는 레비-치비타 기호(\(xyz\)의 짝순열 +1, 홀순열 −1, 같은 지표가 있으면 0). 이 세 식을 각운동량의 교환 관계(commutation relations)라 부른다. 같은 방법으로 \([\hat L_i, \hat x_j] = i\hbar\,\varepsilon_{ijk}\hat x_k\), \([\hat L_i, \hat p_j] = i\hbar\,\varepsilon_{ijk}\hat p_k\)도 나온다 — \(\hat{\mathbf r}\), \(\hat{\mathbf p}\)처럼 이 꼴의 교환 관계를 따르는 것을 벡터 연산자(vector operator)라 한다.

성분끼리는 교환하지 않지만 크기의 제곱 \(\hat L^2 = \hat L_x^2 + \hat L_y^2 + \hat L_z^2\)은 모든 성분과 교환한다. 예를 들어 \([\hat L^2, \hat L_z] = [\hat L_x^2, \hat L_z] + [\hat L_y^2, \hat L_z] = -i\hbar(\hat L_x\hat L_y + \hat L_y\hat L_x) + i\hbar(\hat L_y\hat L_x + \hat L_x\hat L_y) = 0\).

$$[\hat L^2, \hat L_x] = [\hat L^2, \hat L_y] = [\hat L^2, \hat L_z] = 0, \qquad \Delta L_x\,\Delta L_y \ge \frac{\hbar}{2}\,\bigl|\langle \hat L_z\rangle\bigr|$$
둘째 식은 3장의 로버트슨 불확정성 관계 \(\Delta A\,\Delta B \ge \tfrac12|\langle[\hat A,\hat B]\rangle|\)에 교환 관계를 넣은 것이다. 결론: \(\hat L^2\)과 한 성분(관례상 \(\hat L_z\))은 동시에 정해진 값을 가질 수 있지만, 두 성분은 \(\langle\hat L_z\rangle = 0\)인 특별한 경우가 아니면 동시에 정해질 수 없다. 우리가 쓰는 기저 \(|l\,m\rangle\)은 \(\hat L^2\)과 \(\hat L_z\)의 동시 고유 상태다.

정준 교환 관계 \([\hat x_i, \hat p_j] = i\hbar\delta_{ij}\)만 써서 \([\hat L_x, \hat L_y] = i\hbar\hat L_z\)를 보여라.

풀이 보기
전략 정의를 넣어 네 항으로 펼치고, 교환하지 않는 짝(같은 좌표의 위치와 운동량)이 있는 항만 남긴다. 교환자의 곱 규칙 \([\hat A, \hat B\hat C] = [\hat A,\hat B]\hat C + \hat B[\hat A,\hat C]\)을 쓴다.
풀이 \([\hat L_x,\hat L_y] = [\hat y\hat p_z - \hat z\hat p_y,\; \hat z\hat p_x - \hat x\hat p_z] = [\hat y\hat p_z, \hat z\hat p_x] - [\hat y\hat p_z, \hat x\hat p_z] - [\hat z\hat p_y, \hat z\hat p_x] + [\hat z\hat p_y, \hat x\hat p_z]\). 가운데 두 항은 공통 좌표가 없거나(\(\hat y, \hat p_z, \hat x\)) 같은 좌표끼리만 있어(\(\hat z, \hat p_y, \hat p_x\)) 0이다. 첫 항: \(\hat y\,[\hat p_z, \hat z]\,\hat p_x = \hat y(-i\hbar)\hat p_x\). 넷째 항: \(\hat x\,[\hat z, \hat p_z]\,\hat p_y = \hat x(i\hbar)\hat p_y\). 합: \(i\hbar(\hat x\hat p_y - \hat y\hat p_x) = i\hbar\hat L_z\).
\([\hat L_x, \hat L_y] = i\hbar\hat L_z\) (나머지 둘은 \(x\to y\to z\to x\) 순환 치환)
검토 고전 역학의 푸아송 괄호 \(\{L_x, L_y\} = L_z\)에 \(i\hbar\)를 곱한 꼴이다(디랙의 대응 규칙). 단위도 맞다: 좌변은 (J·s)², 우변은 J·s × J·s.

\(\hat L_z\)는 \(z\)축 둘레의 방위각 \(\phi\)로 쓰면 가장 간단하다. 구면 좌표로 바꾸면 \(\hat L_z = -i\hbar\,\partial/\partial\phi\)이고, \(\hat L^2\)은 라플라시안의 각도 부분이다(9장에서 \(\nabla^2 = \text{지름 부분} - \hat L^2/\hbar^2 r^2\)으로 쓴다).

$$\hat L_z = -i\hbar\frac{\partial}{\partial\phi}, \qquad \hat L^2 = -\hbar^2\left[\frac{1}{\sin\theta}\frac{\partial}{\partial\theta}\left(\sin\theta\frac{\partial}{\partial\theta}\right) + \frac{1}{\sin^2\theta}\frac{\partial^2}{\partial\phi^2}\right]$$
\(\hat L_z\)의 고유함수는 \(\Phi_m(\phi) = e^{im\phi}/\sqrt{2\pi}\), 고유값 \(m\hbar\). \(\phi\)와 \(\phi+2\pi\)는 같은 점이므로 \(m\)은 정수다. 고리 위의 입자(2차원 회전자) \(\hat H = \hat L_z^2/2I\)의 에너지는 \(m^2\hbar^2/2I\)로 \(\pm m\)이 축퇴한다.

그러면 성분 셋을 행렬로 직접 만들어 교환 관계를 눈으로 확인하자. 다음 절에서 유도할 공식으로 \(l\)마다 \((2l+1)\times(2l+1)\) 행렬 \(L_x, L_y, L_z\)를 만들 수 있다(\(\hbar = 1\) 단위, 기저 순서 \(m = l, l-1, \dots, -l\)).

\([\hat L^2, \hat L_x]\)는 무엇일까?

\(\hat L^2\)은 회전해도 바뀌지 않는 양(스칼라)이라 모든 성분과 교환한다. 계산기에서 A = \(L^2\), B = \(L_x\)로 놓으면 교환자 행렬이 0이다. 그래서 \(\hat L^2\)의 고유값 \(l\)은 어느 축을 고르든 같은 좋은 양자수다.

사다리 연산자로 구하는 고유값

이제 미분 방정식을 잊고 교환 관계만 믿어 보자. 아래 논증은 \([\hat J_i, \hat J_j] = i\hbar\varepsilon_{ijk}\hat J_k\)만 쓰므로, 궤도 각운동량이든 스핀이든 둘의 합이든 똑같이 성립한다. 그래서 일반 각운동량을 \(\hat{\mathbf J}\)로 쓴다. 6장에서 조화 진동자를 \(\hat a\), \(\hat a^\dagger\)로 푼 것과 같은 전략이다.

올림·내림 연산자

\(\hat J_\pm = \hat J_x \pm i\hat J_y\). 에르미트가 아니고 서로의 수반이다(\(\hat J_+^\dagger = \hat J_-\)). 교환 관계에서 곧바로 \([\hat J_z, \hat J_\pm] = \pm\hbar\hat J_\pm\), \([\hat J_+, \hat J_-] = 2\hbar\hat J_z\), \([\hat J^2, \hat J_\pm] = 0\), 그리고 \(\hat J_\mp\hat J_\pm = \hat J^2 - \hat J_z^2 \mp \hbar\hat J_z\)이 나온다. \(\hat J_+\)를 올림 연산자(raising operator), \(\hat J_-\)를 내림 연산자(lowering operator)라 한다.

\(\hat J^2\)과 \(\hat J_z\)의 동시 고유 상태를 \(|\lambda, m\rangle\) (\(\hat J^2 \to \lambda\hbar^2\), \(\hat J_z \to m\hbar\))이라 하자. 논증은 네 걸음이다.

  1. 사다리: \(\hat J_z(\hat J_+|\lambda,m\rangle) = (\hat J_+\hat J_z + \hbar\hat J_+)|\lambda,m\rangle = (m+1)\hbar\,\hat J_+|\lambda,m\rangle\). \(\hat J_+\)는 \(m\)을 1 올리고 \(\lambda\)는 그대로 둔다(\([\hat J^2, \hat J_+] = 0\)). \(\hat J_-\)는 1 내린다.
  2. 끝이 있다: \(\langle\hat J^2 - \hat J_z^2\rangle = \langle\hat J_x^2 + \hat J_y^2\rangle \ge 0\)이므로 \(m^2 \le \lambda\). 사다리는 위아래로 끝나야 한다. 맨 위 \(m_\text{max} \equiv j\)에서 \(\hat J_+|\lambda, j\rangle = 0\).
  3. λ 결정: 맨 위 상태에 \(\hat J_-\hat J_+ = \hat J^2 - \hat J_z^2 - \hbar\hat J_z\)를 걸면 \(0 = (\lambda - j^2 - j)\hbar^2\), 곧 \(\lambda = j(j+1)\). 같은 방법으로 맨 아래는 \(m_\text{min} = -j\).
  4. 양자화: \(-j\)에서 \(j\)까지 정수 걸음으로 가야 하므로 \(2j\)가 0 이상의 정수다: \(j = 0, \tfrac12, 1, \tfrac32, \dots\), \(m = -j, -j+1, \dots, j\) (\(2j+1\)개).
$$\hat J^2|j\,m\rangle = j(j+1)\hbar^2|j\,m\rangle,\qquad \hat J_z|j\,m\rangle = m\hbar|j\,m\rangle,\qquad \hat J_\pm|j\,m\rangle = \hbar\sqrt{j(j+1) - m(m\pm1)}\;|j\,m\pm1\rangle$$
계수는 노름에서 나온다: \(\|\hat J_\pm|j\,m\rangle\|^2 = \langle j\,m|\hat J_\mp\hat J_\pm|j\,m\rangle = \hbar^2[j(j+1) - m(m\pm1)]\). 위상은 관례(콘던–쇼틀리 위상(Condon–Shortley phase))로 양의 실수를 고른다. 같은 계수를 \(\hbar\sqrt{(j\mp m)(j\pm m+1)}\)로도 쓴다.

4단계의 "\(2j\)는 정수"가 정말 피할 수 없는 조건인지 손으로 확인하자. \(j\)를 아무 실수로 가정하고 맨 위 \(m = j\)에서 \(\hat J_-\)로 내려가면, \(k\)번째 걸음의 노름 제곱 인자 \((j+m)(j-m+1)\)이 언제 0이 되는지 본다.

행렬로 쓰면 \(\hat J_z\)는 대각, \(\hat J_\pm\)는 대각선 바로 위·아래에만 원소가 있다. 앞 절의 계산기는 이 공식으로 만든 것이다.

$$\langle j\,m'|\hat J_z|j\,m\rangle = m\hbar\,\delta_{m'm},\quad \langle j\,m'|\hat J_\pm|j\,m\rangle = \hbar\sqrt{j(j+1)-m(m\pm1)}\;\delta_{m',m\pm1},\quad \hat J_x = \tfrac12(\hat J_+ + \hat J_-),\; \hat J_y = \tfrac{1}{2i}(\hat J_+ - \hat J_-)$$

\(j = 1\)(기저 \(m = 1, 0, -1\))에서 \(J_+\), \(J_x\)를 행렬로 쓰고, \(J_x\)의 고유값과 고유값 \(+\hbar\)의 고유벡터를 구하라.

대수만으로는 \(j = \tfrac12, \tfrac32, \dots\)도 허용된다. 그러나 궤도 각운동량 \(\hat L_z = -i\hbar\,\partial_\phi\)의 고유함수 \(e^{im\phi}\)는 \(\phi\)에 대해 한 값이어야 하므로 \(m\), 따라서 \(l\)은 정수다. 반정수는 공간 속 파동함수의 모양이 아닌 내부 자유도, 곧 10장의 스핀에서만 나타난다. 이 장에서 \(j\)는 일반 대수, \(l\)은 궤도(정수)를 뜻한다.

벡터 모형과 각운동량의 측정

\(|l\,m\rangle\) 상태에서 각운동량의 크기는 \(\hbar\sqrt{l(l+1)}\)로 \(z\) 성분의 최댓값 \(l\hbar\)보다 언제나 크다. \(\hat L_x\)와 \(\hat L_y\)는 정해지지 않지만 그 통계는 사다리 연산자로 정확히 계산된다. \(\hat L_x = (\hat L_+ + \hat L_-)/2\)는 \(m\)을 바꾸므로 \(\langle l\,m|\hat L_x|l\,m\rangle = 0\)이고, \(\hat L_x^2 + \hat L_y^2 = \hat L^2 - \hat L_z^2\)와 \(x \leftrightarrow y\) 대칭에서 다음을 얻는다.

$$\langle\hat L_x\rangle = \langle\hat L_y\rangle = 0,\qquad \langle\hat L_x^2\rangle = \langle\hat L_y^2\rangle = \frac{\hbar^2}{2}\left[l(l+1) - m^2\right],\qquad \cos\theta_L = \frac{m}{\sqrt{l(l+1)}}$$
이것을 그림으로 그린 것이 벡터 모형(vector model)이다. 길이 \(\hbar\sqrt{l(l+1)}\)인 벡터가 \(z\)축과 각 \(\theta_L\)을 이루는 원뿔 위 어딘가에 있고, 옆 성분의 크기 \(\hbar\sqrt{l(l+1) - m^2}\)는 정해져 있지만 방향(방위각)은 완전히 불확정이다. 원뿔 둘레를 "도는" 그림은 비유일 뿐 실제 운동이 아니다 — 정상 상태에서는 아무것도 움직이지 않는다.

회전 연산자와 위그너 d 행렬

각운동량은 회전과 떼어 놓을 수 없다. 운동량 \(\hat p\)가 평행 이동 \(e^{-ia\hat p/\hbar}\)를 만들듯(7장), 각운동량은 회전을 만든다. 파동함수를 \(z\)축 둘레로 아주 작은 각 \(\varepsilon\)만큼 돌리면 새 함수는 \(\psi'(\mathbf r) = \psi(R^{-1}\mathbf r) = \psi(x + \varepsilon y,\, y - \varepsilon x,\, z) \approx \psi - \varepsilon(x\partial_y - y\partial_x)\psi = (1 - i\varepsilon\hat L_z/\hbar)\,\psi\)이다. 작은 회전을 거듭하면 지수 함수가 된다.

$$\hat R(\alpha, \hat{\mathbf n}) = \exp\!\left(-\frac{i\alpha\,\hat{\mathbf n}\cdot\hat{\mathbf J}}{\hbar}\right),\qquad \hat R_z(\alpha)\,Y_l^m = e^{-i\alpha\hat L_z/\hbar}\,Y_l^m = e^{-im\alpha}\,Y_l^m$$
\(\hat R\)을 회전 연산자(rotation operator), \(\hat{\mathbf J}\)를 회전의 생성자(generator)라 한다. \(\hat{\mathbf J}\)가 에르미트이므로 \(\hat R\)은 유니터리다. \(z\)축 둘레 회전은 \(Y_l^m\)에 위상 \(e^{-im\alpha}\)만 곱한다 — \(|Y_l^m|^2\)은 \(z\)축 둘레로 대칭이니 당연하다.

거꾸로, 교환 관계는 회전의 성질을 그대로 옮긴 것이다. \(x\)축 둘레 \(\varepsilon\), \(y\)축 둘레 \(\varepsilon\), 다시 거꾸로 \(-\varepsilon\), \(-\varepsilon\) 돌리면 처음으로 돌아오지 않고 \(z\)축 둘레로 \(\varepsilon^2\)만큼 돌아가 있다(책을 직접 돌려 보라). 이것을 생성자로 옮기면 정확히 \([\hat J_x, \hat J_y] = i\hbar\hat J_z\)다. 그래서 공간 회전에 반응하는 것은 무엇이든 — 궤도 운동이든 전자의 스핀이든 원자핵이든 — 같은 대수를 따른다.

회전은 \(\hat J^2\)과 교환하므로 \(j\)를 바꾸지 못한다. 그래서 회전은 \(j\)마다 \((2j+1)\times(2j+1)\) 유니터리 행렬, 곧 위그너 D 행렬(Wigner D-matrix)로 표현된다. 아무 회전이나 \(z\)–\(y\)–\(z\) 오일러 각(Euler angles) \((\alpha, \beta, \gamma)\)로 쪼갤 수 있고, \(z\) 회전은 위상뿐이니 실제 정보는 \(y\)축 둘레 회전에 있다.

$$D^{\,j}_{m'm}(\alpha,\beta,\gamma) = \langle j\,m'|e^{-i\alpha\hat J_z/\hbar}e^{-i\beta\hat J_y/\hbar}e^{-i\gamma\hat J_z/\hbar}|j\,m\rangle = e^{-im'\alpha}\,d^{\,j}_{m'm}(\beta)\,e^{-im\gamma}$$
\(d^{\,j}_{m'm}(\beta) = \langle j\,m'|e^{-i\beta\hat J_y/\hbar}|j\,m\rangle\)가 위그너 작은 d 행렬(Wigner small d-matrix)로, 실수다(사쿠라이 3.5절 관례, QM.wignerd). 회전한 구면 조화 함수는 \(Y_l^m(R^{-1}\hat{\mathbf r}) = \sum_{m'} Y_l^{m'}(\hat{\mathbf r})\,D^{\,l}_{m'm}(R)\) — 같은 \(l\)끼리만 섞인다.
$$d^{\,1/2}(\beta) = \begin{pmatrix}\cos\frac\beta2 & -\sin\frac\beta2\\[2pt] \sin\frac\beta2 & \cos\frac\beta2\end{pmatrix},\qquad d^{\,1}(\beta) = \begin{pmatrix}\frac{1+\cos\beta}{2} & -\frac{\sin\beta}{\sqrt2} & \frac{1-\cos\beta}{2}\\[2pt] \frac{\sin\beta}{\sqrt2} & \cos\beta & -\frac{\sin\beta}{\sqrt2}\\[2pt] \frac{1-\cos\beta}{2} & \frac{\sin\beta}{\sqrt2} & \frac{1+\cos\beta}{2}\end{pmatrix}$$
행 \(m'\), 열 \(m\) 모두 \(+j\)부터 내림차순. \(d^{\,1/2}\)는 \(\beta = 2\pi\)에서 \(-1\)이 된다 — 반정수 각운동량은 한 바퀴 돌리면 부호가 바뀐다(10장). 정수 \(j\)는 \(+1\)로 돌아온다.

\(p_x\)를 \(z\)축 둘레로 각 \(\alpha\) 돌린 함수가 \(\cos\alpha\,p_x + \sin\alpha\,p_y\)임을 \(e^{-i\alpha\hat L_z/\hbar}\)로 보여라.

강체 회전자와 분자 회전 스펙트럼

각운동량 대수가 가장 깨끗하게 드러나는 계는 회전하는 분자다. 이원자 분자를 두 질점이 길이 \(R\)인 막대에 고정된 강체 회전자(rigid rotor)로 보면, 퍼텐셜이 없고 운동 에너지가 전부 회전이다. 고전 \(E = L^2/2I\)를 그대로 연산자로 바꾼다.

$$\hat H = \frac{\hat L^2}{2I},\quad I = \mu R^2,\quad E_J = \frac{\hbar^2}{2I}J(J+1) = hc\,B\,J(J+1),\quad B = \frac{h}{8\pi^2 c\,I}\ [\mathrm{cm^{-1}}]$$
고유 함수는 분자 축 방향의 \(Y_J^M(\theta,\phi)\), 각 준위는 \(2J+1\)겹 축퇴(\(M = -J..J\)). 분광학 관례로 회전 양자수는 \(J\), 에너지는 파수(cm⁻¹, \(E/hc\))로 쓴다. \(B\)를 회전 상수(rotational constant)라 한다. 1 cm⁻¹ = 29.98 GHz = 0.124 meV = 1.44 K × \(k_\mathrm{B}\). 상온 \(k_\mathrm{B}T\) = 208.5 cm⁻¹.

빛이 회전을 일으키려면 분자가 영구 쌍극자를 가져야 하고(CO, HF, HCl은 있고 N₂, O₂, H₂는 없다), 쌍극자 연산자는 \(l = 1\)짜리 벡터 연산자라서 선택 규칙(selection rule) \(\Delta J = \pm1\), \(\Delta M = 0, \pm1\)이 나온다(\(\int Y_{J'}^{M'*}\cos\theta\,Y_J^M\,d\Omega \ne 0\)은 \(J' = J\pm1\)일 때만; 증명은 14장). 따라서 흡수선은

$$\tilde\nu_{J\to J+1} = E_{J+1} - E_J = 2B(J+1) = 2B,\ 4B,\ 6B,\ \dots \qquad(\text{간격 } 2B)$$
실제 분자는 빨리 돌수록 늘어나(원심 뒤틀림(centrifugal distortion)) \(E_J = BJ(J+1) - DJ^2(J+1)^2\)이고 높은 \(J\)에서 선 간격이 조금씩 좁아진다(CO: \(D \approx 6\times10^{-6}\) cm⁻¹). 대칭 이원자 분자 N₂는 마이크로파 흡수가 없지만 라만 산란(\(\Delta J = \pm2\), 스토크스 이동 \(4B(J + \tfrac32)\), 간격 \(4B\))이나 전자 띠의 회전 구조로 보인다.

온도가 정하는 선 세기

기체에서 회전 준위 \(J\)에 있는 분자의 비율은 볼츠만 분포에 축퇴도 \(2J+1\)을 곱한 것이다. 선 세기가 아래 준위의 점유수에 비례한다고 근사하면, 스펙트럼의 모양이 곧 온도계다.

$$\frac{N_J}{N} = \frac{(2J+1)\,e^{-hcBJ(J+1)/k_\mathrm{B}T}}{q_\text{rot}},\qquad q_\text{rot} \approx \frac{k_\mathrm{B}T}{hcB},\qquad J_\text{max} \approx \sqrt{\frac{k_\mathrm{B}T}{2hcB}} - \frac12$$
\(q_\text{rot}\)는 회전 분배 함수(\(k_\mathrm{B}T \gg hcB\)일 때, 열·통계물리 볼츠만 분포). \(J_\text{max}\)는 \(N_J\)를 \(J\)로 미분해 0으로 놓은 것이다. \(\ln[I_J/(2J+1)]\)을 \(E_J\)에 대해 그리면(볼츠만 그림) 기울기가 \(-1/k_\mathrm{B}T\)인 직선이 되고, 이렇게 구한 온도를 회전 온도(rotational temperature)라 한다. 회전 준위는 몇 번의 충돌로 병진 운동과 평형을 이루므로 회전 온도는 기체 온도의 좋은 대리값이다.

핵심 정리

  1. 교환 관계: \(\hat{\mathbf L} = \hat{\mathbf r}\times\hat{\mathbf p}\)에서 \([\hat L_i, \hat L_j] = i\hbar\varepsilon_{ijk}\hat L_k\), \([\hat L^2, \hat L_i] = 0\). 성분 둘은 동시에 정해지지 않고(\(\Delta L_x\Delta L_y \ge \tfrac\hbar2|\langle L_z\rangle|\)), \(\hat L^2\)과 \(\hat L_z\)의 동시 고유 상태 \(|l\,m\rangle\)를 기저로 쓴다. \(\hat L_z = -i\hbar\,\partial_\phi\).
  2. 사다리 대수: \(\hat J_\pm = \hat J_x \pm i\hat J_y\), \([\hat J_z, \hat J_\pm] = \pm\hbar\hat J_\pm\). 교환 관계만으로 \(\hat J^2 \to j(j+1)\hbar^2\), \(\hat J_z \to m\hbar\), \(m = -j..j\), \(2j \in \{0,1,2,\dots\}\). \(\hat J_\pm|j\,m\rangle = \hbar\sqrt{j(j+1)-m(m\pm1)}\,|j\,m\pm1\rangle\). 궤도 각운동량은 단일값 조건으로 정수 \(l\)만.
  3. 구면 조화 함수: \(Y_l^m \propto P_l^m(\cos\theta)e^{im\phi}\)는 \(\hat L_+Y_l^l = 0\)과 \(\hat L_-\)로 만든다. 규격 직교, 완비, 패리티 \((-1)^l\), \(Y_l^{-m} = (-1)^mY_l^{m*}\). 실수 오비탈은 \(Y_l^{\pm m}\)의 합·차(\(p_x = (Y_1^{-1}-Y_1^1)/\sqrt2\)): 같은 \(l\)이지만 \(L_z\)는 \(\pm|m|\hbar\) 반반.
  4. 벡터 모형: \(|\mathbf L| = \hbar\sqrt{l(l+1)} > l\hbar\), \(\langle L_x\rangle = 0\), \(\langle L_x^2\rangle = \tfrac{\hbar^2}{2}[l(l+1)-m^2]\), \(\cos\theta_L = m/\sqrt{l(l+1)}\). \(\mathbf L\)은 \(z\)축과 나란할 수 없다.
  5. 기운 축의 측정: 축 \(\hat{\mathbf n}\)(극각 \(\theta\))으로 재도 결과는 \(m'\hbar\)뿐이고 확률은 \(|d^{\,l}_{m'm}(\theta)|^2\), 기댓값 \(m\hbar\cos\theta\). \(|1,1\rangle\)을 \(x\)로 재면 \(\tfrac14, \tfrac12, \tfrac14\).
  6. 회전: \(\hat R(\alpha,\hat{\mathbf n}) = e^{-i\alpha\hat{\mathbf n}\cdot\hat{\mathbf J}/\hbar}\) — 각운동량은 회전의 생성자이고 교환 관계는 회전의 비가환성이다. \(e^{-i\alpha\hat L_z/\hbar}Y_l^m = e^{-im\alpha}Y_l^m\). \(D^{\,j}_{m'm} = e^{-im'\alpha}d^{\,j}_{m'm}(\beta)e^{-im\gamma}\), 회전은 \(j\)를 바꾸지 않는다. 반정수 \(j\)는 360°에서 \(-1\).
  7. 강체 회전자: \(E_J = hcBJ(J+1)\), \(B = h/8\pi^2cI\), \(I = \mu R^2\), 축퇴 \(2J+1\). 쌍극 선택 규칙 \(\Delta J = \pm1\) → 선 \(2B(J+1)\), 간격 \(2B\). 점유 \(\propto(2J+1)e^{-E_J/k_\mathrm{B}T}\), \(J_\text{max} \approx \sqrt{k_\mathrm{B}T/2hcB} - \tfrac12\): 선 간격이 결합 길이를, 세기 분포가 회전 온도를 준다(OES 기체 온도, FTIR 가스 분석).

연습문제

각운동량은 따로 말이 없으면 \(\hbar\) 단위로 답한다(예: \(\sqrt6\,\hbar\)이면 2.45). 확률은 0–1 사이 소수로 쓴다. 상수: \(h = 6.626\times10^{-34}\) J·s, \(c = 2.998\times10^{10}\) cm/s, 1 u = \(1.6605\times10^{-27}\) kg, \(k_\mathrm{B}/hc = 0.6950\) cm⁻¹/K.

\([\hat L_z, \hat x]\)는?

\([\hat x\hat p_y - \hat y\hat p_x, \hat x] = -\hat y[\hat p_x, \hat x] = -\hat y(-i\hbar) = i\hbar\hat y\). 일반식 \([\hat L_i, \hat x_j] = i\hbar\varepsilon_{ijk}\hat x_k\)에서 \(i = z, j = x\) → \(k = y\), \(\varepsilon_{zxy} = +1\). \(\hat L_z\)가 \(x\)를 \(y\) 쪽으로 돌리는 생성자라는 뜻이다.

\(l = 3\)(f) 상태의 각운동량 크기와 가능한 \(L_z\) 값의 개수를 구하라.

\(|L| = \sqrt{3\cdot4}\,\hbar = \sqrt{12}\,\hbar = 3.46\hbar\). \(m = -3, \dots, 3\)의 7개.

\(\hat J_+|3, 1\rangle = c\,|3, 2\rangle\)에서 \(c\)를 구하라.

\(c = \hbar\sqrt{j(j+1) - m(m+1)} = \hbar\sqrt{12 - 2} = \sqrt{10}\,\hbar = 3.16\hbar\).

\(j = 3/2\)에서 행렬 원소 \(\langle \tfrac32, \tfrac12|\hat J_x|\tfrac32, -\tfrac12\rangle\)를 구하라.

\(\hat J_x = (\hat J_+ + \hat J_-)/2\). \(m = -\tfrac12 \to \tfrac12\)는 \(\hat J_+\)만 기여한다.

\(\tfrac12\hbar\sqrt{\tfrac{15}{4} - (-\tfrac12)(\tfrac12)} = \tfrac12\hbar\sqrt{\tfrac{16}{4}} = \tfrac12\cdot2\hbar = \hbar\).

상태 \(|3, -1\rangle\)에서 \(\Delta L_x\)를 구하고, \(\Delta L_x\Delta L_y\)가 로버트슨 하한을 만족하는지 확인하라.

\(\langle L_x\rangle = 0\), \(\langle L_x^2\rangle = \tfrac{\hbar^2}{2}[l(l+1) - m^2]\).

\(\langle L_x^2\rangle = \tfrac{\hbar^2}{2}(12 - 1) = 5.5\hbar^2\), \(\Delta L_x = \sqrt{5.5}\,\hbar = 2.35\hbar\). \(\Delta L_x\Delta L_y = 5.5\hbar^2 \ge \tfrac\hbar2|\langle L_z\rangle| = 0.5\hbar^2\) — 넉넉히 만족한다. 등호는 \(|m| = l\)일 때만 성립한다: \(\Delta L_x\Delta L_y = \tfrac{\hbar^2}{2}[l(l+1) - l^2] = \tfrac{l\hbar^2}{2} = \tfrac\hbar2\cdot l\hbar\).

각도 부분이 \(Y_1^0\)인 입자가 \(z\)축에서 45° 이내의 원뿔(\(0 \le \theta \le 45^\circ\)) 방향에서 발견될 확률은?

\(P = \frac{3}{4\pi}\cdot2\pi\int_0^{\pi/4}\cos^2\theta\sin\theta\,d\theta\).

\(P = \tfrac32\cdot\tfrac13[1 - \cos^3(\pi/4)] = \tfrac12(1 - 0.3536) = 0.323\). 원뿔이 구 넓이의 14.6 %밖에 안 되지만 \(\cos^2\theta\)가 극 쪽에 몰려 있어 확률은 32 %다. 반대쪽 원뿔도 같으니 두 극 45° 이내에 65 %가 있다.

다음 가운데 \(\hat L_z\)의 고유 함수는?

\(-i\hbar\,\partial_\phi(\sin\theta\,e^{-i\phi}) = -\hbar\sin\theta\,e^{-i\phi}\) → 고유값 \(-\hbar\). 나머지는 \(\cos\phi = (e^{i\phi} + e^{-i\phi})/2\)처럼 \(\pm m\)이 섞인 실수 함수(\(p_x\), \(p_y\) 꼴, \(d_{x^2-y^2}\))다.

\(\psi = \tfrac{1}{\sqrt3}Y_1^1 + \sqrt{\tfrac23}\,Y_2^{-1}\)에서 \(\langle L^2\rangle\)과 \(\langle L_z\rangle\)를 구하라. \(L^2\)을 한 번 재면 어떤 값들이 어떤 확률로 나오는가?

\(L^2 = 2\hbar^2\)(확률 1/3) 또는 \(6\hbar^2\)(2/3). \(\langle L^2\rangle = \tfrac13\cdot2 + \tfrac23\cdot6 = 4.67\hbar^2\). \(L_z = +\hbar\)(1/3) 또는 \(-\hbar\)(2/3) → \(\langle L_z\rangle = -0.333\hbar\). \(\langle L^2\rangle\)은 어떤 측정값(2나 6)과도 같지 않다.

\(|1, 0\rangle\) 상태를 \(z\)축에서 30° 기운 축으로 잴 때 결과가 0일 확률과 \(+\hbar\)일 확률을 구하라.

\(d^1_{00}(\theta) = \cos\theta\), \(d^1_{\pm1,0}(\theta) = \pm\sin\theta/\sqrt2\).

\(P(0) = \cos^230^\circ = 0.750\), \(P(\pm\hbar) = \sin^230^\circ/2 = 0.125\)씩. 합 1, 기댓값 0(\(m = 0\)이므로 어느 축이든 0).

\(|\psi\rangle = (|1,1\rangle + |1,0\rangle)/\sqrt2\)에서 \(\langle L_x\rangle\)를 구하라. \(\langle L_y\rangle\)는 얼마인가?

\(L_x = \frac{\hbar}{\sqrt2}\begin{pmatrix}0&1&0\\1&0&1\\0&1&0\end{pmatrix}\).

\(L_x\psi = \frac{\hbar}{\sqrt2}\cdot\frac{1}{\sqrt2}(1, 1, 1)^T\), \(\psi^\dagger L_x\psi = \frac{\hbar}{2}\cdot\frac{1}{\sqrt2}(1 + 1) = \hbar/\sqrt2 = 0.707\hbar\). \(L_y\)는 순허수 행렬이고 \(\psi\)가 실수라 \(\langle L_y\rangle = 0\). 벡터 모형으로는 \(z\)와 \(xy\) 평면 사이에서 \(x\)쪽으로 기운 각운동량이다.

\(|1,1\rangle\)을 \(y\)축 둘레로 각 \(\beta\) 돌린 뒤 \(L_z\)를 쟀더니 \(+\hbar\)가 나올 확률이 0.5였다. \(\beta\)(0–180°)를 구하라.

생존 진폭은 \(d^1_{11}(\beta) = (1+\cos\beta)/2\).

\(\bigl(\tfrac{1+\cos\beta}{2}\bigr)^2 = 0.5\) → \(1 + \cos\beta = \sqrt2\) → \(\cos\beta = 0.4142\) → \(\beta = 65.5^\circ\). 스핀 1/2라면 \(\cos^2(\beta/2) = 0.5\)에서 90°였을 것이다 — \(j\)가 클수록 같은 각에서 상태가 더 빨리 "빠져나간다".

H³⁵Cl(\(B = 10.44\) cm⁻¹)의 \(J = 2 \to 3\) 순수 회전 흡수선의 파수는?

\(\tilde\nu = 2B(J+1) = 2\times10.44\times3 = 62.6\) cm⁻¹ (원적외선, 파장 160 µm).

¹²C¹⁶O의 회전선 간격이 3.845 cm⁻¹이다. 결합 길이를 구하라(질량 12.000 u, 15.995 u).

\(B = 1.9225\) cm⁻¹, \(I = h/(8\pi^2cB) = 1.456\times10^{-46}\) kg·m². \(\mu = 6.856\) u \(= 1.1385\times10^{-26}\) kg. \(R = \sqrt{I/\mu} = 1.131\times10^{-10}\) m = 0.113 nm.

500 K의 HF 기체(\(B = 20.56\) cm⁻¹)에서 가장 많이 채워진 회전 준위 \(J\)(정수)는?

\(J_\text{max} \approx \sqrt{k_\mathrm{B}T/2hcB} - \tfrac12\)을 구해 가장 가까운 정수를 고르고, 이웃 \(J\)의 \(N_J\)를 비교해 확인한다.

\(k_\mathrm{B}T/hc = 347.5\) cm⁻¹, \(\sqrt{347.5/41.12} - 0.5 = 2.41\). \(N_J \propto (2J+1)e^{-20.56J(J+1)/347.5}\): \(J = 2\): \(5e^{-0.355} = 3.51\), \(J = 3\): \(7e^{-0.710} = 3.44\) → \(J = 2\)(근소한 차이).

배기 라인의 뜨거운 HCl(\(B = 10.44\) cm⁻¹)을 FTIR로 재었더니 \(J = 5\)에서 올라가는 선이 \(J = 1\)에서 올라가는 선보다 1.40배 셌다. 선 세기 \(\propto(2J+1)e^{-hcBJ(J+1)/k_\mathrm{B}T}\)로 보고 기체 온도를 구하라.

\(E_1 = 20.88\), \(E_5 = 313.2\) cm⁻¹, 차 292.3 cm⁻¹. \(\dfrac{I_5/11}{I_1/3} = 1.40\times\dfrac{3}{11} = 0.3818\), \(\ln = -0.9628\). \(k_\mathrm{B}T/hc = 292.3/0.9628 = 303.6\) cm⁻¹ → \(T = 437\) K. 높은 \(J\) 선이 더 세다는 것만으로 상온(300 K에서 비 0.90)보다 뜨겁다는 것을 바로 알 수 있다.

다음 가운데 순수 회전 흡수(마이크로파·원적외선) 스펙트럼이 나타나지 않는 분자는?

N₂는 대칭이라 영구 쌍극자가 없어 \(\Delta J = \pm1\) 쌍극 전이가 일어나지 않는다. 회전 구조는 라만(\(\Delta J = \pm2\))이나 전자 띠(OES의 N₂ 2차 양성 띠)에서 본다.

개념 확인 퀴즈

\(|l\,m\rangle\) 상태의 각운동량 벡터가 \(z\)축과 정확히 나란할 수 없는 이유는?

\(|\mathbf L|^2 = l(l+1)\hbar^2 > (l\hbar)^2\)인 것은 \(\langle L_x^2 + L_y^2\rangle = [l(l+1) - m^2]\hbar^2 \gt 0\)이기 때문이고, 이것은 교환 관계가 요구하는 최소한의 불확정성이다. 예외는 \(l = 0\)(모든 성분이 0)뿐이다.

사다리 논증에서 \(2j\)가 정수여야 하는 이유는?

닿지 못하면 노름 제곱이 음수인 상태가 생긴다(미니 실험). 첫째 보기(단일값)는 궤도 각운동량에서 반정수를 추가로 없애는 조건이다.

\(Y_3^2\)를 \(z\)축 둘레로 60° 돌리면?

\(\hat L_z\) 고유 상태는 \(z\) 회전의 고유 상태이기도 하다. 모양이 실제로 도는 것은 실수 오비탈(\(\pm m\) 섞임)이고, 어떤 회전도 \(l\)은 바꾸지 못한다.

\(|2, 0\rangle\) 상태를 \(x\)축 방향으로 재면 가능한 결과는?

\(d^2_{\pm1,0}(90^\circ) \propto \sin\beta\cos\beta = 0\)이라 \(\pm\hbar\)는 확률 0이다. 확률은 \(P(\pm2) = 3/8\), \(P(0) = 1/4\) (\(d^2_{00} = (3\cos^2\beta - 1)/2 = -1/2\)). 측정 시뮬레이터에서 \(l = 2\), \(m = 0\), θ = 90°로 확인할 수 있다.

기체의 온도를 올리면 회전 흡수 스펙트럼은?

선 위치 \(2B(J+1)\)은 분자 구조(\(B\))만으로 정해진다. 온도는 점유 분포 \((2J+1)e^{-E_J/k_\mathrm{B}T}\)를 바꿔 세기 모양만 바꾼다 — 그래서 간격에서 \(B\)를, 모양에서 \(T\)를 따로 읽을 수 있다.
