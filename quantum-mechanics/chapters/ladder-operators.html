Chapter 06

조화 진동자와 사다리 연산자

실리콘 결정 속 원자는 평형 자리 둘레에서 떨고, 레이저 공진기 속 빛은 모드마다 출렁이며, MEMS 가속도계의 추와 초전도 큐비트의 LC 회로도 흔들린다. 퍼텐셜의 극소점 근처는 모두 포물선이므로 이 모든 것이 조화 진동자다. 현대물리학에서는 슈뢰딩거 방정식을 에르미트 다항식으로 풀어 \(E_n = (n+\tfrac12)\hbar\omega\)를 얻었다. 이 장에서는 미분 방정식을 풀지 않는다. 교환자 \([\hat a, \hat a^\dagger] = 1\) 하나에서 스펙트럼 전체와 행렬 요소를 끌어내고, 그 연산자로 고전처럼 진동하는 결맞음 상태, 한쪽 잡음을 줄인 압축 상태, 힘을 받아 밀려나는 진동자를 다룬다. 마지막으로 위상 공간의 위그너 함수로 "양자다움"을 눈으로 보고, 빛과 격자 진동을 진동자의 모음으로 양자화해 광자와 포논, 열잡음과 영점 요동까지 잇는다. 아래 그림은 결맞음 상태의 위그너 함수가 위상 공간에서 원을 그리며 도는 모습이다. 아래 띠의 \(|\psi(x)|^2\)는 모양을 그대로 지닌 채 고전 진자처럼 오간다.

방울을 끌어 α를 바꾸고, 누르면 멈춤·재생
  • 사다리 연산자 \(\hat a, \hat a^\dagger\)를 정의하고 \([\hat a,\hat a^\dagger]=1\)만으로 에너지 고유값 \((n+\tfrac12)\hbar\omega\), 바닥 상태 파동함수, \(\hat a^\dagger|n\rangle = \sqrt{n+1}|n+1\rangle\)을 유도한다.
  • 포크 기저에서 \(\hat x, \hat p, \hat x^2, \hat x^4\)의 행렬 요소를 사다리 연산자로 계산하고, 선택 규칙 \(\Delta n = \pm1\)과 자른 포크 공간의 한계를 설명한다.
  • 결맞음 상태 \(|\alpha\rangle\)의 포아송 광자 수 분포, 최소 불확정성, 고전 궤도를 따르는 시간 전개를 계산하고 광자 산탄 잡음과 잇는다.
  • 강제 진동자를 하이젠베르크 묘사로 풀어 변위 연산자 \(\hat D(\alpha)\)가 진공을 결맞음 상태로 옮김을 보이고, 힘 펄스의 시점과 크기로 원하는 상태를 만든다.
  • 압축 상태의 \(\Delta x, \Delta p\), 광자 수, dB 표시를 계산하고 압축광이 간섭계의 산탄 잡음 한계를 넘는 원리를 설명한다.
  • 위그너 함수의 성질(주변 분포, 음수 영역, 원점 값과 패리티)을 이용해 수 상태·고양이 상태의 비고전성을 판정한다.
  • 공진기 모드와 격자 진동을 진동자로 양자화하고, 열 점유 \(\langle n\rangle = 1/(e^{\hbar\omega/k_BT}-1)\)와 영점 요동으로 존슨–나이퀴스트 잡음의 양자 보정, 라만 반스토크스 비, MEMS 진동자의 영점 진폭을 계산한다.

사다리 연산자로 푸는 조화 진동자

질량 \(m\), 각진동수 \(\omega\)인 진동자의 해밀토니언은 \(\hat H = \hat p^2/2m + \tfrac12 m\omega^2\hat x^2\)이다. 이 식에는 길이와 운동량의 자연스러운 눈금이 숨어 있다. 운동 에너지와 퍼텐셜 에너지가 같은 크기가 되는 길이와 운동량

$$x_0 = \sqrt{\frac{\hbar}{m\omega}},\qquad p_0 = \frac{\hbar}{x_0} = \sqrt{m\hbar\omega},\qquad \hat H = \frac{\hbar\omega}{2}\left(\frac{\hat x^2}{x_0^2}+\frac{\hat p^2}{p_0^2}\right)$$
\(x_0\)를 진동자 길이라 한다. 이 장의 그림과 시뮬레이터는 모두 \(x/x_0\), \(p/p_0\)를 축으로 쓴다(qm.js의 무차원 관례). \(x_0 p_0 = \hbar\)이다.

괄호 안은 \(u^2+v^2 = (u-iv)(u+iv)\)처럼 인수분해하고 싶은 꼴이다. 연산자는 교환하지 않으므로 그대로 되지는 않지만, 그 어긋남이 바로 핵심이다. 다음 두 연산자를 정의하자.

$$\hat a = \frac{1}{\sqrt2}\left(\frac{\hat x}{x_0}+i\frac{\hat p}{p_0}\right),\qquad \hat a^\dagger = \frac{1}{\sqrt2}\left(\frac{\hat x}{x_0}-i\frac{\hat p}{p_0}\right),\qquad [\hat a,\hat a^\dagger] = \frac{-i}{x_0p_0}[\hat x,\hat p] = 1$$
\(\hat a\)를 내림 연산자(lowering operator), \(\hat a^\dagger\)를 올림 연산자(raising operator)라 하고, 둘을 함께 사다리 연산자(ladder operators)라 한다. 에르미트가 아니므로 관측량이 아니다. 거꾸로 \(\hat x = \tfrac{x_0}{\sqrt2}(\hat a+\hat a^\dagger)\), \(\hat p = \tfrac{ip_0}{\sqrt2}(\hat a^\dagger-\hat a)\)이다.

\(\hat a^\dagger\hat a = \tfrac12(\hat x^2/x_0^2+\hat p^2/p_0^2) - \tfrac12\)이므로(교환자에서 나온 \(-\tfrac12\)) 해밀토니언은

$$\hat H = \hbar\omega\left(\hat N+\tfrac12\right),\qquad \hat N = \hat a^\dagger\hat a,\qquad [\hat N,\hat a] = -\hat a,\qquad [\hat N,\hat a^\dagger] = +\hat a^\dagger$$
\(\hat N\)은 수 연산자(number operator)다. 이제 \(\hat H\)의 고유 상태는 \(\hat N\)의 고유 상태와 같고, 문제는 \(\hat N\)의 고유값을 찾는 일로 줄었다.

\(\hat N|\nu\rangle = \nu|\nu\rangle\)이라 하자. 교환자에서 \(\hat N(\hat a^\dagger|\nu\rangle) = (\hat a^\dagger\hat N+\hat a^\dagger)|\nu\rangle = (\nu+1)\hat a^\dagger|\nu\rangle\)이다. 곧 \(\hat a^\dagger\)는 고유값을 1 올리고, 같은 방법으로 \(\hat a\)는 1 내린다. 에너지로는 \(\hbar\omega\)씩 오르내리는 사다리다. 그런데 사다리는 아래로 끝없이 내려갈 수 없다.

$$\big\|\hat a|\nu\rangle\big\|^2 = \langle\nu|\hat a^\dagger\hat a|\nu\rangle = \nu \ge 0$$
\(\hat a\)를 거듭 쓰면 \(\nu\)가 1씩 줄어 언젠가 음수가 되어야 하는데, 노름의 제곱은 음수일 수 없다. 모순을 피하는 유일한 길은 어떤 상태 \(|0\rangle\)에서 \(\hat a|0\rangle = 0\)이 되어 사다리가 끊기는 것이다. 그때 \(\nu = 0\)이고, 위로는 \(\nu = 0, 1, 2, \ldots\) 정수만 남는다.

따라서 \(E_n = (n+\tfrac12)\hbar\omega\)다. 계수까지 정하면(위상은 실수 양수로 고른다)

$$\hat a|n\rangle = \sqrt n\,|n-1\rangle,\qquad \hat a^\dagger|n\rangle = \sqrt{n+1}\,|n+1\rangle,\qquad |n\rangle = \frac{(\hat a^\dagger)^n}{\sqrt{n!}}|0\rangle$$
\(|n\rangle\)을 수 상태(number state) 또는 포크 상태(Fock state)라 한다. 계수의 제곱은 \(\|\hat a^\dagger|n\rangle\|^2 = \langle n|\hat a\hat a^\dagger|n\rangle = \langle n|(\hat N+1)|n\rangle = n+1\)에서 나온다.

위치 표현으로 옮기면 \(\hat a|0\rangle = 0\)은 1계 미분 방정식이다. \(\xi = x/x_0\)로 쓰면 \(\hat p = -i\hbar\,d/dx\)이므로 \(\hat a = \tfrac{1}{\sqrt2}(\xi + d/d\xi)\), \(\hat a^\dagger = \tfrac{1}{\sqrt2}(\xi - d/d\xi)\)이다.

$$\Big(\xi+\frac{d}{d\xi}\Big)\psi_0 = 0\ \Rightarrow\ \psi_0(x) = \frac{1}{\pi^{1/4}\sqrt{x_0}}\,e^{-x^2/2x_0^2},\qquad \psi_{n+1} = \frac{1}{\sqrt{2(n+1)}}\Big(\xi-\frac{d}{d\xi}\Big)\psi_n$$
2계 미분 방정식(현대물리학에서 푼 에르미트 방정식) 대신 1계 방정식 하나와 미분 연산의 반복으로 모든 고유 함수가 나온다. \(\Delta x = x_0/\sqrt2\)는 바닥 상태의 위치 퍼짐이다.

진동자 길이는 실제 크기를 바로 알려 준다. 반도체 이종 구조에서 포물선 꼴 퍼텐셜(조성을 서서히 바꾼 포물선 양자 우물, 게이트로 만든 양자점)에 갇힌 전자의 수치를 만져 보자.

수 상태와 행렬 요소

수 상태 \(\{|n\rangle\}\)은 정규 직교 기저다(2장의 에르미트 연산자 \(\hat N\)의 고유 상태). 이 기저에서 연산자는 무한 행렬이 되고, 사다리 연산자의 행렬은 놀랄 만큼 단순하다. \(\langle m|\hat a|n\rangle = \sqrt n\,\delta_{m,n-1}\)이므로 \(\hat a\)는 대각선 바로 위 한 줄에만 \(\sqrt1, \sqrt2, \sqrt3, \ldots\)이 있는 행렬이다. 위치와 운동량은

$$\langle m|\hat x|n\rangle = \frac{x_0}{\sqrt2}\Big(\sqrt n\,\delta_{m,n-1}+\sqrt{n+1}\,\delta_{m,n+1}\Big),\qquad \langle m|\hat p|n\rangle = \frac{ip_0}{\sqrt2}\Big(\sqrt{n+1}\,\delta_{m,n+1}-\sqrt n\,\delta_{m,n-1}\Big)$$
위치는 바로 이웃한 준위끼리만 잇는다. 그래서 진동자의 쌍극자 전이(\(\hat H' \propto \hat x\))는 \(\Delta n = \pm1\)만 허용된다 — 이것이 조화 진동자의 선택 규칙(selection rule)이고, 분자 진동의 적외선 흡수가 \(\omega\) 하나에서만 일어나는 이유다(배음은 비조화성 때문에 약하게 나타난다).

거듭제곱은 사다리 연산자를 전개해 "몇 칸 오르내리는가"로 센다. 예를 들어 \(\hat x^2 = \tfrac{x_0^2}{2}(\hat a^2+\hat a^{\dagger2}+\hat a\hat a^\dagger+\hat a^\dagger\hat a)\)에서 대각 성분은 마지막 두 항만 남아 \(\tfrac{x_0^2}{2}(2n+1)\)이다.

$$\langle n|\hat x^2|n\rangle = x_0^2\big(n+\tfrac12\big),\quad \langle n|\hat p^2|n\rangle = p_0^2\big(n+\tfrac12\big),\quad \Delta x\,\Delta p = \big(n+\tfrac12\big)\hbar,\quad \langle\hat T\rangle = \langle\hat V\rangle = \tfrac12E_n$$
\(\langle\hat x\rangle = \langle\hat p\rangle = 0\)이므로 \(\Delta x^2 = \langle\hat x^2\rangle\)(그리피스의 \(\sigma_x\)). 바닥 상태만 최소 불확정 \(\hbar/2\)를 이루고, 들뜬 수 상태는 \(n\)에 비례해 퍼진다. 마지막 식은 비리얼 정리다.

수치 계산에서는 이 무한 행렬을 \(N\)개 준위에서 잘라 쓴다(QM.fock(N)). 공진기 QED·초전도 큐비트 회로 해석, 전자–포논 결합 계산이 모두 이렇게 한다. 그런데 자른 행렬에서는 \([\hat a,\hat a^\dagger] = 1\)이 성립할 수 없다. 유한 행렬의 교환자는 대각합이 늘 0인데 단위 행렬의 대각합은 \(N\)이기 때문이다. 아래 시뮬레이터에서 어긋남이 어디에 몰리는지 확인하라.

시간 전개는 하이젠베르크 묘사(4장)로 보면 한 줄이다. \(d\hat a/dt = \tfrac{i}{\hbar}[\hat H,\hat a] = -i\omega\hat a\)이므로 \(\hat a_H(t) = \hat a\,e^{-i\omega t}\)이고, 이것을 \(\hat x\)로 되돌리면

$$\hat x_H(t) = \hat x\cos\omega t+\frac{\hat p}{m\omega}\sin\omega t,\qquad \hat p_H(t) = \hat p\cos\omega t-m\omega\hat x\sin\omega t$$
고전 진동자의 해와 글자 하나 다르지 않다. 따라서 어떤 상태든 \(\langle\hat x\rangle(t)\), \(\langle\hat p\rangle(t)\)는 고전 궤도를 정확히 따른다. 조화 진동자에서는 에렌페스트 정리(1장)가 근사가 아니라 등식이다. 차이는 요동(\(\Delta x, \Delta p\))과 분포의 모양에서만 나타난다.

수 상태 하나는 정상 상태라 \(\langle\hat x\rangle\)이 늘 0이다. 진동하는 것을 보려면 중첩이 필요하다. 계수 \(c_n\)의 상태는 \(c_n e^{-i(n+1/2)\omega t}\)로 전개되므로(4장), \(\langle\hat x\rangle(t) = \sqrt2x_0\sum_n\sqrt{n+1}\,\mathrm{Re}\big[c_n^*c_{n+1}e^{-i\omega t}\big]\)이다. 이웃한 준위의 짝만 진동수 \(\omega\)로 \(\langle\hat x\rangle\)을 흔든다.

결맞음 상태와 고전 진동

수 상태는 아무리 들떠도 \(\langle\hat x\rangle = 0\)이다. 진자처럼 오가는 진동자, 진폭과 위상이 정해진 전파·레이저 빛은 어떤 양자 상태일까? 고전 진동자의 복소 진폭 \(\alpha\)는 \(x\)와 \(p\)를 한 숫자에 담는다: \(\alpha = (x/x_0+ip/p_0)/\sqrt2\). 그 연산자판이 바로 \(\hat a\)다. 그래서 \(\hat a\)의 고유 상태를 찾는다.

결맞음 상태

\(\hat a|\alpha\rangle = \alpha|\alpha\rangle\)를 만족하는 상태를 결맞음 상태(coherent state)라 한다. \(\hat a\)는 에르미트가 아니므로 고유값 \(\alpha\)는 임의의 복소수이고, 수 상태로 전개하면

$$|\alpha\rangle = e^{-|\alpha|^2/2}\sum_{n=0}^{\infty}\frac{\alpha^n}{\sqrt{n!}}|n\rangle,\qquad P(n) = |\langle n|\alpha\rangle|^2 = e^{-\bar n}\frac{\bar n^{\,n}}{n!},\quad \bar n = |\alpha|^2$$

계수는 \(\hat a\)를 쓰면 \(c_n\sqrt n = \alpha c_{n-1}\)이라는 점화식에서 바로 나온다. 광자 수(또는 들뜬 양자 수)의 분포는 포아송 분포이고, 평균 \(\bar n = |\alpha|^2\), 분산 \(\Delta n^2 = \bar n\)이다. 기댓값은 \(\hat a\)가 오른쪽 켓에, \(\hat a^\dagger\)가 왼쪽 브라에 작용하도록 순서를 맞추면(정규 순서) 계산이 한 줄이다.

$$\langle\hat x\rangle = \sqrt2\,x_0\,\mathrm{Re}\,\alpha,\quad \langle\hat p\rangle = \sqrt2\,p_0\,\mathrm{Im}\,\alpha,\quad \Delta x = \frac{x_0}{\sqrt2},\quad \Delta p = \frac{p_0}{\sqrt2},\quad \Delta x\,\Delta p = \frac\hbar2$$
예: \(\langle\hat x^2\rangle = \tfrac{x_0^2}{2}\langle\alpha|(\hat a^2+\hat a^{\dagger2}+2\hat a^\dagger\hat a+1)|\alpha\rangle = \tfrac{x_0^2}{2}\big((\alpha+\alpha^*)^2+1\big)\)이므로 \(\Delta x^2 = x_0^2/2\). 결맞음 상태는 바닥 상태와 같은 모양의 가우스 파속을 옮겨 놓은 것이다. 3장의 최소 불확정 상태 가운데 폭이 \(x_0/\sqrt2\)인 것이다.

시간이 흐르면 \(c_n \to c_ne^{-i(n+1/2)\omega t}\)이므로 \(\alpha^n \to (\alpha e^{-i\omega t})^n\)이 되어(전역 위상 \(e^{-i\omega t/2}\) 제외)

$$|\alpha\rangle \xrightarrow{\ t\ } |\alpha e^{-i\omega t}\rangle,\qquad \langle\hat x\rangle(t) = \sqrt2\,x_0|\alpha|\cos(\omega t-\varphi),\qquad \alpha = |\alpha|e^{i\varphi}$$
결맞음 상태는 계속 결맞음 상태로 남고, 중심은 고전 궤도를 정확히 따라 위상 공간에서 시계 방향으로 돈다. 폭은 영영 퍼지지 않는다 — 자유 입자 가우스 파속(1장)과 대조된다.

결맞음 상태의 방울이 위상 공간을 한 바퀴 도는 동안 위치 불확정도 \(\Delta x\)는 어떻게 될까?

결맞음 상태는 시간이 지나도 결맞음 상태(\(\alpha \to \alpha e^{-i\omega t}\))이므로 \(\Delta x = \Delta p\)가 늘 바닥 상태의 값이다. 위상 공간에서 둥근 방울이 모양 그대로 돈다. \(|\alpha|\)와도 무관하다 — 진폭이 커질수록 상대적 퍼짐 \(\Delta x/\langle x\rangle_\text{max}\)은 \(1/(2|\alpha|)\)로 줄어 고전 진동에 가까워진다.

강제 진동자와 변위 연산자

결맞음 상태는 실제로 어떻게 만들어질까? 진공(\(|0\rangle\))에 있는 진동자를 고전적인 힘 \(F(t)\)로 밀어 보자. 진동하는 전류가 공진기 모드를, 레이저 펄스가 포논을, 정전기력이 MEMS 추를 미는 상황이다.

$$\hat H(t) = \hbar\omega\big(\hat a^\dagger\hat a+\tfrac12\big) - F(t)\,\hat x,\qquad \frac{d\hat a}{dt} = \frac{i}{\hbar}[\hat H,\hat a] = -i\omega\hat a + i\,\frac{F(t)\,x_0}{\sqrt2\,\hbar}$$
하이젠베르크 묘사(4장)의 운동 방정식이 연산자에 대해 선형이고, 힘 항은 연산자가 아닌 숫자다. 따라서 \(\hat a(t) = \hat a(0)e^{-i\omega t} + \alpha(t)\)로 숫자 하나만큼 밀린다.
$$\alpha(t) = \frac{i\,x_0}{\sqrt2\,\hbar}\int_{-\infty}^{t}F(t')\,e^{-i\omega(t-t')}\,dt'$$
\(\alpha(t)\)는 고전 강제 진동자의 복소 진폭 그대로다. 짧은 충격(\(F = J\delta(t-t_0)\))이면 \(\alpha\)가 \(iJ/(\sqrt2p_0)\)만큼, 곧 위상 공간에서 운동량 방향으로 \(J\)만큼 한 번에 밀린다. 힘이 공진 성분 \(\tilde F(\omega) = \int F e^{i\omega t'}dt'\)을 가질 때만 끝에 남는 진폭이 생긴다.

상태로 말하면 진공이 숫자 \(\alpha\)만큼 "옮겨진" 것이다. 위상 공간에서 상태를 옮기는 유니터리 연산자를 변위 연산자(displacement operator)라 한다.

$$\hat D(\alpha) = e^{\alpha\hat a^\dagger-\alpha^*\hat a},\qquad \hat D^\dagger(\alpha)\,\hat a\,\hat D(\alpha) = \hat a+\alpha,\qquad \hat D(\alpha)|0\rangle = |\alpha\rangle$$
둘째 식에서 \(\hat a\hat D|0\rangle = \hat D(\hat a+\alpha)|0\rangle = \alpha\hat D|0\rangle\)이므로 셋째 식이 나온다. 베이커–캠벨–하우스도르프 공식(\([\hat A,\hat B]\)가 숫자일 때 \(e^{\hat A+\hat B} = e^{\hat A}e^{\hat B}e^{-[\hat A,\hat B]/2}\))으로 \(\hat D = e^{-|\alpha|^2/2}e^{\alpha\hat a^\dagger}e^{-\alpha^*\hat a}\)이고, 이것을 \(|0\rangle\)에 쓰면 앞 절의 전개식이 바로 나온다. 두 변위는 위상 하나를 빼고 더해진다: \(\hat D(\beta)\hat D(\alpha) = e^{i\,\mathrm{Im}(\beta\alpha^*)}\hat D(\alpha+\beta)\).

\(\hat A = \alpha\hat a^\dagger-\alpha^*\hat a\)라 두면 \(\hat D = e^{\hat A}\)이고, 하우스도르프 전개 \(e^{-\hat A}\hat a\,e^{\hat A} = \hat a+[\hat a,\hat A]+\tfrac{1}{2!}[[\hat a,\hat A],\hat A]+\cdots\)에서 \([\hat a,\hat A] = \alpha[\hat a,\hat a^\dagger] = \alpha\)는 숫자이므로 다음 교환자부터 모두 0이다. 따라서 \(\hat D^\dagger\hat a\hat D = \hat a+\alpha\), 같은 방법으로 \(\hat D^\dagger\hat x\hat D = \hat x+\sqrt2x_0\mathrm{Re}\,\alpha\)다. 교환자가 숫자라는 성질 하나가 위상 공간의 평행 이동을 만든다. 운동량 연산자가 \(e^{-ia\hat p/\hbar}\)로 위치를 \(a\)만큼 옮기는 것(7장의 병진)과 같은 구조다.

그러므로 고전적인 힘이 진공에서 출발한 진동자에 남기는 것은 언제나 결맞음 상태이고, \(n\)개 양자로 들뜰 확률은 정확히 포아송 \(P(0\to n) = e^{-|\alpha|^2}|\alpha|^{2n}/n!\)이다. 약한 힘의 1차 섭동론(14장)이 주는 \(P(0\to1) \approx |\alpha|^2\)은 이 식의 첫 항이다. 흡수한 평균 에너지 \(|\alpha|^2\hbar\omega\)는 고전 계산 \(J^2/2m\)과 같다.

압축 상태

결맞음 상태는 \(\Delta x\)와 \(\Delta p\)가 같은 둥근 방울이다. 불확정성 관계가 제한하는 것은 곱 \(\Delta x\Delta p \ge \hbar/2\)뿐이므로, 한쪽을 줄이고 다른 쪽을 늘린 타원 방울도 최소 불확정 상태가 될 수 있다. 이것을 압축 상태(squeezed state)라 한다. 위치를 정밀하게 재는 데 쓰는 상태라면 \(\Delta x\)를 진공보다 작게, 그 대가로 \(\Delta p\)를 크게 만든다.

$$\hat S(\zeta) = \exp\!\Big[\tfrac12\big(\zeta^*\hat a^2-\zeta\hat a^{\dagger2}\big)\Big],\quad \zeta = re^{i\phi},\qquad \hat S^\dagger\hat a\hat S = \hat a\cosh r-\hat a^\dagger e^{i\phi}\sinh r$$
\(\hat S\)를 압축 연산자(squeeze operator), \(r\)을 압축 매개변수라 한다. \(\phi = 0\)이면 \(\hat x \to \hat xe^{-r}\), \(\hat p \to \hat pe^{r}\)로 바뀌어 압축 진공 \(\hat S(r)|0\rangle\)은 \(\Delta x = e^{-r}x_0/\sqrt2\), \(\Delta p = e^{r}p_0/\sqrt2\)이다. \(\phi\)는 압축 방향을 \(\phi/2\)만큼 돌린다.

\(\hat S\)의 지수에는 \(\hat a^{\dagger2}\)가 들어 있다. 양자를 두 개씩 만드는 연산자다. 그래서 압축 진공의 수 분포에는 짝수만 나타난다.

$$\hat S(r)|0\rangle = \frac{1}{\sqrt{\cosh r}}\sum_{m=0}^{\infty}(-\tanh r)^m\frac{\sqrt{(2m)!}}{2^m\,m!}\,|2m\rangle,\qquad \bar n = \sinh^2r,\qquad \text{압축량} = 20\log_{10}e^{r}\ \text{dB} \approx 8.69\,r\ \text{dB}$$
실험에서는 비선형 결정에 펌프 빛(진동수 \(2\omega\))을 넣어 광자 하나를 \(\omega\) 광자 둘로 쪼개는 매개 하향 변환이 \(\hat a^{\dagger2}\) 항을 만든다. 압축량은 잡음 분산이 진공보다 몇 dB 줄었는지로 적는다(\(10\log_{10}e^{-2r}\)).

압축 진공 \(\hat S(r)|0\rangle\)에서 양자를 세면 어떤 수가 나올까?

\(\hat S\)를 전개하면 \(\hat a^{\dagger2}\)가 거듭 작용하므로 \(|0\rangle\)에서 \(|2\rangle, |4\rangle, \ldots\)만 생긴다. 평균은 \(\sinh^2r\)로 0이 아니다 — "진공"은 이름일 뿐 에너지가 있다. 시뮬레이터 readout의 \(P(1) = 0\)을 확인하라.

위상 공간과 위그너 함수

지금까지 위상 공간의 "방울"을 그려 왔지만, 양자역학에는 \(x\)와 \(p\)를 함께 정하는 확률 분포가 있을 수 없다(불확정성 관계). 그래도 위상 공간 그림을 정확하게 만드는 방법이 있다. 파동함수에서 다음 함수를 만든다.

위그너 함수

$$W(x,p) = \frac{1}{\pi\hbar}\int_{-\infty}^{\infty}\psi^*(x+y)\,\psi(x-y)\,e^{2ipy/\hbar}\,dy\qquad\Big(\text{밀도 행렬이면 }\psi(x-y)\psi^*(x+y)\to\langle x-y|\hat\rho|x+y\rangle\Big)$$

위그너 함수(Wigner function)는 실수이고 \(\iint W\,dx\,dp = 1\)이며, 주변 분포가 정확히 \(\int W\,dp = |\psi(x)|^2\), \(\int W\,dx = |\phi(p)|^2\)이다. \(\langle f(\hat x)+g(\hat p)\rangle = \iint (f+g)\,W\,dx\,dp\)처럼 고전 분포인 양 쓸 수 있지만, 음수가 될 수 있다. 그래서 준확률 분포(quasi-probability distribution)라 부른다. 무차원 단위(\(x/x_0, p/p_0\))에서 \(|W| \le 1/\pi\)다.

가우스 상태(진공, 결맞음, 압축, 열 상태)의 위그너 함수는 어디서나 양수인 가우스 함수다 — 앞 절들의 방울이 바로 그것이다. 순수 상태 가운데 \(W\ge0\)인 것은 가우스 상태뿐이다(허드슨 정리). 수 상태는 다르다.

$$W_n(x,p) = \frac{(-1)^n}{\pi}\,e^{-(\xi^2+\eta^2)}\,L_n\big(2(\xi^2+\eta^2)\big),\qquad \xi = \frac{x}{x_0},\ \eta = \frac{p}{p_0},\qquad W(0,0) = \frac1\pi\big\langle(-1)^{\hat N}\big\rangle$$
\(L_n\)은 라게르 다항식(QM.wignerMN). 수 상태의 위그너 함수는 원점 둘레의 동심 고리이고, 원점 값은 \((-1)^n/\pi\)로 홀수 \(n\)에서 음수다. 일반적으로 원점의 위그너 값은 패리티 \(\hat\Pi = (-1)^{\hat N}\)의 기댓값이다 — 위그너 함수를 실험으로 재는 방법(변위시킨 뒤 패리티 측정)이 이 식에서 나온다.

두 결맞음 상태를 중첩하면 더 극적이다. \(|\alpha\rangle\)과 \(|-\alpha\rangle\)은 위상 공간에서 멀리 떨어진 두 방울인데, 그 중첩 \(|\text{cat}_\pm\rangle \propto |\alpha\rangle\pm|-\alpha\rangle\)은 "두 곳에 동시에 있는" 진동자다. 슈뢰딩거의 사고 실험을 따라 고양이 상태(cat state)라 부른다.

$$W_{\text{cat}\pm} = \frac{W_{\alpha}+W_{-\alpha}\pm\frac{2}{\pi}e^{-(\xi^2+\eta^2)}\cos\!\big(2\sqrt2\,\alpha\,\eta\big)}{2\big(1\pm e^{-2\alpha^2}\big)}\qquad(\alpha\ \text{실수})$$
두 방울 사이 원점에 간섭 무늬가 생긴다. 무늬는 \(p\) 방향으로 주기 \(\pi/(\sqrt2\alpha)\)(단위 \(p_0\))로 진동하며 음수로 내려간다. 두 방울이 멀수록 무늬는 촘촘해지고, 환경과의 작은 상호작용에도 쉽게 지워진다(17장의 결어긋남). 결어긋남이 끝나면 고전적 혼합 \(\tfrac12(|\alpha\rangle\langle\alpha|+|-\alpha\rangle\langle-\alpha|)\)의 두 방울만 남는다.

장의 양자화: 광자와 포논

공진기 속 전자기장, 결정의 격자 진동, 초전도 회로의 전압은 모두 선형 운동 방정식을 따른다. 선형계는 서로 독립인 정규 모드로 나뉘고, 모드 하나의 운동은 정확히 조화 진동자다. 그러므로 양자화도 모드마다 사다리 연산자 한 쌍을 붙이면 끝난다.

$$\hat H = \sum_k\hbar\omega_k\big(\hat a_k^\dagger\hat a_k+\tfrac12\big),\qquad [\hat a_k,\hat a_{k'}^\dagger] = \delta_{kk'},\qquad \hat E(\mathbf r) = \sum_k\sqrt{\frac{\hbar\omega_k}{2\varepsilon_0V}}\big(\hat a_k+\hat a_k^\dagger\big)\,\mathbf u_k(\mathbf r)$$
\(\hat a_k^\dagger\)이 모드 \(k\)에 들뜸 양자 하나를 더한다. 전자기장의 양자가 광자(photon), 격자 진동의 양자가 포논(phonon)이다(고체물리 · 격자 진동과 포논). 장 진폭이 \(\hat a+\hat a^\dagger\), 곧 진동자의 \(\hat x\)에 해당한다. 부피 \(V\)인 모드에서 광자 하나의 장 세기 \(\sqrt{\hbar\omega/2\varepsilon_0V}\)는 1 µm³ 공진기, 1.55 µm 빛에서 약 85 kV/m이다.

모드가 온도 \(T\)의 환경과 열평형에 있으면 상태는 열 상태 \(\hat\rho = e^{-\hat H/k_BT}/Z\)이고, 수 분포는 기하 분포 \(P(n) = \bar n^{\,n}/(\bar n+1)^{n+1}\)이다. 평균 점유수와 에너지는

$$\bar n = \frac{1}{e^{\hbar\omega/k_BT}-1},\qquad \langle E\rangle = \hbar\omega\Big(\bar n+\frac12\Big) = \frac{\hbar\omega}{2}\coth\frac{\hbar\omega}{2k_BT}\ \xrightarrow{\ k_BT\gg\hbar\omega\ }\ k_BT$$
플랑크 분포(보스–아인슈타인 분포, 열·통계물리 · 양자 통계)다. 높은 온도에서는 에너지 등분배 \(k_BT\)로, 낮은 온도에서는 영점 에너지 \(\hbar\omega/2\)로 간다. 영점 요동은 온도를 아무리 낮춰도 남는다.

진동수 15.60(\(\hbar\omega =\) )인 모드가 300에 있으면 평균 점유수 \(\bar n =\) , 모드 에너지는 \(\langle E\rangle/k_BT =\) 이다.

존슨–나이퀴스트 잡음의 양자 보정

저항 \(R\)의 양 끝 전압 요동은 저항에 연결된 전송선의 전자기 모드들이 열 점유되어 생긴다. 고전적으로는 모드 하나에 \(k_BT\)씩이라 단측 스펙트럼 밀도가 \(4k_BTR\)이다. 모드 에너지를 위의 양자 식으로 바꾸면

$$S_V(f) = 4R\,hf\Big[\frac{1}{e^{hf/k_BT}-1}+\frac12\Big] = 2Rhf\coth\frac{hf}{2k_BT}\ \xrightarrow{\ hf\ll k_BT\ }\ 4k_BTR$$

라만 산란으로 포논 세기와 온도 재기

빛이 결정을 지나며 포논 하나를 만들면(스토크스) 진동수가 \(\Omega\)만큼 줄고, 이미 있던 포논 하나를 흡수하면(반스토크스) \(\Omega\)만큼 는다. 두 과정의 진폭은 포논 모드의 \(\hat a^\dagger\), \(\hat a\) 행렬 요소 \(\sqrt{n+1}\), \(\sqrt n\)에 비례하므로 세기는 \(\bar n+1\)과 \(\bar n\)에 비례한다.

$$\frac{I_\text{AS}}{I_\text{S}} = \frac{\bar n}{\bar n+1}\left(\frac{\omega_L+\Omega}{\omega_L-\Omega}\right)^4 = e^{-\hbar\Omega/k_BT}\left(\frac{\omega_L+\Omega}{\omega_L-\Omega}\right)^4$$
둘째 인자는 산란 세기의 \(\omega^4\) 의존성이다. 바닥 온도에서는 \(\bar n\to0\)이라 반스토크스 선이 사라지지만 스토크스 선은 남는다 — 포논 진공에도 \(\hat a^\dagger\)는 작용한다. 이 비로 비접촉 온도 측정을 한다.

핵심 정리

  1. 사다리 연산자: \(\hat a = (\hat x/x_0+i\hat p/p_0)/\sqrt2\), \([\hat a,\hat a^\dagger] = 1\), \(\hat H = \hbar\omega(\hat N+\tfrac12)\), \(x_0 = \sqrt{\hbar/m\omega}\). \(\|\hat a|\nu\rangle\|^2 = \nu\ge0\)이라 사다리는 \(\hat a|0\rangle = 0\)에서 끊기고 \(E_n = (n+\tfrac12)\hbar\omega\). \(\hat a|n\rangle = \sqrt n|n-1\rangle\), \(\hat a^\dagger|n\rangle = \sqrt{n+1}|n+1\rangle\).
  2. 행렬 요소: \(\hat x = \tfrac{x_0}{\sqrt2}(\hat a+\hat a^\dagger)\)는 \(\Delta n = \pm1\)만 잇는다(선택 규칙). \(\langle n|\hat x^2|n\rangle = x_0^2(n+\tfrac12)\), \(\Delta x\Delta p = (n+\tfrac12)\hbar\), \(\langle0|\hat x^4|0\rangle = \tfrac34x_0^4\). 자른 포크 공간에서는 \([\hat a,\hat a^\dagger]\)의 마지막 대각 성분이 \(1-N\)이다.
  3. 결맞음 상태: \(\hat a|\alpha\rangle = \alpha|\alpha\rangle\), \(P(n)\)은 평균 \(|\alpha|^2\)의 포아송(\(\Delta n = |\alpha|\), 산탄 잡음). 최소 불확정 \(\Delta x = x_0/\sqrt2\)를 유지한 채 \(\alpha\to\alpha e^{-i\omega t}\)로 고전 궤도를 돈다. \(|\langle\beta|\alpha\rangle|^2 = e^{-|\alpha-\beta|^2}\).
  4. 강제 진동자와 변위: 고전 힘은 \(\hat a\to\hat a+\alpha(t)\)만 바꾼다. 진공은 결맞음 상태 \(\hat D(\alpha)|0\rangle\)가 되고, \(\alpha = \tfrac{ix_0}{\sqrt2\hbar}\int F e^{-i\omega(t-t')}dt'\), 충격이면 \(iJ/\sqrt2p_0\). 같은 충격도 시점(위상)에 따라 진폭을 더하거나 지운다.
  5. 압축 상태: \(\hat S(r)\)은 \(\Delta x = e^{-r}x_0/\sqrt2\), \(\Delta p = e^{r}p_0/\sqrt2\). 압축 진공은 짝수 \(n\)만, \(\bar n = \sinh^2r\), 압축량 \(8.69r\) dB. 자유 전개로 타원이 돌아 \(\Delta x\)가 \(2\omega\)로 진동한다. 간섭계의 어두운 포트에 넣으면 위상 잡음이 \(e^{-r}/\sqrt{\bar N}\)으로 준다.
  6. 위그너 함수: 주변 분포가 \(|\psi(x)|^2\), \(|\phi(p)|^2\)인 실수 준확률 분포. 가우스 상태만 어디서나 양수이고, \(|n\rangle\)은 \(W(0,0) = (-1)^n/\pi\), 고양이 상태는 주기 \(\pi/\sqrt2\alpha\)의 음수 간섭 무늬를 가진다. 결어긋남은 무늬부터 지운다.
  7. 장의 양자화: 정규 모드마다 진동자, 들뜸 양자가 광자·포논. 열 점유 \(\bar n = 1/(e^{\hbar\omega/k_BT}-1)\), 모드 에너지 \(\hbar\omega(\bar n+\tfrac12)\). 존슨 잡음 \(S_V = 2Rhf\coth(hf/2k_BT)\)은 \(hf\gg k_BT\)에서 영점 요동이 남는다. 라만 \(I_\text{AS}/I_\text{S}\approx e^{-\hbar\Omega/k_BT}\)는 온도계, MEMS의 \(x_\text{zpf}\)는 fm 수준이다.

\(\hat a^\dagger|4\rangle = c_1|5\rangle\), \(\hat a^2|4\rangle = c_2|2\rangle\)일 때 \(c_1\)과 \(c_2\)를 구하라.

\(c_1 = \sqrt5 = 2.24\). \(\hat a^2|4\rangle = \hat a(2|3\rangle) = 2\sqrt3|2\rangle\)이므로 \(c_2 = \sqrt{12} = 3.46\).

조화 진동자에서 \(\langle m|\hat x|n\rangle \ne 0\)인 경우는?

\(\hat x \propto \hat a+\hat a^\dagger\)는 한 칸만 오르내리므로 \(m = n\pm1\)이다. 그래서 쌍극자 전이는 \(\Delta n = \pm1\)만 허용되고 진동 흡수 스펙트럼은 \(\omega\) 한 줄이다.

\(\langle2|\hat x^2|0\rangle\)을 \(x_0^2\) 단위로 구하라.

\(\hat x^2|0\rangle = \tfrac{x_0^2}{2}(\hat a+\hat a^\dagger)^2|0\rangle = \tfrac{x_0^2}{2}(|0\rangle+\sqrt2|2\rangle)\). 따라서 \(\langle2|\hat x^2|0\rangle = \tfrac{\sqrt2}{2}x_0^2 = 0.707x_0^2\).

수 상태 \(|3\rangle\)의 \(\Delta x\Delta p\)를 \(\hbar\) 단위로 구하라.

\(\Delta x^2 = x_0^2(n+\tfrac12)\), \(\Delta p^2 = p_0^2(n+\tfrac12)\)이므로 \(\Delta x\Delta p = (n+\tfrac12)x_0p_0 = 3.5\hbar\).

사다리 연산자로 \(\langle1|\hat x^4|1\rangle\)을 \(x_0^4\) 단위로 구하라.

\(\langle1|\hat x^4|1\rangle = \|\hat x^2|1\rangle\|^2\). 먼저 \(\hat x^2|1\rangle\)을 \(|1\rangle, |3\rangle\)으로 전개한다.

\(\hat x|1\rangle = \tfrac{x_0}{\sqrt2}(|0\rangle+\sqrt2|2\rangle)\), \(\hat x|0\rangle = \tfrac{x_0}{\sqrt2}|1\rangle\), \(\hat x|2\rangle = \tfrac{x_0}{\sqrt2}(\sqrt2|1\rangle+\sqrt3|3\rangle)\). 따라서 \(\hat x^2|1\rangle = \tfrac{x_0^2}{2}(|1\rangle+2|1\rangle+\sqrt6|3\rangle) = \tfrac{x_0^2}{2}(3|1\rangle+\sqrt6|3\rangle)\), 노름 제곱 \(\tfrac{x_0^4}{4}(9+6) = 3.75x_0^4\). 일반식 \(\tfrac{x_0^4}{4}(6n^2+6n+3)\)과 같다.

\(N = 10\) 준위로 자른 행렬 \(\hat a\), \(\hat a^\dagger\)로 계산한 \([\hat a,\hat a^\dagger]\)의 마지막 대각 성분과 대각합을 구하라.

자른 행렬에서 \((\hat a\hat a^\dagger)_{kk} = k+1\)(\(k \lt N-1\)), 마지막은 0이고 \((\hat a^\dagger\hat a)_{kk} = k\)다. 따라서 대각 성분은 처음 9개가 1, 마지막이 \(0-9 = -9\). 대각합은 \(9-9 = 0\) — 유한 행렬 교환자의 대각합은 늘 0이다.

\(|\alpha| = 3\)인 결맞음 상태의 평균 양자 수, 표준 편차, 정확히 9개일 확률을 구하라.

\(\bar n = 9\), \(\Delta n = 3\), \(P(9) = e^{-9}9^9/9! = 0.132\).

\(\alpha = 1\), \(\beta = -1\)인 두 결맞음 상태의 겹침 확률 \(|\langle\beta|\alpha\rangle|^2\)을 구하라.

\(|\langle\beta|\alpha\rangle|^2 = e^{-|\alpha-\beta|^2} = e^{-4} = 0.0183\). 위상 공간에서 중심 사이 거리 \(2\sqrt2\)는 방울 폭(0.71)의 4배라 거의 겹치지 않는다.

바닥 상태 진동자에 짧은 충격을 주어 결맞음 진폭 \(|\alpha| = 1.2\)가 되었다. 진동자가 여전히 바닥 상태에 있을 확률은?

\(P(0) = |\langle0|\alpha\rangle|^2 = e^{-|\alpha|^2} = e^{-1.44} = 0.237\).

진공에 충격을 주어 \(\alpha = 0.5i\)를 만들고, 정확히 1/4 주기 뒤에 같은 충격(\(+0.5i\))을 한 번 더 주었다. 마지막 평균 양자 수는?

첫 진폭은 1/4 주기 동안 \(e^{-i\pi/2}\)을 곱받는다.

1/4 주기 뒤 \(0.5i\cdot e^{-i\pi/2} = 0.5\). 둘째 충격 뒤 \(\alpha = 0.5+0.5i\), \(\bar n = |\alpha|^2 = 0.5\). 같은 방향(한 주기 뒤)이면 1.0, 반대(반주기 뒤)면 0이므로 그 중간이다 — 두 충격은 서로 수직이라 확률처럼 더해졌다.

잡음 분산을 6 dB 줄인 압축 진공의 압축 매개변수 \(r\)과 평균 양자 수를 구하라.

\(10\log_{10}e^{2r} = 6\)에서 \(r = 6\ln10/20 = 0.691\). \(\bar n = \sinh^2(0.691) = 0.558\).

\(r = 1\)인 압축 진공에서 양자 0개와 2개를 셀 확률을 구하라.

\(P(0) = 1/\cosh1 = 0.648\). \(P(2) = \frac{1}{\cosh r}\tanh^2r\,\frac{2!}{(2\cdot1!)^2} = 0.648\times0.580\times0.5 = 0.188\). \(P(1) = 0\)이다.

\(f = k_BT/h = 1.381\times10^{-23}\times4.2/6.626\times10^{-34} = 8.75\times10^{10}\) Hz = 87.5 GHz. \(\bar n = 1/(e-1) = 0.582\).

개념 확인 퀴즈

\(\hat a\)를 거듭 써서 내려가는 사다리가 반드시 \(n = 0\)에서 끝나야 하는 이유는?

끝없이 내려가면 언젠가 \(\nu \lt 0\)인데 그것은 노름의 제곱이다. 모순을 피하려면 \(\hat a|0\rangle = 0\)이어야 하고, 고유값은 정수가 된다. \(\hat a\)는 에르미트가 아니다.

결맞음 상태 \(|\alpha\rangle\)은 어느 연산자의 고유 상태인가?

\(\hat a|\alpha\rangle = \alpha|\alpha\rangle\). 광자 하나를 빼도(검출해도) 상태가 그대로라는 뜻이다. \(\hat a^\dagger\)는 정규화 가능한 고유 상태가 없고, \(\hat N\)의 고유 상태는 수 상태다.

압축 진공이 진공과 다른 점으로 옳은 것은?

불확정성 관계는 여전히 지켜지고(최소 \(\hbar/2\)), 줄인 만큼 반대쪽이 는다. \(\hat a^{\dagger2}\)가 쌍으로 만들므로 짝수만, 평균 \(\sinh^2r\)개다.

위그너 함수가 음수인 영역이 있다는 것의 의미는?

주변 분포 \(\int W\,dp = |\psi|^2\)는 늘 양수다. 음수는 \(\hbar\) 크기의 작은 영역에만 있고, 양자 간섭(고양이 상태의 무늬)과 \(|n\rangle\)의 패리티처럼 고전 확률로 설명할 수 없는 성질을 나타낸다.

온도를 0 K에 가깝게 내릴 때 결정의 광학 포논 모드에 대한 설명으로 옳은 것은?

\(\bar n\to0\)이므로 반스토크스(\(\propto\bar n\))는 사라지지만 스토크스(\(\propto\bar n+1\))는 남는다 — 진공에서도 \(\hat a^\dagger|0\rangle = |1\rangle\)이 가능하다. 영점 에너지 \(\hbar\Omega/2\)는 그대로다.
