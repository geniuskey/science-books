Chapter 02

상태 공간과 디랙 표기

01장에서 전자의 상태는 함수 \(\psi(x)\)였다. 그런데 같은 전자를 운동량 \(\phi(p)\)로 적어도, 에너지 준위들의 계수 \(c_n\)으로 적어도, 스핀처럼 숫자 두 개로 적어도 물리는 똑같다. 이 장에서는 이 모든 표기의 공통 뼈대인 복소 벡터 공간을 세운다. 상태는 화살표 \(|\psi\rangle\)이고, 기저를 고르면 그 화살표가 숫자 목록(성분)이 되며, 물리량은 행렬이 된다. 기저를 돌리면 성분은 모두 바뀌지만 확률의 합, 내적, 고유값은 그대로다. 이 사실 하나가 양자역학의 계산을 선형대수로 바꾸고, TCAD가 슈뢰딩거 방정식을 행렬 고유값 문제로 푸는 근거가 된다.

상태 화살표 끝이나 초록 축 끝을 끌어 보세요
  • 켓 \(|\psi\rangle\)·브라 \(\langle\psi|\)·내적 \(\langle\phi|\psi\rangle\)을 열벡터·켤레 전치·행렬 곱으로 계산하고, 전역 위상과 상대 위상을 구별한다.
  • 직교 정규 기저의 완비성 \(\sum_n|n\rangle\langle n| = \hat 1\)과 사영 연산자 \(\hat P_n = |n\rangle\langle n|\)로 성분·확률을 구한다.
  • 연산자의 행렬 요소 \(A_{mn} = \langle m|\hat A|n\rangle\)를 쓰고, 에르미트·유니터리 연산자의 성질과 기저 변환 \(A' = S^\dagger A S\)를 다룬다.
  • 에르미트 행렬의 고유값 문제를 풀고 스펙트럼 분해 \(\hat A = \sum_a a\,|a\rangle\langle a|\)로 연산자의 함수를 계산한다.
  • 위치·운동량 고유 상태의 δ 정규화 \(\langle x|x'\rangle = \delta(x-x')\), \(\langle x|p\rangle = e^{ipx/\hbar}/\sqrt{2\pi\hbar}\)를 이해하고 두 표현 사이를 푸리에 변환으로 오간다.
  • 유한 차분으로 해밀토니언을 \(N\times N\) 행렬로 만들어 고유값의 격자 수렴(\(\propto\Delta x^2\))을 확인하고, 텐서곱으로 두 자유도의 상태 공간을 만든다.

상태 벡터와 힐베르트 공간

양자역학의 첫 번째 공준은 이렇다: 계의 상태는 복소 벡터 공간의 벡터 하나로 완전히 기술된다. 디랙은 이 벡터를 켓(ket) \(|\psi\rangle\)이라는 기호로 썼다. 벡터이므로 더할 수 있고 복소수를 곱할 수 있다 — 이것이 중첩 원리다. \(|\psi_1\rangle\)과 \(|\psi_2\rangle\)이 가능한 상태라면 \(\alpha|\psi_1\rangle + \beta|\psi_2\rangle\)도 가능한 상태다. 계수가 실수가 아니라 복소수라는 점이 고전 확률과 갈라지는 지점이다.

벡터 공간에 내적이 정의되어 길이와 각도를 잴 수 있고, 극한을 취해도 공간 밖으로 나가지 않는(완비) 공간을 힐베르트 공간(Hilbert space)이라 한다. 스핀 하나는 2차원, 원자의 준위 몇 개만 남긴 모형은 유한 차원, 1차원 입자의 파동함수는 제곱 적분 가능한 함수 전체 \(L^2\)라는 무한 차원 공간이다. 이 장의 계산은 대부분 2–3차원에서 하지만, 모든 정리가 무한 차원에서도 (조금의 주의와 함께) 성립한다.

켓, 브라, 내적

기저를 하나 정하면 켓은 성분의 열벡터가 된다. 켓마다 짝이 되는 브라(bra) \(\langle\psi|\)가 있는데, 열벡터를 켤레 전치한 행벡터다. 브라와 켓을 붙이면 "브라–켓(bracket)" \(\langle\phi|\psi\rangle\), 즉 내적이 된다.

$$|\psi\rangle \doteq \begin{pmatrix} c_1\\ c_2\\ \vdots \end{pmatrix},\qquad \langle\psi| \doteq \begin{pmatrix} c_1^* & c_2^* & \cdots \end{pmatrix},\qquad \langle\phi|\psi\rangle = \sum_n d_n^*\,c_n$$
\(\doteq\)는 "이 기저에서 이렇게 표현된다"는 뜻이다(사쿠라이의 표기). \(d_n\)은 \(|\phi\rangle\)의 성분. 함수 공간에서는 합이 적분이 된다: \(\langle\phi|\psi\rangle = \int \phi^*(x)\,\psi(x)\,dx\).
내적의 성질

① \(\langle\phi|\psi\rangle = \langle\psi|\phi\rangle^*\) (순서를 바꾸면 켤레) ② 켓에 대해 선형: \(\langle\phi|(\alpha|\psi_1\rangle+\beta|\psi_2\rangle) = \alpha\langle\phi|\psi_1\rangle + \beta\langle\phi|\psi_2\rangle\), 브라에 대해서는 켤레 선형 ③ \(\langle\psi|\psi\rangle \ge 0\), 0은 영벡터일 때만. 노름 \(\|\psi\| = \sqrt{\langle\psi|\psi\rangle}\). 물리적 상태는 \(\langle\psi|\psi\rangle = 1\)로 정규화한다. ④ 코시–슈바르츠 부등식 \(|\langle\phi|\psi\rangle|^2 \le \langle\phi|\phi\rangle\langle\psi|\psi\rangle\) — 03장 불확정성 관계의 출발점이다.

\(|\alpha\rangle = i|1\rangle - 2|2\rangle - i|3\rangle\), \(|\beta\rangle = i|1\rangle + 2|3\rangle\)이다(\(\{|n\rangle\}\)은 직교 정규 기저). \(\langle\alpha|\), \(\langle\alpha|\beta\rangle\), \(\langle\beta|\alpha\rangle\)를 구하고, 두 켓을 정규화하라.

풀이 \(\langle\alpha| = -i\langle1| - 2\langle2| + i\langle3|\). \(\langle\alpha|\beta\rangle = (-i)(i) + (-2)(0) + (i)(2) = 1 + 2i\). \(\langle\beta|\alpha\rangle = \langle\alpha|\beta\rangle^* = 1-2i\)(직접 계산해도 \((-i)(i) + 0 + 2(-i) = 1-2i\)). \(\langle\alpha|\alpha\rangle = 1+4+1 = 6\), \(\langle\beta|\beta\rangle = 1+4 = 5\)이므로 정규화된 켓은 \(|\alpha\rangle/\sqrt6\), \(|\beta\rangle/\sqrt5\).

직교 정규 기저, 완비성, 사영 연산자

서로 직교하고 길이가 1인 벡터 집합 \(\{|n\rangle\}\), 곧 \(\langle m|n\rangle = \delta_{mn}\)이면서 모든 벡터를 그 선형 결합으로 쓸 수 있으면 직교 정규 기저(orthonormal basis)라 한다. 그러면 성분은 내적 하나로 뽑힌다.

$$|\psi\rangle = \sum_n c_n|n\rangle,\qquad c_n = \langle n|\psi\rangle,\qquad \langle\psi|\psi\rangle = \sum_n|c_n|^2 = 1$$
둘째 식은 첫 식에 \(\langle m|\)을 곱하면 바로 나온다. 셋째 식(파스발 등식)은 "모든 결과의 확률을 더하면 1"이라는 뜻이다.

첫 두 식을 합치면 \(|\psi\rangle = \sum_n |n\rangle\langle n|\psi\rangle\)이다. 이것이 모든 \(|\psi\rangle\)에 대해 성립하므로 괄호 안의 연산자는 단위 연산자다.

$$\sum_n |n\rangle\langle n| = \hat 1 \qquad(\text{완비성 관계})$$
완비성 관계(completeness relation)는 "단위 연산자 끼워 넣기"라는 만능 도구다. 어떤 식의 중간에든 \(\hat 1 = \sum_n|n\rangle\langle n|\)을 넣으면 추상적 식이 성분 계산으로 바뀐다. 예: \(\langle\phi|\psi\rangle = \sum_n\langle\phi|n\rangle\langle n|\psi\rangle = \sum_n d_n^*c_n\).

사영 연산자

\(\hat P_n = |n\rangle\langle n|\)은 벡터를 \(|n\rangle\) 방향으로 "그림자 지게" 하는 사영 연산자(projection operator)다. 그림자의 그림자는 그대로이므로 \(\hat P_n^2 = \hat P_n\)이고, 고유값은 0(수직 성분)과 1(평행 성분)뿐이다. 여러 기저 벡터가 펼치는 부분 공간에 대한 사영은 합 \(\hat P = \sum_{n\in S}|n\rangle\langle n|\)이다. 측정에서 결과가 부분 공간 \(S\)에 들어갈 확률은

$$P(S) = \langle\psi|\hat P|\psi\rangle = \|\hat P|\psi\rangle\|^2 = \sum_{n\in S}|c_n|^2$$
03장에서 축퇴된 고유값의 측정과 상태 붕괴 \(|\psi\rangle\to\hat P|\psi\rangle/\|\hat P|\psi\rangle\|\)에 이 식을 그대로 쓴다.

연산자의 행렬 표현: 에르미트와 유니터리

선형 연산자(linear operator) \(\hat A\)는 켓을 켓으로 보내며 \(\hat A(\alpha|\psi\rangle+\beta|\phi\rangle) = \alpha\hat A|\psi\rangle + \beta\hat A|\phi\rangle\)를 만족한다. 기저 \(\{|n\rangle\}\)를 정하면 연산자는 숫자 표, 곧 행렬이 된다. 완비성을 양쪽에 끼워 넣으면

$$\hat A = \sum_{m,n}|m\rangle\,A_{mn}\,\langle n|,\qquad A_{mn} = \langle m|\hat A|n\rangle$$
\(A_{mn}\)을 행렬 요소(matrix element)라 한다. \(n\)번째 열은 \(\hat A|n\rangle\)의 성분이다. 연산자의 곱은 행렬 곱, \(\hat A|\psi\rangle\)은 행렬 × 열벡터, \(\langle\phi|\hat A|\psi\rangle\)은 행 × 행렬 × 열이다.

에르미트 수반과 에르미트 연산자

연산자 \(\hat A\)의 에르미트 수반(Hermitian adjoint) \(\hat A^\dagger\)는 모든 벡터에 대해 \(\langle\phi|\hat A^\dagger|\psi\rangle = \langle\psi|\hat A|\phi\rangle^*\)인 연산자다. 행렬로는 켤레 전치 \((A^\dagger)_{mn} = A_{nm}^*\). 규칙: \((\hat A\hat B)^\dagger = \hat B^\dagger\hat A^\dagger\), \((c\hat A)^\dagger = c^*\hat A^\dagger\), \((|\psi\rangle\langle\phi|)^\dagger = |\phi\rangle\langle\psi|\), 그리고 켓 \(\hat A|\psi\rangle\)에 대응하는 브라는 \(\langle\psi|\hat A^\dagger\)이다.

\(\hat A^\dagger = \hat A\)인 연산자가 에르미트 연산자(Hermitian operator)다. 기댓값 \(\langle\hat A\rangle = \langle\psi|\hat A|\psi\rangle\)이 언제나 실수이므로 측정 가능한 물리량(관측량)은 모두 에르미트 연산자로 나타낸다. 위치 \(\hat x\), 운동량 \(\hat p\), 해밀토니언 \(\hat H\), 스핀 \(\hat S_z\)가 모두 그렇다.

\(\hat p = -i\hbar\,d/dx\)는 왜 에르미트인가

유니터리 연산자: 길이와 각도를 지키는 회전

\(\hat U^\dagger\hat U = \hat U\hat U^\dagger = \hat 1\)인 연산자를 유니터리 연산자(unitary operator)라 한다. \(\langle\hat U\phi|\hat U\psi\rangle = \langle\phi|\hat U^\dagger\hat U|\psi\rangle = \langle\phi|\psi\rangle\)이므로 모든 내적(따라서 모든 확률)이 보존된다. 복소 공간의 "회전"이다. 시간 전개 \(\hat U(t) = e^{-i\hat Ht/\hbar}\)(04장), 스핀 회전 \(e^{-i\theta\,\hat{\mathbf n}\cdot\boldsymbol\sigma/2}\)(10장), 큐비트 게이트(18장), 기저 변환이 모두 유니터리다. 에르미트 \(\hat H\)이면 \(e^{-i\hat H t}\)는 늘 유니터리다.

고유값 문제와 스펙트럼 정리

\(\hat A|a\rangle = a|a\rangle\)를 만족하는 0이 아닌 켓 \(|a\rangle\)를 고유 상태(eigenstate), 수 \(a\)를 고유값이라 한다. 행렬로는 \(\det(A - \lambda\,1) = 0\)의 근이다. 에르미트 연산자의 고유값 문제에는 세 가지 결정적 성질이 있다.

에르미트 연산자의 정리

① 고유값은 실수다. \(\langle a|\hat A|a\rangle = a\langle a|a\rangle\)와 그 켤레 \(a^*\langle a|a\rangle\)가 같으므로 \(a = a^*\). ② 다른 고유값의 고유 상태는 직교한다. \(\langle a'|\hat A|a\rangle\)를 왼쪽·오른쪽으로 계산하면 \((a - a')\langle a'|a\rangle = 0\). ③ 고유 상태들이 완비 기저를 이룬다(축퇴가 있으면 그 부분 공간 안에서 직교화). 그래서

\(\hat A = \sum_a a\,|a\rangle\langle a| = \sum_a a\,\hat P_a\)

이것이 스펙트럼 정리(spectral theorem)다. 행렬로는 \(A = U\,\operatorname{diag}(a_1,a_2,\dots)\,U^\dagger\), \(U\)의 열이 고유벡터다.

2×2 에르미트 행렬은 늘 \(H = h_0\,1 + \mathbf h\cdot\boldsymbol\sigma\)로 쓸 수 있다: \(h_0 = (H_{00}+H_{11})/2\), \(h_z = (H_{00}-H_{11})/2\), \(H_{01} = h_x - ih_y\). 파울리 행렬의 고유값이 \(\pm1\)이므로 고유값은 \(E_\pm = h_0 \pm |\mathbf h|\)이고, 고유 상태는 블로흐 구에서 \(\pm\hat{\mathbf h}\) 방향의 두 점이다. 행렬이 에르미트가 아니면 이 구조가 깨진다: 고유값이 복소수가 될 수 있고 고유 상태가 직교하지 않는다. 열린 계(흡수 경계, NEGF의 자기 에너지)를 다룰 때 일부러 쓰는 비에르미트 해밀토니언의 복소 고유값 \(E - i\Gamma/2\)는 수명 \(\hbar/\Gamma\)를 뜻한다.

2×2 행렬 \(\begin{pmatrix}0 & 1\\ c & 0\end{pmatrix}\)에서 \(c = 1\)(에르미트)이면 고유값은 \(\pm1\)이다. \(c = -1\)로 바꾸면(비에르미트) 고유값은?

\(\lambda^2 = c\)이므로 \(c = -1\)이면 \(\lambda = \pm i\). 실수 고유값은 에르미트성(또는 그에 준하는 대칭)이 보장하는 성질이다. 아래 실험실에서 "비에르미트"를 고르고 왼쪽 아래 원소를 \(b^*\)에서 떼어 내 보라 — 고유값이 실축을 벗어난다.

위치·운동량 표현과 연속 기저

위치 연산자 \(\hat x\)의 고유값은 연속이다. 고유 켓 \(|x\rangle\)(\(\hat x|x\rangle = x|x\rangle\))들을 기저로 쓰면 합이 적분이 되고, 크로네커 델타가 디랙 델타가 된다.

$$\langle x|x'\rangle = \delta(x-x'),\qquad \int|x\rangle\langle x|\,dx = \hat 1,\qquad \psi(x) = \langle x|\psi\rangle$$
01장의 파동함수 \(\psi(x)\)는 다름 아닌 "위치 기저에서의 성분"이다. 내적은 \(\langle\phi|\psi\rangle = \int\langle\phi|x\rangle\langle x|\psi\rangle dx = \int\phi^*\psi\,dx\). 이렇게 연속 고유값의 고유 상태를 델타 함수로 맞추는 것을 δ 정규화(delta-function normalization)라 한다.

\(|x\rangle\) 자체는 \(\langle x|x\rangle = \delta(0) = \infty\)이므로 힐베르트 공간의 정규화된 상태가 아니다. 그래도 기저로는 완벽하게 작동한다. 이산 격자에서 극한을 취하면 이유가 보인다: 간격 \(\Delta x\)의 격자점 켓 \(|j\rangle\)은 \(\langle i|j\rangle = \delta_{ij}\)이고, 성분은 \(c_j = \sqrt{\Delta x}\,\psi(x_j)\)이다. \(|x_j\rangle = |j\rangle/\sqrt{\Delta x}\)로 두면 \(\langle x_i|x_j\rangle = \delta_{ij}/\Delta x \to \delta(x-x')\)가 된다.

운동량 고유 상태와 푸리에 변환

운동량 연산자의 위치 표현 \(\langle x|\hat p|\psi\rangle = -i\hbar\,\partial_x\psi(x)\)에서 고유 상태를 구하면 평면파다. δ 정규화 \(\langle p|p'\rangle = \delta(p-p')\)에 맞추면

$$\langle x|p\rangle = \frac{1}{\sqrt{2\pi\hbar}}\,e^{ipx/\hbar},\qquad \phi(p) = \langle p|\psi\rangle = \frac{1}{\sqrt{2\pi\hbar}}\int e^{-ipx/\hbar}\psi(x)\,dx$$
두 번째 식은 완비성 \(\int|x\rangle\langle x|dx\)를 끼워 넣은 것, 곧 01장의 푸리에 변환이다. 같은 상태를 위치 기저와 운동량 기저로 본 두 "성분 목록"이며, 파스발 등식 \(\int|\psi|^2dx = \int|\phi|^2dp\)는 기저 변환이 유니터리라는 사실이다. 운동량 표현에서는 \(\hat x \to i\hbar\,\partial_p\).

위치 기저는 연속이라 무한 차원이지만, 컴퓨터는 유한한 행렬만 다룬다. 가장 간단한 길은 위치를 간격 \(\Delta x\)의 격자점 \(x_j\)로 자르는 것이다. 성분 \(\psi_j = \psi(x_j)\)들이 \(N\)차원 벡터가 되고, 2차 도함수를 중심 차분 \(\psi''_j \approx (\psi_{j+1} - 2\psi_j + \psi_{j-1})/\Delta x^2\)로 바꾸면 해밀토니언이 삼중 대각 행렬이 된다. 이것이 유한 차분법(finite-difference method)이다.

$$H_{jj} = 2t + V_j,\qquad H_{j,j\pm1} = -t,\qquad t = \frac{\hbar^2}{2m^*\Delta x^2}$$
양 끝 바깥은 \(\psi = 0\)(무한 벽)으로 둔다. \(H\)는 실대칭(에르미트) 행렬이므로 4절의 정리가 모두 성립한다: 고유값(에너지)은 실수, 고유벡터(격자 위의 파동함수)는 서로 직교, \(N\)개의 고유벡터가 완비 기저. 이 책의 단위에서 \(\hbar^2/2m_\mathrm{e} = 0.0381\ \mathrm{eV\cdot nm^2}\)이므로 \(\Delta x = 0.1\) nm이면 자유 전자의 \(t = 3.81\) eV다.

무한 우물(폭 \(L\), 내부 격자점 \(N\)개, \(\Delta x = L/(N+1)\))에서는 행렬의 고유값을 정확히 쓸 수 있다: 고유벡터가 \(\psi_j = \sin(n\pi j/(N+1))\)이므로

$$E_n^{\mathrm{FD}} = 2t\left[1-\cos\frac{n\pi}{N+1}\right] \approx E_n\left[1 - \frac{1}{12}\left(\frac{n\pi}{N+1}\right)^2\right]$$
상대 오차가 \((n\pi\Delta x/L)^2/12\), 곧 \(\Delta x^2\)에 비례한다(2차 정확도). 격자를 두 배 촘촘히 하면 오차는 1/4이 된다. 항상 정확한 값보다 낮게 나온다.

텐서곱: 자유도가 둘 이상일 때

전자는 위치와 스핀을 함께 가진다. 큐비트 두 개, 전자와 정공, 나노시트의 가둠 방향과 수송 방향도 그렇다. 부분계 A의 상태 공간 \(\mathcal H_A\)(차원 \(d_A\))와 B의 \(\mathcal H_B\)(차원 \(d_B\))를 합친 공간은 텐서곱(tensor product) \(\mathcal H_A\otimes\mathcal H_B\)이고, 차원은 곱 \(d_Ad_B\)이다. 기저는 \(|i\rangle\otimes|j\rangle = |i\rangle|j\rangle = |ij\rangle\)이고, 내적은 각 부분의 내적의 곱이다: \(\langle i'j'|ij\rangle = \delta_{i'i}\delta_{j'j}\).

$$|\Psi\rangle = \sum_{i,j}c_{ij}\,|i\rangle\otimes|j\rangle,\qquad (\hat A\otimes\hat B)\,|a\rangle\otimes|b\rangle = \hat A|a\rangle\otimes\hat B|b\rangle$$
행렬로는 크로네커 곱: \(A\otimes B\)는 \(A\)의 각 원소 \(A_{ij}\)를 블록 \(A_{ij}B\)로 바꾼 \(d_Ad_B\times d_Ad_B\) 행렬이다. 순서는 이 책의 관례대로 왼쪽 인자(A, \(q_0\))가 큰 자리다: \(|00\rangle, |01\rangle, |10\rangle, |11\rangle\).

부분계마다 상태를 하나씩 정해 \(|a\rangle\otimes|b\rangle\)로 쓸 수 있는 상태를 곱 상태(product state)라 하고, 그렇게 쓸 수 없는 상태를 얽힌 상태라 한다. 두 큐비트에서는 계수 행렬 \(c_{ij}\)의 행렬식이 판정 기준이다: 곱 상태면 \(c_{ij} = a_ib_j\)이므로 \(c_{00}c_{11} - c_{01}c_{10} = 0\).

두 큐비트 상태 (a) \(\frac12(|00\rangle + |01\rangle + |10\rangle + |11\rangle)\), (b) \(\frac{1}{\sqrt2}(|00\rangle + |11\rangle)\)이 곱 상태인지 판정하고, 곱 상태면 인수로 나눠라.

핵심 정리

  1. 상태는 힐베르트 공간의 켓 \(|\psi\rangle\), 브라 \(\langle\psi|\)는 그 켤레 전치다. 내적 \(\langle\phi|\psi\rangle = \sum d_n^*c_n\)은 확률 진폭이고 \(|\langle\phi|\psi\rangle|^2\)이 확률이다. 전역 위상은 물리가 아니지만 상대 위상은 간섭으로 드러난다.
  2. 직교 정규 기저의 성분은 \(c_n = \langle n|\psi\rangle\), 완비성 \(\sum_n|n\rangle\langle n| = \hat 1\)은 어디든 끼워 넣어 추상 식을 성분 계산으로 바꾼다. 사영 연산자 \(\hat P = |n\rangle\langle n|\)은 \(\hat P^2 = \hat P\), 확률은 \(\langle\psi|\hat P|\psi\rangle\).
  3. 연산자는 행렬 \(A_{mn} = \langle m|\hat A|n\rangle\)이다. 에르미트 \(\hat A = \hat A^\dagger\)는 관측량(실수 기댓값), 유니터리 \(\hat U^\dagger\hat U = \hat 1\)은 내적을 지키는 회전(시간 전개·스핀 회전·게이트·기저 변환)이다.
  4. 기저 변환은 \(c' = S^\dagger c\), \(A' = S^\dagger AS\)(\(S\)의 열 = 새 기저). 대각합·행렬식·고유값·확률의 합은 변하지 않는다.
  5. 에르미트 연산자의 고유값은 실수, 고유 상태는 직교하고 완비하다(스펙트럼 정리 \(\hat A = \sum_a a|a\rangle\langle a|\)). 연산자의 함수는 \(f(\hat A) = \sum_a f(a)|a\rangle\langle a|\). 2×2는 \(h_0 + \mathbf h\cdot\boldsymbol\sigma\), \(E_\pm = h_0\pm|\mathbf h|\). 비에르미트면 고유값이 복소수가 될 수 있다.
  6. 연속 기저는 δ 정규화: \(\langle x|x'\rangle = \delta(x-x')\), \(\psi(x) = \langle x|\psi\rangle\), \(\langle x|p\rangle = e^{ipx/\hbar}/\sqrt{2\pi\hbar}\). 위치·운동량 표현은 푸리에 변환(유니터리 기저 변환)으로 이어진다.
  7. 유한 차분은 \(\hat H\)를 삼중 대각 행렬(대각 \(2t+V_j\), 비대각 \(-t\), \(t = \hbar^2/2m^*\Delta x^2\))로 만들고 고유값 오차는 \(\propto\Delta x^2\)이다. 이것이 강결합 모형이자 TCAD 슈뢰딩거–포아송의 핵심이다. 두 자유도의 공간은 텐서곱(차원의 곱)이며, 곱으로 쓸 수 없는 상태가 얽힘이다.

연습문제

\(\{|0\rangle, |1\rangle\}\)과 \(\{|1\rangle, |2\rangle, \dots\}\)는 직교 정규 기저다. 파울리 행렬 \(\sigma_x = \begin{pmatrix}0&1\\1&0\end{pmatrix}\), \(\sigma_y = \begin{pmatrix}0&-i\\i&0\end{pmatrix}\), \(\sigma_z = \begin{pmatrix}1&0\\0&-1\end{pmatrix}\). \(\hbar^2/2m_\mathrm{e} = 0.0381\ \mathrm{eV\cdot nm^2}\). 특별한 말이 없으면 답이 ±1% 이내면 정답이다.

\(|\psi\rangle = N[(2-i)|0\rangle + 3i|1\rangle]\)가 정규화되도록 하는 양의 실수 \(N\)은?

\(\langle\psi|\psi\rangle = N^2(|2-i|^2 + |3i|^2) = N^2(5+9) = 14N^2 = 1\) → \(N = 1/\sqrt{14} = 0.267\).

\(|a\rangle = (1+i)|0\rangle + i|1\rangle\), \(|b\rangle = 2|0\rangle - |1\rangle\)일 때 \(\langle a|b\rangle\)의 실수부와 허수부는?

브라의 계수는 켤레: \(\langle a| = (1-i)\langle0| - i\langle1|\).

\(\langle a|b\rangle = (1-i)(2) + (-i)(-1) = 2 - 2i + i = 2 - i\). 실수부 2, 허수부 −1. (\(\langle b|a\rangle = 2+i\).)

다음 중 에르미트 행렬은?

에르미트는 대각 원소가 실수이고 \(A_{21} = A_{12}^*\). 둘째만 만족한다. 첫째는 \(A_{21} = i \ne (i)^* = -i\)(대칭이지만 에르미트 아님), 셋째는 대각에 \(i\), 넷째는 반대칭 실행렬(반에르미트 — \(i\)를 곱하면 \(\sigma_y\)가 된다).

\(A = \begin{pmatrix}2 & 1-i\\ 1+i & 3\end{pmatrix}\)의 고유값을 큰 것부터 구하라.

\(\lambda^2 - (\operatorname{Tr}A)\lambda + \det A = 0\).

\(\operatorname{Tr}A = 5\), \(\det A = 6 - |1-i|^2 = 6-2 = 4\). \(\lambda^2 - 5\lambda + 4 = 0\) → \(\lambda = 4, 1\). 고유벡터: \(\lambda = 4\)에서 \((1-i, 2)/\sqrt6\), \(\lambda = 1\)에서 \((-2, 1+i)/\sqrt6\) — 직교한다.

\(|\psi\rangle = \frac{1}{\sqrt5}(|0\rangle + 2i|1\rangle)\)에서 \(\langle\sigma_y\rangle\)는?

\(\sigma_y|\psi\rangle = \frac{1}{\sqrt5}\begin{pmatrix}-i\cdot2i\\ i\cdot1\end{pmatrix} = \frac{1}{\sqrt5}\begin{pmatrix}2\\ i\end{pmatrix}\). \(\langle\psi| = \frac{1}{\sqrt5}(1, -2i)\)이므로 \(\langle\sigma_y\rangle = \frac15[2 + (-2i)(i)] = \frac15(2+2) = 0.8\). 블로흐 벡터로는 \((0, 0.8, -0.6)\)의 \(y\) 성분이다.

\(|\psi\rangle = \frac{1}{\sqrt5}(2|0\rangle + |1\rangle)\)를 \(x\) 기저로 측정할 때 \(|+\rangle\)이 나올 확률은?

\(\langle +|\psi\rangle = \frac{1}{\sqrt{10}}(2+1) = \frac{3}{\sqrt{10}}\), 확률 \(9/10 = 0.9\).

3준위 상태 \(|\psi\rangle = \frac13(|1\rangle + 2i|2\rangle - 2|3\rangle)\)에 사영 연산자 \(\hat P = |2\rangle\langle2| + |3\rangle\langle3|\)를 적용한다. \(\langle\psi|\hat P|\psi\rangle\)(결과가 2 또는 3일 확률)는? \(\hat P\)를 두 번 적용하면 어떻게 되는가?

\(\hat P|\psi\rangle = \frac13(2i|2\rangle - 2|3\rangle)\), \(\|\hat P\psi\|^2 = (4+4)/9 = 0.889\). \(\hat P^2 = \hat P\)이므로 두 번 적용해도 같은 벡터다.

\(y\) 기저 \(|\pm i\rangle = \frac{1}{\sqrt2}(|0\rangle \pm i|1\rangle)\)에서 \(\sigma_z\)의 비대각 행렬 요소 \(\langle +i|\sigma_z|-i\rangle\)는?

\(\sigma_z|-i\rangle = \frac{1}{\sqrt2}(|0\rangle + i|1\rangle) = |+i\rangle\)이므로 \(\langle +i|\sigma_z|-i\rangle = 1\). 대각 요소는 \(\langle\pm i|\sigma_z|\pm i\rangle = 0\). 즉 \(y\) 기저에서 \(\sigma_z\)의 행렬은 \(\begin{pmatrix}0&1\\1&0\end{pmatrix}\)이다.

\(A = \begin{pmatrix}5 & 4\\ 4 & 5\end{pmatrix}\)의 양의 제곱근 \(\sqrt A\)(고유값이 모두 양수인 것)를 스펙트럼 분해로 구하라. 원소 \((\sqrt A)_{11}\)과 \((\sqrt A)_{12}\)는?

고유값 9와 1, 고유벡터 \((1, \pm1)/\sqrt2\).

\(\hat P_9 = \frac12\begin{pmatrix}1&1\\1&1\end{pmatrix}\), \(\hat P_1 = \frac12\begin{pmatrix}1&-1\\-1&1\end{pmatrix}\). \(\sqrt A = 3\hat P_9 + 1\hat P_1 = \begin{pmatrix}2&1\\1&2\end{pmatrix}\). 확인: \(\begin{pmatrix}2&1\\1&2\end{pmatrix}^2 = \begin{pmatrix}5&4\\4&5\end{pmatrix}\) ✓.

자유 전자를 격자 간격 0.10 nm의 유한 차분으로 풀 때 비대각 원소의 크기 \(t = \hbar^2/2m_\mathrm{e}\Delta x^2\)는?

\(t = 0.0381/0.01 = 3.81\) eV. 강결합 사슬로 보면 띠 폭이 \(4t = 15.2\) eV다.

무한 우물의 바닥 에너지를 유한 차분으로 구할 때 상대 오차가 1% 미만이 되는 가장 작은 내부 격자점 수 \(N\)은? (근사식이 아니라 정확한 \(E^{\mathrm{FD}}_1 = 2t[1-\cos(\pi/(N+1))]\)를 써라.)

근사식으로는 \((\pi/(N+1))^2/12 \lt 0.01\). 경계 근처 값을 정확한 식으로 확인한다.

상대 오차 \(1 - 2(1-\cos x)/x^2\), \(x = \pi/(N+1)\). \(N = 8\): 1.01%, \(N = 9\): 0.82%. 따라서 \(N = 9\)(\(\Delta x = L/10\)).

폭 10 nm의 GaAs 무한 우물(\(m^* = 0.067m_\mathrm{e}\))을 내부 격자점 9개로 풀었다. 행렬의 가장 낮은 고유값은 몇 meV인가? (정확한 값은 56.1 meV)

\(\Delta x = 1.0\) nm, \(t = 0.0381/(0.067\times1.0^2) = 0.5687\) eV. \(E_1^{\mathrm{FD}} = 2t[1-\cos(\pi/10)] = 1.1373\times0.04894 = 0.05566\) eV = 55.7 meV. 오차 −0.82%.

Si 반전층(\(\Delta_2\) 골짜기, \(m_z = 0.916m_\mathrm{e}\))의 수직 전기장이 0.50 MV/cm이다. 삼각 우물 근사로 바닥 부띠 에너지(전도대 바닥 기준)와 전하 중심 \(\langle z\rangle = 2E_0/3qF\)를 구하라. (\(a_1 = 2.338\))

0.50 MV/cm = 0.050 V/nm이므로 \(qF = 0.050\) eV/nm. \(E_0 = 2.338\,(0.0381\,(qF)^2/m_z)^{1/3}\).

\(0.0381\times0.0025/0.916 = 1.040\times10^{-4}\ \mathrm{eV^3}\), 세제곱근 0.04703 eV, \(E_0 = 2.338\times0.04703 = 0.110\) eV = 110 meV. \(\langle z\rangle = 2(0.110)/(3\times0.050) = 1.47\) nm. 고전적으로는 전하가 계면에 붙는데 1.5 nm쯤 떨어져 있다 — SiO₂ 두께로 환산하면 약 0.5 nm의 CET 증가다(\(1.47\times3.9/11.7\)).

예제의 상태 \(\psi(x) = \sqrt\kappa\,e^{-\kappa|x|}\), \(\kappa = 2.0\ \mathrm{nm^{-1}}\)인 자유 전자의 운동 에너지 기댓값 \(\langle T\rangle = \langle p^2\rangle/2m_\mathrm{e}\)를 운동량 표현 \(|\phi(p)|^2 = \frac{2}{\pi}\frac{p_0^3}{(p^2+p_0^2)^2}\)으로 구하라.

\(\int_{-\infty}^\infty\frac{u^2}{(1+u^2)^2}du = \frac\pi2\).

\(\langle p^2\rangle = \frac2\pi p_0^3\cdot\frac{1}{p_0}\cdot\frac\pi2 = p_0^2 = \hbar^2\kappa^2\). \(\langle T\rangle = \hbar^2\kappa^2/2m_\mathrm{e} = 0.0381\times4.0 = 0.152\) eV. 위치 표현에서는 꼭짓점의 \(\psi''\)에 델타 함수가 숨어 있어 조심해야 하지만, 운동량 표현에서는 곧바로 나온다 — 좋은 기저를 고르면 계산이 쉬워진다.

두 큐비트 상태 \(\frac12(|00\rangle + |01\rangle + |10\rangle - |11\rangle)\)의 공존도 \(C = 2|c_{00}c_{11} - c_{01}c_{10}|\)는? 곱 상태인가?

\(c_{00}c_{11} - c_{01}c_{10} = \frac14(-1) - \frac14(1) = -\frac12\), \(C = 1\). 최대로 얽힌 상태다. 실제로 \(\frac{1}{\sqrt2}(|0\rangle|+\rangle + |1\rangle|-\rangle)\)으로 쓸 수 있다 — 두 항의 B 상태가 직교하는 슈미트 꼴이다(아다마르 + CNOT 회로로 만든다, 18장).

위치를 nm로 잴 때 \(\langle x|\psi\rangle = \psi(x)\)와 \(\langle x|x'\rangle\)의 단위로 옳은 것은? (\(|\psi\rangle\)은 정규화된 상태)

\(\int|\psi|^2dx = 1\)이 무차원이므로 \(\psi\)는 nm−1/2. \(\int|x\rangle\langle x|dx = \hat 1\)에서 \(|x\rangle\)은 nm−1/2의 "단위"를 가지므로 \(\langle x|x'\rangle = \delta(x-x')\)는 nm⁻¹ — 델타 함수의 단위는 인자의 역수다. 연속 기저 성분이 확률이 아니라 확률 밀도의 진폭인 이유다.

개념 확인 퀴즈

\(\langle\phi|\psi\rangle = 0.6 + 0.3i\)이면 \(\langle\psi|\phi\rangle\)는?

\(\langle\psi|\phi\rangle = \langle\phi|\psi\rangle^*\). 두 순서의 확률 \(|\cdot|^2 = 0.45\)는 같다.

\(|\psi\rangle\)과 \(-|\psi\rangle\)(전역 위상 π)의 관계는?

모든 확률 \(|\langle\phi|\psi\rangle|^2\)이 같다. 단, 중첩의 한 성분에만 −1을 곱하면(상대 위상) 다른 상태가 된다: \(|+\rangle\) vs \(|-\rangle\).

에르미트 연산자의 서로 다른 고유값에 속한 두 고유 상태는?

\((a - a')\langle a'|a\rangle = 0\)이고 \(a \ne a'\)이므로 \(\langle a'|a\rangle = 0\). 비에르미트 행렬에서는 이 보장이 사라진다(실험실의 겹침 \(|\langle v_1|v_2\rangle|\)).

운동량 고유 상태 \(|p\rangle\)이 실제 전자의 상태가 될 수 없는 이유는?

\(|\langle x|p\rangle|^2 = 1/2\pi\hbar\)가 모든 \(x\)에서 일정하므로 전체 적분이 무한대다. 기저로는 쓰되 물리적 상태는 파속(겹침)이다.

큐비트 3개의 상태 공간 차원과, 일반적인 상태를 적는 데 필요한 복소 성분 수는?

텐서곱의 차원은 곱: \(2^3 = 8\). 곱 상태라면 큐비트마다 2개, 합 6개(정규화·위상 빼면 더 적다)로 충분하지만, 얽힌 상태까지 담으려면 8개가 다 필요하다. \(n\) 큐비트면 \(2^n\) — 양자 컴퓨터의 힘과 고전 시뮬레이션의 어려움이 여기서 나온다.
