Chapter 18

양자 정보와 큐비트

이 책은 지금까지 상태 벡터·측정·시간 전개·스핀·밀도 행렬을 자연을 설명하는 도구로 썼다. 마지막 장에서는 같은 도구로 계산하고 통신하는 기계를 설계한다. 2준위 계 하나가 큐비트(qubit)이고, 블로흐 구 위의 회전이 게이트이며, 얽힘은 고전 정보로 흉내 낼 수 없는 자원이 된다. 아래 블로흐 구에서 화살표(큐비트 상태)가 게이트를 하나씩 지날 때마다 구가 돌아간다. 화살표 끝을 끌어 시작 상태를 바꾸고, 빈 곳을 누르면 다음 게이트로 넘어간다.

화살표 끝을 끌거나 빈 곳을 누르세요
  • 큐비트 상태를 블로흐 벡터로 나타내고, 단일 큐비트 게이트(X, Y, Z, H, S, T, 회전 게이트)를 블로흐 구의 회전으로 이해하며 측정 확률을 계산한다.
  • 텐서곱으로 다큐비트 상태를 쓰고, CNOT로 벨 상태를 만들며, 슈미트 분해·얽힘 엔트로피·공존도로 얽힘의 양을 잰다.
  • CHSH 부등식 \(|S| \le 2\)를 국소 숨은 변수 이론에서 유도하고, 양자역학이 \(S = 2\sqrt2\)까지 위반함을 계산한다.
  • 복제 불가 정리를 증명하고, 양자 순간이동 회로를 단계별로 따라가며 왜 빛보다 빨리 정보를 보낼 수 없는지 설명한다.
  • BB84 프로토콜에서 도청이 남기는 오류율(QBER)과 비밀 키 비율 \(1 - 2h(e)\)를 계산한다.
  • 도이치–조사와 그로버 알고리즘을 간섭과 회전으로 설명하고, 최적 반복 횟수 \(\approx \tfrac{\pi}{4}\sqrt N\)을 구한다.
  • 반복 부호와 증후군 측정으로 오류 정정의 원리를 익히고, 초전도·실리콘 스핀·이온·광자 큐비트와 극저온 CMOS의 공학적 조건(온도·진동수·배선)을 수치로 비교한다.

큐비트와 단일 큐비트 게이트

고전 비트는 0 아니면 1이다. 양자역학에서 서로 구별되는 두 상태 \(|0\rangle\), \(|1\rangle\)을 가진 계 — 전자 스핀의 위·아래(10장), 광자의 수평·수직 편광(3장), 원자나 인공 원자의 바닥·들뜬 준위 — 는 둘의 임의의 중첩에 있을 수 있다. 정보 이론에서는 이런 계를 물리적 구현과 상관없이 큐비트라 부른다.

큐비트

2차원 힐베르트 공간의 단위 벡터 \(|\psi\rangle = \alpha|0\rangle + \beta|1\rangle\), \(|\alpha|^2 + |\beta|^2 = 1\). \(|0\rangle\), \(|1\rangle\)을 계산 기저(computational basis)라 한다. 전체 위상 \(e^{i\gamma}\)는 관측할 수 없으므로 상태는 실수 두 개로 정해진다.

$$|\psi\rangle = \cos\frac{\theta}{2}\,|0\rangle + e^{i\phi}\sin\frac{\theta}{2}\,|1\rangle, \qquad \mathbf r = (\sin\theta\cos\phi,\ \sin\theta\sin\phi,\ \cos\theta) = \bigl(\langle\sigma_x\rangle, \langle\sigma_y\rangle, \langle\sigma_z\rangle\bigr)$$
\(0 \le \theta \le \pi\), \(0 \le \phi \lt 2\pi\). 단위 벡터 \(\mathbf r\)이 블로흐 벡터(Bloch vector)이고 그 끝이 블로흐 구(Bloch sphere) 위의 점이다(3장, 10장). 북극이 \(|0\rangle\), 남극이 \(|1\rangle\), 적도의 \(+x\), \(+y\)가 \(|+\rangle = (|0\rangle+|1\rangle)/\sqrt2\), \(|{+i}\rangle = (|0\rangle+i|1\rangle)/\sqrt2\)이다. 혼합 상태는 구 안쪽의 점이다(17장).

계산 기저로 재면 0이 나올 확률은 \(P(0) = |\alpha|^2 = \cos^2(\theta/2) = (1 + r_z)/2\)이다. 측정 후 상태는 \(|0\rangle\) 또는 \(|1\rangle\)로 붕괴하므로, 큐비트 하나를 한 번 재서 얻는 정보는 1비트뿐이다. 연속적인 \(\theta, \phi\)가 "무한한 정보"를 담는 것처럼 보이지만, 큐비트 \(n\)개로 꺼낼 수 있는 고전 정보는 많아야 \(n\)비트다(홀레보 한계(Holevo bound)). 양자 정보의 힘은 저장 용량이 아니라 진폭끼리의 간섭에서 나온다.

큐비트가 \(\theta = 60^\circ\), \(\phi = 90^\circ\)인 상태에 있다. (가) 켓과 블로흐 벡터를 쓰고, (나) 계산 기저로 잴 때 \(P(0)\)을 구하라. (다) 하다마르 게이트 \(H\)를 건 뒤의 블로흐 벡터와 \(P(0)\)은?

닫힌 계의 시간 전개는 유니터리다(4장). 큐비트에 거는 연산, 곧 양자 게이트(quantum gate)는 \(2\times2\) 유니터리 행렬이고, 전체 위상을 빼면 블로흐 구의 회전이다(8장의 회전 연산자에서 \(j = \tfrac12\)).

$$\hat U = e^{i\gamma}\,\hat R_{\mathbf n}(\alpha), \qquad \hat R_{\mathbf n}(\alpha) = e^{-i\alpha\,\mathbf n\cdot\boldsymbol\sigma/2} = \cos\frac{\alpha}{2}\,\hat I - i\sin\frac{\alpha}{2}\,(\mathbf n\cdot\boldsymbol\sigma)$$
\(\hat R_{\mathbf n}(\alpha)\)는 블로흐 벡터를 축 \(\mathbf n\) 둘레로 각 \(\alpha\)만큼 돌린다. 각이 \(\alpha/2\)로 들어가는 것이 스피너의 성질이다: \(\alpha = 2\pi\) 회전은 상태에 \(-1\)을 곱한다(관측 불가능한 전체 위상).

다큐비트 상태와 얽힘

두 큐비트의 상태 공간은 각 공간의 텐서곱 \(\mathcal H_A\otimes\mathcal H_B\)이다(2장). 기저는 \(|00\rangle, |01\rangle, |10\rangle, |11\rangle\) 넷이고(왼쪽이 큐비트 0), 일반 상태는 복소 진폭 네 개로 쓴다. \(n\)큐비트면 진폭이 \(2^n\)개다 — 큐비트를 하나 더할 때마다 고전 컴퓨터로 흉내 내는 데 드는 메모리가 두 배가 된다.

$$|\Psi\rangle = \sum_{x\in\{0,1\}^n} c_x\,|x\rangle, \qquad \sum_x |c_x|^2 = 1, \qquad |a\rangle\otimes|b\rangle = (a_0|0\rangle + a_1|1\rangle)\otimes(b_0|0\rangle + b_1|1\rangle) = \sum_{ij} a_ib_j\,|ij\rangle$$
곱 상태는 진폭이 \(c_{ij} = a_ib_j\)로 인수분해되는 특별한 경우다. 그렇게 쓸 수 없는 상태를 얽힌 상태(entangled state)라 한다.

큐비트 30개의 상태 벡터를 진폭마다 배정밀도 복소수(16바이트)로 저장하면 진폭 개, 메모리 가 든다.

두 큐비트 게이트 가운데 가장 중요한 것은 제어 NOT(controlled-NOT, CNOT)이다. 제어 큐비트가 \(|1\rangle\)일 때만 표적 큐비트를 뒤집는다: \(|c, t\rangle \to |c, t\oplus c\rangle\). 고전적인 XOR처럼 보이지만, 제어 큐비트가 중첩에 있으면 결과는 얽힘이다.

$$|\Phi^\pm\rangle = \frac{|00\rangle \pm |11\rangle}{\sqrt2}, \qquad |\Psi^\pm\rangle = \frac{|01\rangle \pm |10\rangle}{\sqrt2}$$
네 벨 상태(Bell states)는 2큐비트 공간의 직교 정규 기저다. \(|\Psi^-\rangle\)은 10장의 스핀 단일항이다. 회로 입력을 \(|00\rangle, |01\rangle, |10\rangle, |11\rangle\)로 바꾸면 차례로 \(|\Phi^+\rangle, |\Psi^+\rangle, |\Phi^-\rangle, |\Psi^-\rangle\)가 나오고, 회로를 거꾸로 돌리면(CNOT 뒤 \(H\)) 벨 기저 측정이 된다.

\(|00\rangle\)에서 시작해 큐비트 0에 \(H\), 이어서 CNOT(제어 0, 표적 1)를 건다. 각 단계의 상태를 쓰고, 이 상태가 곱 상태로 쓰일 수 없음을 보여라. 큐비트 0만 재면 결과는 어떤가?

풀이 보기
전략 게이트를 차례로 기저 상태에 적용하고, 곱 상태라면 \(c_{00}c_{11} = c_{01}c_{10}\)이어야 한다는 조건을 쓴다(\(c_{ij} = a_ib_j\)).
풀이 \(H\): \(|00\rangle \to (|00\rangle + |10\rangle)/\sqrt2\). CNOT: \(|10\rangle \to |11\rangle\)이므로 \((|00\rangle + |11\rangle)/\sqrt2 = |\Phi^+\rangle\). \(c_{00}c_{11} = \tfrac12\)인데 \(c_{01}c_{10} = 0\)이라 인수분해되지 않는다. 큐비트 0을 재면 0과 1이 반반이고, 0이 나오면 큐비트 1은 반드시 0, 1이 나오면 반드시 1이다.
\(|\Phi^+\rangle = (|00\rangle + |11\rangle)/\sqrt2\); 각자는 무작위(반반)지만 둘의 결과는 완전히 같다.
검토 큐비트 0의 축약 밀도 행렬은 \(\hat\rho_0 = \operatorname{Tr}_1|\Phi^+\rangle\langle\Phi^+| = \hat I/2\) — 블로흐 벡터 길이 0인 최대 혼합 상태다(17장). 전체는 순수 상태인데 부분은 완전히 무작위라는 것이 얽힘의 표지다.

순수한 2큐비트 상태의 얽힘은 한 숫자로 잴 수 있다. 어떤 2큐비트 순수 상태든 국소 기저를 잘 고르면 항이 둘뿐인 슈미트 분해(Schmidt decomposition)로 쓸 수 있다.

$$|\Psi\rangle = \sqrt{\lambda}\,|a_1\rangle|b_1\rangle + \sqrt{1-\lambda}\,|a_2\rangle|b_2\rangle, \qquad S_E = -\lambda\log_2\lambda - (1-\lambda)\log_2(1-\lambda), \qquad C = 2\,|c_{00}c_{11} - c_{01}c_{10}|$$
\(\lambda\)는 축약 밀도 행렬 \(\hat\rho_A\)의 고유값이다. \(S_E\)는 \(\hat\rho_A\)의 폰 노이만 엔트로피로 얽힘 엔트로피(entanglement entropy)라 부르며, 곱 상태면 0, 벨 상태면 최대 1(이른바 1 "ebit")이다. \(C\)는 공존도(concurrence)로, 순수 상태에서 \(C = 2\sqrt{\lambda(1-\lambda)}\)이고 \(\hat\rho_A\)의 블로흐 벡터 길이는 \(\sqrt{1 - C^2}\)이다.

\(|\Psi\rangle = \sqrt{0.8}\,|00\rangle + \sqrt{0.2}\,|11\rangle\)의 얽힘 엔트로피와 공존도, 그리고 큐비트 A의 블로흐 벡터를 구하라.

벨 부등식과 CHSH

1935년 아인슈타인·포돌스키·로젠(EPR)은 이렇게 물었다. \(|\Phi^+\rangle\)의 두 큐비트를 멀리 떼어 놓아도 한쪽을 재면 다른 쪽 결과를 확실히 예측할 수 있다. 멀리 떨어진 측정이 서로 영향을 줄 수 없다면(국소성), 결과는 처음부터 정해져 있었어야 하지 않을까? 그렇다면 양자역학은 그 "숨은 변수"를 모르는 불완전한 이론이다. 1964년 벨은 이 질문을 실험으로 판정할 수 있는 부등식으로 바꾸었다.

CHSH 부등식

측정 결과가 숨은 변수 \(\lambda\)와 그 자리의 설정만으로 정해진다고 하자: \(A(a, \lambda), B(b, \lambda) = \pm1\) (국소 숨은 변수 이론(local hidden variable theory)). 그러면 어떤 분포 \(\rho(\lambda)\)에 대해서도 \(|S| \le 2\)이다(클라우저·혼·시모니·홀트, 1969).

$$S = \int\!\rho(\lambda)\,\Bigl\{A(a)\bigl[B(b) - B(b')\bigr] + A(a')\bigl[B(b) + B(b')\bigr]\Bigr\}\,d\lambda, \qquad |S| \le 2$$
증명: 각 \(\lambda\)에서 \(B(b), B(b') = \pm1\)이므로 \(B(b) - B(b')\)와 \(B(b) + B(b')\) 중 하나는 0이고 다른 하나는 \(\pm2\)다. 그러므로 중괄호는 언제나 \(\pm2\)이고, 그 평균의 크기는 2를 넘을 수 없다. 결과가 미리 정해져 있다는 가정과 국소성만 썼다.

양자역학의 예측을 계산하자. 블로흐 구의 \(x\)–\(z\) 평면에서 각 \(\theta\) 방향 스핀 성분 \(\sigma_\theta = \cos\theta\,\sigma_z + \sin\theta\,\sigma_x\)를 잰다고 하면, \(|\Phi^+\rangle\)에서

$$E(a, b) = \langle\Phi^+|\sigma_a\otimes\sigma_b|\Phi^+\rangle = \cos(a - b), \qquad S_\text{max} = 2\sqrt2 \approx 2.83$$
\(\langle\sigma_z\otimes\sigma_z\rangle = \langle\sigma_x\otimes\sigma_x\rangle = 1\), 섞인 항 \(\langle\sigma_z\otimes\sigma_x\rangle = 0\)에서 나온다. 최댓값 \(2\sqrt2\)는 양자역학이 허용하는 상한(치렐손 한계(Tsirelson bound))이다. 광자 편광에서는 블로흐 각이 편광판 각의 두 배이므로 \(E = \cos2(\alpha - \beta)\)로 쓴다.

복제 불가 정리와 양자 순간이동

고전 정보는 마음대로 복사할 수 있다. 메모리 셀을 읽고, 증폭기로 신호를 키우고, 백업을 만든다. 양자 정보는 그럴 수 없다. 이 사실이 양자 암호의 안전성, 양자 통신의 거리 한계, 오류 정정의 설계를 모두 결정한다.

복제 불가 정리

임의의 미지 상태 \(|\psi\rangle\)에 대해 \(\hat U(|\psi\rangle|0\rangle) = |\psi\rangle|\psi\rangle\)를 만드는 유니터리 \(\hat U\)는 없다(우터스·주렉, 디크스, 1982). 서로 직교하는 상태들(예: \(|0\rangle\), \(|1\rangle\)만)은 복사할 수 있지만, 직교하지 않는 두 상태를 함께 복사하는 기계는 없다. 이것을 복제 불가 정리(no-cloning theorem)라 한다.

두 상태 \(|\psi\rangle\), \(|\phi\rangle\)을 모두 복사하는 유니터리 \(\hat U\)가 있다고 가정하고 모순을 이끌어 내라. 선형성만으로도 증명해 보라.

풀이 보기
전략 유니터리는 내적을 보존한다. 복사 전후의 내적을 비교한다.
풀이 복사 전: \((\langle\psi|\langle0|)(|\phi\rangle|0\rangle) = \langle\psi|\phi\rangle\). 복사 후: \((\langle\psi|\langle\psi|)(|\phi\rangle|\phi\rangle) = \langle\psi|\phi\rangle^2\). 유니터리면 둘이 같아야 하므로 \(\langle\psi|\phi\rangle = \langle\psi|\phi\rangle^2\), 곧 \(\langle\psi|\phi\rangle = 0\) 또는 1. 선형성: \(|0\rangle \to |00\rangle\), \(|1\rangle \to |11\rangle\)이면 \(|+\rangle|0\rangle \to (|00\rangle + |11\rangle)/\sqrt2\)인데, 원하는 결과는 \(|{+}{+}\rangle = (|00\rangle + |01\rangle + |10\rangle + |11\rangle)/2\)다. 둘은 다르다.
같은 기계로 복사할 수 있는 상태는 서로 같거나 직교해야 한다 — 미지의 일반 상태는 복사할 수 없다.
검토 선형성 증명에서 "복사기"는 CNOT다. CNOT는 \(|0\rangle\), \(|1\rangle\)은 완벽히 복사하지만 중첩은 복사 대신 얽힘을 만든다. 2절의 벨 회로가 바로 실패한 복사기였다.

완벽한 복사는 불가능하지만 "적당한" 복사는 가능하다. 미지 상태 하나에서 두 사본을 만들 때 각 사본의 충실도는 최대 \(5/6 \approx 0.833\)이다(부제크–힐러리 보편 복제기). 한편 상태를 한 번 재서 그 결과대로 새 상태를 만드는 고전적 방법(측정 후 준비)의 평균 충실도는 \(2/3\)이다. 이 \(2/3\)는 "양자 채널을 썼다"고 주장하려면 넘어야 하는 기준선이다.

그러면 큐비트를 멀리 보내려면? 직접 보내는 대신 미리 나눠 가진 얽힘과 고전 통신 2비트로 상태를 옮길 수 있다. 이것이 양자 순간이동(quantum teleportation)이다(베넷 등, 1993; 첫 실험 1997). 핵심 항등식은 앨리스의 두 큐비트를 벨 기저로 다시 쓰는 것이다.

$$|\psi\rangle_0\,|\Phi^+\rangle_{12} = \tfrac12\Bigl[\,|\Phi^+\rangle_{01}\,|\psi\rangle_2 + |\Phi^-\rangle_{01}\,Z|\psi\rangle_2 + |\Psi^+\rangle_{01}\,X|\psi\rangle_2 + |\Psi^-\rangle_{01}\,XZ|\psi\rangle_2\,\Bigr]$$
\(|\psi\rangle = \alpha|0\rangle + \beta|1\rangle\)는 앨리스가 보낼 미지 상태(큐비트 0), 큐비트 1은 앨리스, 큐비트 2는 밥이 가진 얽힘의 반쪽이다. 앨리스가 벨 측정을 하면 네 결과가 각각 확률 1/4로 나오고, 밥의 큐비트는 \(|\psi\rangle\)에 알려진 파울리 연산이 걸린 상태가 된다.

앨리스의 측정 결과가 \(m_1 m_2 = 11\)이었다. 밥의 큐비트 상태를 \(\alpha, \beta\)로 쓰고, 보정 후 \(|\psi\rangle\)이 됨을 보여라. 밥이 결과를 받기 전 그의 큐비트의 밀도 행렬은?

풀이 보기
전략 회로 ②의 CNOT·\(H\)는 \(|\Psi^-\rangle\)을 \(|11\rangle\)로 보낸다. 항등식에서 \(|\Psi^-\rangle\)에 붙은 밥의 상태를 읽는다.
풀이 밥의 상태는 \(XZ|\psi\rangle = X(\alpha|0\rangle - \beta|1\rangle) = -\beta|0\rangle + \alpha|1\rangle\). 보정: 먼저 \(X\) → \(\alpha|0\rangle - \beta|1\rangle\), 이어서 \(Z\) → \(\alpha|0\rangle + \beta|1\rangle = |\psi\rangle\) (\(ZX\cdot XZ = I\)). 결과를 모르는 밥에게는 네 경우가 1/4씩 섞여 있으므로 \(\hat\rho_B = \tfrac14\sum_{P\in\{I,X,Z,XZ\}} P|\psi\rangle\langle\psi|P^\dagger = \hat I/2\).
보정 전 \(-\beta|0\rangle + \alpha|1\rangle\); \(X\) 후 \(Z\)로 \(|\psi\rangle\) 복원; 결과를 받기 전 \(\hat\rho_B = \hat I/2\)

같은 자원을 거꾸로 쓰면 초밀집 부호화(superdense coding)가 된다: 미리 나눈 벨 쌍이 있으면 앨리스가 자기 큐비트에 \(I, X, Z, XZ\) 중 하나를 걸어 보내는 것만으로 밥에게 고전 2비트를 전한다. 순간이동은 "벨 쌍 + 2비트 = 큐비트 1개", 초밀집 부호화는 "벨 쌍 + 큐비트 1개 = 2비트"다. 거리가 먼 양자 통신은 광섬유 손실 때문에 직접 보낼 수 없고, 복제 불가 정리 때문에 증폭할 수도 없다. 그래서 중간 마디에서 순간이동을 이어 붙이는 얽힘 교환으로 거리를 늘리는 양자 중계기가 연구되고 있다.

양자 키 분배: BB84

암호 통신의 가장 확실한 방법은 메시지만큼 긴 무작위 키를 한 번만 쓰는 일회용 암호다. 문제는 키를 어떻게 안전하게 나눠 갖느냐다. 양자 키 분배(quantum key distribution, QKD)는 "엿보면 흔적이 남는다"는 양자역학의 성질로 이 문제를 푼다. 첫 프로토콜은 베넷과 브라사르의 BB84(1984)이다.

  1. 전송: 앨리스는 광자마다 무작위 비트와 무작위 기저(+: \(|0\rangle, |1\rangle\) = 수평·수직, ×: \(|+\rangle, |-\rangle\) = ±45°)를 골라 편광 광자를 보낸다.
  2. 측정: 밥은 광자마다 무작위 기저를 골라 잰다. 기저가 맞으면 비트가 그대로, 틀리면 반반 무작위로 나온다.
  3. 선별: 공개 채널로 기저만 비교하고 기저가 같은 것만 남긴다(평균 절반). 이것이 선별 키(sifted key)다.
  4. 오류 추정: 선별 키 일부를 공개해 비교하고 양자 비트 오류율(quantum bit error rate, QBER) \(e\)를 잰다.
  5. 후처리: 오류를 고치고(정보 조정), 도청자가 알 수 있는 정보만큼 키를 줄인다(비밀 증폭).

도청자 이브가 광자를 가로채 무작위 기저로 재고 그 결과대로 새 광자를 보내면(가로채기–재전송), 이브의 기저가 틀린 절반의 경우 광자 상태가 바뀌고, 그중 절반에서 밥의 비트가 틀린다. 복제 불가 정리 때문에 이브는 원본을 남겨 두고 사본만 잴 수 없다.

$$e_\text{Eve} = f\times\tfrac12\times\tfrac12 = \frac{f}{4}, \qquad r = 1 - 2h(e), \qquad h(e) = -e\log_2 e - (1-e)\log_2(1-e)$$
\(f\)는 이브가 가로챈 비율이다. 전부 가로채면 QBER 25%. \(r\)은 선별 키 1비트당 남길 수 있는 비밀 키 비율(쇼어–프레스킬 한계)로, \(h(e)\)는 이진 엔트로피(확률과 통계의 베르누이 분포에서 정의한 정보량의 평균)다. \(e\)만큼의 비트를 고치는 데 \(h(e)\), 이브의 정보를 지우는 데 다시 \(h(e)\)를 쓴다. \(r = 0\)이 되는 \(e \approx 11.0\%\)를 넘으면 키를 만들 수 없다.

이브가 모든 광자를 가로채 무작위 기저로 재고 다시 보낸다. 선별 키의 오류율은?

이브의 기저가 틀릴 확률 1/2 × 그 경우 밥이 틀릴 확률 1/2 = 1/4. 시뮬레이터에서 이브를 100%로 놓고 확인하자. 11% 한계를 훨씬 넘으므로 앨리스와 밥은 키를 버린다.

BB84의 안전성은 "측정하면 상태가 흐트러진다"는 데서 온다. 3절의 얽힘으로도 키를 나눌 수 있다: 벨 쌍의 두 반쪽을 앨리스와 밥이 재면 같은 기저에서 결과가 완전히 상관되고, 남은 설정으로 CHSH 값을 재서 도청자가 끼어들었는지 확인한다(에커트의 E91, 1991). \(S\)가 \(2\sqrt2\)에 가까울수록 제3자와 공유된 상관이 없다는 뜻이라, 장치 내부를 믿지 않고도 안전성을 보이는 길이 열린다.

양자 알고리즘: 도이치–조사와 그로버

\(n\)큐비트에 \(H\)를 하나씩 걸면 \(2^n\)개 입력의 균등 중첩이 된다. 함수 \(f\)를 계산하는 회로를 이 중첩에 한 번 걸면 모든 \(f(x)\)가 "동시에" 계산된다. 하지만 측정하면 하나만 나오므로 이것만으로는 쓸모가 없다. 양자 알고리즘의 기술은 답이 아닌 진폭들은 상쇄 간섭으로 지우고 답만 보강 간섭으로 키우는 데 있다.

$$\hat U_f|x\rangle|y\rangle = |x\rangle|y\oplus f(x)\rangle \;\Longrightarrow\; \hat U_f|x\rangle|-\rangle = (-1)^{f(x)}\,|x\rangle|-\rangle$$
\(\hat U_f\)는 함수 \(f: \{0,1\}^n \to \{0,1\}\)를 계산하는 가역 회로, 곧 오라클(oracle)이다. 보조 큐비트를 \(|-\rangle\)에 두면 \(f(x)\)가 보조 큐비트가 아니라 입력의 위상으로 돌아온다(위상 되차기(phase kickback)). 이제 \(f\)의 정보가 진폭의 부호에 실렸고, 간섭으로 읽을 수 있다.

도이치–조사 문제(1992): \(f\)가 상수(모두 0 또는 모두 1)이거나 균형(정확히 절반이 1)이라는 약속이 있다. 어느 쪽인지 판정하라. 고전 결정론적 알고리즘은 최악의 경우 \(2^{n-1} + 1\)번 물어야 하지만, 양자 회로는 한 번이면 된다: \(H^{\otimes n}\) → 오라클 → \(H^{\otimes n}\) 뒤에 \(|0\cdots0\rangle\)의 진폭은

$$\langle 0^n|H^{\otimes n}\hat U_f H^{\otimes n}|0^n\rangle = \frac{1}{2^n}\sum_x (-1)^{f(x)} = \begin{cases}\pm1 & \text{상수}\\ 0 & \text{균형}\end{cases}$$
상수면 모든 항이 같은 부호로 더해져 \(|0^n\rangle\)이 확실히 나오고, 균형이면 정확히 상쇄되어 절대 나오지 않는다. 모두 0을 재면 "상수", 하나라도 1이면 "균형".

그로버 검색(1996): 정렬되지 않은 \(N = 2^n\)개 항목 중 \(f(w) = 1\)인 하나 \(w\)를 찾는다. 고전적으로는 평균 \(N/2\)번 확인해야 한다. 그로버 알고리즘은 균등 중첩 \(|s\rangle\)에서 시작해 두 반사를 번갈아 건다.

$$\hat G = \underbrace{(2|s\rangle\langle s| - \hat I)}_{\text{확산: 평균에 대한 반전}}\;\underbrace{(\hat I - 2|w\rangle\langle w|)}_{\text{오라클: } w\text{의 부호 뒤집기}}, \qquad P_k = \sin^2\bigl[(2k+1)\theta\bigr], \quad \sin\theta = \frac{1}{\sqrt N}$$
\(k\)번 반복한 뒤 \(w\)를 찾을 확률이 \(P_k\)다. 두 반사의 곱은 \(|w\rangle\)과 \(|s\rangle\)이 펼치는 평면에서의 \(2\theta\) 회전이다. 최적 반복 횟수는 \((2k+1)\theta \approx \pi/2\)에서 \(k_\text{opt} \approx \frac{\pi}{4}\sqrt N\). 진폭은 \(\sqrt N\)번 만에 키워지므로 제곱근 속도 향상이고, 이보다 빠른 양자 검색은 없음이 증명되어 있다.

3큐비트(\(N = 8\))에서 표시된 항목 하나를 찾는다. 반복마다 표시된 항목의 진폭과 찾을 확률을 구하고, 최적 반복 횟수를 정하라.

오류와 오류 정정 맛보기

큐비트는 환경과 얽히며 결맞음을 잃는다(17장의 \(T_1\), \(T_2\)). 게이트 시간 \(t_g\) 동안의 오류는 대략 \(t_g/T_2\)이다. 예를 들어 \(t_g = 20\) ns, \(T_2 = 100\) µs면 \(1 - e^{-t_g/T_2} \approx 2\times10^{-4}\)다. 쓸모 있는 알고리즘은 수백만 번 이상의 게이트가 필요하므로, 물리 큐비트를 아무리 좋게 만들어도 오류를 고치는 방법이 있어야 한다.

그런데 양자 오류 정정에는 세 가지 장애가 있어 보인다. 복제 불가 정리 때문에 큐비트를 여러 벌 복사해 다수결을 할 수 없고, 측정하면 중첩이 무너지며, 오류가 연속적이다(조금 돌아간 상태). 세 가지 모두 피해 갈 수 있다.

  • 복사 대신 얽힘: \(\alpha|0\rangle + \beta|1\rangle \to \alpha|000\rangle + \beta|111\rangle\). CNOT 두 개로 만든다. 이것은 \(|\psi\rangle^{\otimes3}\)이 아니므로 복제 불가 정리와 모순되지 않는다.
  • 값 대신 패리티를 잰다: \(Z_1Z_2\), \(Z_2Z_3\)(이웃한 두 큐비트가 같은지)만 재면 어느 큐비트가 뒤집혔는지 알 수 있지만, \(\alpha\), \(\beta\)에 대해서는 아무것도 알 수 없다. 이 결과를 증후군(syndrome)이라 한다.
  • 오류의 이산화: 작은 회전 \(\cos\epsilon\,I - i\sin\epsilon\,X\)도 증후군을 재는 순간 "오류 없음"(확률 \(\cos^2\epsilon\)) 또는 "X 오류"(확률 \(\sin^2\epsilon\))로 확정된다. 그래서 파울리 오류 \(X, Y, Z\)만 고칠 수 있으면 모든 오류를 고칠 수 있다.

각 큐비트가 독립적으로 확률 \(p\)로 뒤집힌다면, 3큐비트 부호가 실패하는 것은 두 개 이상 뒤집힐 때다. 거리 \(d\)(홀수) 반복 부호로 일반화하면 \((d+1)/2\)개 이상 뒤집힐 때 실패한다(이항 분포).

$$P_L^{(3)} = 3p^2(1-p) + p^3 = 3p^2 - 2p^3, \qquad P_L^{(d)} = \sum_{k=(d+1)/2}^{d}\binom{d}{k}p^k(1-p)^{d-k}$$
\(p \lt 1/2\)이면 \(P_L^{(3)} \lt p\)로 이득이다. \(p\)가 작으면 \(P_L \approx \binom{d}{(d+1)/2}p^{(d+1)/2}\) — 거리를 2 늘릴 때마다 오류가 \(p\)배씩 줄어든다.

두 스핀 사이의 교환 결합 \(\hat H = J\,\hat{\mathbf S}_1\cdot\hat{\mathbf S}_2/\hbar^2\)는 \(|{\uparrow\downarrow}\rangle\)과 \(|{\downarrow\uparrow}\rangle\)을 맞바꾼다. 두 양자점의 제만 에너지 차 \(\Delta E_Z\)가 없으면 시간 \(t = h/2J\)에 완전한 SWAP, 그 절반에 얽힘을 만드는 \(\sqrt{\text{SWAP}}\)이 된다. \(\Delta E_Z \gg J\)이면 교환은 대신 조건부 위상(CZ 게이트)으로 작동한다.

이온과 중성 원자. 전기장 덫(이온)이나 광학 집게(중성 원자)로 붙잡은 원자의 초미세 준위는 자연이 만든 완벽히 똑같은 큐비트다. 이온들은 쿨롱 반발로 사슬을 이루고, 공유된 진동 모드(6장의 포논)를 매개로 레이저가 얽힘 게이트를 만든다. 중성 원자는 한 원자를 리드베리 상태로 들뜨게 하면 이웃이 들뜨지 못하는 리드베리 봉쇄(9장)를 쓴다. 둘 다 결맞음이 매우 길지만 게이트가 느리고, 레이저·광학계의 규모가 확장의 과제다.

광자. 광자는 상온에서도 결맞음을 오래 지키고 광섬유로 멀리 간다 — 통신의 자연스러운 큐비트다. 대신 광자끼리는 거의 상호작용하지 않으므로, 두 큐비트 게이트를 측정과 앞먹임(측정 결과에 따라 다음 연산을 바꾸기)으로 유도한다. 큰 규모의 광 양자 계산에는 손실이 적은 실리콘 광집적 회로와 고효율 단일 광자 광원·검출기가 필요하다.

에필로그: 이 책을 돌아보며

이 책은 파동함수의 확률 해석에서 출발해 상태 공간, 측정, 시간 전개라는 틀을 세우고(제1부), 정확히 풀리는 계와 대칭으로 그 틀을 채웠으며(제2부), 각운동량·수소 원자·스핀·동일 입자로 원자의 구조를 읽고(제3부), 섭동·변분·WKB·산란으로 풀리지 않는 문제에 다가갔다(제4부). 마지막 부는 장 속의 전자, 밀도 행렬과 결어긋남, 그리고 이 장의 큐비트였다. 아래 단계 그림은 실리콘 스핀 큐비트 하나를 설명하는 데 이 책의 어느 장이 쓰이는지 보여 준다.

양자역학은 100년 전에는 원자 스펙트럼을 설명하는 이론이었고, 50년 전에는 트랜지스터·레이저·MRI를 설계하는 도구였으며, 이제는 얽힘과 중첩 그 자체를 자원으로 쓰는 공학이 되었다. 측정 공준, 복제 불가, 신호 불가 — 처음에는 철학적 수수께끼였던 원리들이 이 장에서는 암호의 안전성과 오류 정정의 설계 규칙이 되었다. 어느 길로 가든, 이 책에서 계산해 본 행렬과 파동함수와 블로흐 벡터가 출발점이 될 것이다.

이 책의 도구 가운데 "결맞음 시간 \(T_2\)를 늘리는 방법"과 가장 직접 관련된 것은?

\(T_2\)는 위상이 흩어지는 시간이다. 느린 잡음은 스핀 에코·동적 결합 끊기로 되돌리고, 잡음원(²⁹Si 핵스핀)은 동위원소 정제로 없앤다. 둘 다 17장에서 다룬 밀도 행렬과 블로흐 방정식의 응용이다.

핵심 정리

  1. 큐비트 \(\cos\frac\theta2|0\rangle + e^{i\phi}\sin\frac\theta2|1\rangle\)은 블로흐 구의 점이고, 단일 큐비트 게이트는 블로흐 구의 회전 \(e^{-i\alpha\,\mathbf n\cdot\boldsymbol\sigma/2}\)이다. \(H\)는 \(x \leftrightarrow z\)를 바꿔 \(HZH = X\)이며, \(\{H, T\}\)와 CNOT는 보편 게이트 집합이다. 측정은 \(P(0) = (1 + r_z)/2\)이고 큐비트 \(n\)개로 꺼낼 수 있는 고전 정보는 \(n\)비트뿐이다.
  2. \(n\)큐비트 상태는 진폭 \(2^n\)개다. 곱으로 인수분해되지 않으면 얽힌 상태이고, 순수 2큐비트 상태의 얽힘은 슈미트 계수의 엔트로피 \(S_E\)나 공존도 \(C = 2|c_{00}c_{11} - c_{01}c_{10}|\)로 잰다. \(H\) + CNOT가 벨 상태를 만든다.
  3. 국소 숨은 변수 이론은 \(|S| \le 2\)(CHSH)를 지키지만, 벨 상태는 \(E = \cos(a-b)\)로 \(S = 2\sqrt2\)까지 위반한다. 베르너 상태는 \(S = 2\sqrt2\,p\)라 \(p \gt 1/\sqrt2\)가 필요하다. 빈틈 없는 실험(2015)이 국소 실재론을 배제했다.
  4. 미지의 상태는 복제할 수 없다(내적 보존). 순간이동은 벨 쌍 + 고전 2비트로 큐비트를 옮기고 원본을 파괴하며, 고전 비트가 오기 전 밥의 상태는 \(\hat I/2\)라 신호를 빛보다 빨리 보낼 수 없다. 베르너 자원의 순간이동 충실도는 \((1+p)/2\), 고전 한계는 2/3이다.
  5. BB84에서 가로채기–재전송은 QBER \(f/4\)를 남기고, 비밀 키 비율은 \(1 - 2h(e)\)로 \(e \approx 11\%\)에서 0이 된다. 안전성은 복제 불가와 측정 교란에서 온다.
  6. 도이치–조사는 위상 되차기와 간섭으로 한 번의 질의로 상수/균형을 판정하고, 그로버는 두 반사의 곱인 \(2\theta\) 회전(\(\sin\theta = 1/\sqrt N\))으로 \(\approx\frac\pi4\sqrt N\)번 만에 답을 찾는다 — 지나치게 돌리면 확률이 다시 준다.
  7. 오류 정정은 얽힘으로 정보를 펼치고 패리티(증후군)만 재서 오류를 고친다. 반복 부호는 \(P_L = 3p^2 - 2p^3\)(거리 3), 표면 부호는 문턱 약 1%, 패치당 \(2d^2 - 1\)큐비트다. 플랫폼마다 진동수와 온도가 \(P_\text{exc} = 1/(1 + e^{hf/k_BT})\)로 묶이며(5 GHz 트랜스몬 → 수십 mK, Si 스핀 \(28\) GHz/T), 극저온 CMOS와 300 mm 공정이 실리콘 큐비트 확장의 열쇠다.

연습문제

필요하면 \(h = 6.626\times10^{-34}\) J·s, \(k_B = 1.381\times10^{-23}\) J/K \(= 86.17\ \mu\text{eV/K}\), \(\mu_B/h = 13.996\) GHz/T, \(h(e) = -e\log_2e - (1-e)\log_2(1-e)\)를 쓴다. 블로흐 각과 측정 각은 \(x\)–\(z\) 평면 기준이다.

블로흐 각 \(\theta = 100^\circ\), \(\phi = 30^\circ\)인 큐비트를 계산 기저로 잴 때 1이 나올 확률은?

\(P(1) = \sin^2(\theta/2)\). \(\phi\)는 상관없다.

\(P(1) = \sin^2 50^\circ = 0.766^2 = 0.587\). 같은 값을 \((1 - \cos100^\circ)/2 = (1 + 0.174)/2 = 0.587\)로도 얻는다.

\(|0\rangle\)에 \(H\), \(T\), \(H\)를 차례로 건 뒤 계산 기저로 잴 때 0이 나올 확률은?

블로흐 벡터로 따라간다: \(H\) → \(+x\), \(T\) → \(z\)축 둘레 45°, \(H\) → \(x\)와 \(z\) 교환.

\((0,0,1) \to (1,0,0) \to (\cos45^\circ, \sin45^\circ, 0) \to (0, -\sin45^\circ, \cos45^\circ)\). \(P(0) = (1 + 0.707)/2 = 0.854 = \cos^2(\pi/8)\).

다음 중 얽힌 상태는?

곱 상태 조건 \(c_{00}c_{11} = c_{01}c_{10}\)을 확인한다. 셋째만 \((1)(-1) \ne (1)(1)\)이고 공존도 \(C = 2|{-\tfrac14} - \tfrac14| = 1\)로 최대 얽힘이다. 첫째는 \(|+\rangle|+\rangle\), 둘째는 \(|+\rangle|-\rangle\), 넷째는 \(|+\rangle|0\rangle\).

큐비트 40개의 상태 벡터를 진폭당 16바이트(배정밀도 복소수)로 저장하면 몇 TB(\(10^{12}\) 바이트)가 필요한가?

\(2^{40} = 1.0995\times10^{12}\).

\(2^{40}\times16 = 1.759\times10^{13}\) 바이트 \(= 17.6\) TB. 큐비트 하나를 더하면 35.2 TB가 된다.

입력이 10비트인 함수가 상수이거나 균형이라는 약속이 있다. 고전 결정론적 알고리즘이 최악의 경우 확실히 판정하려면 몇 번 물어야 하나? (양자 알고리즘은 1번)

절반(\(2^9\))까지 같은 값이 나와도 아직 균형일 수 있다.

\(2^{10}/2 + 1 = 512 + 1 = 513\)번. 512번 연속 같은 값이면 균형일 수 없으므로 한 번 더 보면 확정된다.

\(|\Psi\rangle = \sqrt{0.9}\,|00\rangle + \sqrt{0.1}\,|11\rangle\)의 얽힘 엔트로피와 공존도를 구하라.

슈미트 계수 \(\lambda = 0.9\). \(C = 2\sqrt{\lambda(1-\lambda)}\).

\(S_E = -0.9\log_2 0.9 - 0.1\log_2 0.1 = 0.1368 + 0.3322 = 0.469\) 비트. \(C = 2\sqrt{0.09} = 0.600\). 축약 상태의 블로흐 벡터 길이는 \(\sqrt{1 - 0.36} = 0.8\).

\(|\Phi^+\rangle\)에서 \(a = 0\), \(a' = 60^\circ\), \(b = 30^\circ\), \(b' = 90^\circ\)(블로흐 각)로 잴 때 \(S = E(a,b) - E(a,b') + E(a',b) + E(a',b')\)는?

\(E(a, b) = \cos(a - b)\).

\(\cos30^\circ - \cos90^\circ + \cos30^\circ + \cos30^\circ = 0.866 - 0 + 0.866 + 0.866 = 2.60\). 2를 넘지만 최적값 2.83보다는 작다.

얽힌 광자 쌍 광원의 가시도(베르너 순도)가 \(p = 0.80\)이다. 최적 각도에서 기대되는 CHSH 값은?

모든 상관이 \(p\)배.

\(S = 2\sqrt2\times0.80 = 2.26\). 위반 여유 0.26을 통계적으로 확인하려면 \(\sigma_S \approx 2/\sqrt{N}\)이 그보다 충분히 작도록 설정당 수백 쌍 이상이 필요하다.

순도 \(p = 0.60\)인 베르너 상태를 자원으로 순간이동하면 평균 충실도는? 이 값은 고전 한계 2/3보다 큰가?

밥의 상태는 \(p|\psi\rangle\langle\psi| + (1-p)\hat I/2\)가 된다.

\(F = p + (1-p)/2 = (1 + p)/2 = 0.800 \gt 0.667\). 같은 자원은 CHSH는 위반하지 못하지만(\(S = 1.70\)) 순간이동에는 쓸모가 있다 — 얽힘의 쓸모는 과제마다 다르다.

잡음이 없는 BB84 채널에서 이브가 광자의 40%를 가로채기–재전송한다. 선별 키의 QBER와 쇼어–프레스킬 비밀 키 비율 \(r = 1 - 2h(e)\)은?

\(e = f/4\).

\(e = 0.40/4 = 0.100\). \(h(0.1) = 0.1\times3.322 + 0.9\times0.152 = 0.469\), \(r = 1 - 0.938 = 0.0620\). 키는 만들 수 있지만 선별 키의 6%만 남는다.

10큐비트(\(N = 1024\))에서 표시된 항목 하나를 찾는 그로버 알고리즘의 최적 반복 횟수는? (\(k = \text{round}[\pi/(4\theta) - 1/2]\), \(\sin\theta = 1/\sqrt N\))

\(\theta = \arcsin(1/32)\).

\(\theta = 0.031255\) rad, \(\pi/(4\theta) - 0.5 = 24.63\) → \(k = 25\). 성공 확률 \(\sin^2(51\theta) = 0.9995\). 고전 평균 512번에 비해 약 20배 적다.

물리 비트 반전 확률이 \(p = 0.020\)일 때 3큐비트 반복 부호의 논리 오류율은?

\(P_L = 3p^2 - 2p^3\).

\(3(4.0\times10^{-4}) - 2(8.0\times10^{-6}) = 1.200\times10^{-3} - 1.6\times10^{-5} = 1.18\times10^{-3}\). 약 17배 개선이다.

\(g = 2.00\)인 실리콘 전자 스핀 큐비트의 진동수를 20.0 GHz로 맞추려면 자기장이 얼마여야 하나?

\(f = g(\mu_B/h)B\).

\(B = 20.0/(2\times13.996) = 0.714\) T. 제만 에너지 \(hf = 82.7\ \mu\text{eV}\)에 해당한다.

6.0 GHz 트랜스몬의 유효 온도가 50 mK이다. 열평형 들뜸 확률은? (2준위로 근사)

\(x = hf/k_BT\), \(P_\text{exc} = 1/(1 + e^x)\).

\(x = (6.626\times10^{-34}\times6.0\times10^9)/(1.381\times10^{-23}\times0.050) = 5.76\). \(P_\text{exc} = 1/(1 + e^{5.76}) = 3.14\times10^{-3}\). 초기화 오류 0.3%는 오류 정정 문턱에 비해 작지 않아, 측정 후 조건부 리셋 등으로 더 낮춘다.

두 스핀 큐비트 사이의 교환을 \(J/h = 5.0\) MHz로 켠다. (가) \(\Delta E_Z = 0\)일 때 완전한 SWAP에 걸리는 시간은? (나) 미세 자석 때문에 \(\Delta E_Z/h = 5.0\) MHz이면 \(|{\uparrow\downarrow}\rangle \to |{\downarrow\uparrow}\rangle\)의 최대 확률은?

\(P = \frac{J^2}{J^2 + \Delta E_Z^2}\sin^2(\pi\sqrt{J^2 + \Delta E_Z^2}\,t/h)\).

(가) \(\pi Jt/h = \pi/2\) → \(t = h/2J = 1/(2\times5.0\ \text{MHz}) = 100\) ns. (나) \(J^2/(J^2 + \Delta E_Z^2) = 25/50 = 0.500\). 그래서 SWAP를 쓰려면 \(\Delta E_Z \ll J\), CZ를 쓰려면 \(\Delta E_Z \gg J\)로 설계한다.

앨리스와 밥이 \(|\Phi^+\rangle\)을 나눠 가졌다. 앨리스가 자기 큐비트를 \(z\) 기저로 재느냐 \(x\) 기저로 재느냐를 골라 밥에게 1비트를 보내려 한다. 옳은 것은?

앨리스가 \(z\)로 재면 밥은 \(|0\rangle\), \(|1\rangle\)의 반반 혼합, \(x\)로 재면 \(|+\rangle\), \(|-\rangle\)의 반반 혼합을 갖는다. 둘 다 \(\hat I/2\)로 같은 밀도 행렬이라 어떤 측정 통계도 같다. 앨리스의 결과를 고전 통신으로 받아야 비로소 상관이 보인다.

개념 확인 퀴즈

큐비트 하나에 대한 설명으로 옳은 것은?

홀레보 한계: \(n\)큐비트로는 최대 \(n\)비트. 전체 위상은 관측되지 않고, \(Z\)는 상대 위상만 바꿔 \(z\) 측정 확률은 그대로다.

CHSH 값 \(S = 2.4\)를 측정했다. 이 결과가 배제하는 것은?

\(|S| \le 2\)는 국소성과 실재성(결과의 사전 결정)만으로 유도된다. 2.4는 양자역학의 한계 \(2\sqrt2\) 안이다. 신호를 보낼 수 있다는 뜻도 아니다.

양자 순간이동이 복제 불가 정리와 모순되지 않는 이유는?

측정 뒤 앨리스의 큐비트들은 \(|\psi\rangle\)과 무관한 계산 기저 상태다. 고전 2비트에도 \(\alpha, \beta\)는 담기지 않는다(네 결과가 각 1/4).

그로버 알고리즘에 대한 설명으로 옳지 않은 것은?

\(P_k = \sin^2[(2k+1)\theta]\)는 진동한다. 최적점을 지나면 확률이 다시 떨어진다. \(N = 4\)이면 \(\theta = 30^\circ\), \(3\theta = 90^\circ\)라 한 번에 정확히 1이다.

5 GHz 트랜스몬을 4 K에 두면 안 되는 가장 직접적인 이유는?

\(hf/k_B = 0.24\) K이므로 4 K에서는 큐비트가 열적으로 거의 섞인 상태다(\(\bar n \approx 16\)). 게다가 알루미늄 접합은 \(T_c \approx 1.2\) K 아래에서만 초전도다. 수십 mK가 필요하고, 그래서 제어 전자 회로만 4 K 단에 둔다.
