# 과목 확장 계획

각 과목은 독립된 교과서 한 권이다. **2026-10부터 주 독자는 반도체 회사 직원이다.** 자매 서가 [SemiBooks](https://semi.euiyun.com/)(소자·공정·메모리·광학 등 응용)가 전제로 하는 기초 과학을 채우는 순서로 과목을 고르고, 장마다 `.callout.semi`("반도체에서는") 상자로 현장과 SemiBooks 해당 장을 잇는다.

 공통 엔진(`engine/`) 위에 과목 폴더 하나를 추가하는 방식으로 늘려 간다.
아래 목차는 표준 대학 강의 계획서를 바탕으로 한 초안이며, 집필을 시작할 때 `course.json`으로 옮긴다.

## 공유 라이브러리 계획

- **`engine/lib/quantum.js`** (전역 `Q`) — 단위 nm·eV·fs. 1D 슈뢰딩거 고유값(유한 차분 + 스투름 이분법), 유한·무한 우물, 전달 행렬 투과, WKB, 파울러–노드하임, 크랭크–니콜슨 파속 전파, 조화 진동자·수소 파동함수, 양자 통계·상태 밀도, 크로니히–페니 띠, 반도체·절연막 대표 물성. 현대물리·고체물리 공용.
- **`engine/lib/solid.js`** (전역 `Solid`) — 결정 구조와 3D 정사영 그리기(끌어 돌리기), 밀러 면·면 밀도, 역격자·구조 인자·분말 XRD, 입방정 탄성·임계 두께, 점결함·확산 프로파일, 포논 사슬·디바이/아인슈타인 비열, 자유 전자·배선 크기 효과(FS·MS), 거의 자유 전자·강결합·경험적 의사퍼텐셜 띠, 캐리어 통계(전하 중성 풀이)·이동도·속도 포화·SRH/오제·pn·쇼트키·접촉 비저항, 로런츠·드루드 유전 함수, 브릴루앙·평균장·스토너–울파스, 저차원 상태 밀도·란다우어. 고체물리 전용으로 시작.
- **`engine/lib/em.js`** (전역 `EM`) — 복소수·수치 벡터 미분, 점전하 장선·등고선, 라플라스·푸아송 격자 풀이(SOR, 유전율·전도도 지도, 전극 전하·에너지), 정전 용량·저항·인덕턴스·특성 임피던스 공식(사쿠라이 배선 용량, 나선 인덕터), 비오–사바르(선분·고리 타원 적분), 손실 매질 평면파·표피 깊이·플라스마, 프레넬·다층 박막·엘립소메트리, 전송선(입력 임피던스·L 정합·스터브·바운스·TDR·RC 배선·엘모어·누화)·스미스 차트, 도파관·공진기·슬랩, 쌍극자·선형·배열 안테나, FDTD 1D/2D, 2D 모멘트 법, 열지도·화살표 그리기. 전자기학 전용으로 시작.

- **`engine/lib/phys.js`** — 벡터(2D/3D) 연산, 단위 있는 수량 표시, ODE 적분기(RK4·심플렉틱 오일러), 자유 물체도·힘 화살표 그리기, 궤적 기록/그래프. 일반물리·정역학·동역학·유체역학 공용.
- **`engine/lib/mech.js`** — 강체·트러스·보 모델, 반력·전단력·굽힘 모멘트 도표, 관성 모멘트·도심 계산, 마찰. 정역학·동역학 공용.
- **`engine/lib/flow.js`** — 퍼텐셜 유동 중첩(균일류·원천·와류·쌍극자), 유선·속도장 시각화, 무디 선도, 관망 계산. 유체역학 전용으로 시작.
- **`engine/lib/mol2d.js`** — 2D 골격 구조식 렌더러, 굽은 화살표(전자 이동) 애니메이션, 뉴먼·의자 형태 투영. 유기화학 전용으로 시작하고, 일반화학 9–10장의 루이스 구조에도 재사용.
- 엔진 core 추가 후보: 용어 툴팁(`<dfn>`), 장 간 교차 참조(`data-ref="gases#ideal-gas"`), 인쇄용 스타일, 교수자용 문제 세트 묶음 링크.
