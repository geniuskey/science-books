Chapter 23

축전기와 유전체

카메라 플래시는 건전지로 몇 초 동안 에너지를 모았다가 1000분의 1초 만에 터뜨린다. 심장 제세동기, 컴퓨터 메모리, 스마트폰의 터치스크린, 전기차의 회생 제동 — 모두 전하와 에너지를 잠시 담아 두는 축전기를 쓴다. 이 장에서는 축전기가 전하를 얼마나 담는지(전기 용량), 여러 개를 이으면 어떻게 되는지, 에너지가 어디에 저장되는지(전기장 속!), 그리고 판 사이에 절연체를 넣으면 왜 용량이 커지는지 알아본다.

위 판을 위아래로 끌어 간격을 바꿔 보세요 · 전지 기호를 누르면 연결/분리
  • 전기 용량 \(C = Q/V\)를 정의하고 평행판·구·원통 축전기의 용량을 구한다.
  • 직렬·병렬 연결의 등가 용량을 계산하고, 각 축전기의 전하와 전압을 구한다.
  • 축전기의 저장 에너지 \(U = \tfrac12CV^2\)와 전기장의 에너지 밀도 \(u = \tfrac12\epsilon_0E^2\)를 쓴다.
  • 유전 상수 \(K\)로 유전체가 용량·전압·장·에너지에 주는 영향을 설명하고, 분극과 유도 전하로 그 원인을 해석한다.

축전기와 전기 용량

절연된 두 도체에 크기가 같고 부호가 반대인 전하 \(\pm Q\)를 주면 그 사이에 전위차 \(V\)가 생긴다. 이런 장치가 축전기(capacitor)다. 전하를 2배로 하면 장이 2배, 전위차도 2배가 되므로 \(Q\)와 \(V\)는 비례하고, 그 비례 상수가 전기 용량(capacitance)이다.

$$C = \frac{Q}{V}, \qquad C_\text{평행판} = \frac{\epsilon_0A}{d}$$
단위 패럿 F = C/V. 실제 축전기는 pF(10⁻¹²)–μF(10⁻⁶) 정도. 용량은 도체의 모양과 배치(와 사이의 물질)만으로 정해지고, \(Q\)나 \(V\)에는 의존하지 않는다. 평행판: 넓이 \(A\), 간격 \(d\), 판 사이 장 \(E = \sigma/\epsilon_0 = Q/\epsilon_0A\), \(V = Ed\) → \(C = \epsilon_0A/d\). 이제 \(\epsilon_0\)의 단위를 F/m로 쓸 수 있다.

충전된 평행판 축전기를 전지에서 떼어 낸 뒤 판 간격을 2배로 벌린다. 판 사이의 전위차는?

떼어 내면 전하 \(Q\)가 고정된다. \(C = \epsilon_0A/d\)가 1/2이 되므로 \(V = Q/C\)는 2배. 장 \(E = \sigma/\epsilon_0\)은 그대로이고, 간격이 2배라 \(V = Ed\)도 2배다. 전지에 연결된 채라면 \(V\)가 고정되고 \(Q\)가 절반이 된다.

축전기의 직렬과 병렬 연결

회로에서는 축전기 여러 개를 이어 쓴다. 이어진 묶음 전체와 똑같이 행동하는 축전기 하나의 용량을 등가 용량(equivalent capacitance)이라 한다.

$$\frac{1}{C_\text{직렬}} = \frac{1}{C_1} + \frac{1}{C_2} + \cdots, \qquad C_\text{병렬} = C_1 + C_2 + \cdots$$

축전기에 저장된 에너지

축전기를 충전하는 것은 전하를 한 판에서 다른 판으로 조금씩 옮기는 일이다. 이미 \(q\)만큼 옮겨 전위차가 \(v = q/C\)일 때, \(dq\)를 더 옮기려면 일 \(v\,dq\)가 든다. 처음에는 전위차가 0이라 쉽고, 점점 어려워진다.

$$U = \int_0^Q\frac{q}{C}\,dq = \frac{Q^2}{2C} = \frac12CV^2 = \frac12QV$$
\(V\)–\(q\) 그래프 아래 삼각형의 넓이. \(QV\)가 아니라 \(\tfrac12QV\)인 이유는 평균 전위차가 \(V/2\)이기 때문이다.

에너지는 어디에 있을까? 평행판의 경우 \(U = \tfrac12CV^2 = \tfrac12(\epsilon_0A/d)(Ed)^2 = \tfrac12\epsilon_0E^2(Ad)\)이고 \(Ad\)는 장이 있는 부피다. 그러므로 에너지는 전기장 자체에 저장되어 있다고 볼 수 있다. 이 결론은 평행판이 아닌 어떤 장에도 성립하며, 29장에서 빛(전자기파)이 에너지를 나르는 근거가 된다.

$$u = \frac{U}{\text{부피}} = \frac12\epsilon_0E^2$$
\(u\): 에너지 밀도(energy density), J/m³.

카메라 플래시의 축전기 150를 300로 충전하면 에너지 가 저장된다. 이를 1.0 동안 방출하면 평균 일률은 이다. 같은 에너지를 1.5 V 건전지로 채우는 데 전하 가 지나가야 한다(전지가 더 높은 전압을 만들어 주는 회로를 거쳐).

(a) 150 μF 축전기를 300 V로 충전하면 저장 에너지는? 1.0 ms에 방출하면 평균 일률은? (b) 공기 중에서 가능한 가장 큰 장(\(3.0\times10^6\) V/m)의 에너지 밀도는?

풀이 보기
풀이 (a) \(U = \tfrac12(150\times10^{-6})(300)^2 = 6.75\) J, \(P = 6.75/1.0\times10^{-3} = 6.75\) kW. (b) \(u = \tfrac12(8.854\times10^{-12})(3.0\times10^6)^2 = 39.8\) J/m³.
(a) 6.75 J, 6.75 kW (b) 약 40 J/m³
검토 건전지로는 낼 수 없는 일률이다. 축전기는 에너지를 "모아서 한 번에" 쓰는 장치다. (b)는 휘발유(약 3 × 10¹⁰ J/m³)보다 10억 배 작다 — 축전기의 에너지 밀도 한계는 유전체의 절연 내력이 정한다.

전하 나누기: 사라지는 에너지

충전된 축전기를 충전되지 않은 축전기에 이으면 전하가 흘러 두 축전기의 전압이 같아진다. 전하는 보존되지만 에너지는 그렇지 않다!

\(V_0\)으로 충전된 축전기를 같은 용량의 빈 축전기에 이었다. 연결 후 두 축전기에 저장된 에너지의 합은 처음 에너지의 몇 배일까?

전하 \(Q_0\)이 반씩 나뉘어 전압이 \(V_0/2\). 에너지는 \(2\times\tfrac12C(V_0/2)^2 = \tfrac14CV_0^2\), 처음의 절반이다. 나머지 절반은 도선의 저항에서 열로, 일부는 전자기파로 나간다 — 저항이 아무리 작아도 정확히 절반이다.

유전체

실제 축전기는 판 사이에 종이·플라스틱·세라믹 같은 절연체를 넣는다. 이렇게 하면 (1) 얇은 간격을 기계적으로 유지할 수 있고, (2) 공기보다 높은 전압을 견디며, (3) 용량이 커진다. 판 사이를 채우는 절연체를 유전체(dielectric)라 하고, 용량이 커지는 배율을 유전 상수(dielectric constant) \(K\)라 한다.

$$C = KC_0, \qquad \epsilon = K\epsilon_0, \qquad C_\text{평행판} = \frac{K\epsilon_0A}{d} = \frac{\epsilon A}{d}$$
\(\epsilon\): 물질의 유전율(permittivity). 전지에서 떼어 낸(Q 고정) 축전기에 유전체를 넣으면 \(V = V_0/K\), \(E = E_0/K\), \(U = U_0/K\). 전지에 연결된(V 고정) 상태라면 \(Q = KQ_0\), \(U = KU_0\).

유전체 속에서 무슨 일이 일어나나

전지에서 떼어 낸 충전된 축전기에 유전체(K = 3)를 끝까지 밀어 넣는다. 판 사이 전위차와 저장 에너지는?

핵심 정리

  1. 전기 용량 \(C = Q/V\)(F). 기하로만 정해진다. 평행판 \(\epsilon_0A/d\), 구형 \(4\pi\epsilon_0r_ar_b/(r_b - r_a)\), 원통형 \(2\pi\epsilon_0L/\ln(r_b/r_a)\).
  2. 직렬: 같은 Q, \(1/C = \sum1/C_i\). 병렬: 같은 V, \(C = \sum C_i\). 복잡한 회로는 안쪽부터 묶는다.
  3. 저장 에너지 \(U = Q^2/2C = \tfrac12CV^2 = \tfrac12QV\). 에너지는 장에 있다: \(u = \tfrac12\epsilon_0E^2\).
  4. 충전된 축전기를 빈 축전기와 이으면 전하는 보존되지만 에너지의 \(C_2/(C_1 + C_2)\)가 열·복사로 나간다.
  5. 유전체: \(C = KC_0\), \(\epsilon = K\epsilon_0\). Q 고정이면 \(V, E, U\)가 1/K, V 고정이면 \(Q, U\)가 K배. 분극으로 생긴 유도 전하 \(\sigma_i = \sigma(1 - 1/K)\)가 장을 약하게 한다. 최대 전압 = 절연 내력 × 두께.

연습문제

특별한 말이 없으면 \(\epsilon_0 = 8.854\times10^{-12}\) F/m, \(k = 8.988\times10^9\) N·m²/C²를 쓴다. 답이 ±1% 이내면 정답이다.

12 V에 연결한 축전기에 6.0 μC이 충전되었다. 용량은?

\(C = Q/V = 6.0/12 = 0.50\) μF.

넓이 0.050 m², 간격 1.5 mm인 평행판 축전기의 용량은?

\(C = \epsilon_0A/d = (8.854\times10^{-12})(0.050)/(1.5\times10^{-3}) = 2.95\times10^{-10}\) F.

앞 문제의 축전기를 9.0 V 전지에 연결했다. 전하와 판 사이의 장은?

\(Q = CV = 2.66\times10^{-9}\) C, \(E = V/d = 9.0/0.0015 = 6.0\times10^3\) V/m.

4.0 μF(C₁)과 12.0 μF(C₂)을 직렬로 24 V에 연결했다. 등가 용량, 각 축전기의 전하, C₁의 전압은?

\(C = (1/4 + 1/12)^{-1} = 3.0\) μF, \(Q = (3.0)(24) = 72\) μC, \(V_1 = 72/4.0 = 18\) V (\(V_2 = 6\) V).

2.0, 3.0, 5.0 μF 축전기를 병렬로 10 V에 연결했다. 등가 용량과 전지에서 나간 전체 전하는?

\(C = 10\) μF, \(Q = 100\) μC.

4.0 μF 두 개를 직렬로 잇고, 이 묶음과 6.0 μF을 병렬로 이은 뒤, 그 전체를 8.0 μF과 직렬로 이었다. 등가 용량은?

직렬 2.0 → 병렬 2.0 + 6.0 = 8.0 → 8.0과 8.0 직렬 = 4.0 μF.

50 μF 축전기를 200 V로 충전했다. 저장 에너지는?

\(U = \tfrac12CV^2 = \tfrac12(50\times10^{-6})(200)^2 = 1.0\) J.

세기 \(5.0\times10^4\) V/m인 전기장의 에너지 밀도는?

\(u = \tfrac12\epsilon_0E^2 = 1.11\times10^{-2}\) J/m³.

100 V로 충전한 2.0 μF 축전기를 똑같은 빈 축전기에 이었다. 나중 전압과 잃은 에너지는?

\(V = 50\) V. \(U_0 = \tfrac12(2\times10^{-6})(100)^2 = 0.010\) J, \(U = 2\times\tfrac12(2\times10^{-6})(50)^2 = 0.0050\) J → 잃은 에너지 \(5.0\times10^{-3}\) J(절반).

12 V 전지에 연결된 5.0 nF 축전기에 유전 상수 2.5인 유전체를 채웠다. 나중 용량과 전하는?

\(C = KC_0 = 12.5\) nF, \(Q = CV = 1.5\times10^{-7}\) C(처음의 2.5배).

2.0 mJ를 저장한 축전기를 전지에서 떼어 낸 뒤 유전 상수 4.0인 유전체를 채웠다. 나중 에너지와, 판이 유전체를 끌어당기며 한 일은?

\(U = U_0/K = 0.50\) mJ. 줄어든 1.5 mJ가 유전체에 한 일이다.

두께 0.10 mm인 폴리스타이렌(절연 내력 \(2\times10^7\) V/m) 층을 넣은 축전기의 최대 전압은?

\(V_\text{max} = (2\times10^7)(1.0\times10^{-4}) = 2.0\times10^3\) V.

반지름 5.0 cm인 도체 구와 안지름 5.5 cm인 동심 도체 껍질로 된 구형 축전기의 용량은? 같은 넓이·간격의 평행판 근사와 비교하라.

\(C = \dfrac{r_ar_b}{k(r_b - r_a)} = \dfrac{(0.050)(0.055)}{(8.988\times10^9)(0.005)} = 6.12\times10^{-11}\) F. 평행판 근사 \(\epsilon_0(4\pi r_a^2)/d = 5.56\times10^{-11}\) F — 간격이 반지름보다 훨씬 작으면 두 값이 가까워진다.

전지에서 떼어 낸 충전된 평행판 축전기의 판을 더 벌렸다. 변하지 않는 것은?

Q가 고정이므로 \(\sigma\)와 \(E = \sigma/\epsilon_0\)가 그대로다. V = Ed와 U는 늘고 C는 준다.

유전체를 넣으면 같은 전하에서 판 사이 장이 약해지는 이유는?

유도 전하 \(\mp\sigma_i\)가 자유 전하 \(\pm\sigma\)의 장을 일부 상쇄한다: \(E = (\sigma - \sigma_i)/\epsilon_0\).

개념 확인 퀴즈

평행판 축전기의 간격을 절반으로, 넓이를 2배로 하면 용량은?

\(C = \epsilon_0A/d\): 2 × 2 = 4.

서로 다른 축전기 두 개를 직렬로 이었다. 옳은 것은?

\(V_i = Q/C_i\).

축전기의 전압을 2배로 하면 저장 에너지는?

\(U = \tfrac12CV^2\).

축전기의 에너지는 어디에 저장되어 있다고 보는가?

\(u = \tfrac12\epsilon_0E^2\)를 장이 있는 부피에 대해 적분하면 \(\tfrac12CV^2\)이다.

전지에 연결된 축전기에 유전체를 넣으면?

V가 고정이라 E = V/d도 그대로다. 전지가 전하를 더 보내 Q = KQ₀.
