Chapter 02

직선 운동

출발하는 자동차, 떨어지는 사과, 브레이크를 밟는 버스 — 한 직선을 따라 움직이는 운동은 역학의 출발점이다. 이 장에서는 위치·속도·가속도를 정의하고, 이 셋이 기울기와 넓이로 서로 이어져 있음을 그래프로 확인한다. 아래 화면을 누르고 있으면 가속 페달, 떼면 브레이크다.

누르고 있으면 가속 · 떼면 브레이크
  • 변위와 이동 거리, 평균 속도와 평균 속력을 구별하고 x–t 그래프의 할선 기울기로 해석한다.
  • 순간 속도를 극한 \(v = dx/dt\)로 정의하고 x–t 그래프의 접선 기울기로 읽는다.
  • 가속도 \(a = dv/dt\)를 정의하고 속도와 가속도의 부호로 빨라짐·느려짐을 판단한다.
  • 등가속도 운동의 네 공식을 유도하고 제동·추격 문제에 적용한다.
  • 자유 낙하를 \(a = -g\)인 등가속도 운동으로 다루고, v–t 그래프 아래 넓이(적분)로 변위를 구한다.

변위, 시간, 평균 속도

직선 운동을 기술하려면 먼저 직선 위에 원점과 양의 방향을 정한 좌표축(x축)이 필요하다. 물체를 크기 없는 점 입자로 보면, 그 상태는 시각 \(t\)와 위치 \(x\)만으로 완전히 정해진다. 위치가 \(x_1\)에서 \(x_2\)로 바뀌었을 때 위치의 변화 \(\Delta x = x_2 - x_1\)을 변위(displacement)라 한다. 변위는 부호(방향)를 가진 양이고, 실제로 지나온 길의 길이인 이동 거리(distance traveled)와 다르다.

평균 속도와 평균 속력

평균 속도(average velocity)는 변위를 걸린 시간으로 나눈 값 \(v_{\text{av},x} = \Delta x/\Delta t\)로, 부호가 있다. 평균 속력(average speed)은 이동 거리를 시간으로 나눈 값으로, 언제나 0 이상이다. 출발점으로 돌아오면 평균 속도는 0이지만 평균 속력은 0이 아니다.

$$v_{\text{av},x} = \frac{\Delta x}{\Delta t} = \frac{x_2 - x_1}{t_2 - t_1}$$
x–t 그래프에서 두 점 \((t_1, x_1)\), \((t_2, x_2)\)를 잇는 할선의 기울기다. SI 단위는 m/s.

서울에서 부산까지 고속도로로 400를 4.5 만에 갔다면 평균 속력은 ()이다.

위 미니 실험의 산책(동쪽 300 m를 200 s, 서쪽 100 m를 100 s)에서 전체 300 s 동안의 평균 속도와 평균 속력을 구하라. 동쪽이 +x다.

풀이 보기
전략 평균 속도에는 변위를, 평균 속력에는 이동 거리를 쓴다.
풀이 변위 \(\Delta x = +300 - 100 = +200\) m, 이동 거리 \(300 + 100 = 400\) m. \(v_{\text{av},x} = 200/300 = +0.667\) m/s, 평균 속력 \(= 400/300 = 1.33\) m/s.
평균 속도 +0.667 m/s (동쪽), 평균 속력 1.33 m/s
검토 방향을 바꾸는 운동에서는 평균 속력이 평균 속도의 크기보다 크다. 한 방향으로만 가면 둘은 같다.

순간 속도

속도계가 가리키는 값은 "지금 이 순간"의 속도다. 평균 속도의 시간 간격 \(\Delta t\)를 점점 줄이면 할선은 한 점에서 곡선에 닿는 접선에 다가간다. 그 극한이 순간 속도(instantaneous velocity)다.

$$v_x = \lim_{\Delta t\to0}\frac{\Delta x}{\Delta t} = \frac{dx}{dt}$$
순간 속도는 x–t 그래프의 접선 기울기이며, 위치를 시간으로 미분한 값이다. 순간 속도의 크기를 속력이라 한다.

그래프를 읽는 감각을 기르는 가장 좋은 방법은 직접 그려 보는 것이다. 아래에서 x–t 그래프를 손으로 그리면, 물체가 그 그래프대로 움직이고 속도와 가속도 그래프가 저절로 만들어진다.

가속도

속도가 바뀌는 빠르기가 가속도(acceleration)다. 위치와 속도의 관계가 그대로 속도와 가속도 사이에서 되풀이된다.

$$a_{\text{av},x} = \frac{\Delta v_x}{\Delta t}, \qquad a_x = \lim_{\Delta t\to0}\frac{\Delta v_x}{\Delta t} = \frac{dv_x}{dt} = \frac{d^2x}{dt^2}$$
가속도는 v–t 그래프의 접선 기울기다. SI 단위는 m/s². x–t 그래프에서는 곡선이 위로 휘면(아래로 볼록) \(a > 0\), 아래로 휘면 \(a < 0\)이다.
"감속 = 음의 가속도"가 아니다

가속도의 부호는 좌표축의 방향을 나타낼 뿐이다. 물체가 빨라지는지 느려지는지는 속도와 가속도의 부호가 같은지로 정해진다. −x 방향으로 달리는 차가 브레이크를 밟으면 가속도는 양수다.

자동차가 정지 상태에서 6.0 s 만에 100 km/h에 이르렀다. 평균 가속도를 m/s²와 g 단위로 구하라.

등가속도 운동

가속도가 일정하면 v–t 그래프는 기울기 \(a\)인 직선이다. 따라서 \(v_x = v_{0x} + a_xt\). 위치는 그 직선 아래 넓이(뒤에서 적분으로 정당화한다)로 구할 수 있다.

$$\begin{aligned} v_x &= v_{0x} + a_xt & x &= x_0 + v_{0x}t + \tfrac12a_xt^2 \\ v_x^2 &= v_{0x}^2 + 2a_x(x - x_0) & x - x_0 &= \tfrac12(v_{0x} + v_x)\,t \end{aligned}$$
가속도가 일정할 때만 성립한다. 세 번째 식은 처음 두 식에서 \(t\)를 소거한 것으로, 시간이 주어지지 않은 문제(제동 거리 등)에 쓴다.

처음 속도 \(v_{0x} =\) 10, 가속도 \(a_x =\) 2.0로 4.0 동안 움직이면 속도는 , 변위는 가 된다.

30.0 m/s(108 km/h)로 달리던 자동차가 브레이크를 밟아 −6.00 m/s²로 일정하게 감속했다. 정지할 때까지 걸리는 시간과 거리는?

풀이 보기
전략 시간은 \(v = v_0 + at\)에서, 거리는 \(v^2 = v_0^2 + 2a\Delta x\)에서 (\(v = 0\)).
풀이 \(t = (0 - 30.0)/(-6.00) = 5.00\) s. \(\Delta x = (0 - 30.0^2)/(2\times(-6.00)) = 75.0\) m.
t = 5.00 s, Δx = 75.0 m
검토 \(\Delta x = \tfrac12(v_0 + v)t = \tfrac12(30.0)(5.00) = 75.0\) m로 확인된다. 제동 거리는 \(v_0^2\)에 비례하므로 속력이 2배면 4배가 된다.

추격 문제

두 물체가 "만난다"는 것은 같은 시각에 같은 위치에 있다는 뜻이다. 두 물체의 \(x(t)\)를 각각 쓰고 \(x_A(t) = x_B(t)\)를 풀면 된다. x–t 그래프에서는 두 곡선의 교점이다.

과속 차가 일정한 속력 v로 서 있는 경찰차 옆을 지나는 순간, 경찰차가 일정한 가속도로 출발해 쫓아간다. 경찰차가 과속 차를 따라잡는 순간 경찰차의 속력은?

같은 시간 동안 같은 거리를 갔으므로 두 차의 평균 속도가 같다. 경찰차의 평균 속도는 \((0 + v_B)/2\)이므로 \(v_B/2 = v\) → \(v_B = 2v\). 가속도와 무관하다! 아래에서 지연 시간을 0으로 두고 확인하라.

자유 낙하

공기 저항을 무시할 수 있으면, 지표 근처의 모든 물체는 무게와 모양에 상관없이 같은 가속도로 떨어진다. 갈릴레이가 처음 밝힌 이 사실은 1971년 아폴로 15호 우주인이 달에서 망치와 깃털을 동시에 떨어뜨려 극적으로 확인했다. 이 일정한 가속도의 크기가 중력 가속도(acceleration due to gravity) \(g\)다. 위로 던지든 아래로 던지든, 공중에 있는 동안의 운동을 자유 낙하(free fall)라 한다.

자유 낙하

위쪽을 +y로 잡으면 \(a_y = -g\) (\(g = 9.80\) m/s², 표준값 9.806 65 m/s²)인 등가속도 운동이다: \(v_y = v_{0y} - gt\), \(y = y_0 + v_{0y}t - \tfrac12gt^2\), \(v_y^2 = v_{0y}^2 - 2g(y - y_0)\).

공을 위로 던졌다. 공이 최고점에 있는 순간, 속도와 가속도는?

가속도는 비행 내내 \(-g\)다. 최고점에서 가속도가 0이라면 공은 그 자리에 영원히 멈춰 있어야 한다. 아래 v–t 그래프에서 최고점을 지날 때도 기울기가 변하지 않음을 확인하라.

미적분으로 본 운동

가속도가 일정하지 않으면 등가속도 공식은 쓸 수 없다. 대신 미분과 적분의 관계를 직접 쓴다. 미분이 기울기라면 그 역연산인 적분은 넓이다. 짧은 시간 \(dt\) 동안의 변위는 \(v_x\,dt\)이고, 이것을 모두 더하면 v–t 그래프 아래 넓이가 된다.

$$x(t) = x_0 + \int_0^t v_x(t')\,dt', \qquad v_x(t) = v_{0x} + \int_0^t a_x(t')\,dt'$$
v–t 그래프 아래 (부호 있는) 넓이 = 변위, a–t 그래프 아래 넓이 = 속도 변화. t축 아래(\(v < 0\))의 넓이는 음으로 센다. 이동 거리는 \(\int|v_x|\,dt\)다.

왼쪽 v–t 그래프의 흰 점 여섯 개를 위아래로 끌어 속도 그래프를 바꾸고, 아래쪽 ◆ 손잡이를 좌우로 끌어 적분 끝 시각 t를 바꾼다. 초록 넓이는 +, 빨강 넓이는 −로 센다. 오른쪽 x–t 그래프의 높이가 정확히 그 넓이만큼 변한다. 해볼 것: ① v가 음수인 구간에서 x가 줄어드는 것을 보라. ② 넓이의 합이 0이 되게 만들면 물체는 출발점으로 돌아온다. ③ v–t의 꼭짓점(v = 0을 지나는 곳)이 x–t의 극대·극소다.
심화: 등가속도 공식을 적분으로 유도하기

\(a_x\)가 상수이면 \(v_x = v_{0x} + \int_0^t a_x\,dt' = v_{0x} + a_xt\). 이것을 다시 적분하면 \(x = x_0 + \int_0^t (v_{0x} + a_xt')\,dt' = x_0 + v_{0x}t + \tfrac12a_xt^2\). 또 연쇄 법칙으로 \(a_x = \dfrac{dv_x}{dt} = \dfrac{dv_x}{dx}\dfrac{dx}{dt} = v_x\dfrac{dv_x}{dx}\)이므로 \(\int v_x\,dv_x = \int a_x\,dx\) → \(v_x^2 = v_{0x}^2 + 2a_x(x - x_0)\). 이 마지막 형태는 가속도가 위치의 함수일 때(용수철 등)도 쓸 수 있다 — 7장 에너지 보존의 씨앗이다.

정지해 있던 자동차의 가속도가 \(a_x(t) = 4.0\text{ m/s}^2 - (0.50\text{ m/s}^3)t\)이다(\(x_0 = 0\)). 속도가 최대가 되는 시각, 그때의 속도와 위치를 구하라.

전략 적분으로 \(v(t)\), \(x(t)\)를 구한다. 속도가 최대인 순간은 \(dv/dt = a = 0\).
풀이 \(v = \int_0^t(4.0 - 0.50t')dt' = 4.0t - 0.25t^2\), \(x = 2.0t^2 - t^3/12\). \(a = 0\) → \(t = 8.0\) s. \(v(8.0) = 32 - 16 = 16\) m/s, \(x(8.0) = 128 - 42.7 = 85.3\) m.

검토 등가속도 공식을 잘못 쓰면(평균 가속도 2.0 m/s²로 \(\tfrac12at^2\)) 64 m가 나온다. 초반에 가속도가 커서 실제로는 더 멀리 간다.

핵심 정리

  1. 변위 \(\Delta x = x_2 - x_1\)는 부호가 있고 경로와 무관하다. 평균 속도 \(\Delta x/\Delta t\)는 x–t 그래프의 할선 기울기, 평균 속력은 이동 거리/시간이다.
  2. 순간 속도 \(v_x = dx/dt\)는 x–t 그래프의 접선 기울기, 가속도 \(a_x = dv_x/dt\)는 v–t 그래프의 접선 기울기다.
  3. 속도와 가속도의 부호가 같으면 빨라지고, 다르면 느려진다.
  4. 등가속도: \(v_x = v_{0x} + a_xt\), \(x = x_0 + v_{0x}t + \tfrac12a_xt^2\), \(v_x^2 = v_{0x}^2 + 2a_x\Delta x\), \(\Delta x = \tfrac12(v_{0x} + v_x)t\).
  5. 자유 낙하는 \(a_y = -g\)(9.80 m/s²)인 등가속도 운동이다. 최고점에서도 가속도는 \(-g\)다.
  6. v–t 그래프 아래 부호 있는 넓이 \(\int v_x\,dt\)가 변위, a–t 아래 넓이가 속도 변화다.

연습문제

특별한 말이 없으면 \(g = 9.80\) m/s²를 쓰고 공기 저항은 무시한다. 답이 ±1% 이내면 정답이다.

2009년 우사인 볼트는 100 m를 9.58 s에 달렸다. 평균 속도는?

\(v = 100/9.58 = 10.4\) m/s (약 37.6 km/h).

둘레 400 m인 트랙을 80.0 s에 한 바퀴 돌았다. 평균 속력은? (평균 속도는 얼마인지도 생각해 보라.)

평균 속력 \(= 400/80.0 = 5.00\) m/s. 출발점으로 돌아왔으므로 변위가 0, 평균 속도도 0이다.

어떤 거리의 절반을 60.0 km/h로, 나머지 절반을 40.0 km/h로 갔다. 전체 평균 속력은?

50 km/h가 아니다. 각 구간에 걸린 시간을 구하라(전체 거리를 2d로 두면 편하다).

\(t = d/60 + d/40\), 평균 속력 \(= 2d/t = 2/(1/60 + 1/40) = 48.0\) km/h. 느린 구간에 더 오래 머물기 때문에 산술 평균보다 작다.

비행기가 정지 상태에서 일정하게 가속해 32.0 s 만에 이륙 속력 80.0 m/s에 이른다. 가속도와 활주 거리는?

\(a = 80.0/32.0 = 2.50\) m/s². \(\Delta x = \tfrac12(0 + 80.0)(32.0) = 1280\) m.

입자의 위치가 \(x(t) = 3.0t^3 - 2.0t\) (x는 m, t는 s)이다. \(t = 2.0\) s에서 속도와 가속도는?

\(v = 9.0t^2 - 2.0 = 34.0\) m/s, \(a = 18t = 36.0\) m/s².

108 km/h로 달리던 운전자가 위험을 보고 0.750 s 뒤에 브레이크를 밟았다. 감속도는 7.50 m/s²이다. (a) 브레이크를 밟은 뒤 미끄러진 거리, (b) 위험을 본 순간부터 정지까지 거리는?

반응 시간 동안은 처음 속력 그대로 간다.

\(v_0 = 30.0\) m/s. (a) \(30.0^2/(2\times7.50) = 60.0\) m. (b) \(60.0 + 30.0\times0.750 = 82.5\) m.

제트기의 이륙 속력은 70.0 m/s, 최대 가속도는 2.00 m/s²이다. 활주로는 최소 몇 m여야 하는가?

\(v^2 = 2aL\) → \(L = 70.0^2/(2\times2.00) = 1225\) m.

우물에 돌을 떨어뜨렸더니 2.40 s 뒤에 물에 닿았다. 우물의 깊이는? (소리가 오는 시간은 무시한다.)

\(d = \tfrac12(9.80)(2.40)^2 = 28.2\) m.

공을 12.0 m/s로 똑바로 위로 던졌다. 최고 높이와, 던진 손으로 돌아올 때까지의 시간은?

\(H = 12.0^2/(2\times9.80) = 7.35\) m, \(T = 2\times12.0/9.80 = 2.45\) s.

높이 30.0 m 옥상 끝에서 공을 8.00 m/s로 똑바로 위로 던졌다. 공이 땅에 닿을 때까지의 시간과 그때의 속력은?

\(0 = 30.0 + 8.00t - 4.90t^2\)을 근의 공식으로 푼다. 속력은 \(v^2 = v_0^2 + 2gh\)로도 구할 수 있다.

\(4.90t^2 - 8.00t - 30.0 = 0\) → \(t = (8.00 + \sqrt{64.0 + 588})/9.80 = 3.42\) s. \(v = \sqrt{8.00^2 + 2(9.80)(30.0)} = 25.5\) m/s.

30.0 m/s로 달리는 과속 차가 경찰차 옆을 지나고, 2.00 s 뒤에 경찰차가 4.00 m/s²로 가속하며 출발한다. 과속 차가 지나간 순간부터 따라잡을 때까지의 시간과 그동안 과속 차가 간 거리는?

\(30.0t = \tfrac12(4.00)(t - 2.00)^2\), \(t > 2.00\) s인 근.

\(2(t-2)^2 = 30t\) → \(t^2 - 19t + 4 = 0\) → \(t = (19 + \sqrt{345})/2 = 18.8\) s. \(x = 30.0\times18.79 = 564\) m. (추격 시뮬레이터에서 v = 30, a = 4, 지연 2로 확인하라.)

엘리베이터의 속도가 0에서 4.0 s 동안 일정하게 12 m/s까지 늘고, 6.0 s 동안 12 m/s를 유지한 뒤, 2.0 s 동안 일정하게 줄어 멈췄다. 움직인 거리는?

v–t 그래프 아래 넓이: \(\tfrac12(4.0)(12) + (6.0)(12) + \tfrac12(2.0)(12) = 24 + 72 + 12 = 108\) m.

입자의 속도가 \(v(t) = 3.0t^2 - 2.0t\) (m/s)이고 \(t = 0\)에서 \(x = 4.0\) m이다. \(t = 3.0\) s에서의 위치는?

\(x = 4.0 + \int_0^{3.0}(3.0t^2 - 2.0t)\,dt = 4.0 + [t^3 - t^2]_0^{3.0} = 4.0 + 27 - 9.0 = 22.0\) m.

어떤 물체의 x–t 그래프가 증가하면서 위로 볼록(기울기가 점점 작아짐)하다. 옳은 것은?

그래프가 증가 → 기울기(속도) 양수. 기울기가 줄어듦 → 가속도 음수. 부호가 반대이므로 느려진다.

같은 높이에서 공 A는 가만히 놓고, 공 B는 아래로 5 m/s로 던졌다. 공중에 있는 동안 두 공의 가속도는?

자유 낙하의 가속도는 처음 속도와 무관하게 g다. 처음 속도는 v–t 그래프의 절편만 바꾸고 기울기는 바꾸지 않는다.

개념 확인 퀴즈

v–t 그래프에서 기울기와 아래 넓이가 각각 뜻하는 것은?

\(a = dv/dt\)(기울기), \(\Delta x = \int v\,dt\)(넓이).

x–t 그래프가 t축에 평행한 직선이다. 물체는?

기울기 0 → 속도 0. 위치는 0이 아닐 수도 있다.

\(v_x < 0\), \(a_x > 0\)인 물체는?

속도와 가속도의 부호가 반대 → 느려진다. 계속되면 멈춘 뒤 +x 방향으로 간다.

정지 상태에서 등가속도로 출발한 물체가 처음 1 s 동안 2 m를 갔다. 처음 3 s 동안 가는 거리는?

\(x = \tfrac12at^2 \propto t^2\) → \(3^2 = 9\)배, 18 m.

공을 위로 던졌다. 올라가는 동안과 내려오는 동안 같은 높이를 지날 때의 속도는?

\(v_y^2 = v_{0y}^2 - 2g(y - y_0)\)는 높이만의 함수이므로 크기가 같다(공기 저항이 없을 때).
