Chapter 09

강체의 회전

바퀴, 팽이, 하드 디스크, 지구 — 회전하는 물체에서는 점마다 속도가 다르다. 축 가까운 점은 느리고 테두리는 빠르다. 그래도 모든 점은 같은 각도만큼 돈다. 이 장은 회전을 각도의 언어로 다시 쓰고, 회전하는 물체의 에너지가 질량뿐 아니라 질량이 축에서 얼마나 멀리 퍼져 있는지에 달려 있음을 보인다. 아래 바퀴의 테두리를 잡고 돌려 보자.

바퀴를 잡고 돌린다
  • 각변위(라디안)·각속도·각가속도를 정의하고 rpm과 rad/s를 서로 바꾼다.
  • 등각가속도 회전의 네 식을 직선 운동과 대응시켜 쓰고, θ–t·ω–t 그래프를 해석한다.
  • 강체 위 점의 \(v = r\omega\), \(a_\text{tan} = r\alpha\), \(a_\text{rad} = \omega^2 r\)을 구하고 벨트·톱니 문제를 푼다.
  • 회전 운동 에너지 \(K = \tfrac12 I\omega^2\)를 쓰고, 에너지 보존으로 도르래와 구르는 물체의 속력을 구한다.
  • 관성 모멘트를 질점의 합과 적분으로 계산하고, 평행축 정리 \(I_P = I_\text{cm} + Md^2\)를 유도해 쓴다.

각변위, 각속도, 각가속도

강체(rigid body)는 모양과 크기가 변하지 않는 물체다. 고정된 축을 도는 강체의 모든 점은 같은 시간에 같은 각도만큼 돈다. 그래서 회전은 각도 하나 \(\theta\)로 기술된다. 물리에서 각도는 라디안(radian)으로 잰다: 반지름 \(r\)인 원에서 호의 길이 \(s\)를 반지름으로 나눈 값이다.

$$\theta = \frac{s}{r}\ \ (\text{rad}), \qquad 1\ \text{rev} = 2\pi\ \text{rad} = 360^\circ, \qquad 1\ \text{rad} \approx 57.3^\circ$$

각위치가 시간에 따라 \(\theta(t)\)로 바뀔 때, 직선 운동의 속도·가속도에 대응하는 양을 정의한다.

각속도와 각가속도

각속도(angular velocity) \(\omega_z = d\theta/dt\) (rad/s), 각가속도(angular acceleration) \(\alpha_z = d\omega_z/dt\) (rad/s²). 축에서 보아 반시계 방향을 +로 잡는다. 평균값은 \(\omega_\text{av} = \Delta\theta/\Delta t\), \(\alpha_\text{av} = \Delta\omega/\Delta t\)이다.

등각가속도 회전

각가속도가 일정하면 2장의 등가속도 운동 식이 기호만 바뀌어 그대로 성립한다: \(x \to \theta\), \(v \to \omega\), \(a \to \alpha\).

직선 운동 (a 일정)

\(v = v_0 + at\)
\(x = x_0 + v_0t + \tfrac12at^2\)
\(v^2 = v_0^2 + 2a(x - x_0)\)
\(x - x_0 = \tfrac12(v_0 + v)t\)

회전 운동 (α 일정)

\(\omega = \omega_0 + \alpha t\)
\(\theta = \theta_0 + \omega_0t + \tfrac12\alpha t^2\)
\(\omega^2 = \omega_0^2 + 2\alpha(\theta - \theta_0)\)
\(\theta - \theta_0 = \tfrac12(\omega_0 + \omega)t\)

정지해 있던 바퀴가 일정한 각가속도로 돌기 시작했다. 처음 2초 동안 돈 각과 그다음 2초 동안 돈 각의 비는?

\(\theta \propto t^2\)이므로 \(\theta(2) : \theta(4) = 1 : 4\), 그다음 2초는 \(4 - 1 = 3\). 아래에서 ω₀ = 0으로 놓고 θ–t 그래프를 보라(갈릴레이의 홀수 법칙과 같다).

선속도·선가속도와의 관계

축에서 거리 \(r\)인 점은 원을 그린다. 각 \(\theta\)만큼 돌면 호 \(s = r\theta\)를 가므로, 시간으로 미분하면 접선 방향 속력과 가속도가 나온다. 점은 원운동을 하므로 3장의 구심 가속도도 있다.

$$v = r\omega, \qquad a_\text{tan} = \frac{dv}{dt} = r\alpha, \qquad a_\text{rad} = \frac{v^2}{r} = \omega^2 r$$
\(\omega, \alpha\)는 반드시 rad 단위(rad/s, rad/s²)여야 한다. rpm이나 °/s를 넣으면 틀린다. 전체 가속도 크기는 \(a = \sqrt{a_\text{tan}^2 + a_\text{rad}^2}\).

회전 운동 에너지

회전하는 바퀴는 전체가 움직이지 않아도(질량 중심 정지) 운동 에너지를 가진다. 각 조각 \(m_i\)의 속력이 \(r_i\omega\)이므로 모두 더하면

$$K = \sum_i\tfrac12 m_i(r_i\omega)^2 = \tfrac12\Big(\sum_i m_i r_i^2\Big)\omega^2 = \tfrac12 I\omega^2$$
\(I = \sum m_i r_i^2\)를 관성 모멘트(moment of inertia)라 한다(단위 kg·m²). 직선 운동의 질량 역할을 한다: \(K = \tfrac12mv^2 \leftrightarrow \tfrac12I\omega^2\).
관성 모멘트

회전축에 대해 \(I = \sum m_i r_i^2\) (\(r_i\): 축까지의 수직 거리). 같은 물체라도 축이 바뀌면 I가 바뀐다. 질량이 축에서 멀리 퍼져 있을수록 크다 — 같은 ω에서 더 큰 에너지가 필요하다.

질량 50, 반지름 3인 원판 팽이(\(I = \tfrac12MR^2\))가 1500로 돈다. 관성 모멘트는 , 회전 운동 에너지는 이다. 이 에너지면 팽이를 들어 올릴 수 있다.

에너지 보존과 회전

도르래에 감긴 줄에 매달린 추가 떨어지면, 잃은 중력 퍼텐셜 에너지가 추의 병진 운동 에너지와 도르래의 회전 운동 에너지로 나뉜다. 줄이 미끄러지지 않으면 \(v = R\omega\)로 묶인다.

$$mgh = \tfrac12mv^2 + \tfrac12I\omega^2 = \tfrac12\Big(m + \frac{I}{R^2}\Big)v^2 \quad\Rightarrow\quad v = \sqrt{\frac{2mgh}{m + I/R^2}}$$

질량 4.00 kg, 반지름 0.100 m인 원판 도르래에 감긴 줄에 2.00 kg 추를 매달고 정지 상태에서 놓았다. 1.00 m 떨어졌을 때 추의 속력은?

풀이 보기
풀이 \(I/R^2 = \tfrac12M = 2.00\) kg. \(v = \sqrt{2(2.00)(9.80)(1.00)/(2.00 + 2.00)} = 3.13\) m/s.
v = 3.13 m/s (자유 낙하라면 4.43 m/s)
검토 에너지의 절반이 도르래 회전으로 갔다. 미니 실험의 처음 값과 같다.

관성 모멘트 계산

질점 몇 개라면 \(\sum m_ir_i^2\)를 그대로 더한다. 막대·원판처럼 질량이 연속으로 퍼져 있으면 작은 조각 \(dm\)으로 쪼개 적분한다.

$$I = \sum_i m_i r_i^2 \qquad\longrightarrow\qquad I = \int r^2\,dm$$
\(dm\)을 좌표로 쓴다: 선밀도 \(\lambda\)이면 \(dm = \lambda\,dx\), 면밀도 \(\sigma\)이면 \(dm = \sigma\,dA\), 부피밀도 \(\rho\)이면 \(dm = \rho\,dV\).

경사면 경주

평행축 정리

같은 막대도 중심축보다 끝축에서 I가 4배였다. 일반적으로, 질량 중심을 지나는 축에 대한 \(I_\text{cm}\)을 알면 그와 평행하고 거리 \(d\)만큼 떨어진 모든 축의 I를 바로 구할 수 있다.

평행축 정리

질량 \(M\)인 물체의, 질량 중심을 지나는 축과 평행하며 거리 \(d\)인 축 P에 대한 관성 모멘트는 \(I_P = I_\text{cm} + Md^2\)이다(평행축 정리(parallel-axis theorem)). 따라서 평행한 축들 가운데 \(I\)는 질량 중심축에서 가장 작다.

(a) 질량 0.800 kg, 길이 1.20 m 막대의 끝을 지나는 수직축에 대한 I를 평행축 정리로 구하라. (b) 질량 M, 반지름 R인 원판의 가장자리 한 점을 지나고 원판에 수직인 축에 대한 I는?

풀이 보기
풀이 (a) \(I_\text{cm} = \tfrac1{12}(0.800)(1.20)^2 = 0.0960\) kg·m², \(d = 0.600\) m: \(I = 0.0960 + 0.800(0.600)^2 = 0.384\) kg·m² \(= \tfrac13ML^2\) ✓. (b) \(I = \tfrac12MR^2 + MR^2 = \tfrac32MR^2\).
(a) 0.384 kg·m² (b) 3MR²/2
검토 앞 예제의 세 질점도 확인된다: \(x_\text{cm} = 2/3\) m, \(I_\text{cm} = 3.50 - 6.00(2/3)^2 = 0.833\), \(x = 0.5\) 축: \(0.833 + 6.00(1/6)^2 = 1.00\) ✓.

핵심 정리

  1. 각도는 라디안 \(\theta = s/r\)로 잰다. \(\omega = d\theta/dt\), \(\alpha = d\omega/dt\). 1 rev = 2π rad, rpm × 2π/60 = rad/s.
  2. α가 일정하면 \(\omega = \omega_0 + \alpha t\), \(\theta = \theta_0 + \omega_0t + \tfrac12\alpha t^2\), \(\omega^2 = \omega_0^2 + 2\alpha\Delta\theta\) — 직선 운동과 같은 꼴.
  3. 강체의 모든 점은 같은 ω, α를 가진다. 점의 \(v = r\omega\), \(a_\text{tan} = r\alpha\), \(a_\text{rad} = \omega^2r\).
  4. 회전 운동 에너지 \(K = \tfrac12I\omega^2\), 관성 모멘트 \(I = \sum m_ir_i^2 = \int r^2dm\). I는 축에 따라 다르다.
  5. 고리 \(MR^2\), 원판 \(\tfrac12MR^2\), 구 \(\tfrac25MR^2\), 막대(중심) \(\tfrac1{12}ML^2\), 막대(끝) \(\tfrac13ML^2\).
  6. 평행축 정리 \(I_P = I_\text{cm} + Md^2\): 평행한 축 중 질량 중심축의 I가 최소.
  7. 구르는 물체 \(v = \sqrt{2gh/(1+c)}\) (\(I = cMR^2\)): 모양만이 경주의 승패를 정한다.

연습문제

특별한 말이 없으면 \(g = 9.80\) m/s²를 쓴다. 답이 ±1% 이내면 정답이다. 각도 답은 rad 단위로 쓴다.

LP 레코드판은 \(33\tfrac13\) rpm으로 돈다. 각속도는 몇 rad/s인가?

\(\omega = (100/3)(2\pi/60) = 3.49\) rad/s.

정지한 바퀴가 일정한 각가속도로 4.00 s 만에 12.0 rad/s가 되었다. 각가속도와 그동안 돈 각은?

\(\alpha = 12.0/4.00 = 3.00\) rad/s², \(\theta = \tfrac12(0 + 12.0)(4.00) = 24.0\) rad.

1200 rpm으로 돌던 선풍기 날개가 일정하게 감속해 50.0 바퀴를 더 돌고 멈췄다. 각가속도와 멈추는 데 걸린 시간은?

\(\omega^2 = \omega_0^2 + 2\alpha\Delta\theta\), \(\Delta\theta = 50.0\times2\pi\) rad.

\(\omega_0 = 125.7\) rad/s, \(\Delta\theta = 314.2\) rad. \(\alpha = -\omega_0^2/2\Delta\theta = -25.1\) rad/s². \(t = 2\Delta\theta/\omega_0 = 5.00\) s.

각위치가 \(\theta(t) = 3.00t^2 - 1.00t^3\) (rad, s)이다. \(t = 1.00\) s에서 각속도와, \(t > 0\)에서 바퀴가 순간 정지하는 시각은?

\(\omega = 6.00t - 3.00t^2\) → \(\omega(1) = 3.00\) rad/s. \(\omega = 0\): \(t = 2.00\) s.

반지름 0.300 m인 바퀴가 50.0 rad/s로 일정하게 돈다. 테두리 점의 속력과 구심 가속도는?

\(v = (0.300)(50.0) = 15.0\) m/s, \(a_\text{rad} = (50.0)^2(0.300) = 750\) m/s².

반지름 0.500 m인 바퀴가 어느 순간 ω = 4.00 rad/s, α = 6.00 rad/s²이다. 테두리 점의 전체 가속도 크기는?

\(a_\text{tan} = 3.00\), \(a_\text{rad} = 16.0\times0.500 = 8.00\) m/s² → \(a = \sqrt{9.00 + 64.0} = 8.54\) m/s².

반지름 4.00 cm 모터 풀리가 1800 rpm으로 돌며 벨트로 반지름 12.0 cm 풀리를 돌린다. 큰 풀리의 회전 속도와 벨트 속력은?

\(r_1\omega_1 = r_2\omega_2\) → \(n_2 = 1800\times4.00/12.0 = 600\) rpm. \(v = (0.0400)(188.5) = 7.54\) m/s.

한 변이 0.400 m인 정사각형의 네 꼭짓점에 0.500 kg 질점이 하나씩 있다(가벼운 틀로 연결). 정사각형 중심을 지나고 면에 수직인 축에 대한 I는?

각 질점까지 거리 \(r = 0.400/\sqrt2 = 0.283\) m. \(I = 4(0.500)(0.0800) = 0.160\) kg·m².

질량 2.00 kg, 길이 1.50 m인 균일한 막대가 중심을 지나는 수직축 주위로 6.00 rad/s로 돈다. 회전 운동 에너지는?

\(I = \tfrac1{12}(2.00)(1.50)^2 = 0.375\) kg·m², \(K = \tfrac12(0.375)(6.00)^2 = 6.75\) J.

질량 20.0 kg, 반지름 0.250 m인 원판 플라이휠에 \(1.00\times10^4\) J를 저장하려면 몇 rpm으로 돌려야 하는가?

\(I = 0.625\) kg·m², \(\omega = \sqrt{2K/I} = 178.9\) rad/s → \(n = 178.9\times60/2\pi = 1.71\times10^3\) rpm.

길이 0.800 m, 질량 1.20 kg인 막대의 선밀도가 \(\lambda(x) = \lambda_0x/L\)이다(\(x\): 한쪽 끝부터). \(x = 0\) 끝을 지나는 수직축에 대한 I는?

\(M = \lambda_0L/2\), \(I = \int_0^Lx^2\lambda_0\frac{x}{L}dx = \lambda_0L^3/4\).

\(I = \lambda_0L^3/4 = \tfrac12ML^2 = \tfrac12(1.20)(0.800)^2 = 0.384\) kg·m². (균일하면 \(\tfrac13ML^2\) — 질량이 먼 쪽에 몰려 더 크다.)

질량 2.00 kg, 반지름 0.300 m인 원판의 가장자리를 지나고 원판 면에 수직인 축에 대한 I는?

\(I = \tfrac12MR^2 + MR^2 = \tfrac32(2.00)(0.0900) = 0.270\) kg·m².

질량 3.00 kg, 반지름 0.200 m인 원판 도르래에 감긴 줄에 1.50 kg 추를 매달아 정지 상태에서 놓았다. 2.00 m 떨어졌을 때 추의 속력과 도르래의 각속도는?

\(v = \sqrt{2mgh/(m + M/2)} = \sqrt{2(1.50)(9.80)(2.00)/3.00} = 4.43\) m/s, \(\omega = v/R = 22.1\) rad/s.

같은 질량·반지름의 속 빈 원통(얇은 껍질)과 속 찬 원통을 같은 경사면에서 굴린다. 바닥에 먼저 닿는 것은?

속 찬 원통 \(c = 1/2\), 속 빈 원통 \(c = 1\). \(c\)가 작은 쪽이 \(v = \sqrt{2gh/(1+c)}\)가 커 먼저 닿는다.

일정하게 도는 회전목마에서 축에서 1 m인 아이 A와 3 m인 아이 B에 대해 옳은 것은?

ω가 같으므로 \(v = r\omega\)와 \(a_\text{rad} = \omega^2r\) 모두 r에 비례해 3배.

개념 확인 퀴즈

바퀴의 각속도가 음수이고 각가속도가 양수이다. 바퀴는?

ω와 α의 부호가 반대면 느려진다. 반시계가 +이므로 ω < 0은 시계 방향.

같은 질량의 고리와 원판(같은 반지름)을 같은 ω로 돌릴 때 회전 운동 에너지의 비 K고리 : K원판은?

\(MR^2 : \tfrac12MR^2 = 2 : 1\).

물체의 관성 모멘트가 가장 작은 회전축은 (평행한 축들 가운데)?

평행축 정리 \(I = I_\text{cm} + Md^2\)에서 \(d = 0\)일 때 최소.

등각가속도로 빨라지는 바퀴의 테두리 점에서 시간이 지나도 변하지 않는 양은?

\(a_\text{tan} = r\alpha\)는 일정하다. ω가 커지므로 \(v\)와 \(a_\text{rad} = \omega^2r\)는 커지고, 전체 가속도는 점점 중심 쪽으로 기운다.

다이빙 선수가 몸을 웅크리면 빨리 돈다. 이것과 관련된 양의 변화는?

질량을 축 가까이 모으면 I가 작아진다. 왜 그때 ω가 커지는지는 10장의 각운동량 보존이 설명한다.
