Chapter 13

진동

그네, 시계추, 기타 줄, 자동차 서스펜션, 분자 속 원자 — 평형점을 중심으로 같은 운동을 되풀이하는 것은 어디에나 있다. 놀라운 것은 이 모든 진동이 변위에 비례하는 복원력이라는 단 하나의 조건에서 같은 수학, 사인 곡선을 따른다는 점이다. 아래 상자를 끌어당겼다가 놓아 보자. 펜이 그 운동을 종이에 그린다.

상자를 좌우로 끌었다가 놓아 보세요
  • 진폭·주기·진동수·각진동수·위상을 정의하고 서로 바꾼다.
  • \(F = -kx\)에서 단순 조화 운동의 식 \(x = A\cos(\omega t + \phi)\)를 얻고, 원운동의 투영으로 해석한다.
  • 초기 조건(\(x_0, v_0\))에서 진폭과 위상을 구하고 속도·가속도를 계산한다.
  • 진동의 에너지 \(E = \tfrac12kA^2\)으로 임의 위치의 속력을 구하고, 수직 용수철을 평형점 기준으로 다룬다.
  • 단진자·물리 진자의 주기를 유도하고, 작은 각 근사의 한계를 정량적으로 설명한다.
  • 감쇠 진동의 세 영역(저·임계·과감쇠)과 강제 진동의 공명 곡선을 해석한다.

진동의 묘사

평형 위치에서 벗어난 물체를 다시 평형 쪽으로 되돌리는 힘을 복원력(restoring force)이라 한다. 복원력 때문에 물체는 평형점을 지나치고, 반대편에서 다시 되돌아오는 운동을 되풀이한다. 이러한 운동이 주기 운동(periodic motion) 또는 진동(oscillation)이다.

진동을 묘사하는 양

진폭(amplitude) \(A\): 평형에서 최대 변위의 크기(항상 양수). 주기(period) \(T\): 한 번 왕복하는 데 걸리는 시간. 진동수(frequency) \(f = 1/T\): 1초당 왕복 횟수(단위 Hz = s⁻¹). 각진동수(angular frequency) \(\omega = 2\pi f\)(rad/s).

$$f = \frac{1}{T}, \qquad \omega = 2\pi f = \frac{2\pi}{T}$$

주기가 0.50인 진동은 진동수 , 각진동수 이고, 1분 동안 왕복한다.

복원력 F = −kx

용수철처럼 복원력이 변위에 정비례하는 경우가 가장 중요하다: \(F_x = -kx\)(훅 법칙, 6장). 음의 부호는 힘이 늘 평형(x = 0) 쪽을 향한다는 뜻이다. 이 경우의 진동을 단순 조화 운동(simple harmonic motion, SHM)이라 한다. 평형 근처의 작은 진동은 거의 모두 이렇게 근사할 수 있다(퍼텐셜 에너지 곡선의 바닥은 포물선처럼 생겼다, 7장).

용수철에 달린 추가 3.0 s 동안 12번 왕복했다. 주기, 진동수, 각진동수를 구하라.

단순 조화 운동의 식과 원운동

뉴턴 제2법칙 \(ma_x = -kx\)는 위치와 그 2계 도함수 사이의 관계식, 즉 미분 방정식이다.

$$\frac{d^2x}{dt^2} = -\frac{k}{m}x = -\omega^2 x \qquad\Rightarrow\qquad x(t) = A\cos(\omega t + \phi), \quad \omega = \sqrt{\frac{k}{m}}$$
"두 번 미분하면 자기 자신의 \(-\omega^2\)배"인 함수는 사인·코사인뿐이다. \(\omega t + \phi\)를 위상(phase), \(\phi\)를 위상 상수(phase constant)라 한다.

주기 \(T = 2\pi\sqrt{m/k}\)는 진폭과 무관하다. 크게 흔들면 더 먼 거리를 가지만 복원력도 그만큼 커서 더 빨리 움직이기 때문이다. 미분하면 속도와 가속도가 나온다.

$$v_x = -\omega A\sin(\omega t+\phi), \qquad a_x = -\omega^2 A\cos(\omega t+\phi) = -\omega^2 x$$
최대 속력 \(v_\text{max} = \omega A\)(평형점), 최대 가속도 \(a_\text{max} = \omega^2A\)(양 끝). 속도는 위치보다 위상이 90° 앞서고, 가속도는 위치와 정반대(180°)다.

질량 0.50인 추를 용수철 상수 200인 용수철에 달면 \(\omega\) = , 주기 , 진동수 로 진동한다.

원운동의 투영

반지름 \(A\)인 원을 각속도 \(\omega\)로 도는 점을 생각하자. 시각 \(t\)에 이 점이 +x축과 이루는 각은 \(\theta = \omega t + \phi\)이고, x좌표는 \(A\cos(\omega t+\phi)\) — 단순 조화 운동과 똑같다. 이 원을 기준원(reference circle)이라 한다.

초기 조건에서 A와 φ 구하기

\(t = 0\)에서 \(x_0 = A\cos\phi\), \(v_0 = -\omega A\sin\phi\)이다. 두 식을 풀면

$$A = \sqrt{x_0^2 + \left(\frac{v_0}{\omega}\right)^2}, \qquad \tan\phi = -\frac{v_0}{\omega x_0}$$
\((x, v/\omega)\) 평면(위상 공간(phase space))에서 상태는 반지름 \(A\)인 원 위를 시계 방향으로 돈다. 초기 상태 점의 각이 \(-\phi\)이다. arctan의 사분면은 \(x_0, v_0\)의 부호로 정한다.

같은 용수철–질량계에서 진폭만 2배로 키우면 주기는?

\(T = 2\pi\sqrt{m/k}\)에는 A가 없다. 아래 위상 공간의 점을 바깥으로 끌어 진폭을 키워도 T가 변하지 않는다. 대신 최대 속력과 최대 가속도는 2배가 된다.

단순 조화 운동의 에너지와 수직 용수철

용수철 힘은 보존력이므로 역학적 에너지가 보존된다. 양 끝(\(x = \pm A\))에서는 모두 퍼텐셜 에너지, 평형점에서는 모두 운동 에너지다.

$$E = \tfrac12 mv_x^2 + \tfrac12 kx^2 = \tfrac12 kA^2 = \tfrac12 m v_\text{max}^2 \qquad\Rightarrow\qquad v_x = \pm\omega\sqrt{A^2 - x^2}$$
위치만 알면 속력이 나온다. \(K = U\)인 곳은 \(x = \pm A/\sqrt2\). 시간 평균으로는 K와 U가 각각 E의 절반씩이다.

예제 13.2의 진동(\(k = 200\) N/m, \(m = 0.500\) kg, \(A = 0.0250\) m)에서 총에너지, 최대 속력, \(x = 0.0100\) m에서의 속력을 구하라.

풀이 보기
풀이 \(E = \tfrac12(200)(0.0250)^2 = 0.0625\) J. \(v_\text{max} = \omega A = 20.0\times0.0250 = 0.500\) m/s. \(v = 20.0\sqrt{0.0250^2 - 0.0100^2} = 0.458\) m/s.
E = 0.0625 J, vmax = 0.500 m/s, v(0.0100 m) = 0.458 m/s
검토 \(x = 0.4A\)에서도 속력은 최대의 92%다. 평형 근처에서는 오래 빠르게, 끝에서 잠깐 느리게 움직인다.

응용: 수직 용수철

용수철에 추를 매달면 중력 때문에 용수철이 \(\Delta l\)만큼 늘어난 곳에서 평형을 이룬다: \(k\Delta l = mg\). 이 새 평형점에서 잰 변위를 \(y\)라 하면 알짜힘은 \(-k(\Delta l + y) + mg = -ky\) — 중력이 사라지고 똑같은 단순 조화 운동이 남는다. 주기도 \(2\pi\sqrt{m/k}\) 그대로다.

단진자와 물리 진자

길이 \(L\)인 가벼운 줄 끝에 작은 추를 단 단진자(simple pendulum)를 생각하자. 복원력은 중력의 접선 성분 \(-mg\sin\theta\)이고, 호의 길이는 \(s = L\theta\)이다.

$$\omega = \sqrt{\frac{g}{L}}, \qquad T = 2\pi\sqrt{\frac{L}{g}} \qquad(\text{작은 진폭})$$
질량과 진폭에 무관하다(갈릴레이가 성당의 샹들리에에서 발견한 등시성(isochronism)). 정확한 주기는 진폭 \(\theta_0\)가 클수록 길어진다: \(T = T_0\left(1 + \tfrac1{16}\theta_0^2 + \tfrac{11}{3072}\theta_0^4 + \cdots\right)\).

길이 1 m 진자의 진폭을 5°에서 60°로 키우면 주기는 어떻게 될까?

큰 각에서는 \(\sin\theta < \theta\)라 복원력이 선형 근사보다 약하고, 그래서 더 느리게 돈다. 60°에서 \(T/T_0 = 1.073\). 아래 실험실에서 정확한 진자(진한 추)와 선형 근사 진자(흐린 추)가 점점 어긋나는 것을 보라.

물리 진자

크기가 있는 강체가 질량 중심이 아닌 회전축에 매달려 흔들리면 물리 진자(physical pendulum)다. 회전축에서 질량 중심까지 거리가 \(d\)이면 중력의 토크는 \(\tau = -mgd\sin\theta\)이고, \(\tau = I\alpha\)(10장)에 작은 각 근사를 쓰면

$$\frac{d^2\theta}{dt^2} = -\frac{mgd}{I}\theta \qquad\Rightarrow\qquad T = 2\pi\sqrt{\frac{I}{mgd}}$$
\(I\)는 회전축에 대한 관성 모멘트(9장, 평행축 정리 \(I = I_\text{cm} + md^2\)). 점질량이면 \(I = mL^2\), \(d = L\)로 단진자 식이 된다.

감쇠 진동

실제 진동은 마찰과 공기 저항으로 점점 잦아든다. 저항력이 속도에 비례한다고 하자: \(F = -bv\)(\(b\): 감쇠 상수(damping constant), kg/s). 운동 방정식은 \(m\ddot x + b\dot x + kx = 0\)이고, 감쇠가 너무 크지 않으면 해는

$$x(t) = A_0 e^{-(b/2m)t}\cos(\omega' t + \phi), \qquad \omega' = \sqrt{\frac{k}{m} - \frac{b^2}{4m^2}}$$
진폭은 지수적으로 줄고(포락선 \(A_0e^{-bt/2m}\)), 진동은 \(\omega_0 = \sqrt{k/m}\)보다 조금 느려진다. 진폭이 절반이 되는 시간은 \(t_{1/2} = 2m\ln2/b\).
감쇠의 세 영역

저감쇠(underdamping) \(b < 2\sqrt{km}\): 진동하며 줄어든다. 임계 감쇠(critical damping) \(b = 2\sqrt{km}\): 진동하지 않고 가장 빨리 평형으로 돌아간다. 과감쇠(overdamping) \(b > 2\sqrt{km}\): 진동하지 않고 느리게 기어 들어간다.

강제 진동과 공명

그네를 밀어 주듯 진동자에 주기적인 힘 \(F_0\cos\omega_d t\)를 계속 가하면 처음의 과도적 움직임이 감쇠로 사라진 뒤, 진동자는 구동 진동수 \(\omega_d\)로 진동한다. 이것이 강제 진동(forced oscillation)이다. 정상 상태의 진폭은

$$A(\omega_d) = \frac{F_0}{\sqrt{(k - m\omega_d^2)^2 + b^2\omega_d^2}}$$
\(\omega_d\)가 고유 진동수 \(\omega_0 = \sqrt{k/m}\) 근처일 때 진폭이 크게 커진다 — 공명(resonance). 공명 때 진폭은 약 \(F_0/(b\omega_0)\)로, 감쇠가 작을수록 크고 뾰족하다. 공명 봉우리의 날카로움은 품질 인자(quality factor) \(Q = m\omega_0/b\)로 나타낸다.

2000년 런던 밀레니엄 다리는 개통일에 보행자의 걸음과 공명해 좌우로 크게 흔들렸다. 보수 공사로 감쇠기를 달아 감쇠 상수 b를 키웠다. b를 2배로 하면 공명 때의 진폭은?

공명 진폭은 \(F_0/(b\omega_0)\)이므로 b에 반비례한다. 공명 진동수 자체는 거의 그대로다. 실제로 다리에는 감쇠기 91개를 달아 감쇠를 크게 늘렸다. 아래에서 b를 바꾸며 스윕해 보라.

핵심 정리

  1. 진동은 진폭 A, 주기 T, 진동수 f = 1/T, 각진동수 ω = 2πf로 묘사한다.
  2. 복원력 \(F = -kx\)이면 단순 조화 운동: \(x = A\cos(\omega t+\phi)\), \(\omega = \sqrt{k/m}\). 주기는 진폭과 무관하다. \(v_\text{max} = \omega A\), \(a = -\omega^2x\).
  3. SHM은 기준원 위 등속 원운동의 투영이다. 초기 조건에서 \(A = \sqrt{x_0^2 + (v_0/\omega)^2}\), \(\tan\phi = -v_0/(\omega x_0)\).
  4. 에너지 \(E = \tfrac12kA^2\) 보존 → \(v = \omega\sqrt{A^2-x^2}\). 수직 용수철은 평형점(Δl = mg/k)을 기준으로 하면 같은 SHM이다.
  5. 단진자 \(T = 2\pi\sqrt{L/g}\)(작은 각, 질량 무관), 물리 진자 \(T = 2\pi\sqrt{I/mgd}\). 큰 진폭에서는 주기가 길어진다(60°에서 7%).
  6. 감쇠 진동: 진폭 \(\propto e^{-bt/2m}\), \(\omega' = \sqrt{k/m - b^2/4m^2}\). 임계 감쇠 \(b = 2\sqrt{km}\)에서 가장 빨리 평형으로 돌아간다.
  7. 강제 진동의 진폭은 \(\omega_d \approx \omega_0\)에서 최대(공명), 공명 진폭은 약 \(F_0/b\omega_0\), \(Q = m\omega_0/b\).

연습문제

특별한 말이 없으면 \(g = 9.80\) m/s²를 쓴다. 답이 ±1% 이내면 정답이다.

소리굽쇠가 440 Hz로 진동한다. 주기와 각진동수는?

\(T = 1/440 = 2.27\times10^{-3}\) s, \(\omega = 2\pi(440) = 2.76\times10^3\) rad/s.

0.300 kg 추를 단 용수철이 주기 0.500 s로 진동한다. 용수철 상수는?

\(k = 4\pi^2m/T^2 = 4\pi^2(0.300)/(0.500)^2 = 47.4\) N/m.

진폭 0.0800 m, 진동수 2.00 Hz인 단순 조화 운동의 최대 속력과 최대 가속도는?

\(\omega = 4\pi = 12.57\) rad/s. \(v_\text{max} = \omega A = 1.01\) m/s, \(a_\text{max} = \omega^2A = 12.6\) m/s².

\(x(t) = (0.0500\ \text{m})\cos[(8.00\ \text{rad/s})t + \pi/3]\)이다. \(t = 0\)에서 위치와 속도는?

\(x(0) = 0.0500\cos60^\circ = 0.0250\) m. \(v(0) = -\omega A\sin60^\circ = -(8.00)(0.0500)(0.866) = -0.346\) m/s.

k = 250 N/m 용수철에 0.500 kg 추가 진폭 0.0400 m로 진동한다. 총에너지와 x = 0.0200 m에서의 속력은?

\(E = \tfrac12(250)(0.0400)^2 = 0.200\) J. \(v = \sqrt{(k/m)(A^2 - x^2)} = \sqrt{500(1.20\times10^{-3})} = 0.775\) m/s.

위 문제의 진동에서 운동 에너지와 퍼텐셜 에너지가 같아지는 위치(양수)는?

\(U = E/2\)이어야 하므로 \(\tfrac12kx^2 = \tfrac14kA^2\) → \(x = A/\sqrt2 = 0.0283\) m.

0.400 kg 추를 매달자 용수철이 9.80 cm 늘어났다. 이 추가 위아래로 진동할 때의 진동수는?

\(T = 2\pi\sqrt{\Delta l/g} = 2\pi\sqrt{0.0980/9.80} = 0.628\) s → \(f = 1.59\) Hz. 질량은 필요 없다.

길이 1.00 m 단진자를 달(\(g = 1.62\) m/s²)로 가져가면 주기는?

\(T = 2\pi\sqrt{1.00/1.62} = 4.94\) s(지구의 2.46배).

길이 0.750 m 진자가 20번 왕복하는 데 34.8 s가 걸렸다. 이 곳의 중력 가속도는?

\(T = 34.8/20 = 1.74\) s. \(g = 4\pi^2L/T^2 = 4\pi^2(0.750)/(1.74)^2 = 9.78\) m/s². 도전 과제에서 이 방법을 쓴다.

길이 1.00 m인 균일한 미터자의 한쪽 끝에서 25.0 cm 되는 곳에 구멍을 뚫어 축에 걸었다. 작은 진폭의 주기는?

평행축 정리: \(I = \tfrac1{12}mL^2 + md^2\), d = 0.250 m.

\(I/m = 0.08333 + 0.0625 = 0.1458\) m². \(T = 2\pi\sqrt{0.1458/(9.80\times0.250)} = 1.53\) s.

질량 0.500 kg 진동자의 감쇠 상수가 0.200 kg/s이다. 진폭이 처음의 절반이 되는 데 걸리는 시간은?

\(e^{-bt/2m} = 1/2\) → \(t = 2m\ln2/b = 2(0.500)(0.693)/0.200 = 3.47\) s.

k = 200 N/m, m = 0.500 kg인 진동자가 임계 감쇠되려면 감쇠 상수가 얼마여야 하는가?

\(b_c = 2\sqrt{km} = 2\sqrt{100} = 20.0\) kg/s.

m = 2.00 kg, k = 800 N/m, b = 4.00 kg/s인 진동자에 \(F_0 = 5.00\) N, \(\omega_d = 18.0\) rad/s의 힘을 가한다. 정상 상태 진폭은?

\(k - m\omega_d^2 = 800 - 2.00(18.0)^2 = 152\) N/m, \(b\omega_d = 72.0\) N/m. \(A = 5.00/\sqrt{152^2 + 72.0^2} = 5.00/168.2 = 0.0297\) m. 공명(ωd = 20.0 rad/s, 6.25 cm)의 절반도 안 된다 — 공명 봉우리가 그만큼 뾰족하다.

용수철–질량계의 진폭을 2배로 하면 무엇이 2배가 되는가?

\(v_\text{max} = \omega A\)는 2배, 주기·진동수는 그대로, 에너지 \(\tfrac12kA^2\)은 4배다.

위로 가속하는 엘리베이터 안에서 단진자의 주기는 정지해 있을 때에 비해 어떻게 되는가?

엘리베이터 안에서 유효 중력 가속도는 \(g + a\)로 커지므로 \(T = 2\pi\sqrt{L/(g+a)}\)는 짧아진다. (반대로 자유 낙하하는 엘리베이터에서는 진자가 흔들리지 않는다.)

개념 확인 퀴즈

단순 조화 운동에서 물체가 평형점(x = 0)을 지나는 순간에 대해 옳은 것은?

\(a = -\omega^2x\)이므로 x = 0에서 a = 0, 에너지가 모두 운동 에너지라 속력은 최대다.

단진자 추의 질량을 2배로 하면 주기는?

복원력(mg sin θ)과 관성(m)이 함께 2배가 되어 상쇄된다. 중력 질량 = 관성 질량의 결과다.

같은 용수철에 달린 추를 지구에서 달로 가져가 수직으로 진동시키면?

\(T = 2\pi\sqrt{m/k}\)에 g가 없다. 중력은 평형점을 Δl = mg/k만큼 옮길 뿐이다(수직 용수철 시뮬레이터). 단진자와 대조적이다.

자동차 충격 흡수기를 가장 바람직하게 설계한 것은?

임계 감쇠는 출렁임 없이 가장 빨리 평형으로 돌아간다. 과감쇠는 충격을 받은 뒤 차체가 천천히 돌아와 다음 충격에 대비하지 못한다.

강제 진동에서 구동 진동수를 고유 진동수보다 훨씬 크게 하면 진동자의 운동은?

\(\omega_d \gg \omega_0\)이면 \(A \approx F_0/m\omega_d^2\)로 작아지고 위상 지연은 180°에 가까워진다. 공명 시뮬레이터에서 벽과 상자의 움직임을 비교해 보라.
