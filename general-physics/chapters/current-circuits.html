Chapter 24

전류와 직류 회로

스위치를 켜면 불이 거의 동시에 들어온다. 그런데 도선 속 전자는 1초에 0.1 mm도 움직이지 않는다. 어떻게 된 일일까? 지금까지는 멈춰 있는 전하(정전기)를 다뤘다. 이 장에서는 전하가 흐르는 전류를 다룬다. 전류를 방해하는 저항, 전류를 밀어 주는 기전력, 그리고 어떤 복잡한 회로든 풀 수 있게 해 주는 키르히호프 법칙을 익히고, 축전기를 저항으로 충전할 때 나타나는 시간 상수를 알아본다.

저항의 흰 원을 좌우로 끌어 저항을 바꿔 보세요 · 점은 전하의 흐름
  • 전류 \(I = dQ/dt\)와 전류 밀도, 유동 속력 \(I = nqv_dA\)의 관계를 설명한다.
  • 비저항으로 저항 \(R = \rho L/A\)를 구하고, 옴의 법칙 \(V = IR\)와 온도에 따른 변화를 다룬다.
  • 기전력과 내부 저항이 있는 전원의 단자 전압과 회로의 전력, 최대 전력 전달 조건을 구한다.
  • 저항의 직렬·병렬과 키르히호프의 분기점·고리 법칙으로 여러 고리 회로를 푼다.
  • RC 회로의 충전·방전 \(q(t)\), \(i(t)\)와 시간 상수 \(\tau = RC\)를 쓴다.

전류

단면을 지나는 전하의 흐름률이 전류(electric current)다. 단위는 암페어(A = C/s). 관례상 전류의 방향은 양전하가 움직이는 방향으로 정한다. 금속에서 실제로 움직이는 것은 전자이므로 전자의 흐름은 전류와 반대 방향이다.

$$I = \frac{dQ}{dt}, \qquad I = nqv_dA, \qquad J = \frac{I}{A} = nqv_d$$
\(n\): 단위 부피당 전하 운반자의 수(구리는 \(8.5\times10^{28}\) m⁻³), \(v_d\): 유동 속력(drift speed), \(J\): 전류 밀도(current density)(A/m²).

저항과 옴의 법칙

많은 물질에서 전류 밀도는 전기장에 비례한다: \(\vec J = \vec E/\rho\). 비례 상수 \(\rho\)가 비저항(resistivity)(Ω·m)이고, 그 역수가 전도도 \(\sigma = 1/\rho\)다. 길이 \(L\), 단면적 \(A\)인 도선에 적용하면 \(V = EL\), \(I = JA\)이므로

$$V = IR, \qquad R = \frac{\rho L}{A}, \qquad \rho(T) = \rho_0\big[1 + \alpha(T - T_0)\big]$$
\(R\): 저항(resistance), 단위 옴(Ω = V/A). \(V\)와 \(I\)가 비례하는 것을 옴의 법칙(Ohm's law)이라 하지만, 이는 자연 법칙이 아니라 특정 물질(옴성 물질)의 성질이다. \(\alpha\): 비저항의 온도 계수. 금속은 \(\alpha > 0\)(뜨거우면 저항 증가), 반도체는 \(\alpha < 0\).

기전력, 내부 저항, 전력

전류가 계속 흐르려면 회로가 닫혀 있고, 어딘가에서 전하를 낮은 전위에서 높은 전위로 "퍼 올려" 주어야 한다. 그 역할을 하는 장치(전지, 발전기, 태양 전지)의 단위 전하당 일을 기전력(electromotive force, emf) \(\mathcal E\)라 한다. 이름과 달리 힘이 아니라 전위차(V)다.

실제 전원에는 내부 저항(internal resistance) \(r\)이 있어 전류가 흐르면 단자 전압이 떨어진다. 저항 \(R\)인 부하에 연결하면

$$V_\text{단자} = \mathcal E - Ir, \qquad I = \frac{\mathcal E}{R + r}, \qquad P = VI = I^2R = \frac{V^2}{R}$$
\(P\): 소자가 받는 전력(W). 저항에서 전기 에너지는 열이 된다(줄 열). 전원이 내놓는 전력 \(\mathcal EI\) 중 \(I^2r\)은 전원 자체를 데운다. 부하가 받는 전력은 \(R = r\)일 때 최대 \(\mathcal E^2/4r\)이다(최대 전력 전달).

기전력 12 V, 내부 저항 2 Ω인 전지의 두 단자를 굵은 도선(저항 ≈ 0)으로 바로 이으면 전류는?

\(I = \mathcal E/r = 6\) A. 단자 전압은 0이 되고, 전지의 전력 72 W가 모두 전지 내부에서 열이 된다(단락). 아래에서 부하 저항을 가장 작게 끌어 보라.

저항의 연결과 키르히호프 법칙

저항의 등가 공식은 축전기와 반대다. 직렬은 전류가 같고 전압이 더해지므로 저항이 더해지고, 병렬은 전압이 같고 전류가 더해지므로 역수가 더해진다.

$$R_\text{직렬} = R_1 + R_2 + \cdots, \qquad \frac{1}{R_\text{병렬}} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots$$
병렬 등가 저항은 가장 작은 저항보다도 작다. 집의 콘센트는 모두 병렬이라 전기 기구를 켤수록 전체 저항이 줄고 전류가 커진다(그래서 차단기가 있다).

직렬·병렬로 줄일 수 없는 회로도 있다. 그럴 때는 두 개의 법칙만으로 모든 직류 회로를 풀 수 있다 — 독일의 키르히호프가 1845년에 정리했다.

키르히호프 법칙

분기점 법칙(junction rule): 분기점으로 들어오는 전류의 합 = 나가는 전류의 합 (\(\sum I = 0\), 전하 보존). 고리 법칙(loop rule): 닫힌 고리를 한 바퀴 돌 때 전위 변화의 합은 0 (\(\sum\Delta V = 0\), 정전기장이 보존장이므로).

RC 회로

저항을 거쳐 축전기를 충전하면 전류는 처음에 \(\mathcal E/R\)로 컸다가 축전기 전압이 오를수록 줄어든다. 고리 법칙 \(\mathcal E - iR - q/C = 0\)과 \(i = dq/dt\)에서 미분 방정식 \(dq/dt = (\mathcal EC - q)/RC\)가 나오고, 그 해는 지수 함수다.

$$\text{충전: } q = C\mathcal E\left(1 - e^{-t/RC}\right),\ i = \frac{\mathcal E}{R}e^{-t/RC}, \qquad \text{방전: } q = Q_0e^{-t/RC},\ i = -\frac{Q_0}{RC}e^{-t/RC}$$
\(\tau = RC\): 시간 상수(time constant)(Ω·F = s). \(t = \tau\)에서 충전은 63.2%, 방전은 36.8%가 남는다. 약 \(5\tau\)면 사실상 끝난다. 절반이 되는 시간은 \(\tau\ln2 = 0.693\tau\).

빈 축전기를 저항을 거쳐 충전한다. 시간 상수 \(\tau = RC\)만큼 지났을 때 축전기의 전하는 최종 값의 몇 %일까?

\(1 - e^{-1} = 0.632\). 처음 속도대로 계속 충전되었다면 정확히 \(\tau\)에 다 찼을 것이다 — 그래프의 처음 접선이 최종 값과 만나는 시각이 \(\tau\)다.

핵심 정리

  1. 전류 \(I = dQ/dt\)(A), 방향은 양전하의 흐름. \(I = nqv_dA\). 금속 속 유동 속력은 mm/s 이하로 아주 느리다.
  2. \(R = \rho L/A\), \(V = IR\)(옴성 소자), \(\rho = \rho_0[1 + \alpha\Delta T]\). 전구·다이오드는 비옴성이다.
  3. 실제 전원: \(V = \mathcal E - Ir\). 전력 \(P = VI = I^2R = V^2/R\). 부하 전력 최대는 \(R = r\)(효율 50%).
  4. 직렬 \(R = \sum R_i\), 병렬 \(1/R = \sum1/R_i\). 키르히호프: 분기점 \(\sum I = 0\)(전하 보존), 고리 \(\sum\Delta V = 0\)(에너지 보존).
  5. RC 회로: 충전 \(q = C\mathcal E(1 - e^{-t/RC})\), 방전 \(q = Q_0e^{-t/RC}\), 시간 상수 \(\tau = RC\)(63%/37%).

\(Q = It = (3.6)(180) = 648\) C, \(N = Q/e = 4.04\times10^{21}\)개.

지름 2.05 mm인 구리 도선에 20 A가 흐른다. 유동 속력은?

\(A = 3.30\times10^{-6}\) m², \(v_d = I/neA = 4.44\times10^{-4}\) m/s.

지름 0.50 mm, 길이 2.0 m인 니크롬선의 저항은?

\(R = \rho L/A = (1.00\times10^{-6})(2.0)/[\pi(0.25\times10^{-3})^2] = 10.2\) Ω.

20 °C에서 35 Ω인 텅스텐 필라멘트(\(\alpha = 0.0045\) K⁻¹)가 2000 °C가 되면 저항은? (일차 근사)

\(R = 35[1 + 0.0045(1980)] = 347\) Ω. 켜는 순간 전류가 정상일 때보다 10배쯤 커서 전구는 켤 때 잘 끊어진다.

450 Ω 저항에 9.0 V를 걸면 전류는?

\(I = V/R = 0.020\) A = 20 mA.

기전력 9.0 V, 내부 저항 0.50 Ω인 전지에서 2.0 A가 흐른다. 단자 전압과 전지 내부에서 열로 나가는 전력은?

\(V = 9.0 - (2.0)(0.50) = 8.0\) V, \(P = I^2r = 2.0\) W.

기전력 6.0 V, 내부 저항 1.5 Ω인 전원에서 부하가 받는 전력을 최대로 하는 부하 저항과 그 전력은?

\(R = r = 1.5\) Ω, \(P = \mathcal E^2/4r = 36/6 = 6.0\) W.

120 V에서 60 W인 전구가 켜져 있을 때 저항과 전류는?

\(R = V^2/P = 240\) Ω, \(I = P/V = 0.50\) A.

12 Ω과 6 Ω을 병렬로 잇고, 이 묶음과 8 Ω을 직렬로 24 V에 연결했다. 등가 저항과 6 Ω 저항의 전류는?

\(R_p = 4\) Ω, \(R = 12\) Ω, \(I = 2.0\) A, 병렬부 전압 8.0 V → \(I_6 = 1.33\) A.

시뮬레이터와 같은 모양의 회로에서 \(\mathcal E_1 = 10\) V, \(\mathcal E_2 = 4\) V, \(R_1 = R_2 = 2\) Ω, \(R_3 = 4\) Ω이다. 가운데 전류 \(I_3\)(아래로 +)와 오른쪽 전류 \(I_2\)(위로 +)는?

위쪽 분기점 전위 V: \((10 - V)/2 + (4 - V)/2 = V/4\).

\(28 = 5V\) → \(V = 5.6\) V. \(I_3 = 1.4\) A, \(I_2 = (4 - 5.6)/2 = -0.80\) A, \(I_1 = 2.2\) A.

2.0 kΩ과 50 μF을 9.0 V 전지에 직렬로 이었다. 시간 상수와, \(t = 2\tau\)에서의 전하는?

\(\tau = 0.10\) s, \(q = C\mathcal E(1 - e^{-2}) = (450\text{ μC})(0.865) = 3.89\times10^{-4}\) C.

220 μF 축전기가 4.7 kΩ 저항을 통해 방전한다. 전하가 처음의 10%가 되는 데 걸리는 시간은?

\(e^{-t/\tau} = 0.10\) → \(t = \tau\ln10 = (1.034)(2.303) = 2.38\) s.

빈 100 μF 축전기를 저항을 거쳐 12 V 전지로 완전히 충전했다. 저항에서 열로 나간 에너지는?

전지가 한 일은 \(Q\mathcal E = C\mathcal E^2\), 축전기 에너지는 \(\tfrac12C\mathcal E^2\).

\(C\mathcal E^2 - \tfrac12C\mathcal E^2 = \tfrac12C\mathcal E^2 = 7.2\times10^{-3}\) J. 저항 값과 무관하다 — 23장 전하 나누기와 같은 이야기다.

같은 전구 두 개를 전지에 직렬로 이은 경우와 병렬로 이은 경우, 전구 하나의 밝기는? (내부 저항 무시)

직렬: 전구마다 \(V/2\) → \(P = V^2/4R\). 병렬: 전구마다 \(V\) → \(V^2/R\). 4배.

전압계를 실수로 회로에 직렬로 연결했다. 무슨 일이 일어나나?

전압계의 저항은 매우 크다. 직렬이면 회로 전체의 전류를 막는다. 반대로 전류계를 병렬로 이으면 단락되어 전류계가 망가질 수 있다.

개념 확인 퀴즈

같은 재료로 된 도선의 길이와 지름을 모두 2배로 하면 저항은?

\(R \propto L/d^2\): 2/4 = 1/2.

건전지를 오래 쓰면 기전력은 거의 그대로인데 손전등이 어두워진다. 주된 이유는?

\(V = \mathcal E - Ir\). 전자는 소모되지 않는다 — 화학 반응물이 소모된다.

병렬로 연결한 저항 중 하나를 더 추가하면 전체 저항은?

길이 하나가 더 생긴 것과 같다. \(1/R\)에 양수가 더해진다.

고리 법칙이 성립하는 근본 이유는?

분기점 법칙은 전하 보존, 고리 법칙은 에너지 보존(보존장)이다. 변하는 자기장이 있으면 고리 법칙이 수정된다(27장).

RC 회로의 저항을 2배로 하면?

최종 전하 \(C\mathcal E\)는 R과 무관. 처음 전류 \(\mathcal E/R\)는 절반.
