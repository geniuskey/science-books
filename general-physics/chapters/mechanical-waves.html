Chapter 15

역학적 파동

경기장의 파도타기 응원에서 사람들은 제자리에서 일어났다 앉을 뿐인데, '파도'는 경기장을 한 바퀴 돈다. 파동은 물질이 아니라 교란(모양)과 에너지가 전달되는 현상이다. 13장의 진동이 공간으로 퍼져 나가면 파동이 된다. 아래 줄의 왼쪽 끝을 잡고 흔들어 파동을 만들어 보자.

화면을 누른 채 위아래로 흔들어 보세요
  • 횡파와 종파를 구별하고, 파동이 전달하는 것이 매질이 아니라 교란과 에너지임을 설명한다.
  • 주기적 파동의 진폭·파장·진동수·주기·파수·각진동수 사이의 관계 \(v = f\lambda = \omega/k\)를 쓰고, 파동 함수 \(y(x,t) = A\cos(kx - \omega t)\)를 해석한다.
  • 뉴턴 법칙으로 줄의 파동 속력 \(v = \sqrt{F/\mu}\)와 파동 방정식을 유도한다.
  • 사인파가 나르는 평균 일률 \(P_\text{av} = \tfrac12\sqrt{\mu F}\,\omega^2A^2\)을 계산한다.
  • 중첩 원리로 간섭을 설명하고, 고정단·자유단·밀도가 다른 줄과의 경계에서 반사·투과를 예측한다.
  • 양 끝이 고정된 줄의 정상파와 고유 진동수 \(f_n = n\,v/2L\)을 구하고 마디·배의 위치를 찾는다.

파동의 종류

줄, 용수철, 물, 공기처럼 파동을 전달하는 물질을 매질(medium)이라 하고, 매질의 변형이 전달되는 파동을 역학적 파동(mechanical wave)이라 한다(빛 같은 전자기파는 매질이 필요 없다, 29장). 매질의 각 부분은 평형 위치 근처에서 진동할 뿐 파동과 함께 멀리 가지 않는다. 파동이 진행하는 속력 \(v\)를 파동 속력(wave speed)이라 한다.

횡파와 종파

매질의 변위가 파동의 진행 방향에 수직이면 횡파(transverse wave), 나란하면 종파(longitudinal wave)다. 줄의 파동은 횡파, 용수철을 앞뒤로 밀고 당겨 만든 파동과 음파(16장)는 종파다. 물결파는 두 성분이 함께 있어 수면의 입자가 원(타원)을 그린다.

주기적 파동과 파동 함수

줄의 끝을 단순 조화 운동으로 계속 흔들면 줄의 모든 부분이 같은 진동수로 진동하는 주기적 파동(periodic wave)이 생긴다. 특히 사인 모양의 파동을 사인파(sinusoidal wave)라 한다.

$$v = f\lambda = \frac{\omega}{k}, \qquad k = \frac{2\pi}{\lambda}, \qquad \omega = 2\pi f = \frac{2\pi}{T}$$
\(k\): 파수(wave number)(rad/m), \(\omega\): 각진동수(rad/s). 파동 속력은 매질이 정하고(다음 절), 진동수는 파원이 정한다. 파장은 그 결과다.

파동을 수식으로 쓰려면 위치 \(x\)에 있는 매질 입자의 시각 \(t\)에서의 변위 \(y(x,t)\) — 파동 함수(wave function) — 가 필요하다. 모양이 바뀌지 않고 속력 \(v\)로 진행하는 파동은 간단한 성질을 가진다.

$$y(x,t) = A\cos(kx - \omega t) \quad(+x\text{ 방향}), \qquad y(x,t) = A\cos(kx + \omega t) \quad(-x\text{ 방향})$$
위상 \(kx - \omega t\)가 일정한 점(예: 마루)은 \(dx/dt = \omega/k = v\)로 움직인다. 매질 입자의 가로 속도와 가속도는 \(v_y = \partial y/\partial t = \omega A\sin(kx - \omega t)\), \(a_y = \partial^2y/\partial t^2 = -\omega^2 y\) — 각 입자는 단순 조화 운동을 한다.

심화: 파동 방정식

\(y = f(x - vt)\)를 두 번 미분하면 \(\partial^2y/\partial x^2 = f''\), \(\partial^2y/\partial t^2 = v^2f''\)이므로 모든 진행파는 파동 방정식(wave equation) $$\frac{\partial^2 y}{\partial x^2} = \frac{1}{v^2}\frac{\partial^2 y}{\partial t^2}$$을 만족한다. 이 방정식은 선형이므로 해 두 개의 합도 해다 — 중첩 원리의 수학적 근거다. 다음 절에서 줄에 뉴턴 제2법칙을 적용하면 이 방정식이 \(v^2 = F/\mu\)와 함께 나온다. 장 머리의 줄은 이 방정식을 유한 차분으로 직접 적분한 것이다.

줄의 파동 속력

팽팽한 기타 줄을 튕기면 파동은 매우 빠르게, 느슨하고 무거운 밧줄에서는 느리게 퍼진다. 줄을 원래 위치로 되돌리는 것은 장력 \(F\)이고, 그에 저항하는 관성은 단위 길이당 질량, 곧 선밀도(linear mass density) \(\mu = m/L\)이다.

$$v = \sqrt{\frac{F}{\mu}}$$
\(F\): 장력(N), \(\mu\): 선밀도(kg/m). 일반적으로 파동 속력 = \(\sqrt{\text{복원력 요소}/\text{관성 요소}}\)이다(음파는 16장에서 \(\sqrt{B/\rho}\)).

선밀도 10인 줄을 도르래에 걸고 질량 2.0인 추를 매달면 장력은 이고 파동 속력은 다. 펄스가 3.00 m를 가는 데 가 걸린다. 속력을 2배로 하려면 추를 으로 바꿔야 한다.

선밀도 15.0 g/m인 줄의 한쪽 끝을 벽에 묶고 다른 쪽을 도르래에 걸어 2.00 kg 추를 매달았다. 벽과 도르래 사이는 2.00 m이다. 파동 속력과, 펄스가 벽에서 도르래까지 가는 시간은?

파동의 에너지

파동은 물질은 나르지 않지만 에너지는 나른다. 줄의 왼쪽 끝을 흔드는 손은 줄에 일을 하고, 그 에너지가 줄을 따라 흘러간다. 위치 \(x\)에서 왼쪽 부분이 오른쪽 부분에 가하는 가로 방향 힘은 \(-F\,\partial y/\partial x\)이므로, 그 점을 지나는 순간 일률은

$$P(x,t) = -F\frac{\partial y}{\partial x}\frac{\partial y}{\partial t} = \sqrt{\mu F}\,\omega^2A^2\sin^2(kx - \omega t), \qquad P_\text{av} = \tfrac12\sqrt{\mu F}\,\omega^2A^2$$
사인파의 평균 일률은 진폭의 제곱과 진동수의 제곱에 비례한다. 이 결과는 13장 진동의 에너지 \(\tfrac12kA^2\)가 진폭의 제곱에 비례한 것과 같은 이유다.

심화: 세기와 역제곱 법칙

3차원으로 퍼지는 파동은 단위 넓이당 일률, 곧 세기(intensity) \(I\)(W/m²)로 기술한다. 점 파원이 모든 방향으로 고르게 일률 \(P\)를 내면 반지름 \(r\)인 구면을 같은 에너지가 지나므로 \(I = P/4\pi r^2\): 거리가 2배면 세기는 1/4이다. 에너지가 넓게 퍼질 뿐 사라지지 않는다.

중첩 원리

두 파동이 겹치면 각 점의 실제 변위는 각 파동이 따로 있을 때의 변위의 합이다: \(y(x,t) = y_1(x,t) + y_2(x,t)\) (중첩 원리(principle of superposition)). 겹친 뒤에도 각 파동은 원래 모양 그대로 지나간다.

경계에서의 반사

파동이 줄의 끝이나 다른 매질과의 경계에 닿으면 일부 또는 전부가 반사된다. 끝이 벽에 묶인 고정단(fixed end)에서는 줄이 벽을 위로 당기고, 벽은 반작용으로 줄을 아래로 당긴다. 그 결과 반사된 펄스는 뒤집힌다. 고리에 걸려 자유롭게 미끄러지는 자유단(free end)에서는 끝이 펄스 높이의 두 배까지 튀어 올랐다가 같은 쪽 펄스를 돌려보낸다.

사인파의 간섭

같은 방향으로 진행하는 진동수가 같은 두 사인파 \(y_1 = A\cos(kx - \omega t)\), \(y_2 = A\cos(kx - \omega t + \phi)\)를 더하면 삼각함수 합 공식으로

$$y = \left[2A\cos\frac{\phi}{2}\right]\cos\!\left(kx - \omega t + \frac{\phi}{2}\right)$$
합도 같은 진동수의 사인파이며 진폭은 위상차 \(\phi\)에 따라 0(\(\phi = \pi\))에서 \(2A\)(\(\phi = 0\))까지 변한다.

풀이 \(2A\cos(\phi/2) = 2(3.00)\cos30^\circ = 5.20\) mm. \(2A\cos(\phi/2) = A\) → \(\cos(\phi/2) = 1/2\) → \(\phi = 2\pi/3\) (120°).
5.20 mm; φ = 2π/3 = 120°
검토 위 미니 실험에서 φ = 60°와 120°로 확인하라. 위상차 120°에서는 두 파동을 더해도 하나와 같은 진폭이다.

정상파와 줄의 고유 진동

양 끝이 고정된 줄에 사인파를 보내면 끝에서 반사된 파동과 원래 파동이 반대 방향으로 진행하며 겹친다. 진폭이 같고 반대로 가는 두 사인파의 합은 더 이상 진행하지 않는 정상파(standing wave)가 된다.

$$y = y_1 + y_2 = -A\cos(kx + \omega t) + A\cos(kx - \omega t) = (2A\sin kx)\sin\omega t$$
\(x = 0\)의 고정단에서 뒤집혀 반사된 파동 \(y_1\)과 원래 파동 \(y_2\)의 합은 \(x = 0\)에서 늘 0이다. 위치마다 진폭 \(2A|\sin kx|\)가 다른 단순 조화 운동이다. 마디(node)는 \(x = 0, \lambda/2, \lambda, \ldots\), 배(antinode)는 \(x = \lambda/4, 3\lambda/4, \ldots\).

양 끝(\(x = 0, L\))이 모두 마디여야 하므로 줄의 길이는 반 파장의 정수배여야 한다: \(L = n\lambda/2\). 줄은 아무 진동수로나 정상파를 만들지 못하고, 다음 진동수에서만 크게 울린다.

$$\lambda_n = \frac{2L}{n}, \qquad f_n = n\frac{v}{2L} = \frac{n}{2L}\sqrt{\frac{F}{\mu}} \qquad (n = 1, 2, 3, \ldots)$$
\(f_1\): 기본 진동수(fundamental frequency). \(f_n = nf_1\)을 배음(harmonics)이라 하고, 이 진동 양식들을 줄의 정규 모드(normal modes)라 한다.

줄을 기본 진동수의 정확히 3배로 흔들면 줄은 어떤 모양으로 진동할까?

\(f_3 = 3f_1\)은 세 번째 정규 모드이므로 \(L = 3\lambda/2\): 배 3개. 아래 실험실에서 진동수를 훑어 공명을 찾아보라.

CHALLENGE

고유 진동수 맞히기

아래 눈금의 흰 점을 끌어 진동수를 정한다
문제—
결과—
점수—
무작위로 주어진 줄(길이·장력·선밀도)을 지정된 모드 n으로 울리는 진동수를 계산해 입력하거나 눈금에서 끈 뒤 ‘울려 보기’를 누른다. 오차 2% 이내면 줄이 그 모드로 크게 울리며 명중이다. 계산 순서: \(v = \sqrt{F/\mu}\) → \(f_n = nv/2L\).

핵심 정리

  1. 역학적 파동은 매질을 통해 교란과 에너지를 전달한다. 매질의 운동이 진행 방향에 수직이면 횡파, 나란하면 종파.
  2. 주기적 파동: \(v = f\lambda = \omega/k\), \(k = 2\pi/\lambda\), \(\omega = 2\pi f\). +x로 진행하는 사인파 \(y = A\cos(kx - \omega t)\); 일반적으로 \(y = f(x \mp vt)\)이며 파동 방정식 \(\partial^2y/\partial x^2 = (1/v^2)\partial^2y/\partial t^2\)을 만족한다.
  3. 줄의 파동 속력 \(v = \sqrt{F/\mu}\) — 매질(장력·선밀도)이 정하고, 진폭·진동수와 무관하다. 매질 입자의 최대 속력 \(\omega A\)와 혼동하지 않는다.
  4. 사인파의 평균 일률 \(P_\text{av} = \tfrac12\sqrt{\mu F}\,\omega^2A^2\) — 진폭과 진동수의 제곱에 비례한다. 점 파원의 세기는 \(1/r^2\)로 준다.
  5. 중첩 원리: 변위는 더해진다. 고정단에서 반사파는 뒤집히고 자유단에서는 그대로다. 임피던스가 큰(무거운) 줄과의 경계에서 반사파가 뒤집힌다. 같은 방향 두 사인파의 합성 진폭은 \(2A\cos(\phi/2)\).
  6. 양 끝 고정 줄의 정상파 \(y = (2A\sin kx)\sin\omega t\): \(L = n\lambda/2\), \(f_n = nv/2L = nf_1\). 마디 간격 \(\lambda/2\), 모드 n에는 배가 n개.

연습문제

특별한 말이 없으면 \(g = 9.80\) m/s²를 쓰고, 줄의 장력은 줄 전체에서 같다고 본다. 답이 ±1% 이내면 정답이다.

진동수 256 Hz인 소리굽쇠가 공기 중에 파장 1.34 m인 음파를 만든다. 음파의 속력은?

\(v = f\lambda = (256)(1.34) = 343\) m/s.

줄의 파동이 \(y = (0.0400\text{ m})\sin(5.00x - 20.0t)\)(SI 단위)로 주어진다. 파동의 속력은? 진행 방향은?

\(v = \omega/k = 20.0/5.00 = 4.00\) m/s, \(kx - \omega t\) 꼴이므로 +x 방향.

위 문제의 파동의 파장과 진동수는?

\(\lambda = 2\pi/k = 2\pi/5.00 = 1.26\) m, \(f = \omega/2\pi = 20.0/2\pi = 3.18\) Hz. 확인: \(f\lambda = 4.00\) m/s.

위 파동에서 줄 한 점의 최대 가로 속력과 최대 가로 가속도는?

\(\partial y/\partial t\)와 \(\partial^2y/\partial t^2\)의 진폭: \(\omega A\), \(\omega^2A\).

\(\omega A = (20.0)(0.0400) = 0.800\) m/s, \(\omega^2A = (400)(0.0400) = 16.0\) m/s².

장력 50.0 N, 선밀도 0.0200 kg/m인 줄에서 파동 속력은?

\(v = \sqrt{50.0/0.0200} = 50.0\) m/s.

길이 5.00 m, 질량 0.400 kg인 밧줄을 80.0 N으로 당겨 놓았다. 한쪽 끝에서 만든 펄스가 다른 끝까지 가는 시간은?

\(\mu = 0.400/5.00 = 0.0800\) kg/m, \(v = \sqrt{80.0/0.0800} = 31.6\) m/s, \(t = 5.00/31.6 = 0.158\) s.

장력 60.0 N에서 파동 속력이 30.0 m/s인 줄이 있다. 속력을 45.0 m/s로 높이려면 장력을 얼마로 해야 하는가?

\(F \propto v^2\) → \(F = 60.0\times(45.0/30.0)^2 = 135\) N.

선밀도 0.0300 kg/m, 장력 27.0 N인 줄에 진폭 5.00 mm, 진동수 60.0 Hz의 사인파를 보낸다. 평균 일률은?

\(\sqrt{\mu F} = 0.900\) kg/s, \(\omega = 377\) rad/s, \(P = \tfrac12(0.900)(377)^2(0.00500)^2 = 1.60\) W.

같은 줄에서 진폭을 2배로, 진동수를 절반으로 바꾸면 평균 일률은?

\(P \propto \omega^2A^2\) → \((1/2)^2\times2^2 = 1\). 그대로다.

양 끝이 고정된 길이 0.800 m인 줄에서 파동 속력이 240 m/s이다. 기본 진동수는?

\(f_1 = v/2L = 240/1.60 = 150\) Hz.

양 끝이 고정된 길이 1.20 m인 줄이 120 Hz에서 배가 4개인 정상파로 진동한다. 파동 속력과 파장은?

\(n = 4\) → \(\lambda = 2L/4 = 0.600\) m, \(v = f\lambda = 72.0\) m/s.

기타 줄(진동 길이 0.640 m, 선밀도 1.20 g/m)을 G3(196 Hz)에 맞추려면 장력이 얼마여야 하는가?

\(v = 2Lf_1 = 2(0.640)(196) = 251\) m/s, \(F = \mu v^2 = (1.20\times10^{-3})(250.9)^2 = 75.5\) N.

양 끝이 고정된 길이 0.900 m인 줄의 연속한 두 공명 진동수가 420 Hz와 525 Hz이다. 기본 진동수와 파동 속력은?

이웃한 배음의 차가 기본 진동수다: \(f_{n+1} - f_n = f_1\).

\(f_1 = 525 - 420 = 105\) Hz(420 Hz는 4번째, 525 Hz는 5번째 배음). \(v = 2Lf_1 = 2(0.900)(105) = 189\) m/s.

진폭이 각각 4.00 mm이고 진동수·파장이 같은 두 사인파가 같은 방향으로 진행하며 위상차가 90°이다. 합성파의 진폭은?

\(2A\cos(\phi/2) = 8.00\cos45^\circ = 5.66\) mm.

가벼운 줄이 무거운 줄에 이어져 있다. 가벼운 줄에서 위로 볼록한 펄스가 경계에 도착하면 반사된 펄스와 투과된 펄스는?

무거운 줄(임피던스가 큼)은 고정단처럼 작용해 반사파가 뒤집힌다(\(R < 0\)). 투과파는 항상 같은 쪽이다(\(T > 0\)). 반사 시뮬레이터에서 확인하라.

개념 확인 퀴즈

줄 끝을 흔드는 진동수를 2배로 하면(장력·선밀도는 그대로) 무엇이 바뀌는가?

속력은 매질이 정한다(\(\sqrt{F/\mu}\)). \(v = f\lambda\)가 일정하므로 파장이 절반.

횡파에서 줄의 한 점이 가장 빠르게 움직이는 순간은?

각 점은 단순 조화 운동을 하므로 평형 위치에서 가장 빠르고 마루·골에서 순간 정지한다.

두 펄스가 상쇄 간섭으로 줄이 순간적으로 완전히 평평해졌다. 그 순간 에너지는?

줄은 평평하지만(늘어남 없음 → 퍼텐셜 0) 겹친 부분이 빠르게 움직이고 있다. 그래서 다음 순간 두 펄스가 다시 나타난다.

기타 줄의 장력을 4배로 하면 기본 진동수는?

\(f_1 = \sqrt{F/\mu}/2L \propto \sqrt F\). 한 옥타브(2배) 올라간다.

양 끝이 고정된 줄의 세 번째 배음(n = 3)에서 양 끝을 뺀 마디의 수는?

마디는 양 끝 포함 n + 1 = 4개, 양 끝을 빼면 2개. 배는 3개다.
