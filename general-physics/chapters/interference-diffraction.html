Chapter 31

간섭과 회절

기하 광학은 빛이 곧게 간다고 보았다. 그러나 틈이나 장애물이 파장에 견줄 만큼 작아지면 빛은 그림자 속으로 휘어 들어가고(회절), 두 갈래로 나뉜 빛이 다시 만나면 밝고 어두운 무늬를 만든다(간섭). 1801년 토머스 영의 이중 슬릿 실험은 빛이 파동이라는 결정적 증거였다. 이 장에서는 비눗방울의 무지갯빛, 안경의 반사 방지막, CD의 무늬, 분광기, 그리고 망원경이 볼 수 있는 한계를 모두 "경로차"라는 한 가지 생각으로 설명한다.

두 파원(흰 원)을 끌어 보세요 · 어두운 줄 = 상쇄 간섭
  • 결맞음을 설명하고 경로차·위상차로 보강·상쇄 간섭의 조건을 쓴다.
  • 이중 슬릿의 밝은 무늬 조건 \(d\sin\theta = m\lambda\)와 무늬 간격 \(\Delta y = \lambda L/d\)를 계산한다.
  • 반사할 때의 위상 반전을 고려해 박막 간섭을 분석한다.
  • 단일 슬릿 회절의 어두운 무늬 \(a\sin\theta = m\lambda\)를 유도하고 적용한다.
  • 회절 격자로 파장을 재고, 원형 구멍의 레일리 분해능 \(\theta_R = 1.22\lambda/D\)를 계산한다.

결맞음과 경로차

두 파동이 한 점에서 만나면 변위가 더해진다(중첩, 15장). 두 파동이 마루와 마루로 만나면 진폭이 커지는 보강 간섭(constructive interference), 마루와 골로 만나면 지워지는 상쇄 간섭(destructive interference)이다. 같은 위상으로 출발한 두 파동은 지나온 길이의 차, 곧 경로차가 위상차를 결정한다.

$$\phi = 2\pi\frac{\Delta r}{\lambda}, \qquad \text{보강: } \Delta r = m\lambda, \qquad \text{상쇄: } \Delta r = \big(m + \tfrac12\big)\lambda, \qquad I = 4I_1\cos^2\frac\phi2$$
\(m = 0, \pm1, \pm2, \dots\). 세기 \(I_1\)인 두 파동이 보강되면 \(4I_1\)(진폭 2배), 상쇄되면 0. 평균은 \(2I_1\) — 에너지는 사라지지 않고 다시 배치될 뿐이다.

무늬가 보이려면 두 파동의 위상차가 시간에 따라 변하지 않아야 한다 — 결맞음(coherence). 전구 두 개는 원자들이 제멋대로 빛을 내 위상차가 10⁻⁸ s 남짓마다 바뀌므로 무늬가 평균되어 사라진다. 그래서 간섭 실험은 한 광원의 빛을 둘로 나누어(슬릿, 반투명 거울, 박막의 두 면) 만나게 하거나, 위상이 고른 레이저를 쓴다.

영의 이중 슬릿

한 광원의 빛이 간격 \(d\)인 두 슬릿을 지나 멀리(\(L \gg d\)) 있는 스크린에 닿는다. 각 \(\theta\) 방향으로 가는 두 광선은 거의 나란하고, 경로차는 \(d\sin\theta\)다.

$$\text{밝은 무늬: } d\sin\theta = m\lambda, \qquad \text{어두운 무늬: } d\sin\theta = \big(m + \tfrac12\big)\lambda, \qquad y_m \approx \frac{m\lambda L}d,\quad \Delta y = \frac{\lambda L}d$$
작은 각 근사(\(\sin\theta \approx \tan\theta \approx \theta\)). 무늬 간격은 파장에 비례하고 슬릿 간격에 반비례한다 — 눈에 보이는 무늬로 0.5 μm의 파장을 잴 수 있다.

파장 633의 빛을 간격 0.25인 이중 슬릿에 비추고 1.5 떨어진 스크린에서 보면 무늬 간격은 , 첫째 밝은 무늬의 각은 이다.

두 슬릿 사이의 간격 \(d\)를 두 배로 넓히면 스크린의 무늬는?

\(\Delta y = \lambda L/d\). 슬릿이 멀어지면 같은 각에서 경로차가 더 빨리 커져, 무늬가 촘촘해진다.

박막 간섭

비눗막이나 물 위의 기름막은 두께가 빛의 파장 정도라, 윗면과 아랫면에서 반사된 두 빛이 간섭한다. 아랫면에서 반사된 빛은 막 속을 왕복한 \(2t\)만큼 더 가고, 막 속에서는 파장이 \(\lambda/n\)이다. 여기에 한 가지가 더 있다: 반사할 때 위상이 뒤집히기도 한다.

$$\text{반전 1번: } 2nt = \big(m + \tfrac12\big)\lambda\ (\text{밝음}),\quad 2nt = m\lambda\ (\text{어두움}); \qquad \text{반전 0 또는 2번: 조건이 서로 바뀐다}$$
\(\lambda\)는 진공(공기) 속 파장. 두께가 위치마다 다르면 색마다 보강되는 곳이 달라 무지갯빛 띠가 생긴다.

세워 둔 비눗막은 물이 아래로 흘러내려 위쪽이 점점 얇아진다. 터지기 직전 가장 얇은 맨 위는 어떻게 보일까?

두께가 0에 가까우면 경로차는 0이지만 반사의 위상 반전이 한 번 있어 두 반사광이 상쇄된다 — 모든 색이 다 지워진다.

단일 슬릿 회절

슬릿 하나만 있어도 무늬가 생긴다. 하위헌스 원리에 따르면 슬릿 안의 모든 점이 새 파원이고, 그 파들이 서로 간섭한다. 가운데는 모든 파가 같은 위상으로 만나 가장 밝고, 어떤 각에서는 완전히 지워진다.

$$\text{어두운 무늬: } a\sin\theta = m\lambda\ (m = \pm1, \pm2, \dots), \qquad \text{가운데 밝은 무늬의 폭} \approx \frac{2\lambda L}{a}, \qquad I = I_0\Big(\frac{\sin\beta}{\beta}\Big)^2,\ \beta = \frac{\pi a\sin\theta}{\lambda}$$
슬릿이 좁을수록 빛이 넓게 퍼진다. \(a \gg \lambda\)이면 퍼짐이 사라지고 기하 광학으로 돌아간다.

폭 0.10 mm인 슬릿에 600 nm 빛을 비춘다. 2.0 m 떨어진 스크린의 가운데 밝은 무늬 폭은?

풀이 보기
풀이 첫째 어두운 무늬 \(y_1 = \lambda L/a = 12\) mm, 폭 \(2y_1 = 24\) mm.
약 24 mm
검토 이중 슬릿 무늬 간격의 식 \(\lambda L/d\)와 꼴이 같다 — 실제 이중 슬릿 무늬는 단일 슬릿 무늬(포락선) 안에 들어 있다.

회절 격자와 분해능

슬릿을 두 개에서 \(N\)개로 늘리면 밝은 무늬의 위치(\(d\sin\theta = m\lambda\))는 그대로지만 무늬가 훨씬 가늘고 밝아진다. 모든 슬릿의 빛이 정확히 같은 위상일 때만 보강되기 때문이다. 1 mm에 수백 줄을 새긴 회절 격자(diffraction grating)는 색마다 아주 다른 각으로 빛을 보내 파장을 정밀하게 잰다.

$$d\sin\theta = m\lambda, \qquad d = \frac{1}{\text{단위 길이당 줄 수}}, \qquad m_\text{max} < \frac d\lambda$$
CD의 트랙 간격은 1.6 μm로 반사형 회절 격자다. 무지갯빛이 도는 이유.

원형 구멍과 레일리 분해능

망원경이나 눈의 동공 같은 원형 구멍(지름 \(D\))도 빛을 회절시킨다. 점 광원의 상은 점이 아니라 가운데 밝은 원반(에어리 원반)과 흐린 고리들이다. 두 점 광원의 원반이 너무 겹치면 하나로 보인다. 한쪽 원반의 중심이 다른 쪽의 첫째 어두운 고리에 오는 각을 구별의 한계로 삼는다 — 레일리 기준(Rayleigh criterion).

$$\theta_R = 1.22\,\frac{\lambda}{D}$$
1.22는 원형 구멍의 계산에서 나오는 수(긴 슬릿이면 1). 구멍이 크고 파장이 짧을수록 더 가까운 두 점을 구별한다 — 큰 망원경, 짧은 파장의 전자 현미경.

핵심 정리

  1. 결맞은 두 파동의 경로차 \(\Delta r\): \(m\lambda\)이면 보강, \((m + \tfrac12)\lambda\)이면 상쇄. 세기 \(I = 4I_1\cos^2(\phi/2)\).
  2. 이중 슬릿: 밝은 무늬 \(d\sin\theta = m\lambda\), 무늬 간격 \(\Delta y = \lambda L/d\).
  3. 박막: 왕복 광학 경로 \(2nt\)와 반사의 위상 반전(작은 n → 큰 n)을 함께 센다. 반전 1번이면 \(2nt = (m + \tfrac12)\lambda\)가 밝음.
  4. 단일 슬릿: 어두운 무늬 \(a\sin\theta = m\lambda\), 가운데 무늬 폭 \(2\lambda L/a\). 좁을수록 넓게 퍼진다.
  5. 회절 격자: \(d\sin\theta = m\lambda\), 슬릿이 많을수록 선이 가늘고 밝다 → 분광.
  6. 원형 구멍의 분해능: \(\theta_R = 1.22\lambda/D\) (레일리 기준).

연습문제

답이 ±1% 이내면 정답이다.

\(\lambda L/d = 5.0\) mm.

간격 0.050 mm인 이중 슬릿에 600 nm 빛을 비출 때 셋째(m = 3) 밝은 무늬의 각은?

\(\sin\theta = 3(600\times10^{-9})/(5.0\times10^{-5}) = 0.036\) → 2.06°.

간격 0.40 mm인 이중 슬릿, 파장 480 nm, 스크린 거리 1.2 m. 가운데에서 첫째 어두운 무늬까지의 거리는?

\(y = \tfrac12\lambda L/d = 0.72\) mm.

물(n = 1.33) 위에 두께 280 nm의 기름막(n = 1.45)이 떠 있다. 위에서 볼 때 가장 강하게 반사되는 가시광의 파장은?

공기→기름은 반전, 기름→물(큰 n → 작은 n)은 반전 없음: 반전 1번. \(2nt = (m + \tfrac12)\lambda\) → \(\lambda = 812/(m + \tfrac12)\) nm = 1624, 541, 325, … 가시광은 541 nm.

유리 위 MgF₂(n = 1.38) 막으로 500 nm의 반사를 없애려면 최소 두께는?

반전 2번 → \(2nt = \lambda/2\), \(t = \lambda/4n = 90.6\) nm.

공기 속 비눗막(n = 1.33)이 600 nm 빛을 가장 강하게 반사한다. 가능한 최소 두께는?

\(t = \lambda/4n = 113\) nm.

폭 0.050 mm인 슬릿에 550 nm 빛을 비출 때 첫째 어두운 무늬의 각은?

\(\sin\theta = \lambda/a = 0.011\) → 0.630°.

폭 0.20 mm인 슬릿에 633 nm 레이저를 비춘다. 1.5 m 떨어진 스크린의 가운데 밝은 무늬 폭은?

\(2\lambda L/a = 9.50\) mm.

1 mm에 500줄인 격자에서 450 nm 빛의 2차 밝은 선의 각은?

\(d = 2.0\) μm, \(\sin\theta = 2(0.45)/2.0 = 0.45\) → 26.7°.

1 mm에 1200줄인 격자에 650 nm 빛을 비추면 몇 차까지 볼 수 있는가?

\(d/\lambda = 833/650 = 1.28\) → 1차까지.

1 mm에 300줄인 격자에서 어떤 빛의 1차 선이 10.0°에 나타났다. 파장은?

\(\lambda = d\sin\theta = (3.333\ \mu\text{m})(0.1736) = 579\) nm (수은의 노란 선).

구경 10 cm인 망원경의 550 nm에서의 분해능은?

\(1.22\lambda/D = 6.71\times10^{-6}\) rad (1.4″).

자동차 전조등 두 개가 1.4 m 떨어져 있다. 동공 지름 5.0 mm, 파장 550 nm라면 얼마나 먼 곳에서부터 두 개로 구별할 수 없는가?

\(\theta_R = 1.342\times10^{-4}\) rad, 거리 \(= 1.4/\theta_R = 10.4\) km.

손전등 두 개로 한 벽을 비추면 간섭 무늬가 보이지 않는 이유는?

독립된 두 광원은 결맞지 않는다.

이중 슬릿 장치 전체를 물(n = 1.33) 속에 넣으면 무늬 간격은?

물속 파장이 \(\lambda/n\)이므로 \(\Delta y = (\lambda/n)L/d\).

개념 확인 퀴즈

이중 슬릿 무늬에서 빨간빛과 파란빛 중 무늬 간격이 넓은 것은?

\(\Delta y \propto \lambda\). 흰빛을 쓰면 가운데는 흰색이고 바깥 무늬는 안쪽이 파랗고 바깥이 붉은 색 띠가 된다.

상쇄 간섭이 일어난 곳의 에너지는?

무늬 전체의 평균 세기는 두 세기의 합과 같다.

단일 슬릿의 폭을 줄이면 가운데 밝은 무늬는?

\(\sin\theta_1 = \lambda/a\).

회절 격자의 줄 수(같은 간격)를 늘리면?

위치는 \(d\)와 \(\lambda\)로만 정해진다. 선폭 ∝ 1/N.

망원경의 분해능을 높이는 방법은?

\(\theta_R = 1.22\lambda/D\). 배율만 높이면 흐린 원반이 커질 뿐이다.
