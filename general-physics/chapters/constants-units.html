SI 단위와 접두사

기본 단위

  • 길이 m, 질량 kg, 시간 s
  • 전류 A, 온도 K, 물질량 mol, 광도 cd

유도 단위

  • N = kg·m/s², J = N·m, W = J/s, Pa = N/m²
  • C = A·s, V = J/C, Ω = V/A, F = C/V
  • T = N/(A·m), Wb = T·m², H = Wb/A, Hz = s⁻¹
