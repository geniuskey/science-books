Chapter 03

평면 운동

던진 공, 커브를 도는 자동차, 강을 건너는 배 — 운동이 직선을 벗어나면 위치·속도·가속도가 모두 벡터가 된다. 이 장의 핵심 아이디어는 하나다. 평면 운동은 서로 독립인 두 개의 직선 운동이다. 아래 화면을 눌러 공을 던져 보면서 시작하자.

화면을 누르면 그 방향으로 공을 던진다
  • 위치·변위·속도·가속도를 벡터로 쓰고, 속도가 궤적의 접선 방향임을 설명한다.
  • 포물선 운동을 수평 등속 운동과 수직 등가속도 운동으로 분해해 비행 시간·최고점·사거리를 구한다.
  • 같은 속력에서 사거리가 최대가 되는 각도와, 같은 사거리를 주는 두 각도를 설명한다.
  • 등속 원운동의 구심 가속도 \(a = v^2/r\)을 유도하고, 비등속 원운동에서 접선·법선 성분을 구별한다.
  • 상대 속도 \(\vec v_{A/C} = \vec v_{A/B} + \vec v_{B/C}\)로 강 건너기·바람 속 비행 문제를 푼다.

위치, 속도, 가속도 벡터

평면 위의 점은 원점에서 그 점까지의 위치 벡터(position vector) \(\vec r = x\hat\imath + y\hat\jmath\)로 나타낸다. 시간 \(\Delta t\) 동안 점이 \(\vec r_1\)에서 \(\vec r_2\)로 움직이면 변위(displacement)는 \(\Delta\vec r = \vec r_2 - \vec r_1\)이고, 평균 속도는 \(\vec v_\text{av} = \Delta\vec r/\Delta t\)이다. \(\Delta t\)를 0으로 보내면 순간 속도가 된다.

$$\vec v = \lim_{\Delta t\to0}\frac{\Delta\vec r}{\Delta t} = \frac{d\vec r}{dt} = \frac{dx}{dt}\hat\imath + \frac{dy}{dt}\hat\jmath, \qquad \vec a = \frac{d\vec v}{dt}$$
성분마다 따로 미분한다. 이것이 "평면 운동 = 두 직선 운동"의 수학적 근거다.

가속도 벡터는 속도 벡터가 얼마나 빨리, 어느 쪽으로 바뀌는지를 말한다. 속도의 크기(속력)가 일정해도 방향이 바뀌면 가속도가 있다. 가속도를 궤적의 접선 방향 성분 \(a_\parallel\)과 법선(곡률 중심) 방향 성분 \(a_\perp\)으로 나누면 의미가 분명해진다.

\(a_\parallel\) — 접선 성분

속력을 바꾼다. 속도와 같은 방향이면 빨라지고, 반대면 느려진다.

\(a_\perp\) — 법선 성분

방향을 바꾼다. 항상 곡선의 안쪽(휘어지는 쪽)을 향한다.

드론이 \(t = 1.0\) s에 \(\vec r_1 = (2.0\hat\imath + 1.0\hat\jmath)\) m, \(t = 3.0\) s에 \(\vec r_2 = (8.0\hat\imath + 5.0\hat\jmath)\) m에 있었다. 평균 속도의 성분, 크기, 방향을 구하라.

전략 성분별로 \(\Delta x/\Delta t\), \(\Delta y/\Delta t\)를 구한 뒤 피타고라스와 arctan.
풀이 \(\vec v_\text{av} = \dfrac{(6.0, 4.0)\,\text{m}}{2.0\,\text{s}} = (3.0, 2.0)\) m/s, \(|\vec v_\text{av}| = \sqrt{3.0^2+2.0^2} = 3.6\) m/s, \(\theta = \arctan(2.0/3.0) = 33.7^\circ\) (+x축에서).

포물선 운동

공기 저항을 무시하면 던진 물체에 작용하는 가속도는 \(\vec a = -g\hat\jmath\) 하나뿐이다(\(g = 9.80\) m/s²). 수평 방향에는 가속도가 없으므로 \(v_x\)는 끝까지 그대로이고, 수직 방향은 2장의 자유 낙하와 똑같다. 이 둘은 서로를 전혀 모른다.

같은 높이에서 공 A는 그냥 놓고, 공 B는 수평으로 세게 던졌다. 어느 공이 먼저 바닥에 닿을까?

수직 운동은 수평 속도와 무관하다. 두 공은 언제나 같은 높이에 있다 — 아래 실험에서 섬광 사진의 점들을 가로로 비교해 보라.

운동 방정식과 세 가지 핵심 양

원점에서 속력 \(v_0\), 각도 \(\theta_0\)로 던지면 초기 속도 성분은 \(v_{0x} = v_0\cos\theta_0\), \(v_{0y} = v_0\sin\theta_0\)이다.

$$x = (v_0\cos\theta_0)\,t, \qquad y = (v_0\sin\theta_0)\,t - \tfrac12 g t^2, \qquad v_y = v_0\sin\theta_0 - g t$$
\(t\)를 소거하면 \(y = x\tan\theta_0 - \dfrac{g}{2v_0^2\cos^2\theta_0}x^2\) — 아래로 열린 포물선이다.

지면에서 던져 같은 높이에 떨어질 때, 비행 시간·최고점·사거리는 다음과 같다(\(v_y = 0\)인 순간이 최고점, \(y = 0\)으로 돌아오는 순간이 착지).

$$T = \frac{2v_0\sin\theta_0}{g}, \qquad H = \frac{v_0^2\sin^2\theta_0}{2g}, \qquad R = \frac{v_0^2\sin 2\theta_0}{g}$$

속력 20, 각도 30로 9.8인 곳에서 던지면, 공은 동안 날아 최고 까지 올라갔다가 떨어진 곳에 떨어진다.

\(\sin 2\theta_0\)는 \(\theta_0 = 45^\circ\)에서 최대이므로 같은 속력이면 45°가 가장 멀리 간다. 또 \(\sin 2\theta = \sin(180^\circ - 2\theta)\)이므로 \(\theta\)와 \(90^\circ - \theta\)는 같은 사거리를 준다 — 위 문단에서 각도를 30°와 60°로 바꿔 확인해 보라. 높이 쏜 쪽이 더 오래 날 뿐이다.

원숭이와 사냥꾼

나무에 매달린 원숭이를 정확히 겨냥해 총을 쏘는 순간, 원숭이가 손을 놓고 떨어진다. 총알은 맞을까? 중력이 없다면 총알은 겨냥선을 따라 원숭이에게 간다. 중력이 있으면 총알과 원숭이가 똑같이 \(\tfrac12gt^2\)만큼 겨냥선 아래로 떨어진다. 따라서 (총알이 바닥에 닿기 전에 도달하기만 하면) 반드시 맞는다.

원운동

반지름 \(r\)인 원을 일정한 속력 \(v\)로 도는 운동을 등속 원운동(uniform circular motion)이라 한다. 속력은 일정하지만 속도의 방향은 끊임없이 바뀌므로 가속도가 있다. 시간 \(\Delta t\) 동안 속도가 각 \(\Delta\theta\)만큼 돌아가면 \(|\Delta\vec v| \approx v\,\Delta\theta\)이고, \(\Delta\theta = v\Delta t/r\)이므로

$$a_\text{rad} = \frac{v^2}{r} = \frac{4\pi^2 r}{T^2} = \omega^2 r \qquad (\text{방향: 원의 중심})$$
\(T\): 주기(한 바퀴 시간), \(\omega = 2\pi/T\): 각속도. 중심을 향하므로 구심 가속도(centripetal acceleration)라 부른다.

상대 속도

속도는 누가 재느냐에 따라 다르다. 강물 위의 배, 바람 속의 비행기, 달리는 기차 안에서 걷는 사람 — 관찰자(기준틀)마다 속도가 다르다. 물체 A의 B에 대한 속도를 \(\vec v_{A/B}\)라 쓰면

$$\vec v_{A/C} = \vec v_{A/B} + \vec v_{B/C}, \qquad \vec v_{A/B} = -\vec v_{B/A}$$
아래첨자의 안쪽 글자 B가 "상쇄"되는 꼴이다. 벡터로 더해야 한다는 점에 주의(크기끼리 더하면 안 된다).

강물이 오른쪽으로 흐른다. 배가 뱃머리를 정확히 맞은편(위쪽)으로 향하고 전속력으로 가면, 배는 어디에 도착할까?

땅에 대한 배의 속도는 (물에 대한 배의 속도) + (물의 속도)다. 물살이 배를 하류로 밀어 대각선으로 건넌다. 건너는 시간은 물살과 무관하다!

핵심 정리

  1. 속도 \(\vec v = d\vec r/dt\)는 궤적의 접선 방향이다. 가속도의 접선 성분은 속력을, 법선 성분은 방향을 바꾼다.
  2. 포물선 운동은 수평 등속(\(a_x = 0\))과 수직 자유 낙하(\(a_y = -g\))의 합이며, 두 운동은 독립이다.
  3. 같은 높이로 돌아올 때 \(T = 2v_0\sin\theta_0/g\), \(H = v_0^2\sin^2\theta_0/2g\), \(R = v_0^2\sin2\theta_0/g\). 최대 사거리는 45°, \(\theta\)와 \(90^\circ-\theta\)는 같은 사거리.
  4. 등속 원운동의 가속도는 중심을 향하고 크기는 \(v^2/r = \omega^2 r = 4\pi^2r/T^2\)이다.
  5. 비등속 원운동에서는 \(a_\parallel = dv/dt\)(접선)와 \(a_\text{rad} = v^2/r\)(중심)이 함께 있다.
  6. 상대 속도는 벡터 덧셈: \(\vec v_{A/C} = \vec v_{A/B} + \vec v_{B/C}\). 강을 건너는 시간은 강을 가로지르는 성분만으로 정해진다.

연습문제

특별한 말이 없으면 \(g = 9.80\) m/s²를 쓰고 공기 저항은 무시한다. 답이 ±1% 이내면 정답이다.

입자가 (3.0 m, −2.0 m)에서 (−1.0 m, 4.0 m)로 움직였다. 변위의 크기는?

성분별로 미분: \(a_x = 2\), \(a_y = 6t\).

\(\vec a = (2, 6t) = (2, 12)\) m/s² → \(|\vec a| = \sqrt{4+144} = 12.2\) m/s².

공을 지면에서 15.0 m/s, 40.0°로 던졌다. 같은 높이에 떨어질 때까지 수평 거리는?

\(R = v_0^2\sin2\theta/g = (225)\sin80^\circ/9.80 = 22.6\) m.

위 문제의 공이 올라가는 최고 높이는?

\(H = v_0^2\sin^2\theta/2g = 225(0.6428)^2/19.6 = 4.74\) m.

높이 1.80 m에서 공을 수평으로 10.0 m/s로 던졌다. 공이 바닥에 닿는 곳까지의 수평 거리는?

\(t = \sqrt{2(1.80)/9.80} = 0.606\) s, \(x = 10.0\times0.606 = 6.06\) m.

20.0 m/s로 던져 같은 높이의 30.0 m 떨어진 과녁을 맞히려 한다. 가능한 두 발사각을 작은 것부터 구하라.

\(\sin2\theta = Rg/v_0^2\). 두 해는 \(90^\circ\)에 대해 대칭이다.

\(\sin2\theta = (30.0)(9.80)/400 = 0.735\) → \(2\theta = 47.3^\circ\) 또는 \(132.7^\circ\) → \(\theta = 23.7^\circ, 66.3^\circ\). 발사대 시뮬레이터로 확인해 보라.

높이 30.0 m 건물 옥상에서 공을 25.0 m/s, 수평 위 35.0°로 던졌다. 땅에 닿을 때까지 시간과 수평 거리는?

\(y = h + v_{0y}t - \tfrac12gt^2 = 0\)을 근의 공식으로 푼다(양의 근).

\(v_{0y} = 14.34\) m/s. \(4.90t^2 - 14.34t - 30.0 = 0\) → \(t = 4.34\) s. \(x = (25.0\cos35^\circ)(4.34) = 20.48\times4.34 = 88.8\) m.

적도 위의 사람은 지구 자전으로 반지름 \(6.37\times10^6\) m의 원을 24.0 h에 한 바퀴 돈다. 구심 가속도는?

\(a = 4\pi^2R/T^2 = 4\pi^2(6.37\times10^6)/(86400)^2 = 0.0337\) m/s² (g의 0.34%).

원심 분리기가 반지름 0.100 m에서 3000 rpm으로 돈다. 시료의 구심 가속도는 g의 몇 배인가?

\(\omega = 3000\times2\pi/60 = 314\) rad/s, \(a = \omega^2r = 9.87\times10^3\) m/s² \(= 1007g\).

비행기가 공기에 대해 북쪽으로 200 km/h로 난다. 동쪽으로 50.0 km/h의 바람이 분다. 땅에 대한 속력과 방향(북쪽에서 동쪽으로 잰 각)은?

\(\vec v = (50.0, 200)\) km/h → \(|\vec v| = 206\) km/h, \(\arctan(50/200) = 14.0^\circ\).

비가 8.0 m/s로 수직으로 내린다. 12 m/s로 달리는 차의 옆 창문에 보이는 빗줄기는 수직에서 몇 도 기울어 있는가?

\(\tan\alpha = 12/8.0\) → \(\alpha = 56.3^\circ\). 미니 실험에서 확인하라.

공기 저항이 없을 때, 포물선 운동의 최고점에서 공의 가속도는?

가속도는 비행 내내 \(-g\hat\jmath\)이다. 최고점에서 0이 되는 것은 속도의 수직 성분뿐이다.

등속 원운동에 대해 옳은 것은?

속도의 방향이 계속 바뀌므로 가속도가 있고, 그 방향은 중심이다(호도그래프 시뮬레이터).

개념 확인 퀴즈

같은 속력으로 30°와 60°로 던진 두 공(같은 높이로 착지)에 대해 옳은 것은?

\(\sin60^\circ = \sin120^\circ\)이므로 사거리는 같다. 비행 시간은 \(\sin\theta\)에 비례해 60° 쪽이 \(\sqrt3\)배 길다.

원운동하는 물체의 속력을 2배로, 반지름을 2배로 하면 구심 가속도는?

\(a = v^2/r\) → \(4/2 = 2\)배.

수평으로 날아가는 비행기에서 짐을 떨어뜨렸다. 공기 저항이 없다면 비행기 조종사가 보는 짐의 궤적은?

짐의 수평 속도는 비행기와 같으므로 비행기 기준으로 수평 속도는 0이다. 땅에서 보면 포물선이다.

물살보다 빠른 배가 가장 빨리 강을 건너려면 뱃머리를 어디로 향해야 하는가?

건너는 시간은 가로 성분 \(v_\text{배}\cos\phi\)로만 정해지므로 \(\phi = 0\)이 가장 빠르다(대신 하류로 밀린다).
