Chapter 14

화학 평형

밀폐된 플라스크 속 갈색 NO₂ 기체는 시간이 지나도 색이 일정해진다. 반응이 멈춘 것처럼 보이지만, 분자 수준에서는 NO₂가 N₂O₄로 합쳐지고 N₂O₄가 다시 쪼개지는 일이 같은 속도로 끝없이 일어나고 있다. 이 장에서는 그 동적 평형을 하나의 숫자, 평형 상수로 나타내고, 평형 농도를 계산하며, 조건을 바꾸었을 때 평형이 어느 쪽으로 이동하는지 예측한다.

  • 동적 평형을 정반응·역반응 속도가 같아진 상태로 설명하고, K = kf/kr를 이해한다.
  • 질량 작용 법칙으로 Kc·Kp 식을 쓰고, Kp = Kc(RT)Δn으로 환산한다.
  • K의 크기를 해석하고, 반응식을 뒤집거나 곱하거나 더할 때 K가 어떻게 바뀌는지, 불균일 평형에서 무엇을 빼는지 안다.
  • 반응 지수 Q를 K와 비교해 반응이 진행할 방향을 판단한다.
  • ICE 표를 세우고 근의 공식이나 근사(5% 규칙)로 평형 농도를 구한다.
  • 르샤틀리에 원리로 농도·압력·부피·온도·촉매의 효과를 예측하고, 반트호프 식으로 K(T)를 계산한다.

동적 평형

13장의 반응들은 대개 한 방향으로만 진행한다고 보았다. 그러나 실제로 모든 반응은 원리적으로 거꾸로도 일어난다. 무색의 N₂O₄를 밀폐 용기에 넣으면 일부가 갈색 NO₂로 쪼개진다.

$$\ce{N2O4(g) <=> 2NO2(g)}$$

처음에는 N₂O₄만 있으므로 정반응만 일어난다. NO₂가 쌓이면 NO₂끼리 부딪혀 N₂O₄로 돌아가는 역반응이 빨라지고, 정반응은 N₂O₄가 줄면서 느려진다. 결국 두 속도가 같아지면 각 물질의 농도가 더 이상 변하지 않는다. 이 상태를 화학 평형(chemical equilibrium)이라 한다. 반응은 멈춘 것이 아니라 양쪽으로 같은 속도로 계속 일어나므로 동적 평형이다.

평형에서 정반응 속도 = 역반응 속도이다. 두 방향이 모두 단일 단계라면 \(k_f[\ce{N2O4}] = k_r[\ce{NO2}]^2\)이고, 정리하면

$$\frac{[\ce{NO2}]^2}{[\ce{N2O4}]} = \frac{k_f}{k_r} = \text{일정} = K$$
속도 상수의 비는 온도만의 함수이므로, 평형 농도들의 이 조합은 처음에 무엇을 얼마나 넣었는지와 무관하게 일정하다.

평형 상수와 질량 작용 법칙

1864년 굴드베르그와 보게는 여러 실험에서, 평형 농도를 계수만큼 거듭제곱해 생성물/반응물로 나눈 값이 일정하다는 것을 발견했다. 이것을 질량 작용 법칙(law of mass action)이라 한다.

평형 상수 Kc $$\ce{aA + bB <=> cC + dD}:\qquad K_c = \frac{[\ce{C}]^c[\ce{D}]^d}{[\ce{A}]^a[\ce{B}]^b}$$

[ ]는 평형에서의 몰농도. 지수는 균형 맞춘 반응식의 계수다(속도 법칙과 달리 실험으로 정할 필요가 없다). \(K_c\)는 온도에만 의존한다.

K에는 단위가 없다

엄밀하게 K는 각 농도를 표준 농도 1 M(기체는 표준 압력)로 나눈 "활동도"로 정의되어 단위가 없다. 그래서 이 책에서도 K에 단위를 붙이지 않는다. 다만 수치는 농도(M)나 압력(atm)을 그대로 넣은 값과 같다.

어떤 온도에서 \(\ce{N2(g) + 3H2(g) <=> 2NH3(g)}\)의 평형 혼합물을 분석했더니 [N₂] = 0.921 M, [H₂] = 0.763 M, [NH₃] = 0.157 M였다. \(K_c\)는?

풀이 보기
전략 질량 작용 식을 쓰고 평형 농도를 그대로 대입한다. 계수가 지수가 된다.
풀이 $$K_c = \frac{[\ce{NH3}]^2}{[\ce{N2}][\ce{H2}]^3} = \frac{(0.157)^2}{(0.921)(0.763)^3} = \frac{0.02465}{0.4091} = 0.0603$$
Kc ≈ 0.0603
검토 \([\ce{H2}]^3\)을 빠뜨리기 쉽다. \(K_c\) < 1이지만 1에서 크게 멀지 않으므로 반응물과 생성물이 둘 다 상당량 있는 평형이다.

기체 반응의 Kp

기체의 농도는 분압에 비례하므로(\([\ce{A}] = n/V = P_\ce{A}/RT\)) 분압으로 평형 상수를 쓸 수도 있다.

$$K_p = \frac{P_\ce{C}^{\,c}P_\ce{D}^{\,d}}{P_\ce{A}^{\,a}P_\ce{B}^{\,b}}, \qquad K_p = K_c(RT)^{\Delta n}$$
\(\Delta n\) = (기체 생성물 계수 합) − (기체 반응물 계수 합). 압력을 atm으로 쓸 때 \(R = 0.08206\) L·atm/(mol·K). \(\Delta n = 0\)이면 \(K_p = K_c\).

500 °C에서 \(\ce{N2(g) + 3H2(g) <=> 2NH3(g)}\)의 \(K_p = 1.45\times10^{-5}\)이다(압력 atm). 같은 온도의 \(K_c\)는?

풀이 보기
전략 \(\Delta n = 2 - (1+3) = -2\). \(K_c = K_p(RT)^{-\Delta n} = K_p(RT)^2\).
풀이 \(RT = (0.08206)(773.15) = 63.44\). $$K_c = (1.45\times10^{-5})(63.44)^2 = 0.0584$$
Kc ≈ 0.0584
검토 기체 몰수가 줄어드는 반응(\(\Delta n < 0\))에서는 \(K_c > K_p\)이다. \(RT\)가 1보다 크면 \((RT)^{\Delta n}\)이 1보다 작기 때문이다.

K의 크기, 반응식 조작, 불균일 평형

K의 크기가 말해 주는 것

K는 분자에 생성물, 분모에 반응물이 있으므로 그 크기로 평형의 위치를 바로 읽을 수 있다.

K는 속도를 말하지 않는다

H₂와 O₂의 혼합물은 K가 엄청나게 크지만 불꽃이 없으면 몇 년이 지나도 반응하지 않는다. K는 평형이 어디에 있는지를, 속도 상수와 활성화 에너지(13장)는 평형에 얼마나 빨리 가는지를 말한다.

반응식 조작과 K

반응식을새 평형 상수예

검토 더한 식에서 NO가 양쪽에서 지워져야 한다(2NO가 (1)의 생성물이자 (2)의 반응물). (a)가 반응물 쪽으로 치우쳤으니 역방향인 (b)는 생성물 쪽으로 치우친 큰 K가 맞다.

불균일 평형

반응물과 생성물이 서로 다른 상에 있는 평형을 불균일 평형(heterogeneous equilibrium)이라 한다. 순수한 고체와 순수한 액체는 K 식에서 뺀다. 이들의 "농도"(밀도/몰 질량)는 양이 얼마든 일정하고, 활동도가 1이기 때문이다. 묽은 용액의 용매(물)도 같은 이유로 뺀다.

$$\ce{CaCO3(s) <=> CaO(s) + CO2(g)}\qquad K_c = [\ce{CO2}],\quad K_p = P_{\ce{CO2}}$$

반응 지수 Q와 반응의 방향

임의의 순간(평형이 아니어도)의 농도를 K 식에 넣은 값을 반응 지수(reaction quotient) Q라 한다. Q를 K와 비교하면 반응이 어느 쪽으로 진행할지 알 수 있다.

$$Q_c = \frac{[\ce{C}]^c[\ce{D}]^d}{[\ce{A}]^a[\ce{B}]^b}\ (\text{현재 농도})\qquad \begin{cases} Q < K: & \text{정반응 진행 (→)} \\ Q = K: & \text{평형} \\ Q > K: & \text{역반응 진행 (←)} \end{cases}$$

직관적으로, Q < K는 생성물이 "모자란" 상태이므로 생성물을 더 만드는 쪽으로, Q > K는 생성물이 "넘치는" 상태이므로 반응물 쪽으로 간다. 어느 경우든 Q가 K에 가까워지는 방향이다.

평형 농도 계산: ICE 표

처음 농도와 K를 알 때 평형 농도를 구하는 표준 방법은 ICE 표다. 처음(Initial), 변화(Change), 평형(Equilibrium)의 세 줄로 농도를 정리한다. 변화량은 미지수 하나 \(x\)와 계수비로 쓴다.

  1. 균형 맞춘 반응식과 K 식을 쓴다. 필요하면 Q로 방향을 정한다.
  2. I 줄에 처음 농도(mol ÷ L)를 쓴다.
  3. C 줄에 \(-ax, -bx, +cx, +dx\)처럼 계수를 곱한 변화를 쓴다.
  4. E 줄 = I + C를 K 식에 넣어 \(x\)를 푼다. 근이 둘이면 농도가 음수가 되지 않는 근을 고른다.
  5. E 줄 값으로 K를 다시 계산해 검토한다.

448 °C에서 \(\ce{H2(g) + I2(g) <=> 2HI(g)}\)의 \(K_c = 50.5\)이다. 1.000 L 용기에 H₂ \(1.000\times10^{-3}\) mol과 I₂ \(2.000\times10^{-3}\) mol을 넣었을 때 평형 농도는?

전략 HI가 없으므로 Q = 0 < K, 정반응 진행. ICE 표를 세운다.

[H₂] = 6.5 × 10⁻⁵ M, [I₂] = 1.065 × 10⁻³ M, [HI] = 1.870 × 10⁻³ M
검토 \((1.870\times10^{-3})^2/[(6.5\times10^{-5})(1.065\times10^{-3})] = 50.5\) ✓. K가 커서 한계 반응물 H₂가 거의 다 소모되었다.

K가 작을 때의 근사와 5% 규칙

K가 매우 작으면 반응이 조금밖에 진행하지 않아 \(x\)가 처음 농도보다 훨씬 작다. 그러면 \([\ce{A}]_0 - x \approx [\ce{A}]_0\)로 놓아 식을 간단히 할 수 있다. 근사 후에는 반드시 \(x/[\ce{A}]_0\)가 5% 미만인지 확인한다. 넘으면 근의 공식(또는 반복 대입)으로 다시 푼다. 처음 농도에 비해 K가 대략 1/1000 이하일 때 근사가 잘 맞는다.

25 °C에서 \(\ce{N2O4(g) <=> 2NO2(g)}\)의 \(K_c = 4.64\times10^{-3}\)이다. [N₂O₄]₀ = 0.100 M에서 시작할 때 평형 농도를 구하라.

풀이 보기
전략 E 줄: [N₂O₄] = 0.100 − x, [NO₂] = 2x. 먼저 근사를 시도하고 5% 규칙을 확인한다.
풀이 근사: \(4x^2/0.100 = 4.64\times10^{-3}\) → \(x = 0.0108\). \(x/0.100 = 10.8\%\) > 5% — 근사 실패.
정확한 풀이: \(4x^2 = 4.64\times10^{-3}(0.100 - x)\) → \(4x^2 + 4.64\times10^{-3}x - 4.64\times10^{-4} = 0\). $$x = \frac{-4.64\times10^{-3} + \sqrt{(4.64\times10^{-3})^2 + 16(4.64\times10^{-4})}}{8} = 0.0102$$
[N₂O₄] = 0.0898 M, [NO₂] = 0.0204 M
검토 \((0.0204)^2/0.0898 = 4.64\times10^{-3}\) ✓. 근사값(0.0108)과 5% 정도 차이가 난다. K가 처음 농도의 1/20밖에 안 되므로 근사가 맞지 않는 것이 당연하다.

르샤틀리에 원리

르샤틀리에 원리

평형 상태의 계에 농도·압력·온도 변화 같은 교란을 주면, 계는 그 교란을 부분적으로 상쇄하는 방향으로 이동해 새로운 평형에 이른다.

원리 자체는 정성적이지만, 대부분은 Q와 K의 비교로 정확히 설명된다. 농도와 압력 변화는 Q를 바꾸고(K는 그대로), 온도 변화만 K 자체를 바꾼다.

압력과 부피

\(\ce{N2O4 <=> 2NO2}\)의 부피를 절반으로 줄이면 모든 농도가 두 배가 된다. 분자는 2제곱, 분모는 1제곱이므로 \(Q = (2[\ce{NO2}])^2/(2[\ce{N2O4}]) = 2K\), 곧 Q > K가 되어 역반응(몰수가 적은 쪽)으로 이동한다. 일반적으로 부피를 \(1/n\)로 줄이면 \(Q_c = n^{\Delta n}K_c\)이다.

온도와 반트호프 식

온도는 K 자체를 바꾼다. 열을 반응물이나 생성물처럼 생각하면 방향을 기억하기 쉽다. 흡열 반응(\(\Delta H^\circ > 0\))은 "반응물 + 열 ⇌ 생성물"이므로 가열하면 정반응으로 가고 K가 커진다. 발열 반응은 가열하면 K가 작아진다. 정량적으로는 반트호프 식(van 't Hoff equation)을 쓴다(17장에서 \(\Delta G^\circ = -RT\ln K\)로부터 유도한다).

$$\ln\frac{K_2}{K_1} = -\frac{\Delta H^\circ}{R}\left(\frac{1}{T_2} - \frac{1}{T_1}\right)$$
\(\Delta H^\circ\)가 온도 범위에서 일정하다고 가정한다. 13장 아레니우스 두 점 식과 꼴이 같다 — 실제로 \(K = k_f/k_r\)이고 \(\Delta H^\circ = E_{a,f} - E_{a,r}\)이다.

핵심 정리

  1. 화학 평형은 정반응·역반응 속도가 같아진 동적 상태이며, \(K = k_f/k_r\)는 온도만의 함수다. 평형은 어느 쪽에서든 접근할 수 있다.
  2. 질량 작용 법칙: \(K_c = [\ce{C}]^c[\ce{D}]^d/[\ce{A}]^a[\ce{B}]^b\)(지수 = 계수). 기체는 \(K_p = K_c(RT)^{\Delta n}\). 순수 고체·액체는 K 식에서 뺀다.
  3. K ≫ 1이면 생성물 쪽, K ≪ 1이면 반응물 쪽으로 치우친다. 반응식을 뒤집으면 1/K, n배 하면 Kⁿ, 더하면 곱.
  4. Q < K이면 정반응, Q > K이면 역반응이 진행해 Q가 K에 다가간다.
  5. ICE 표로 평형 농도를 구한다. 2차식은 근의 공식으로 풀고 물리적으로 가능한 근을 고른다. 작은 K는 근사 후 5% 규칙으로 확인한다.
  6. 르샤틀리에 원리: 농도·압력 변화는 Q를, 온도는 K를 바꾼다. 압축하면 기체 몰수가 적은 쪽, 가열하면 흡열 쪽으로 이동한다. 촉매는 평형을 바꾸지 않는다.
  7. 반트호프 식 \(\ln(K_2/K_1) = -(\Delta H^\circ/R)(1/T_2 - 1/T_1)\)으로 다른 온도의 K를 구한다.

연습문제

답은 유효숫자 3자리 정도로 입력한다. ±1% 이내면 정답으로 처리한다. 지수는 2.5e-3 또는 2.5×10^-3 형식으로 쓴다. \(R = 0.08206\) L·atm/(mol·K) = 8.314 J/(mol·K).

\(\ce{2SO2(g) + O2(g) <=> 2SO3(g)}\)의 평형에서 [SO₂] = 0.0500 M, [O₂] = 0.0300 M, [SO₃] = 0.200 M이다. \(K_c\)는?

\(K_c = (0.200)^2/[(0.0500)^2(0.0300)] = 0.0400/7.50\times10^{-5} = 533\).

25 °C에서 \(\ce{N2O4(g) <=> 2NO2(g)}\)의 평형 분압이 \(P_{\ce{NO2}} = 0.310\) atm, \(P_{\ce{N2O4}} = 0.850\) atm이다. \(K_p\)는?

\(K_p = (0.310)^2/0.850 = 0.113\).

250 °C에서 \(\ce{PCl5(g) <=> PCl3(g) + Cl2(g)}\)의 \(K_p = 1.80\)이다. \(K_c\)는?

\(\Delta n = 2 - 1 = 1\), \(K_c = K_p/(RT)\).

\(K_c = 1.80/[(0.08206)(523.15)] = 1.80/42.93 = 0.0419\).

448 °C에서 \(\ce{H2(g) + I2(g) <=> 2HI(g)}\)의 \(K_c = 50.5\)이다. 같은 온도에서 \(\ce{2HI <=> H2 + I2}\)와 \(\ce{HI <=> 1/2H2 + 1/2I2}\)의 평형 상수는?

뒤집기: \(1/50.5 = 0.0198\). 뒤집고 ½배: \((0.0198)^{1/2} = 0.141\).

(1) \(\ce{2NOBr(g) <=> 2NO(g) + Br2(g)}\), \(K_1 = 0.014\); (2) \(\ce{Br2(g) + Cl2(g) <=> 2BrCl(g)}\), \(K_2 = 7.2\)일 때, \(\ce{2NOBr(g) + Cl2(g) <=> 2NO(g) + 2BrCl(g)}\)의 K는?

(1) + (2)에서 Br₂가 지워지므로 \(K = K_1K_2 = (0.014)(7.2) = 0.101\).

\(\ce{3Fe(s) + 4H2O(g) <=> Fe3O4(s) + 4H2(g)}\)의 \(K_c\) 식으로 옳은 것은?

순수한 고체 Fe와 Fe₃O₄는 빼고, 기체의 계수는 지수로 남긴다.

500 °C(\(K_c = 0.0584\))에서 [N₂] = 0.10 M, [H₂] = 0.10 M, [NH₃] = 0.050 M인 혼합물이 있다. \(\ce{N2 + 3H2 <=> 2NH3}\)은 어느 방향으로 진행하는가?

\(Q = (0.050)^2/[(0.10)(0.10)^3] = 2.5\times10^{-3}/1.0\times10^{-4} = 25 > 0.0584\). 생성물이 너무 많으므로 역반응이 진행한다.

\(\ce{2SO3(g) <=> 2SO2(g) + O2(g)}\). 처음 [SO₃] = 0.100 M만 넣었고, 평형에서 [O₂] = 0.0150 M였다. \(K_c\)는?

O₂가 x = 0.0150 생겼다면 SO₂는 2x 생기고 SO₃는 2x 줄었다.

E: [SO₃] = 0.100 − 0.0300 = 0.0700, [SO₂] = 0.0300, [O₂] = 0.0150. \(K_c = (0.0300)^2(0.0150)/(0.0700)^2 = 2.76\times10^{-3}\).

448 °C(\(K_c = 50.5\))에서 H₂와 I₂를 각각 0.200 M씩 넣었다. 평형에서 [HI]와 [H₂]는?

양변에 제곱근을 취하면 1차식: \(2x/(0.200 - x) = \sqrt{50.5}\).

\(\sqrt{50.5} = 7.106\). \(2x = 7.106(0.200 - x)\) → \(x = 1.421/9.106 = 0.1561\). [HI] = 2x = 0.312 M, [H₂] = [I₂] = 0.0439 M.

250 °C에서 \(\ce{PCl5(g) <=> PCl3(g) + Cl2(g)}\)의 \(K_c = 0.0420\)이다. [PCl₅]₀ = 0.100 M에서 시작하면 평형 농도는?

\(x^2/(0.100 - x) = 0.0420\). 근사를 하면 x/0.100이 5%를 훨씬 넘는다.

\(x^2 + 0.0420x - 0.00420 = 0\) → \(x = [-0.0420 + \sqrt{0.0420^2 + 4(0.00420)}]/2 = 0.0471\). [PCl₃] = [Cl₂] = 0.0471 M, [PCl₅] = 0.0529 M.

어떤 고온에서 \(\ce{N2(g) + O2(g) <=> 2NO(g)}\)의 \(K_c = 1.0\times10^{-5}\)이다. [N₂]₀ = 0.80 M, [O₂]₀ = 0.20 M에서 시작할 때 평형 [NO]는?

K가 작으므로 \(0.80 - x \approx 0.80\), \(0.20 - x \approx 0.20\).

\((2x)^2/[(0.80)(0.20)] = 1.0\times10^{-5}\) → \(x = 6.32\times10^{-4}\), [NO] = 1.26 × 10⁻³ M. 확인: \(x/0.20 = 0.32\%\) < 5%, 근사 타당.

\(\ce{N2(g) + 3H2(g) <=> 2NH3(g)}\)의 \(K_p\)는 298 K에서 \(5.8\times10^{5}\), \(\Delta H^\circ = -92.2\) kJ이다. 400 K에서의 \(K_p\)는?

\(\ln(K_2/K_1) = -\dfrac{-92\,200}{8.314}\left(\dfrac{1}{400} - \dfrac{1}{298.15}\right) = -9.474\) → \(K_2 = 5.8\times10^5\times e^{-9.474} = 44.7\). 발열 반응이므로 K가 크게 줄었다.

\(\ce{CO(g) + 2H2(g) <=> CH3OH(g)}\), \(\Delta H^\circ < 0\). 메탄올의 평형 수득률을 높이는 변화는?

기체 3 mol → 1 mol이므로 압축하면 오른쪽으로 이동한다. 가열은 발열 반응의 K를 줄이고, 촉매와 비활성 기체(부피 일정)는 평형을 바꾸지 않는다.

25 °C의 단단한 용기에 N₂O₄만 1.00 atm 넣었다. \(\ce{N2O4 <=> 2NO2}\)의 \(K_p = 0.1135\)일 때 평형의 전체 압력과 N₂O₄의 해리 분율은?

분압으로 ICE: \(P_{\ce{N2O4}} = 1.00 - y\), \(P_{\ce{NO2}} = 2y\). 전체 = 1.00 + y.

\(4y^2/(1.00 - y) = 0.1135\) → \(4y^2 + 0.1135y - 0.1135 = 0\) → \(y = 0.155\). 전체 압력 1.155 atm, 해리 분율 15.5%. 이때 \(P_{\ce{NO2}} = 0.310\) atm으로 2번 문제의 자료와 같다.

개념 확인 퀴즈

평형 상태에 대한 설명으로 옳은 것은?

농도가 같을 필요는 없다(그 비가 K로 정해진다). 두 반응은 계속 일어나며 속도만 같다.

\(\ce{H2(g) + I2(g) <=> 2HI(g)}\)의 평형 혼합물을 압축하면?

양쪽 기체 몰수가 같아(Δn = 0) 부피 변화가 Q를 바꾸지 않는다. 모든 농도가 같은 배율로 커질 뿐이다.

어떤 흡열 반응의 온도를 올리면?

온도는 K를 바꾸는 유일한 변수다. 흡열 반응은 열을 "반응물"로 보면 가열 시 오른쪽으로 가고, 반트호프 식에서도 \(\Delta H^\circ > 0\)이면 \(T\)가 오를 때 K가 커진다.

Q > K인 혼합물에서 일어나는 일은?

생성물이 평형보다 많으므로 역반응으로 생성물이 줄어 Q가 K로 내려간다. K는 온도가 같으면 변하지 않는다.

\(\ce{CaCO3(s) <=> CaO(s) + CO2(g)}\)의 평형 용기에 CaCO₃ 고체를 더 넣으면?

순수한 고체는 K 식(\(K_p = P_{\ce{CO2}}\))에 들어가지 않으므로 그 양은 평형에 영향을 주지 않는다.
