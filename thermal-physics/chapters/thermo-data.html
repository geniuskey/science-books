열역학 자료와 계산기

본문 17개 장에서 쓴 상수·자료·공식을 한곳에 모았다. 표는 대부분 이 책의 계산 엔진 Thermo.*에 들어 있는 자료를 페이지를 열 때 그대로 읽어 그린 것이라, 본문 시뮬레이터·예제와 같은 숫자를 낸다. 표마다 같은 식을 쓰는 계산기를 붙였다. 열화학 표는 검색과 정렬이 되고, 줄을 누르면 반응 계산기에 들어간다. 출처 수준은 표마다 밝혔다. "대표값"은 문헌에 따라 수 % 다를 수 있는 교육용 값이므로, 문제를 풀 때는 문제에 주어진 값을 먼저 쓰고, 없을 때 이 표를 쓴다.

  • CODATA 상수와 압력(Pa·bar·Torr·mTorr)·기체 유량(sccm·slm·mol/s·Pa·m³/s)·몰당 에너지(kJ/mol·eV·cm⁻¹·K) 단위를 바로 바꾼다.
  • 표준 생성 엔탈피·표준 엔트로피·열용량 표로 반응의 \(\Delta H^\circ\), \(\Delta S^\circ\), \(\Delta G^\circ(T)\), \(K(T)\), 역전 온도를 계산하고 엘링엄 선으로 산화물의 안정성을 비교한다.
  • 증기압·판데르발스 상수·이원자 분자 상수·분자 지름으로 버블러 증기압, 임계 상수, 열용량, 평균 자유 행로, 단분자층 시간, 컨덕턴스를 구한다.
  • 편석 계수·헨리 상수·전극 전위·확산 계수·딜–그로브 계수·열전도도를 찾아 쇼이어 분포, 용존 기체, 네른스트 전위, 접합 깊이, 산화막 두께, 접합 온도를 계산한다.
  • 부별 공식 요약에서 식을 찾고, 그 식을 유도한 본문 절로 바로 간다.

아래 표는 Thermo.species를 페이지가 열릴 때 그대로 읽어 만든다(NIST-JANAF·CODATA 대표값). \(\Delta_\mathrm fG^\circ\) 열은 자료에 없는 값을 \(\Delta_\mathrm fG^\circ = \Delta_\mathrm fH^\circ - T\left[S^\circ - \sum_\text{원소}\nu S^\circ_\text{원소}\right]\)로 계산한 것이다(원소의 기준 상태: H₂·O₂·N₂·Cl₂·F₂ 기체, 흑연, 금속 고체). 원소의 기준 상태는 \(\Delta_\mathrm fH^\circ = \Delta_\mathrm fG^\circ = 0\)이지만 \(S^\circ\)는 0이 아니다(제3법칙의 절대 엔트로피, 3장). 상(g, l, s)을 꼭 확인한다: H₂O(l)과 H₂O(g)는 \(\Delta_\mathrm fH^\circ\)가 44.0 kJ/mol 다르다. 머리글을 누르면 정렬되고, 줄을 누르면 아래 반응 계산기의 빈칸(반응물 또는 생성물, 계산기에서 고른 쪽)에 들어간다.

표 찾아 쓰기 연습

필요한 값은 모두 이 부록의 표와 계산기에 있다. 문제에 값이 주어지면 그 값을 쓴다. \(R = 8.314\) J/(mol·K), \(F = 96\,485\) C/mol, \(k = 8.617\times10^{-5}\) eV/K. 따로 말이 없으면 답이 ±1 % 이내면 정답이다.

열화학 표의 \(\Delta_\mathrm fH^\circ\)와 \(S^\circ\)로 \(\ce{Si(s) + O2(g) -> SiO2(s)}\)의 \(\Delta_\mathrm rS^\circ\)와 298.15 K의 \(\Delta_\mathrm fG^\circ(\ce{SiO2})\)를 구하라.

원소의 \(S^\circ\)는 0이 아니다. Si 18.81, O₂ 205.15, SiO₂ 41.46 J/(mol·K).

\(\Delta S^\circ = 41.46 - 18.81 - 205.15 = -182.50\) J/K. \(\Delta G^\circ = -910.7 - 298.15\times(-0.18250) = -910.7 + 54.41 = -856.3\) kJ/mol. 표의 \(\Delta_\mathrm fG^\circ\) 열(계산값)과 같다. 기체 1 mol이 고체에 묶이므로 \(\Delta S\)가 크게 음수다.

\(\ce{SiH4(g) -> Si(s) + 2H2(g)}\)의 298.15 K 표준 깁스 에너지를 구하고, \(\Delta C_P = 0\) 근사로 600 °C의 \(\log_{10}K\)를 구하라.

\(\Delta H^\circ = -34.3\) kJ, \(\Delta S^\circ = 18.81 + 2(130.68) - 204.65\). \(\log_{10}K = -\Delta G^\circ/(2.303RT)\).

\(\Delta S^\circ = 75.52\) J/K, \(\Delta G^\circ_{298} = -34.3 - 298.15\times0.07552 = -56.8\) kJ. 873.15 K: \(\Delta G^\circ = -34.3 - 873.15\times0.07552 = -100.24\) kJ, \(\log_{10}K = 100\,240/(2.3026\times8.314\times873.15) = 6.00\). 열역학적으로는 완전히 분해 쪽이다. LPCVD 폴리실리콘의 증착 속도를 정하는 것은 평형이 아니라 표면 반응 속도다.

엘링엄 근사(\(\Delta C_P = 0\))로 1000 °C에서 \(\ce{Si + O2 -> SiO2}\)의 \(\Delta G^\circ\)와 SiO₂가 분해되는 평형 산소 분압을 구하라.

\(\Delta G^\circ = -910.7 + 1273.15\times0.1825 = -678.4\) kJ. \(\log_{10}p_{\mathrm O_2} = \Delta G^\circ/(2.303RT) = -678\,350/(2.3026\times8.314\times1273.15) = -27.8\). 실제 노 안의 산소 분압은 이보다 훨씬 높으므로 SiO₂는 늘 안정하다. 반대로 SiO₂ 위 금속이 SiO₂를 환원하려면 엘링엄 선이 SiO₂ 아래에 있어야 한다(Ti, Hf, Al).

IPA의 끓는점(82.25 °C)과 증발 엔탈피(39.85 kJ/mol)를 써서 클라우지우스–클라페이롱 식으로 25 °C의 증기압을 Torr로 구하라. 실측(약 45 Torr)보다 큰 이유는?

\(\ln(P/760) = -\dfrac{39\,850}{8.314}\left(\dfrac1{298.15} - \dfrac1{355.4}\right) = -2.591\), \(P = 760e^{-2.591} = 57.0\) Torr. \(\Delta H_\text{vap}\)은 온도가 낮을수록 크다(25 °C에서 약 45 kJ/mol). 끓는점 값을 쓰면 기울기가 작게 잡혀 낮은 온도의 증기압을 크게 외삽한다. 넓은 범위에는 앙투안 식을 쓴다.

CO₂의 판데르발스 상수(a = 0.364 Pa·m⁶/mol², b = 4.267 × 10⁻⁵ m³/mol)로 임계 온도·압력·몰부피를 구하고 실측(304.13 K, 7.38 MPa, 94 cm³/mol)과 비교하라.

\(T_\mathrm c = \dfrac{8(0.364)}{27(8.314)(4.267\times10^{-5})} = 304.0\) K, \(P_\mathrm c = \dfrac{0.364}{27(4.267\times10^{-5})^2} = 7.40\) MPa, \(V_\mathrm c = 3b = 128\) cm³/mol. CRC의 a, b는 \(T_\mathrm c\), \(P_\mathrm c\)에 맞춰 정했으므로 둘은 잘 맞지만, \(V_\mathrm c\)는 36 % 크다. \(Z_\mathrm c = 3/8\)이 실제(0.27)보다 큰 탓이다.

(가) HCl의 회전 상수 \(\tilde B\)를 cm⁻¹로 구하라. (나) 1000 K의 N₂ 분자 가운데 진동 양자수 v = 1에 있는 비율은?

\(\tilde B = \theta_\mathrm{rot}/1.4388\ \text{cm·K}\). 조화 진동자의 \(p_\mathrm v = e^{-\mathrm vx}(1 - e^{-x})\), \(x = \theta_\mathrm{vib}/T\).

(가) \(15.02/1.4388 = 10.44\) cm⁻¹. (나) \(x = 3374/1000 = 3.374\), \(p_1 = e^{-3.374}(1 - e^{-3.374}) = 0.0342\times0.9658 = 0.0331\). 1000 K에서도 N₂의 97 %는 진동 바닥 상태라 \(C_V/R\)이 병진·회전 값 2.5에서 많이 오르지 않았다(표의 2.92).

(가) 300 K, 10 mTorr의 Ar 평균 자유 행로를 mm로 구하라(d = 3.67 Å). (나) 300 K, 10⁻⁶ Torr의 수증기가 부착 계수 1로 표면 자리 10¹⁹ m⁻²를 덮는 데 걸리는 시간은?

(가) \(P = 1.333\) Pa, \(\lambda = \dfrac{1.381\times10^{-23}\times300}{\sqrt2\pi(3.67\times10^{-10})^2\times1.333} = 5.19\times10^{-3}\) m = 5.19 mm. 지름 30 cm 챔버에서 Kn ≈ 0.02인 전이류다. (나) \(\Phi = \dfrac{1.333\times10^{-4}}{\sqrt{2\pi(18.015\times10^{-3}/N_\mathrm A)(1.381\times10^{-23})(300)}} = 4.78\times10^{18}\) m⁻²s⁻¹, \(t = 10^{19}/\Phi = 2.09\) s.

20 °C 질소가 분자류로 흐를 때 지름 4.0 cm, 길이 50 cm 관의 컨덕턴스(구멍과 긴 관을 직렬 합성)를 구하고, 500 L/s 터보 펌프를 이 관으로 연결했을 때의 유효 배기 속도를 구하라.

\(\bar v = \sqrt{8RT/\pi M} = 470.7\) m/s. \(C_o = \tfrac14\bar v\pi d^2/4 = 0.148\) m³/s = 148 L/s, \(C_l = \pi\bar vd^3/12L = 15.8\) L/s, \(C = (1/148 + 1/15.8)^{-1} = 14.3\) L/s. \(S_\text{eff} = (1/500 + 1/14.3)^{-1} = 13.9\) L/s — 펌프의 3 %도 못 쓴다. 관은 굵고 짧게.

초크랄스키 성장에서 용융액의 90 %가 굳었을 때(\(f_\mathrm s = 0.9\)) 그 위치 고체의 농도를 처음 용융액 농도 \(C_0\)에 대한 비로, P(\(k_0\) = 0.35)와 B(\(k_0\) = 0.8)에 대해 구하라.

P: \(0.35\times0.1^{-0.65} = 0.35\times4.467 = 1.56\). B: \(0.8\times0.1^{-0.2} = 0.8\times1.585 = 1.27\). 씨앗 쪽(\(f_\mathrm s = 0\))은 각각 0.35, 0.8이므로 P 도핑 잉곳은 길이 방향 비저항 변화가 B보다 훨씬 크다.

(가) 25 °C, [Cu²⁺] = 1.0 × 10⁻⁴ M 용액에 담근 구리 전극의 전위(V vs SHE)는? (나) 다니엘 전지 \(\ce{Zn + Cu^2+ -> Zn^2+ + Cu}\)의 표준 깁스 에너지는?

(가) \(E = 0.3419 + \dfrac{0.05916}{2}\log_{10}(1.0\times10^{-4}) = 0.3419 - 0.1183 = 0.224\) V. (나) \(E^\circ = 0.3419 - (-0.7618) = 1.1037\) V, \(\Delta G^\circ = -2(96\,485)(1.1037) = -213\) kJ.

붕소 도즈 \(Q = 1.0\times10^{14}\) cm⁻²를 1100 °C에서 30분 드라이브인했다(제한 공급원, 반사 표면). 진성 확산 계수와 배경 \(N_B = 1.0\times10^{16}\) cm⁻³에 대한 접합 깊이를 구하라.

\(D = 0.76\exp\left(-\dfrac{3.46}{8.617\times10^{-5}\times1373.15}\right) = 1.52\times10^{-13}\) cm²/s. \(Dt = 2.74\times10^{-10}\) cm², \(C_0 = Q/\sqrt{\pi Dt} = 3.41\times10^{18}\) cm⁻³. \(x_j = 2\sqrt{Dt\ln(C_0/N_B)} = 2\sqrt{2.74\times10^{-10}\times5.83} = 7.99\times10^{-5}\) cm = 0.799 µm.

(100) 실리콘을 1000 °C 건식 O₂에서 1.0시간 산화한다. 딜–그로브 표의 B, B/A와 처음 두께 \(x_i\) = 25 nm 보정을 써서 산화막 두께를 구하라.

\(B = 0.01044\) µm²/h, \(B/A = 0.0449\) µm/h, \(A = 0.2325\) µm. \(\tau = (x_i^2 + Ax_i)/B\).

\(\tau = (0.025^2 + 0.2325\times0.025)/0.01044 = 0.617\) h. \(x^2 + 0.2325x = 0.01044\times1.617 = 0.01688\) → \(x = \dfrac{-0.2325 + \sqrt{0.2325^2 + 4(0.01688)}}{2} = 0.0581\) µm = 58.1 nm. \(t + \tau = 1.6\) h가 \(A^2/4B = 1.29\) h와 비슷하므로 선형–포물선 사이다.

넓이 1.0 cm²를 지나는 열류가 Si 500 µm, 솔더 50 µm, Cu 2.0 mm, TIM 50 µm를 차례로 지난다(κ는 열전도도 표). 50 W를 쓸 때 전도 열저항의 합과, TIM 바깥면이 25 °C로 유지될 때의 접합(다이 윗면) 온도를 구하라.

\(R = L/\kappa A\): Si \(5\times10^{-4}/(148\times10^{-4}) = 0.0338\), 솔더 \(5\times10^{-5}/(58\times10^{-4}) = 0.0086\), Cu \(2\times10^{-3}/(401\times10^{-4}) = 0.0499\), TIM \(5\times10^{-5}/(4\times10^{-4}) = 0.125\) K/W. 합 0.217 K/W, \(\Delta T = 50\times0.217 = 10.9\) K, \(T_\mathrm j = 35.9\) °C. 두께 50 µm의 TIM이 전체의 58 %를 차지한다.

공기(\(p_{\mathrm O_2}\) = 0.2095 atm)와 평형인 물의 용존 산소 농도를 25 °C와 60 °C에서 mg/L로 구하라(헨리 상수 표의 \(k_\mathrm H\), \(B\)).

25 °C: \(c = 1.3\times10^{-3}\times0.2095 = 2.72\times10^{-4}\) mol/L = 8.71 mg/L. 60 °C: \(k_\mathrm H = 1.3\times10^{-3}e^{1700(1/333.15 - 1/298.15)} = 7.14\times10^{-4}\), \(c = 4.79\) mg/L. 뜨거운 물일수록 기체가 덜 녹는다. 초순수의 용존 산소 목표(수 ppb)는 공기 포화의 1/1000 아래다.
