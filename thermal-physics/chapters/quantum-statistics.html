Chapter 07

양자 통계

6장의 볼츠만 분포는 입자 하나가 열저장체와 에너지를 주고받는 그림에서 나왔다. 기체 분자처럼 입자들이 서로 멀리 떨어져 있으면 그것으로 충분하다. 그러나 금속 속 전자, 공동 속 광자, 결정 속 포논, 나노켈빈까지 식힌 원자처럼 입자들의 파동이 겹치기 시작하면 같은 종류의 입자는 서로 구별할 수 없다는 양자역학의 규칙이 셈법 자체를 바꾼다. 한 상태에 하나만 들어가는 페르미온은 낮은 준위부터 차곡차곡 쌓여 페르미 바다를 만들고, 몇 개든 들어가는 보손은 온도가 내려가면 바닥 상태로 한꺼번에 무너져 내린다. 이 장은 입자 수까지 주고받는 대정준 앙상블로 두 분포를 한 번에 유도하고, 그 결과로 전자 열용량, 반도체 캐리어 농도, 흑체 복사, 디바이 비열, 보스–아인슈타인 응축을 설명한다. 아래에서 왼쪽은 페르미온, 오른쪽은 보손이 같은 사다리 위에서 에너지를 주고받는다. 온도를 내려 보라.

위아래로 끌어 온도를 바꾼다(놓으면 저절로 오르내린다)
  • 구별되는 입자·보손·페르미온을 몇 개의 상태에 넣는 방법의 수를 세고, 상태 수가 입자 수보다 훨씬 많을 때 셋이 \(g^N/N!\)로 모이는 이유를 설명한다.
  • 계가 저장체와 에너지와 입자를 함께 주고받을 때 깁스 인자 \(e^{-(E-\mu N)/kT}\)와 대분배 함수 \(\mathcal Z\)를 유도하고, 궤도 하나의 평균 점유수로 페르미–디랙·보스–아인슈타인 분포를 얻는다.
  • 이상 기체의 화학 퍼텐셜 \(\mu = kT\ln(n\lambda^3)\)을 계산하고, 고전 극한의 조건 \(n\lambda^3 \ll 1\)로 기체·전자·액체 헬륨이 어느 통계를 따르는지 판정한다.
  • 페르미 에너지 \(E_\mathrm F = \frac{\hbar^2}{2m}(3\pi^2 n)^{2/3}\)과 전자 열용량 \(C_V \approx \frac{\pi^2}{2}Nk\frac{kT}{E_\mathrm F}\)을 계산하고, 반도체에서 \(E_c - E_\mathrm F > 3kT\)일 때 볼츠만 근사가 통하는 이유를 보인다.
  • 광자 기체에서 플랑크 법칙·빈 변위 법칙·슈테판–볼츠만 법칙을 이끌고, 방사율과 단색·2색 고온계의 원리로 RTP 웨이퍼 온도 측정 오차를 계산한다.
  • 포논 기체의 디바이 열용량과 아인슈타인 모형을 비교하고, 보스–아인슈타인 응축의 임계 온도와 바닥 상태 점유율 \(N_0/N = 1-(T/T_c)^{3/2}\)을 계산한다.

동일 입자와 상태 세기

5장에서는 겹침수 \(\Omega\)를 셌고, 6장에서는 입자 하나의 분배 함수 \(Z_1\)에서 \(N\)개 입자의 분배 함수를 \(Z = Z_1^N/N!\)로 만들었다. 이 \(N!\)이 바로 "같은 종류의 입자는 바꿔 놓아도 같은 상태"라는 사실을 고전적으로 땜질한 것이다. 땜질이 언제 맞고 언제 틀리는지 보려면 상태를 직접 세 보아야 한다.

양자역학에서 같은 종류의 입자들은 원리적으로 구별할 수 없는 동일 입자(identical particles)다. 두 입자의 좌표를 맞바꾸면 파동 함수는 그대로이거나(\(+\)) 부호만 바뀐다(\(-\)). 앞의 경우가 보손(boson), 뒤의 경우가 페르미온(fermion)이다. 스핀–통계 정리에 따라 정수 스핀 입자(광자, 포논, ⁴He 원자, ⁸⁷Rb 원자)는 보손, 반정수 스핀 입자(전자, 양성자, 중성자, ³He 원자)는 페르미온이다.

$$\psi(x_2, x_1) = +\,\psi(x_1, x_2)\ \ (\text{보손}),\qquad \psi(x_2, x_1) = -\,\psi(x_1, x_2)\ \ (\text{페르미온})$$
페르미온 두 개가 같은 상태 \(a\)에 있으면 \(\psi = \phi_a(x_1)\phi_a(x_2) - \phi_a(x_2)\phi_a(x_1) = 0\)이다. 같은 상태에 페르미온은 둘 이상 들어갈 수 없다 — 파울리 배타 원리(Pauli exclusion principle).

구별할 수 없다는 것은 "어느 입자가 어느 상태에 있나"가 아니라 "각 상태에 입자가 몇 개 있나"(점유수 \(n_1, n_2, \dots\))만이 미시 상태를 정한다는 뜻이다. 에너지가 같은 \(g\)개의 상태에 입자 \(N\)개를 넣는 방법의 수는 세 가지로 갈린다.

$$\Omega_\text{구별} = g^N,\qquad \Omega_\text{BE} = \binom{N+g-1}{N},\qquad \Omega_\text{FD} = \binom{g}{N}$$
보손은 공 \(N\)개와 칸막이 \(g-1\)개를 한 줄로 늘어놓는 방법의 수(5장 아인슈타인 고체의 에너지 덩어리 세기와 같다). 페르미온은 \(g\)개 중 차 있는 \(N\)개를 고르는 방법의 수다.

에너지가 같은 상태 4개에 입자 3개를 넣으면, 구별되는 입자는 가지, 보손은 가지, 페르미온은 가지다. 고전 땜질 \(g^N/N!\)은 로, 보손과 페르미온의 값 사이에 놓인다. \(g\)를 40까지 늘려 세 값이 모이는 것을 보라.

대정준 앙상블과 화학 퍼텐셜

상태를 일일이 세는 방법은 입자가 몇 개만 넘어도 손을 쓸 수 없다. 6장에서 에너지를 정해 놓은 미시 정준 앙상블 대신 열저장체와 에너지를 주고받는 정준 앙상블로 넘어가 계산이 쉬워졌듯이, 여기서는 한 걸음 더 나가 입자도 주고받게 한다. 계는 큰 저장체와 에너지 \(E\)와 입자 수 \(N\)을 교환하고, 저장체는 온도 \(T\)와 화학 퍼텐셜 \(\mu\)를 정해 준다. 이런 계들의 모임을 대정준 앙상블(grand canonical ensemble)이라 한다.

깁스 인자

계와 저장체를 합친 전체는 고립되어 있으니 모든 미시 상태가 똑같이 그럴듯하다(5장의 기본 가정). 계가 특정한 상태 \(s\)에 있을 확률은 그때 저장체가 가질 수 있는 미시 상태의 수 \(\Omega_R\)에 비례한다. 엔트로피 \(S_R = k\ln\Omega_R\)를 \(E_s, N_s\)에 대해 1차까지 펼치고 4장의 \(\partial S/\partial U = 1/T\), \(\partial S/\partial N = -\mu/T\)를 쓰면

$$P(s) \propto \Omega_R(U_0 - E_s,\, N_0 - N_s) = e^{S_R/k},\qquad S_R(U_0 - E_s, N_0 - N_s) \approx S_R(U_0, N_0) - \frac{E_s}{T} + \frac{\mu N_s}{T}$$ $$\boxed{\,P(s) = \frac{1}{\mathcal Z}\,e^{-(E_s - \mu N_s)/kT},\qquad \mathcal Z = \sum_s e^{-(E_s - \mu N_s)/kT}\,}$$
\(e^{-(E-\mu N)/kT}\)를 깁스 인자(Gibbs factor), 모든 상태(입자 수가 다른 상태까지)에 대한 합 \(\mathcal Z\)를 대분배 함수(grand partition function)라 한다. 입자 수가 고정되면(\(N_s\) 일정) 볼츠만 인자로 돌아간다.

대분배 함수에서 평균 입자 수와 평균 에너지를 미분으로 얻는다. 또 \(\Phi = -kT\ln\mathcal Z = U - TS - \mu N\)을 대퍼텐셜(grand potential)이라 하며, 균일한 계에서는 \(\Phi = -PV\)다.

$$\langle N\rangle = kT\,\frac{\partial \ln\mathcal Z}{\partial \mu},\qquad \Phi = -kT\ln\mathcal Z,\qquad d\Phi = -S\,dT - P\,dV - N\,d\mu$$

궤도 하나가 계일 때

서로 상호 작용하지 않는 입자들에서는 단일 입자 궤도(에너지 \(\varepsilon\)인 양자 상태 하나) 하나를 계로 잡을 수 있다. 궤도의 상태는 점유수 \(n\)으로 정해지고 에너지는 \(n\varepsilon\)이다. 페르미온이면 \(n = 0, 1\)뿐이고 보손이면 \(n = 0, 1, 2, \dots\)다. \(x = (\varepsilon - \mu)/kT\)로 두면

$$\text{페르미온: } \mathcal Z = 1 + e^{-x},\quad \bar n = \frac{e^{-x}}{1+e^{-x}} = \frac{1}{e^{x}+1};\qquad \text{보손: } \mathcal Z = \sum_{n=0}^{\infty} e^{-nx} = \frac{1}{1-e^{-x}},\quad \bar n = \frac{1}{e^{x}-1}$$
보손의 기하 급수는 \(x > 0\), 즉 \(\varepsilon > \mu\)일 때만 수렴한다. 그래서 보손 계의 \(\mu\)는 가장 낮은 궤도의 에너지보다 늘 낮다.

화학 퍼텐셜의 값: 이상 기체

\(\mu\)는 무엇이 정하는가? 6장의 병진 분배 함수 \(Z_1 = V/\lambda^3\)(\(\lambda = h/\sqrt{2\pi mkT}\)는 열적 드브로이 파장)로 고전 이상 기체의 자유 에너지 \(F = -kT\ln(Z_1^N/N!)\)를 쓰고 \(\mu = (\partial F/\partial N)_{T,V}\)를 계산하면

$$\mu = -kT\ln\frac{Z_1}{N} = kT\ln\!\left(\frac{N}{V}\lambda^3\right) = kT\ln\frac{n}{n_Q},\qquad n_Q \equiv \frac{1}{\lambda^3} = \left(\frac{2\pi mkT}{h^2}\right)^{3/2}$$
\(n_Q\)를 양자 농도(quantum concentration)라 한다. 입자마다 부피 \(\lambda^3\)을 차지한다고 볼 때 상자를 꽉 채우는 농도다. 내부 자유도(스핀 겹침 \(g_s\), 회전·진동)가 있으면 \(n_Q\)에 내부 분배 함수가 곱해진다.

보통 기체는 \(n \ll n_Q\)라서 \(\mu\)가 큰 음수다. 압력(농도)을 높이면 \(\mu\)가 커져 입자가 "빠져나가려는 경향"이 강해지고, 이것이 화학 평형(12장)과 흡착(14장)의 방향을 정한다. 예를 들어 흡착 자리 하나를 계로 보면, 결합 에너지 \(-\varepsilon_0\)인 자리가 차 있을 확률은 깁스 인자로 \(\theta = 1/(e^{(-\varepsilon_0-\mu)/kT}+1)\)이고 \(e^{\mu/kT} = n\lambda^3 \propto P\)를 넣으면 \(\theta = P/(P+P_0(T))\) — 랭뮤어 등온선이 바로 나온다(14장).

페르미–디랙·보스–아인슈타인 분포와 고전 극한

궤도 하나의 평균 점유수가 이 장의 주인공이다. 에너지 \(\varepsilon\)인 궤도에 평균 몇 개의 입자가 있는가를 셋으로 나란히 쓰면

$$\bar n_\mathrm{FD}(\varepsilon) = \frac{1}{e^{(\varepsilon-\mu)/kT}+1},\qquad \bar n_\mathrm{BE}(\varepsilon) = \frac{1}{e^{(\varepsilon-\mu)/kT}-1},\qquad \bar n_\mathrm{MB}(\varepsilon) = e^{-(\varepsilon-\mu)/kT}$$
각각 페르미–디랙 분포(Fermi–Dirac distribution), 보스–아인슈타인 분포(Bose–Einstein distribution), 맥스웰–볼츠만(고전) 분포다. 분모의 \(+1\), \(-1\), \(0\)만 다르다. \(\mu\)는 총 입자 수 \(N = \sum_i \bar n(\varepsilon_i)\)가 맞도록 정해진다.

페르미–디랙 분포는 0과 1 사이에 갇혀 있고, \(\varepsilon = \mu\)에서 언제나 정확히 \(1/2\)이며, \(\mu\) 근처 폭 몇 \(kT\) 안에서 1에서 0으로 떨어진다. 보스–아인슈타인 분포는 \(\varepsilon\to\mu^+\)에서 발산하고 1보다 클 수 있다. 셋 모두 \((\varepsilon-\mu)/kT \gg 1\)이면 \(e^{-(\varepsilon-\mu)/kT}\)로 같아진다.

페르미–디랙 분포에서 \(\mu\)를 고정하고 온도를 300 K에서 1500 K로 올린다. 에너지가 정확히 \(\varepsilon = \mu\)인 궤도의 평균 점유수는?

\(x = 0\)이면 \(1/(e^0+1) = 1/2\)이다. 온도는 계단의 폭(약 \(4kT\))만 바꾸고, 계단이 1/2을 지나는 자리는 \(\mu\)가 정한다. 실험대에서 T 핸들을 끌어 곡선이 \(\mu\)를 축으로 눕는 것을 보라.

축퇴 페르미 기체와 반도체 캐리어

\(n\lambda^3 \gg 1\)인 페르미온 기체, 곧 금속의 전도 전자부터 보자. 절대 영도에서 계는 에너지가 가장 낮은 상태를 고른다. 페르미온은 궤도마다 하나(스핀까지 치면 \(\mathbf k\)마다 둘)만 들어가므로, 전자 \(N\)개는 가장 낮은 궤도부터 차례로 채워 마지막 전자가 들어간 에너지 \(E_\mathrm F\)까지 꽉 찬 "바다"를 이룬다. 이런 상태를 축퇴(degenerate) 기체라 하고, \(E_\mathrm F\)를 페르미 에너지(Fermi energy)라 한다. \(T = 0\)에서 \(\mu = E_\mathrm F\)이고 페르미–디랙 분포는 \(E_\mathrm F\)에서 끊긴 계단이다.

구 안의 격자점 수에 스핀 2를 곱하면 전자 수다. \(N = 2\cdot\frac{(4/3)\pi k_\mathrm F^3}{(2\pi/L)^3}\)에서

$$k_\mathrm F = (3\pi^2 n)^{1/3},\qquad E_\mathrm F = \frac{\hbar^2 k_\mathrm F^2}{2m} = \frac{\hbar^2}{2m}(3\pi^2 n)^{2/3},\qquad T_\mathrm F = \frac{E_\mathrm F}{k}$$ $$g(E) = \frac{3N}{2E_\mathrm F}\sqrt{\frac{E}{E_\mathrm F}},\qquad U_0 = \int_0^{E_\mathrm F} E\,g(E)\,dE = \frac35 NE_\mathrm F,\qquad P_0 = \frac23\frac{U_0}{V} = \frac25 nE_\mathrm F$$
\(g(E)\)는 단위 에너지당 상태 수인 상태 밀도(density of states), \(T_\mathrm F\)는 페르미 온도(Fermi temperature)다. 절대 영도에서도 남는 압력 \(P_0\)을 축퇴압(degeneracy pressure)이라 한다. 금속 전자는 \(T_\mathrm F \sim 10^4\)–\(10^5\) K라서 상온은 사실상 "절대 영도"다.

전자 열용량이 작은 이유

온도가 \(T\)로 오르면 무엇이 바뀌는가? 바다 깊은 곳의 전자는 \(kT\)만큼 에너지를 얻어도 갈 곳(빈 궤도)이 없다. 들뜰 수 있는 것은 \(E_\mathrm F\) 근처 폭 \(\sim kT\) 안의 전자, 전체의 약 \(kT/E_\mathrm F\)뿐이다. 이 전자들이 각각 \(\sim kT\)를 얻으니 \(U - U_0 \sim N(kT)^2/E_\mathrm F\), 열용량은 \(Nk(kT/E_\mathrm F)\) 정도다. 페르미–디랙 적분을 \(kT/E_\mathrm F\)로 전개하는 조머펠트 전개(Sommerfeld expansion)로 계수까지 구하면

$$C_V = \frac{\pi^2}{2}\,Nk\,\frac{kT}{E_\mathrm F} = \frac{\pi^2}{2}Nk\frac{T}{T_\mathrm F},\qquad \mu(T) \approx E_\mathrm F\left[1 - \frac{\pi^2}{12}\left(\frac{kT}{E_\mathrm F}\right)^2\right]$$
고전 기체라면 \(C_V = \frac32 Nk\)이다. 상온 구리에서 \(T/T_\mathrm F \approx 0.004\)이므로 전자의 몫은 고전값의 1% 남짓이다. 19세기 물리학을 괴롭힌 "전자는 왜 열용량에 기여하지 않는가"의 답이 파울리 배타 원리다. 몰당 계수 \(\gamma = \frac{\pi^2}{2}\frac{Rk}{E_\mathrm F}\)(\(C = \gamma T\))를 전자 비열 계수라 한다.

상온(300 K)의 구리에서 열 때문에 페르미 준위 위로 올라가 있는 전도 전자는 전체의 대략 몇 %일까? (\(T_\mathrm F = 8.2\times10^4\) K)

들뜬 전자의 비율은 \(\sim kT/E_\mathrm F\)의 일부다. 정확히는 \(E_\mathrm F\) 위에 있는 전자 수가 \(g(E_\mathrm F)\,kT\ln 2 = \frac{3\ln 2}{2}N\frac{kT}{E_\mathrm F} \approx 1.04\,N\,T/T_\mathrm F\)라서, 300 K 구리에서는 약 0.4%다. 같은 수의 빈자리가 \(E_\mathrm F\) 아래에 생긴다. 실험대에서 \(T/T_\mathrm F = 0.004\) 근처로 끌어 확인하라.

흑체 복사와 플랑크 법칙

뜨거운 공동(cavity) 속의 전자기파는 광자의 기체다. 광자는 보손이지만 수가 보존되지 않는다. 벽이 광자를 마음대로 흡수하고 방출하므로, 계는 자유 에너지가 최소가 되도록 광자 수를 스스로 고른다. \((\partial F/\partial N)_{T,V} = 0\), 즉 광자 기체의 화학 퍼텐셜은 0이다. 그러면 진동수 \(\nu\)인 전자기 모드 하나(궤도 하나)의 평균 광자 수는 보스–아인슈타인 분포에서 \(\mu = 0\)으로 둔 것이다.

$$\bar n(\nu) = \frac{1}{e^{h\nu/kT}-1},\qquad \text{모드 수: } g(\nu)\,d\nu = \frac{8\pi V\nu^2}{c^3}\,d\nu\ \ (\text{편광 2개 포함})$$ $$u(\nu) = \frac{8\pi h\nu^3}{c^3}\,\frac{1}{e^{h\nu/kT}-1},\qquad B_\lambda(T) = \frac{2hc^2}{\lambda^5}\,\frac{1}{e^{hc/\lambda kT}-1}$$
\(u(\nu)\)는 단위 부피·단위 진동수당 에너지, \(B_\lambda\)는 단위 넓이·단위 입체각·단위 파장당 복사 휘도[W/(m²·sr·m)]다. 평평한 흑체 표면이 반구로 내보내는 복사 출사도는 \(\pi B_\lambda\)다. 이것이 플랑크 법칙(Planck's law)이다.

\(B_\lambda\)를 \(\lambda\)로 미분해 꼭대기를 찾으면 빈 변위 법칙(Wien's displacement law)을, 모든 진동수에 대해 적분하면 슈테판–볼츠만 법칙(Stefan–Boltzmann law)을 얻는다.

$$\lambda_\text{max}T = b = 2.898\times10^{-3}\ \text{m·K},\qquad M = \int_0^\infty \pi B_\lambda\,d\lambda = \sigma T^4,\qquad \sigma = \frac{2\pi^5k^4}{15c^2h^3} = 5.670\times10^{-8}\ \frac{\text{W}}{\text{m}^2\text{K}^4}$$
\(\lambda_\text{max}\)은 \(B_\lambda\)의 꼭대기 파장(\(B_\nu\)의 꼭대기와는 다르다). 상온(300 K)은 9.7 µm, 1000 °C 웨이퍼는 2.3 µm, 3000 K 텅스텐 필라멘트는 0.97 µm, 태양 표면(5772 K)은 0.50 µm에서 가장 밝다.

지름 300 mm 웨이퍼가 1000에서 방사율 0.70로 앞뒷면 모두 복사하면, 내보내는 일률은 \(2\varepsilon\sigma T^4 A\) = 이고 스펙트럼 꼭대기는 다. 온도를 100 °C 올리면 복사 손실은 배가 된다 — RTP 램프가 고온에서 출력을 급히 늘려야 하는 이유다.

방사율과 고온계

실제 물체는 같은 온도의 흑체보다 덜 복사한다. 그 비율이 방사율(emissivity) \(\varepsilon(\lambda, T)\)이다. 열평형에서 물체가 받는 복사와 내는 복사가 파장마다 같아야 하므로, 방사율은 흡수율과 같다 — 키르히호프 복사 법칙(Kirchhoff's law of thermal radiation). 불투명하면 \(\varepsilon = 1 - R\)(반사율)이다. 방사율이 파장에 무관한 물체를 회색체라 한다.

웨이퍼에 접촉하지 않고 온도를 재는 고온계(pyrometer)는 좁은 파장 \(\lambda\)에서 복사 휘도 \(\varepsilon B_\lambda(T)\)를 잰다. 방사율을 \(\varepsilon_\text{set}\)으로 가정했는데 실제가 \(\varepsilon\)이면, 빈 근사(\(e^{hc/\lambda kT}\gg1\))에서

$$\frac{1}{T_\text{read}} - \frac1T = \frac{\lambda}{c_2}\ln\frac{\varepsilon_\text{set}}{\varepsilon}\quad\Longrightarrow\quad \Delta T \approx \frac{\lambda T^2}{c_2}\ln\frac{\varepsilon}{\varepsilon_\text{set}},\qquad c_2 = \frac{hc}{k} = 14\,388\ \text{µm·K}$$
오차는 \(\lambda\)에 비례하므로 짧은 파장의 고온계가 방사율 오차에 덜 민감하다. 두 파장 \(\lambda_1, \lambda_2\)의 휘도 비를 재는 2색 고온계(two-color pyrometer)는 회색체라면 \(\varepsilon\)이 약분되어 사라진다: \(T = c_2\left(\frac1{\lambda_1}-\frac1{\lambda_2}\right)\Big/\left[5\ln\frac{\lambda_2}{\lambda_1} - \ln\frac{B_1}{B_2}\right]\).

0.95 µm 단색 고온계가 웨이퍼 방사율을 0.70으로 가정하고 있다. 뒷면에 막이 입혀져 실제 방사율이 0.60이라면 고온계가 읽는 온도는?

실제로 나오는 복사가 고온계의 가정보다 약하니, 고온계는 "덜 뜨겁다"고 판단한다. 1000 °C에서 오차는 약 \(\frac{\lambda T^2}{c_2}\ln\frac{0.60}{0.70} = -17\) K다. 이 상태로 온도 되먹임 제어를 하면 램프가 출력을 올려 실제 웨이퍼는 17 K 더 뜨거워진다. 실험대의 "단색 고온계" 판독으로 확인하라.

포논 기체와 디바이 열용량

결정의 격자 진동도 정상파 모드의 모임이고, 진동수 \(\omega\)인 모드의 에너지 양자 \(\hbar\omega\)를 포논(phonon)이라 한다. 광자처럼 수가 보존되지 않으니 \(\mu = 0\)인 보손이고, 모드마다 평균 포논 수는 \(1/(e^{\hbar\omega/kT}-1)\)이다. 광자와 다른 점은 원자 \(N\)개의 결정에 모드가 정확히 \(3N\)개뿐이라는 것이다. 6장의 아인슈타인 모형은 \(3N\)개 모드가 모두 같은 진동수 \(\omega_\mathrm E\)라고 보았다. 디바이 모형(Debye model)은 대신 광자처럼 모드 수가 \(\omega^2\)에 비례하는 음파(\(\omega = v_s k\))로 보고, 모드가 \(3N\)개가 되는 차단 진동수 \(\omega_\mathrm D\)에서 끊는다.

$$C_V = 9Nk\left(\frac{T}{\theta_\mathrm D}\right)^3\int_0^{\theta_\mathrm D/T}\frac{x^4e^x}{(e^x-1)^2}\,dx,\qquad \theta_\mathrm D = \frac{\hbar\omega_\mathrm D}{k}$$ $$T \ll \theta_\mathrm D:\quad C_V = \frac{12\pi^4}{5}Nk\left(\frac{T}{\theta_\mathrm D}\right)^3 = 1944\left(\frac{T}{\theta_\mathrm D}\right)^3\ \text{J/(mol·K)},\qquad T \gg \theta_\mathrm D:\ C_V \to 3Nk$$
\(\theta_\mathrm D\)를 디바이 온도(Debye temperature)라 한다(Si 645 K, Cu 343 K, 다이아몬드 2230 K, 대표값). 저온의 \(T^3\) 법칙은 흑체의 \(T^4\) 에너지와 같은 뿌리다: \(kT\)보다 낮은 음향 모드만 들뜨고 그 수가 \(T^3\)에 비례한다. 분산 관계와 포논 상태 밀도는 고체물리 · 포논, 실측 열용량 맞추기는 고체물리 · 열적 성질.

보스–아인슈타인 응축

이번에는 수가 보존되는 보손(⁴He, ⁸⁷Rb 원자)이다. 입자 수가 정해져 있으니 \(\mu\)는 \(N = \sum_i 1/(e^{(\varepsilon_i-\mu)/kT}-1)\)이 되도록 정해지고, 보손이므로 늘 \(\mu < \varepsilon_0 = 0\)이다. 온도를 낮추면 같은 \(N\)을 담기 위해 \(\mu\)가 0에 다가간다. 그런데 들뜬 상태(\(\varepsilon > 0\))에 담을 수 있는 입자 수에는 \(\mu \to 0\)에서의 상한이 있다.

$$N_\text{들뜸} \le \int_0^\infty \frac{g(\varepsilon)\,d\varepsilon}{e^{\varepsilon/kT}-1} = 2.612\,\frac{V}{\lambda^3}\qquad\Longrightarrow\qquad kT_c = \frac{2\pi\hbar^2}{m}\left(\frac{n}{2.612}\right)^{2/3},\qquad \frac{N_0}{N} = 1 - \left(\frac{T}{T_c}\right)^{3/2}\ (T < T_c)$$
\(2.612 = \zeta(3/2)\). \(n\lambda^3\)이 2.612를 넘으면 남는 입자가 모두 바닥 상태 하나에 몰린다. 이것이 보스–아인슈타인 응축(Bose–Einstein condensation)이다. 응축은 실공간에서 입자가 모이는 것이 아니라 운동량 0인 한 상태에 거시적인 수가 들어가는 것이다.

검토 자릿수와 "수 K"라는 크기가 맞는다. 차이는 액체 헬륨 원자들 사이의 강한 상호 작용 때문이고, 같은 이유로 2.17 K 아래 초유체에서도 운동량 0 상태의 비율은 10% 남짓이다. 반면 페르미온인 ³He는 이 온도에서 응축하지 않고, mK까지 내려가 원자가 짝을 지은 뒤에야 초유체가 된다.

핵심 정리

  1. 동일 입자의 미시 상태는 점유수만으로 정해진다. 에너지가 같은 \(g\)개 상태에 \(N\)개: 구별 \(g^N\), 보손 \(\binom{N+g-1}{N}\), 페르미온 \(\binom gN\)(파울리 배타). \(g \gg N\)이면 모두 \(g^N/N!\) — 고전 극한.
  2. 대정준 앙상블: 저장체와 에너지·입자를 교환하는 계의 확률은 깁스 인자 \(P(s) = e^{-(E_s-\mu N_s)/kT}/\mathcal Z\). \(\langle N\rangle = kT\,\partial\ln\mathcal Z/\partial\mu\), \(\Phi = -kT\ln\mathcal Z = U - TS - \mu N = -PV\). 이상 기체의 \(\mu = kT\ln(n\lambda^3)\), \(\lambda = h/\sqrt{2\pi mkT}\).
  3. 분포 함수: 궤도 하나를 계로 보면 \(\bar n = 1/(e^{(\varepsilon-\mu)/kT}\pm1)\)(FD는 +, BE는 −), 고전 극한 \(e^{-(\varepsilon-\mu)/kT}\). FD는 \(\varepsilon = \mu\)에서 1/2, 폭 약 \(4kT\). 고전 극한의 조건은 \(n\lambda^3/g_s \ll 1\)(가볍고 차갑고 빽빽하면 양자).
  4. 축퇴 페르미 기체: \(E_\mathrm F = \frac{\hbar^2}{2m}(3\pi^2n)^{2/3}\), \(g(E) = \frac{3N}{2E_\mathrm F}\sqrt{E/E_\mathrm F}\), \(U_0 = \frac35NE_\mathrm F\), \(P_0 = \frac25nE_\mathrm F\). 페르미 면 근처 \(kT\) 폭만 들떠 \(C_V = \frac{\pi^2}{2}Nk\,T/T_\mathrm F\), \(\mu \approx E_\mathrm F[1-\frac{\pi^2}{12}(T/T_\mathrm F)^2]\). 금속 \(T_\mathrm F\sim10^4\)–\(10^5\) K.
  5. 반도체 캐리어: \(n = N_c\mathcal F_{1/2}(\eta)\), \(N_c = 2/\lambda^{*3}\)(스핀 × 양자 농도). \(E_c - E_\mathrm F > 3kT\)이면 볼츠만 근사 \(n = N_ce^{-(E_c-E_\mathrm F)/kT}\)의 오차가 2% 이하, \(E_\mathrm F = E_c\)에서는 31% 과대 평가.
  6. 흑체 복사: 광자 기체는 \(\mu = 0\)인 보손. \(B_\lambda = \frac{2hc^2}{\lambda^5}\frac{1}{e^{hc/\lambda kT}-1}\), \(\lambda_\text{max}T = 2898\) µm·K, \(M = \varepsilon\sigma T^4\). 단색 고온계의 오차 \(\Delta T \approx \frac{\lambda T^2}{c_2}\ln\frac{\varepsilon}{\varepsilon_\text{set}}\)는 짧은 파장일수록 작고, 2색 고온계는 회색체의 \(\varepsilon\)을 약분한다.
  7. 보스 기체: 포논은 \(\mu = 0\), 모드 \(3N\)개 → 디바이 \(C_V \to 1944(T/\theta_\mathrm D)^3\) J/(mol·K)(저온), \(3R\)(고온). 수가 보존되는 보손은 \(n\lambda^3 > 2.612\)에서 응축: \(kT_c = \frac{2\pi\hbar^2}{m}(n/2.612)^{2/3}\), \(N_0/N = 1-(T/T_c)^{3/2}\).

연습문제

상수: \(h = 6.626\times10^{-34}\) J·s, \(\hbar = 1.0546\times10^{-34}\) J·s, \(k = 1.381\times10^{-23}\) J/K \(= 8.617\times10^{-5}\) eV/K, \(m_e = 9.109\times10^{-31}\) kg, \(u = 1.6605\times10^{-27}\) kg, \(\sigma = 5.670\times10^{-8}\) W/(m²·K⁴), \(b = 2.898\times10^{-3}\) m·K, \(c_2 = 14\,388\) µm·K. 따로 말이 없으면 답이 ±1% 이내면 정답이다.

에너지가 같은 상태 5개에 동일 입자 2개를 넣는 방법의 수를 페르미온과 보손에 대해 각각 구하라.

페르미온은 \(\binom gN\), 보손은 \(\binom{N+g-1}{N}\).

페르미온 \(\binom52 = 10\), 보손 \(\binom62 = 15\). 차이 5는 두 입자가 같은 상태에 있는 경우(5가지)다. 구별되는 입자라면 \(5^2 = 25\)이고, \(25/2! = 12.5\)는 두 값의 평균이다.

다음 중 페르미–디랙 통계를 따르는 것은?

³He는 양성자 2개·중성자 1개·전자 2개, 모두 7개의 스핀 ½ 입자로 이루어져 전체 스핀이 반정수 → 페르미온. ⁴He는 입자 8개로 정수 스핀 → 보손. 광자(스핀 1)와 포논은 보손이다.

300 K에서 화학 퍼텐셜보다 0.10 eV 위에 있는 궤도의 페르미–디랙 점유수를 구하라.

\(kT = 8.617\times10^{-5}\times300 = 0.02585\) eV, \(x = 0.10/0.02585 = 3.87\). \(f = 1/(e^{3.87}+1) = 1/(47.9+1) = 0.0205\). \(x > 3\)이라 볼츠만 값 \(e^{-3.87} = 0.0209\)과 2% 차이다.

표면 흡착 자리 하나는 비어 있거나(에너지 0) 원자 하나가 결합 에너지 \(-0.45\) eV로 붙어 있다. 기체의 화학 퍼텐셜이 \(\mu = -0.40\) eV, 온도가 300 K일 때 자리가 차 있을 확률은?

\(\mathcal Z = 1 + e^{-(\varepsilon-\mu)/kT}\), \(\varepsilon = -0.45\) eV.

\((\varepsilon-\mu)/kT = (-0.45+0.40)/0.025852 = -1.934\). \(\theta = e^{1.934}/(1+e^{1.934}) = 1/(e^{-1.934}+1) = 0.874\). 압력을 낮춰 \(\mu\)가 내려가면 θ도 줄어든다(랭뮤어 등온선).

300 K, 1 bar의 헬륨 기체(\(M = 4.0026\) g/mol)의 화학 퍼텐셜을 eV로 구하라.

\(m = 6.646\times10^{-27}\) kg, \(\lambda = h/\sqrt{2\pi mkT} = 5.04\times10^{-11}\) m. \(n = P/kT = 2.414\times10^{25}\) m⁻³. \(n\lambda^3 = 3.09\times10^{-6}\), \(\ln = -12.69\). \(\mu = 0.02585\times(-12.69) = -0.328\) eV. 아르곤(−0.417 eV)보다 덜 음수인 것은 가벼워 \(\lambda\)가 길기 때문이다.

전도 전자 농도가 \(10^{18}\) cm⁻³인 반도체에서 300 K 전자의 \(n\lambda^3\)을 구하라(질량은 \(m_e\)). 볼츠만 근사를 써도 되는가?

\(\lambda = 4.30\times10^{-9}\) m, \(\lambda^3 = 7.97\times10^{-26}\) m³, \(n = 10^{24}\) m⁻³. \(n\lambda^3 = 0.0797\). 스핀 2로 나눈 0.04가 1보다 훨씬 작으니 볼츠만 근사가 통한다(오차 약 1.5%). 도핑을 10배 더 올리면 경계에 닿는다.

알루미늄(원자당 전도 전자 3개, \(n = 1.81\times10^{29}\) m⁻³)의 페르미 에너지와 페르미 온도를 구하라.

\(3\pi^2n = 5.359\times10^{30}\), \((\cdot)^{2/3} = 3.061\times10^{20}\) m⁻². \(E_\mathrm F = 6.104\times10^{-39}\times3.061\times10^{20} = 1.869\times10^{-18}\) J \(= 11.7\) eV. \(T_\mathrm F = 1.35\times10^5\) K.

구리의 저온 열용량은 \(C = \gamma T + AT^3\)이고 \(\gamma = 0.695\) mJ/(mol·K²), 디바이 온도 \(\theta_\mathrm D = 343\) K다. 전자 몫과 포논 몫이 같아지는 온도 \(T^*\)를 구하라.

\(A = \frac{12\pi^4}{5}\frac{R}{\theta_\mathrm D^3}\).

\(A = 1944/343^3 = 4.817\times10^{-5}\) J/(mol·K⁴). \(\gamma T^* = AT^{*3}\) → \(T^* = \sqrt{\gamma/A} = \sqrt{6.95\times10^{-4}/4.817\times10^{-5}} = 3.80\) K. 이보다 차가우면 전자가 열을 더 많이 담는다.

구리 전도 전자(\(n = 8.47\times10^{28}\) m⁻³, \(E_\mathrm F = 7.03\) eV)의 절대 영도 축퇴압을 구하라. 구리의 부피 탄성률 약 140 GPa과 비교하면?

\(U_0 = \frac35NE_\mathrm F\), \(P = \frac23 U/V\).

\(P_0 = \frac25nE_\mathrm F = 0.4\times8.47\times10^{28}\times7.03\times1.602\times10^{-19} = 3.82\times10^{10}\) Pa = 38 GPa. 부피 탄성률과 같은 자릿수다. 금속이 쉽게 압축되지 않는 이유의 상당 부분이 전자의 축퇴압이고, 이 압력을 이온과의 인력이 붙잡고 있다. 백색 왜성을 버티게 하는 것도 같은 압력이다.

700 °C 웨이퍼의 복사 휘도 \(B_\lambda\)가 가장 큰 파장은?

\(T = 973.15\) K, \(\lambda_\text{max} = 2.898\times10^{-3}/973.15 = 2.98\times10^{-6}\) m = 2.98 µm.

지름 300 mm 웨이퍼가 1050 °C, 방사율 0.68로 앞뒷면 모두 복사한다. 복사로 잃는 일률을 kW로 구하라(주위에서 받는 복사는 무시).

\(A = \pi(0.15)^2 = 0.07069\) m², \(T = 1323.15\) K, \(\sigma T^4 = 1.738\times10^5\) W/m². \(P = 2\times0.68\times1.738\times10^5\times0.07069 = 1.67\times10^4\) W = 16.7 kW. 정상 상태에서 램프가 이만큼을 공급해야 한다.

0.95 µm 단색 고온계가 방사율을 0.70으로 가정한다. 실제 웨이퍼는 1100 °C, 방사율 0.65다. 고온계는 몇 K만큼 낮게 읽는가?

\(\Delta T \approx \frac{\lambda T^2}{c_2}\ln\frac{\varepsilon}{\varepsilon_\text{set}}\).

\(T = 1373.15\) K, \(\lambda T^2/c_2 = 0.95\times1373.15^2/14388 = 124.5\) K. \(\ln(0.65/0.70) = -0.0741\). \(\Delta T = -9.2\) K. 플랑크 식을 정확히 풀어도 \(-9.2\) K다. 되먹임 제어라면 실제 웨이퍼는 목표보다 9 K 뜨거워진다.

2색 고온계가 0.90 µm와 1.05 µm에서 휘도 비 \(B_1/B_2 = 0.300\)을 쟀다. 회색체로 보고 웨이퍼 온도를 K로 구하라.

\(T = c_2(1/\lambda_1 - 1/\lambda_2)/[5\ln(\lambda_2/\lambda_1) - \ln(B_1/B_2)] = 14388\times0.15873/(0.7708 + 1.2040) = 2283.8/1.9748 = 1157\) K(884 °C). 온도가 낮을수록 짧은 파장 쪽이 상대적으로 어두워져 비가 작아진다.

실리콘(\(\theta_\mathrm D = 645\) K)의 15 K 몰 열용량을 디바이 \(T^3\) 법칙으로 구하라.

\(C_V = 1944\times(15/645)^3 = 1944\times1.258\times10^{-5} = 0.0244\) J/(mol·K). 실온 값(약 20 J/(mol·K))의 천분의 1이다. 극저온 검출기와 양자 소자의 냉각이 빠른 것은 열용량이 이렇게 작기 때문이다.

⁸⁷Rb 원자(\(m = 86.909\,u\)) 기체의 농도가 \(5.0\times10^{19}\) m⁻³이다. 이상 보스 기체의 상자 공식으로 \(T_c\)를 nK로 구하고, \(T = T_c/2\)에서 바닥 상태에 있는 원자의 비율을 구하라.

\(m = 1.4432\times10^{-25}\) kg, \(2\pi\hbar^2/(mk) = 3.504\times10^{-20}\) m²·K. \((n/2.612)^{2/3} = (1.914\times10^{19})^{2/3} = 7.16\times10^{12}\) m⁻². \(T_c = 2.51\times10^{-7}\) K = 251 nK. \(N_0/N = 1 - 0.5^{3/2} = 0.646\).

이상 기체에 맥스웰–볼츠만 통계를 써도 되는 조건으로 가장 알맞은 것은? (\(\lambda\)는 열적 드브로이 파장)

모든 궤도에서 \(\bar n \ll 1\)이어야 하고, 이는 \(e^{\mu/kT} = n\lambda^3/g_s \ll 1\)과 같다. \(\mu\)는 큰 음수가 된다.

개념 확인 퀴즈

광자 기체의 화학 퍼텐셜이 0인 이유는?

벽이 광자를 자유롭게 흡수·방출하므로 평형에서 \((\partial F/\partial N)_{T,V} = \mu = 0\)이다. 포논도 같은 이유로 \(\mu = 0\)이다. 질량이 없는 것과는 무관하다.

금속 전자의 열용량이 고전 기체 값 \(\frac32Nk\)보다 훨씬 작은 이유는?

깊은 곳의 전자는 \(kT\)를 받아도 옮겨 갈 빈 궤도가 없다. 들뜰 수 있는 전자는 약 \(N\,kT/E_\mathrm F\)개이고 그래서 \(C_V \propto T/T_\mathrm F\)다.

반도체에서 \(E_c - E_\mathrm F = 5kT\)일 때 전자 농도를 \(N_c e^{-(E_c-E_\mathrm F)/kT}\)로 써도 되는 이유는?

\(e^{(E-E_\mathrm F)/kT} \ge e^5 \approx 150\)이라 분모의 1을 버려도 1% 미만의 오차다. 이것이 \(n/N_c = n\lambda^{*3}/2 \ll 1\), 곧 고전 극한이다.

RTP에서 2색 고온계가 단색 고온계보다 유리한 점은?

\(B_1/B_2\)에서 \(\varepsilon\)이 약분되는 것은 두 파장의 방사율이 같을 때뿐이다. 박막 간섭으로 \(\varepsilon(\lambda)\)가 출렁이는 패턴 웨이퍼에서는 여전히 오차가 남는다.

보손 기체를 \(T_c\) 아래로 식힐 때 일어나는 일로 옳은 것은?

들뜬 상태의 최대 수용량은 \(2.612V/\lambda^3 \propto T^{3/2}\)라서 온도가 내려가면 줄어든다. 넘치는 입자는 운동량 0 상태로 가고, \(N_0/N = 1-(T/T_c)^{3/2}\)이다. 응축은 운동량 공간의 현상이다.
