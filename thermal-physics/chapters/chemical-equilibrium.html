Chapter 12

화학 평형

반응은 끝까지 가지 않는다. 실레인을 흘려 폴리실리콘을 입히든, 트라이클로로실레인과 수소로 에피층을 기르든, 반응기 출구에는 언제나 반응물과 생성물이 정해진 비율로 섞여 나온다. 아래 두 상자에서 분자 BC는 저절로 B와 C로 쪼개지고, B와 C는 만나면 다시 붙는다. 왼쪽은 BC만, 오른쪽은 B와 C만으로 시작했지만 두 상자의 비 \(Q = N_\mathrm{B}N_\mathrm{C}/(N_\mathrm{BC}V)\)는 같은 값으로 모인다. 그 값이 평형 상수 \(K\)이고, 열역학은 그것이 \(K = e^{-\Delta_\mathrm rG^\circ/RT}\)임을 말해 준다. 이 장은 그 수 하나로 공정 반응기의 조성, 온도·압력의 효과, 금속이 산화될지 환원될지까지 읽는 법을 다룬다.

상자를 누르면 BC 분자를 더 넣는다
  • 반응 진행도 \(\xi\)로 깁스 에너지 \(G(\xi)\)를 쓰고, 최솟값 조건 \(\Delta_\mathrm rG = 0\)에서 \(\Delta_\mathrm rG^\circ = -RT\ln K\)를 유도한다.
  • 무차원 평형 상수 \(K\)와 \(K_P\), \(K_c\), \(K_x\)를 서로 바꾸고, 해리도와 불균일 평형(고체 활동도 1)을 계산한다.
  • 반트호프 식 \(d\ln K/d(1/T) = -\Delta H^\circ/R\)으로 \(K(T)\)를 옮기고, \(\Delta C_P\) 일정 근사와 엘링엄 근사(\(\Delta C_P = 0\))의 차이를 안다.
  • 압력·온도·비활성 기체·원료 주입이 평형을 어느 쪽으로 미는지 르샤틀리에 원리와 정량 계산으로 판단한다.
  • 독립 반응의 수를 세고, 원소 퍼텐셜(깁스 최소화)로 Si–Cl–H 계 같은 다중 평형의 조성과 증착 수율을 구한다.
  • 엘링엄 도표에서 산화물의 안정성 순서, 평형 산소 분압, H₂O/H₂·CO₂/CO 비를 읽고 high-k 계면층, 선택 산화, 포밍 가스 환원에 적용한다.
  • SiH₄·SiH₂Cl₂·SiHCl₃·WF₆·Si₃N₄ CVD 반응의 \(\Delta_\mathrm rG^\circ(T)\)와 평형 전환율을 계산하고, 열역학 한계와 속도론 한계를 구별한다.

반응 진행도와 깁스 에너지 최소

4장에서 \(\ce{A <=> B}\) 한 가지 반응의 깁스 에너지 지형을 보았다. 이제 일반적인 반응 \(\sum_i \nu_i\mathrm A_i = 0\)(반응물의 화학량론 계수 \(\nu_i\)는 음수, 생성물은 양수)으로 넓히자. 반응이 \(d\xi\)만큼 진행하면 모든 물질의 몰수가 같은 비율로 바뀐다: \(dn_i = \nu_i\,d\xi\). 이것이 반응 진행도 \(\xi\)의 정의다. 일정 \(T, P\)에서 깁스 에너지의 변화는

$$dG = \sum_i\mu_i\,dn_i = \Big(\sum_i\nu_i\mu_i\Big)d\xi\qquad\Rightarrow\qquad \Delta_\mathrm rG \equiv \Big(\frac{\partial G}{\partial\xi}\Big)_{T,P} = \sum_i\nu_i\mu_i$$
\(\Delta_\mathrm rG\)는 "지금 조성에서" 반응이 조금 더 진행할 때 \(G\)가 얼마나 바뀌는지를 몰당으로 잰 기울기다. 이름에 \(\Delta\)가 붙었지만 두 상태의 차이가 아니라 미분이다.

화학 퍼텐셜을 활동도 \(a_i\)로 쓰면 \(\mu_i = \mu_i^\circ + RT\ln a_i\)다. 이상 기체는 \(a_i = P_i/P^\circ\)(\(P^\circ = 1\) bar), 순수한 고체·액체는 \(a_i = 1\), 묽은 용액의 용질은 10장에서 본 대로 \(a_i\approx c_i/c^\circ\)다. 넣으면

$$\Delta_\mathrm rG = \Delta_\mathrm rG^\circ + RT\ln Q,\qquad Q = \prod_i a_i^{\nu_i},\qquad \Delta_\mathrm rG^\circ = \sum_i\nu_i\mu_i^\circ = \sum_i\nu_i\Delta_\mathrm fG_i^\circ$$

\(G\)가 최소인 곳에서 기울기는 0이다. 그 조성의 \(Q\)를 \(K\)라 쓰면 열역학이 화학에 준 가장 쓸모 있는 식이 나온다.

평형 상수

$$\Delta_\mathrm rG^\circ = -RT\ln K,\qquad K = \prod_i a_{i,\mathrm{eq}}^{\nu_i} = \exp\!\Big(-\frac{\Delta_\mathrm rG^\circ}{RT}\Big)$$ 평형 상수(equilibrium constant) \(K\)는 평형에서의 활동도 곱이다. 활동도는 무차원이라 \(K\)도 무차원이며, 표준 상태(\(P^\circ\))와 반응식의 계수를 정해야 값이 정해진다. 반응식을 2배 하면 \(K\)는 제곱, 뒤집으면 역수가 된다. 지금 조성의 활동도 곱 \(Q\)는 반응 지수(reaction quotient)이고, \(\Delta_\mathrm rG = RT\ln(Q/K)\)이므로 \(QK\)이면 역반응이 저절로 일어난다.

왜 반응이 중간에서 멈추는가? 대표적인 예 \(\ce{N2O4(g) <=> 2NO2(g)}\)로 \(G(\xi)\)를 직접 지어 보자(처음 N₂O₄ 1 mol, 전체 압력 \(P\)). 몰수는 \(n_{\mathrm{N_2O_4}} = 1-\xi\), \(n_{\mathrm{NO_2}} = 2\xi\), 합 \(n = 1+\xi\)이다.

$$G(\xi) = \underbrace{(1-\xi)\mu^\circ_{\mathrm{N_2O_4}} + 2\xi\,\mu^\circ_{\mathrm{NO_2}}}_{\text{순수 물질 직선}} + \underbrace{(1+\xi)RT\ln\frac{P}{P^\circ}}_{\text{압력 항}} + \underbrace{RT\Big[(1-\xi)\ln y_{\mathrm{N_2O_4}} + 2\xi\ln y_{\mathrm{NO_2}}\Big]}_{\text{혼합 항}\ (<0)}$$
몰분율 \(y_{\mathrm{N_2O_4}} = (1-\xi)/(1+\xi)\), \(y_{\mathrm{NO_2}} = 2\xi/(1+\xi)\). 혼합 항의 기울기는 \(\xi\to0\)에서 \(-\infty\)라서 순수한 반응물(또는 생성물)은 결코 평형이 아니다. 기체 몰수가 늘어나는 반응(\(\Delta n = +1\))이라 압력 항의 기울기 \(RT\ln(P/P^\circ)\)가 압력을 올릴수록 평형을 왼쪽으로 민다.

330 K에서 N₂O₄ 1 mol을 1 bar로 두면 평형 진행도는 \(\xi_\mathrm{eq}\approx0.50\)이다. 피스톤을 눌러 전체 압력을 10 bar로 올리면 골짜기 바닥은 어디로 갈까?

\(K = \frac{y_{\mathrm{NO_2}}^2}{y_{\mathrm{N_2O_4}}}\frac{P}{P^\circ} = \frac{4\xi^2}{1-\xi^2}\frac{P}{P^\circ}\)에서 \(K\)는 그대로(1.35)지만 \(P\)가 10배가 되면 몰분율의 비가 10분의 1로 줄어야 한다. \(\xi = \sqrt{K/(K+4P/P^\circ)} = 0.18\). 시뮬레이터에서 압력을 올리며 바닥이 왼쪽으로 미끄러지는지 보라.

평형 상수의 여러 얼굴: K, KP, Kc와 분자 그림

평형 상수는 거시 열역학에서 나왔지만, 분자 수준에서도 똑같은 수가 나온다. 머리 그림의 반응 \(\ce{BC <=> B + C}\)에서 BC 하나가 단위 시간에 쪼개질 확률을 \(k_\mathrm f\), 부피 \(V\) 안에서 B 하나와 C 하나가 만나 붙을 빈도를 \(k_\mathrm b/V\)라 하자. 평형에서는 쪼개지는 사건과 붙는 사건의 수가 같다.

$$k_\mathrm f N_\mathrm{BC} = \frac{k_\mathrm b}{V}N_\mathrm BN_\mathrm C\qquad\Rightarrow\qquad \frac{N_\mathrm BN_\mathrm C}{N_\mathrm{BC}V} = \frac{k_\mathrm f}{k_\mathrm b} = K_c$$
정반응 속도와 역반응 속도가 같다는 이 조건을 상세 균형(detailed balance)이라 한다. 평형에서 반응이 멈춘 것이 아니라 양방향 사건이 같은 빈도로 계속 일어난다. 평형 농도의 곱이 일정하다는 결과는 19세기에 굴베르와 보게가 실험에서 찾은 질량 작용 법칙(law of mass action)이다.

열역학의 \(K\)는 무차원이지만, 실험실에서는 분압이나 농도로 쓴 상수를 많이 쓴다. 이상 기체에서 \(a_i = P_i/P^\circ = y_iP/P^\circ = c_iRT/P^\circ\)이므로, 기체 몰수 변화 \(\Delta n = \sum_{\text{기체}}\nu_i\)에 따라 다음과 같이 바뀐다.

$$K = K_P\,(P^\circ)^{-\Delta n} = K_c\Big(\frac{c^\circ RT}{P^\circ}\Big)^{\Delta n} = K_x\Big(\frac{P}{P^\circ}\Big)^{\Delta n}$$
\(K_P = \prod P_i^{\nu_i}\)(bar\(^{\Delta n}\)), \(K_c = \prod c_i^{\nu_i}\)(\(c^\circ = 1\) mol/L 기준), \(K_x = \prod y_i^{\nu_i}\). \(K\)와 \(K_c\)는 \(T\)만의 함수지만 \(K_x\)는 압력에 따라 바뀐다. \(\Delta n = 0\)이면 넷이 모두 같다. \(c^\circ RT/P^\circ\)는 \(T\)[K]\(\times0.08314\)다.

반트호프 식: 온도가 K를 옮긴다

4장의 깁스–헬름홀츠 식 \(\partial(\Delta G^\circ/T)/\partial(1/T) = \Delta H^\circ\)에 \(\Delta_\mathrm rG^\circ = -RT\ln K\)를 넣으면, 평형 상수의 온도 의존성이 반응 엔탈피 하나로 정해진다.

반트호프 식

$$\frac{d\ln K}{dT} = \frac{\Delta_\mathrm rH^\circ}{RT^2}\qquad\Longleftrightarrow\qquad \frac{d\ln K}{d(1/T)} = -\frac{\Delta_\mathrm rH^\circ}{R}$$ 반트호프 식(van 't Hoff equation). 흡열 반응(\(\Delta H^\circ>0\))은 온도가 오르면 \(K\)가 커지고, 발열 반응은 작아진다. \(\ln K\)를 \(1/T\)에 대해 그리면 기울기가 \(-\Delta H^\circ/R\)인 직선(반트호프 그림)이 되고, 절편은 \(\Delta S^\circ/R\)이다.

\(\Delta H^\circ\)가 일정하다고 두고 적분하면 클라우지우스–클라페이롱 식(9장)과 똑같은 꼴이 된다. 증기압은 증발 반응 \(\ce{A(l) <=> A(g)}\)의 평형 상수 \(K = P_\text{vap}/P^\circ\)이므로 당연하다.

$$\ln\frac{K_2}{K_1} = -\frac{\Delta_\mathrm rH^\circ}{R}\Big(\frac1{T_2} - \frac1{T_1}\Big)\qquad(\Delta H^\circ\ \text{일정, 곧 }\Delta C_P = 0)$$
넓은 온도 범위에서는 \(\Delta H^\circ\) 자체가 키르히호프 법칙(2장) \(d\Delta H^\circ/dT = \Delta C_P^\circ\)로 바뀐다. 이 책의 계산기(Thermo.rxnAt)는 \(\Delta C_P\)를 298 K 값으로 고정한 근사를 쓴다: \(\Delta H^\circ(T) = \Delta H^\circ_{298} + \Delta C_P(T - 298)\), \(\Delta S^\circ(T) = \Delta S^\circ_{298} + \Delta C_P\ln(T/298)\). 실제 \(C_P\)는 온도에 따라 커지므로 1000 K 위에서는 이 근사의 \(K\)가 문헌값과 수십 % 다를 수 있다. \(\Delta C_P = 0\)으로 두는 더 거친 근사가 6절의 엘링엄 근사다.

분자 그림으로도 같은 식이 나온다. 2절의 \(K_c = k_\mathrm f/k_\mathrm b\)에서 정·역반응의 속도 상수가 각각 아레니우스 꼴(13장) \(k = A e^{-E_a/RT}\)이면 \(K_c\propto e^{-(E_{a,\mathrm f} - E_{a,\mathrm b})/RT}\)이고, 두 활성화 에너지의 차이가 곧 반응 엔탈피(정확히는 내부 에너지)다. 분자 상자 시뮬레이터의 온도 슬라이더는 이 관계로 \(k_\mathrm f\)를 바꾼다.

암모니아 합성(\(\Delta H^\circ = -91.8\) kJ/mol)의 \(K\)는 298 K에서 \(5.4\times10^5\)이다. 700 K(하버 공정의 온도)에서는 대략 얼마일까?

발열 반응이라 \(\ln K\)는 \(1/T\)가 줄면(온도가 오르면) 직선적으로 내려간다. \(\Delta C_P\) 일정 근사로 700 K의 \(K = 6.9\times10^{-5}\), 엘링엄 근사로는 \(3.2\times10^{-4}\)이다. 하버 공정이 고온을 쓰는 것은 평형 때문이 아니라 속도(촉매) 때문이고, 낮아진 \(K\)를 고압(4절)으로 메운다. "빨라진다"는 속도론의 이야기이지 평형의 이야기가 아니다.

르샤틀리에 원리: 평형을 흔들면

평형에 있는 계의 조건을 바꾸면 계는 그 변화를 일부 상쇄하는 쪽으로 새 평형을 찾는다. 압력을 올리면 기체 몰수가 줄어드는 쪽으로, 온도를 올리면 열을 흡수하는(흡열) 쪽으로, 물질을 넣으면 그 물질을 소비하는 쪽으로 간다. 이것이 르샤틀리에 원리(Le Chatelier's principle)다. 말로 된 원리는 편리하지만 가끔 틀린다. 정확한 판단은 늘 \(Q\)와 \(K\)의 비교다.

$$\Big(\frac{\partial\ln K}{\partial T}\Big)_P = \frac{\Delta H^\circ}{RT^2},\qquad K_x = K\Big(\frac{P}{P^\circ}\Big)^{-\Delta n}\ \Rightarrow\ \Big(\frac{\partial\ln K_x}{\partial\ln P}\Big)_T = -\Delta n$$
온도는 \(K\) 자체를 바꾸고, 압력은 \(K\)를 그대로 둔 채 몰분율로 쓴 \(K_x\)를 바꾼다. 비활성 기체를 넣으면 일정 부피에서는 분압이 모두 그대로라 \(Q\)가 바뀌지 않고(이동 없음), 일정 압력에서는 반응 기체가 묽어져 압력을 낮춘 것과 같다(\(\Delta n>0\) 쪽으로).

K를 바꾸는 것

온도뿐이다. 흡열 반응은 고온, 발열 반응은 저온에서 \(K\)가 크다. 촉매는 \(K\)를 바꾸지 않고 평형에 닿는 시간만 줄인다.

Q를 바꾸는 것

압력·부피(\(\Delta n\ne0\)일 때), 원료 주입, 생성물 제거, 일정 압력에서의 희석. \(Q\)가 \(K\)에서 벗어난 만큼 반응이 진행해 다시 \(Q = K\)로 돌아온다.

다중 평형과 평형 조성: Si–Cl–H 계

실제 반응기에서는 반응 하나만 일어나지 않는다. 트라이클로로실레인(TCS)과 수소를 1100 °C의 실리콘 위로 흘리면 출구에서 H₂, HCl, SiHCl₃, SiH₂Cl₂, SiCl₄, SiCl₂, 미량의 SiH₄가 함께 나온다. 이 조성을 구하려면 먼저 반응식이 몇 개 필요한지 세야 한다. 물질이 \(S\)가지(응축상 포함)이고 원소가 \(E\)가지라면, 원소 보존이 만드는 행렬(물질 × 원소 조성)의 계수(rank)가 보통 \(E\)이므로

$$\text{독립 반응의 수} = S - \operatorname{rank}(A)\ \ (\text{보통 } S - E)$$
독립 반응(independent reactions)은 서로의 선형 결합으로 만들 수 없는 반응식들이다. Si–Cl–H 계는 기체 7가지 + Si(s) = 8가지, 원소 3가지이므로 5개다. 어떤 5개를 고르든 결과 조성은 같다. 나머지 반응의 \(K\)는 고른 반응들의 \(K\)를 곱하고 나눠 얻는다(헤스 법칙의 평형판).

독립 반응마다 \(K_j = \prod_i a_i^{\nu_{ij}}\)를 쓰고 원소 보존식과 \(\sum P_i = P\)를 더하면 미지수와 식의 수가 맞는다. 그러나 비선형 연립 방정식을 직접 풀기보다 더 깔끔한 길이 있다. 평형은 원소 보존 조건 아래 \(G = \sum_i n_i\mu_i\)의 최소이므로, 라그랑주 승수 \(\lambda_j\)(원소마다 하나)를 쓰면

$$\mu_i = \sum_j a_{ij}\lambda_j\qquad\Rightarrow\qquad \ln\frac{P_i}{P^\circ} = \frac{1}{RT}\Big(\sum_j a_{ij}\lambda_j - \mu_i^\circ\Big)\quad(\text{기체}),\qquad \mu^\circ_{\mathrm{Si(s)}} = \lambda_\mathrm{Si}\ (\text{고체가 있으면})$$
\(a_{ij}\)는 물질 \(i\) 한 분자 속 원소 \(j\)의 원자 수. \(\lambda_j\)는 원소 \(j\) 원자 1 mol의 화학 퍼텐셜로, 원소 퍼텐셜(element potential)이라 부른다. 물질이 몇 가지든 미지수는 원소 수만큼뿐이다. 실리콘 기판이 있으면 \(\lambda_\mathrm{Si}\)는 고체 실리콘이 정하고, 남은 \(\lambda_\mathrm H\), \(\lambda_\mathrm{Cl}\)를 "분압의 합 = \(P\)"와 "기체 속 H/Cl 원자 비 = 원료의 H/Cl 비" 두 식으로 정한다.

금속 M이 산화물이 되는 반응을 산소 1 mol 기준으로 쓰면 \(\frac{2x}{y}\ce{M} + \ce{O2} \to \frac2y\ce{M_xO_y}\)이다. 금속과 산화물이 순수한 고체라면 \(K = 1/P_{\mathrm{O_2}}\)이므로 \(\Delta_\mathrm rG^\circ = RT\ln P_{\mathrm{O_2,eq}}\)이다. 이 \(\Delta_\mathrm rG^\circ\)를 온도에 대해 여러 금속을 한 그림에 그린 것이 엘링엄 도표(Ellingham diagram)다.

$$\Delta_\mathrm rG^\circ(T) \approx \Delta_\mathrm rH^\circ - T\Delta_\mathrm rS^\circ\ (\text{직선}),\qquad P_{\mathrm{O_2,eq}} = \exp\!\Big(\frac{\Delta_\mathrm rG^\circ}{RT}\Big)$$
\(P_{\mathrm{O_2,eq}}\)(bar)는 평형 산소 분압(equilibrium oxygen partial pressure)이다. 분위기의 산소 분압이 이보다 높으면 금속이 산화되고 낮으면 산화물이 환원된다. \(\Delta C_P = 0\)으로 두면(엘링엄 근사) 선은 직선이고, 기울기 \(-\Delta S^\circ\)는 기체 O₂ 1 mol이 고체 속으로 사라지는 엔트로피라 거의 모든 금속에서 +170–200 J/(mol·K)로 비슷하다. 그래서 선들이 거의 나란하다. 녹는점·끓는점에서는 기울기가 꺾이는데, 이 장의 도표는 그 꺾임을 무시한다.

읽는 규칙은 단순하다. 아래에 있는 선일수록 산화물이 안정하다. 같은 온도에서 선 A가 선 B보다 아래면, 금속 A는 산화물 B를 환원한다(B의 산소를 빼앗는다). 두 반응을 빼면 \(\Delta G^\circ = G_A^\circ - G_B^\circ < 0\)이기 때문이다. 탄소의 선 \(\ce{2C + O2 -> 2CO}\)만 기울기가 음수(기체 1 mol이 2 mol이 됨)라 고온으로 갈수록 내려가고, 1909 K(엘링엄 근사)에서 SiO₂ 선과 엇갈린다. 아크로에서 규석을 탄소로 환원해 금속 실리콘을 만드는 온도가 2000 °C 안팎인 이유다.

SiO₂ 위에 알루미늄을 입히고 500 °C 넘게 가열하면 열역학적으로 어떤 일이 일어날 수 있을까?

Al₂O₃ 선(산소 1 mol당 1273 K에서 −851 kJ)이 SiO₂ 선(−678 kJ)보다 한참 아래다. 따라서 \(\ce{4Al + 3SiO2 -> 2Al2O3 + 3Si}\)는 \(\Delta G^\circ\ll0\)이다. 예전 알루미늄 배선 공정에서 콘택 아래 Si가 녹아 들어가는 스파이킹과 Al–SiO₂ 계면 반응이 이 열역학 때문에 생긴다(속도는 온도가 정한다). 시뮬레이터에서 두 선의 위치를 확인하라.

CVD 반응의 열역학

화학 기상 증착(CVD)은 기체 전구체가 표면에서 반응해 고체를 남기는 과정이다. 열역학은 두 가지를 말해 준다. 첫째, 주어진 온도·조성에서 증착이 가능한가: 증착 반응의 \(\Delta_\mathrm rG = RT\ln(Q/K)\)가 음수여야 한다. \(K/Q\)를 과포화도(supersaturation ratio)라 부르면 증착의 구동력은 \(RT\ln(K/Q)\)이고, 이것이 14장 핵생성의 \(\Delta G_v\)가 된다. 둘째, 평형에 닿았을 때 원료의 몇 %가 막이 되는가: 평형 전환율, 곧 증착 수율(deposition yield)의 상한이다. 실제 성장 속도와 균일도는 표면 반응 속도와 기체 수송이 정하므로(14장), 열역학은 "가능한가"와 "최대 얼마인가"까지만 답한다.

$$\ce{SiH4(g) -> Si(s) + 2H2(g)}\quad \Delta H^\circ = -34.3\ \text{kJ},\ \Delta S^\circ = +75.5\ \text{J/K}$$

실레인 분해는 발열이면서 기체 몰수가 늘어 모든 온도에서 \(K\gg1\)이다(900 K에서 \(5\times10^6\)). 평형만 보면 실레인은 상온에서도 실리콘과 수소로 쪼개져야 하지만 Si–H 결합을 끊는 장벽 때문에 실린더 안에서 수년간 버틴다. LPCVD 폴리실리콘의 580–650 °C는 열역학이 아니라 속도가 정한 온도다. 반면 염소가 붙은 전구체는 흡열이라 고온이 필요하고, 염소가 많을수록 더 높은 온도에서야 \(K\)가 1을 넘는다. 생성되는 HCl이 역반응(식각)을 일으키기 때문이다.

질화 규소 LPCVD \(\ce{3SiH2Cl2 + 4NH3 -> Si3N4 + 6HCl + 6H2}\)는 750 °C에서 \(\Delta G^\circ\approx-550\) kJ(엘링엄 근사), \(K\approx10^{28}\)로 평형상 완전히 진행한다. 막의 조성(Si/N 비)과 수소 함량, 성장 속도는 NH₃/DCS 비와 온도에 따른 표면 반응 속도가 정한다. 이 반응이 만드는 HCl이 NH₃와 만나 염화 암모늄(NH₄Cl)으로 배기관에 쌓이는 것은 저온에서 평형이 바뀌는 또 하나의 예다.

300 °C(573 K)에서 \(\ce{WF6(g) + 3H2(g) -> W(s) + 6HF(g)}\)의 \(\Delta_\mathrm rG^\circ\)와 \(K\)를 \(\Delta C_P\) 일정 근사로 구하라(\(\Delta H^\circ = +81.90\) kJ, \(\Delta S^\circ = +342.18\) J/K, \(\Delta C_P = -6.41\) J/K). H₂/WF₆ = 10, 전체 압력 0.0100 bar(7.6 Torr)로 넣어 평형에 닿으면 남는 WF₆ 분압은 대략 얼마인가?

핵심 정리

  1. 깁스 최소: 반응 진행도 \(dn_i = \nu_i\,d\xi\)로 \(\Delta_\mathrm rG = (\partial G/\partial\xi)_{T,P} = \sum\nu_i\mu_i = \Delta_\mathrm rG^\circ + RT\ln Q\). 혼합 항 때문에 \(G(\xi)\)는 중간에 바닥이 있고, 바닥에서 \(\Delta_\mathrm rG^\circ = -RT\ln K\). \(QK\)이면 역반응.
  2. 평형 상수의 단위: \(K\)는 무차원(활동도: 기체 \(P_i/P^\circ\), 순수 고체·액체 1). \(K = K_P(P^\circ)^{-\Delta n} = K_c(c^\circ RT/P^\circ)^{\Delta n} = K_x(P/P^\circ)^{\Delta n}\). 분자 그림에서 \(K_c = k_\mathrm f/k_\mathrm b\)(상세 균형).
  3. 반트호프 식 \(d\ln K/d(1/T) = -\Delta H^\circ/R\): 흡열은 고온, 발열은 저온에서 \(K\)가 크다. 넓은 온도 범위에서는 \(\Delta C_P\)가 직선을 휘게 한다(\(\Delta C_P\) 일정 근사 \(\ne\) 엘링엄 근사, 고온에서 수십 % 이상 차이).
  4. 르샤틀리에: 온도만 \(K\)를 바꾸고, 압력·주입·제거·희석은 \(Q\)를 바꾼다. 압력↑ → 기체 몰수 감소 쪽(\(\partial\ln K_x/\partial\ln P = -\Delta n\)), 일정 부피의 비활성 기체는 영향 없음, 일정 압력의 희석은 몰수 증가 쪽. 예외(N₂ 과량에서 N₂ 주입)는 \(Q\)로 판단한다.
  5. 다중 평형: 독립 반응 수 = 물질 수 − 원소 수. 원소 퍼텐셜 \(\mu_i = \sum_j a_{ij}\lambda_j\)로 풀면 미지수가 원소 수로 준다. Si–Cl–H 계의 Si 수율은 H₂/TCS 비와 함께 오르고, SiCl₂ 때문에 1350–1450 K 근처에서 최대(평형 20–40 %)다.
  6. 엘링엄 도표: 산소 1 mol당 \(\Delta G^\circ = RT\ln P_{\mathrm{O_2,eq}}\). 아래 선의 금속이 위 선의 산화물을 환원한다. HfO₂·ZrO₂·Al₂O₃는 SiO₂보다 아래(실리콘 위에서 안정), Ta₂O₅는 위. H₂O/H₂·CO₂/CO 비가 산소 분압을 정하고, W는 \(10^{-7}\lesssim P_{\mathrm{H_2O}}/P_{\mathrm{H_2}}\lesssim1\)에서 Si만 산화하는 선택 산화가 가능하다(900 °C, 엘링엄 근사).
  7. CVD 열역학: SiH₄ 분해는 모든 온도에서 \(K\gg1\)(속도가 온도를 정함), 염화실레인은 흡열이라 Cl이 많을수록 고온 필요. WF₆ 수소 환원은 엔트로피가 이기는 흡열 반응, Si 환원은 자기 제한 핵생성. 열역학은 가능성과 수율 상한만 말하고, 선택성·속도는 속도론(13·14장)이 정한다.

연습문제

열화학 자료는 부록 A(298.15 K, 1 bar)를 쓴다. \(R = 8.314\) J/(mol·K), \(P^\circ = 1\) bar, \(c^\circ = 1\) mol/L. 문제에 "엘링엄 근사"라고 하면 \(\Delta H^\circ, \Delta S^\circ\)를 298 K 값으로 고정한다. 따로 말이 없으면 답이 ±1 % 이내면 정답이다.

1000 K에서 \(\Delta_\mathrm rG^\circ = +20.0\) kJ/mol인 반응의 평형 상수는?

\(K = \exp(-20{,}000/(8.314\times1000)) = e^{-2.406} = 0.0902\). \(\Delta_\mathrm rG^\circ>0\)이어도 \(K\)는 0이 아니다.

800 K에서 측정한 평형 상수가 \(K = 1.0\times10^{-3}\)이다. \(\Delta_\mathrm rG^\circ\)는?

\(\Delta_\mathrm rG^\circ = -RT\ln K = -8.314\times800\times\ln(10^{-3}) = +45.9\) kJ/mol.

일정 부피·일정 온도의 용기에서 평형인 \(\ce{N2 + 3H2 <=> 2NH3}\) 혼합물에 아르곤을 넣어 전체 압력을 2배로 만들었다. 평형은?

반응 기체의 분압 \(P_i = n_iRT/V\)가 그대로라 \(Q = K\)가 유지된다. 비활성 기체는 일정 압력에서 넣을 때만(부피가 늘어 분압이 줄 때) 평형을 옮긴다. \(K\)는 온도만의 함수다.

350 K에서 \(\ce{N2O4(g) <=> 2NO2(g)}\)의 \(K = 4.43\)이다. \(K_c\)(mol/L 단위)는?

\(\Delta n = +1\)이므로 \(K_c = K(c^\circ RT/P^\circ)^{-1} = 4.43/(0.08314\times350) = 4.43/29.10 = 0.152\) mol/L.

어떤 반응의 평형 상수가 300 K에서 310 K로 올리자 정확히 2배가 되었다. \(\Delta H^\circ\)가 일정하다고 보고 \(\Delta H^\circ\)를 구하라. (생화학의 "10 도에 2배" 규칙이 평형에 적용된다면 어떤 엔탈피에 해당하는가?)

\(\ln2 = -(\Delta H^\circ/R)(1/310 - 1/300)\).

\(\Delta H^\circ = R\ln2/(1/300 - 1/310) = 8.314\times0.6931/(1.0753\times10^{-4}) = 53.6\) kJ/mol.

350 K, 전체 압력 2.00 bar에서 N₂O₄의 해리도 \(\alpha\)는? (\(K = 4.43\))

\(K = \frac{4\alpha^2}{1-\alpha^2}\frac{P}{P^\circ}\) → \(\alpha = \sqrt{K/(K + 4P/P^\circ)} = \sqrt{4.43/12.43} = 0.597\). 1 bar에서는 0.725였으니 압력을 2배로 하면 해리가 줄어든다.

1000 K에서 \(\ce{CO + H2O <=> CO2 + H2}\)의 \(K = 1.10\)이다. CO와 H₂O를 1 mol씩 넣었을 때 평형에서 반응한 CO의 비율은?

\(\Delta n = 0\)이라 압력과 무관하다. \(K = \xi^2/(1-\xi)^2\) → \(\xi = \sqrt K/(1 + \sqrt K) = 1.0488/2.0488 = 0.512\).

엘링엄 근사로 600 K에서 \(\ce{4Cu + O2 -> 2Cu2O}\)(\(\Delta H^\circ = -337.2\) kJ, \(\Delta S^\circ = -151.47\) J/K)의 평형 산소 분압(bar)의 상용로그를 구하라.

\(\Delta_\mathrm rG^\circ = -337.2 + 600\times0.15147 = -246.3\) kJ. \(\log_{10}P_{\mathrm{O_2}} = \Delta G^\circ/(RT\ln10) = -246{,}318/(8.314\times600\times2.3026) = -21.4\). 질소 속 산소 1 ppm(\(10^{-6}\) bar)도 이보다 15자릿수 높으니, 불활성 기체만으로는 구리 산화를 막을 수 없다(포밍 가스가 필요한 이유).

\(\ce{NiO(s) + H2(g) <=> Ni(s) + H2O(g)}\)의 \(\Delta H^\circ = -2.13\) kJ, \(\Delta S^\circ = +50.04\) J/K다. 엘링엄 근사로 800 K에서 NiO가 환원되는 \(P_{\mathrm{H_2O}}/P_{\mathrm{H_2}}\)의 최댓값은?

\(\Delta G^\circ = -2.13 - 800\times0.05004 = -42.16\) kJ, \(K = e^{42{,}162/(8.314\times800)} = 566\). 불균일 평형이라 \(K = P_{\mathrm{H_2O}}/P_{\mathrm{H_2}}\)이고, 비가 566보다 작으면 환원된다. 수증기가 수소보다 수백 배 많아도 니켈은 금속으로 남는다.

H₂, HCl, SiH₄, SiH₂Cl₂, SiHCl₃, SiCl₄, Si(s)로 이루어진 계(SiCl₂는 무시)의 독립 반응은 몇 개인가?

물질 7가지, 원소 3가지(Si, H, Cl), 원소 행렬의 계수 3이므로 \(7 - 3 = 4\)개.

700 K에서 \(\ce{N2 + 3H2 <=> 2NH3}\)의 \(K = 6.88\times10^{-5}\)이다. N₂ : H₂ = 1 : 3으로 넣었을 때 전체 압력 10.0 bar와 50.0 bar에서 평형 NH₃ 몰분율을 구하라.

\(\xi\)로 몰수를 쓰고 \(K = \frac{(2\xi)^2(4-2\xi)^2}{(1-\xi)(3-3\xi)^3}(P/P^\circ)^{-2}\)를 수치로 푼다.

10 bar: \(\xi = 0.0499\), \(y = 2\xi/(4-2\xi) = 0.0256\). 50 bar: \(\xi = 0.194\), \(y = 0.107\). 압력이 5배일 때 수율이 4.2배로, 비례보다 약간 덜 오른다.

1300 K, 전체 압력 1.00 bar에서 SiHCl₃ 1 mol과 H₂ 10 mol을 넣는다. 반응 \(\ce{SiHCl3 + H2 <=> Si(s) + 3HCl}\) 하나만 일어난다고 보고(\(K_{1300} = 0.0224\)) 평형에서 반응한 SiHCl₃의 비율을 구하라.

기체 몰수: \(1-\xi\), \(10-\xi\), \(3\xi\), 합 \(11 + \xi\). \(K = \frac{(3\xi)^3}{(1-\xi)(10-\xi)(11+\xi)}\frac{P}{P^\circ}\).

이분법으로 풀면 \(\xi = 0.383\). 실제로는 SiCl₄·SiCl₂로 실리콘이 새어 나가 다중 평형의 Si 수율은 약 32 %다(5절 시뮬레이터).

900 °C(1173 K)에서 H₂–H₂O 분위기로 Si만 산화하고 W는 금속으로 두려 한다. 엘링엄 근사로 \(\ce{Si + 2H2O -> SiO2 + 2H2}\)(\(\Delta H^\circ = -427.04\) kJ, \(\Delta S^\circ = -93.67\) J/K)와 \(\ce{W + 2H2O -> WO2 + 2H2}\)(\(\Delta H^\circ = -106.03\) kJ, \(\Delta S^\circ = -98.42\) J/K)의 평형 \(P_{\mathrm{H_2O}}/P_{\mathrm{H_2}}\)를 각각 구하라.

\(K = (P_{\mathrm{H_2}}/P_{\mathrm{H_2O}})^2\)이므로 경계의 비는 \(K^{-1/2}\).

Si: \(\Delta G^\circ = -427.04 + 1173\times0.09367 = -317.17\) kJ, \(K = 1.33\times10^{14}\), 비 \(= K^{-1/2} = 8.68\times10^{-8}\). W: \(\Delta G^\circ = -106.03 + 1173\times0.09842 = +9.42\) kJ, \(K = 0.381\), 비 \(= 1.62\). 따라서 \(8.7\times10^{-8} < P_{\mathrm{H_2O}}/P_{\mathrm{H_2}} < 1.6\)이 선택 산화 창이다(\(\Delta C_P\)를 넣으면 W 경계는 0.70으로 내려간다).

엘링엄 근사로 750 °C(1023 K)에서 \(\ce{3SiH2Cl2(g) + 4NH3(g) -> Si3N4(s) + 6HCl(g) + 6H2(g)}\)의 \(\Delta_\mathrm rG^\circ\)와 \(\log_{10}K\)를 구하라. \(\Delta_\mathrm fH^\circ\)(kJ/mol): SiH₂Cl₂ −320.5, NH₃ −45.9, Si₃N₄ −744.8, HCl −92.31. \(S^\circ\)(J/(mol·K)): SiH₂Cl₂ 286.7, NH₃ 192.77, Si₃N₄ 113.0, HCl 186.90, H₂ 130.68.

\(\Delta H^\circ = -153.56\) kJ, \(\Delta S^\circ = +387.30\) J/K.

\(\Delta H^\circ = -744.8 + 6(-92.31) - 3(-320.5) - 4(-45.9) = -153.56\) kJ. \(\Delta S^\circ = 113.0 + 6(186.90) + 6(130.68) - 3(286.7) - 4(192.77) = 387.30\) J/K. \(\Delta G^\circ = -153.56 - 1023\times0.3873 = -549.8\) kJ, \(\log_{10}K = 549{,}768/(8.314\times1023\times2.3026) = 28.1\).

엘링엄 도표(산소 1 mol 기준)에서 1000 °C의 선 위치가 Ta₂O₅ −588, SiO₂ −678, Al₂O₃ −851, HfO₂ −904 kJ이다. 실리콘 위에 직접 올렸을 때 열역학적으로 실리콘에 환원되는 것은?

SiO₂ 선보다 위에 있는 산화물은 Si에 산소를 빼앗긴다: \(\ce{5Si + 2Ta2O5 -> 5SiO2 + 4Ta}\), \(\Delta G^\circ\approx-453\) kJ. HfO₂와 Al₂O₃는 SiO₂보다 아래라 안정하다.

엘링엄 근사에서 \(\ce{Si + O2 -> SiO2}\)(\(\Delta H^\circ = -910.7\) kJ, \(\Delta S^\circ = -182.5\) J/K)와 \(\ce{2C + O2 -> 2CO}\)(\(\Delta H^\circ = -221.06\) kJ, \(\Delta S^\circ = +178.69\) J/K)의 선이 만나는 온도는? 이 온도 위에서 탄소가 SiO₂를 환원한다(CO 1 bar).

두 선이 같으려면 \(-910.7 + 0.1825T = -221.06 - 0.17869T\) → \(T = 689.64/0.36119 = 1909\) K(약 1640 °C). 실제 아크로는 CO를 빼내고 2000 °C 근처에서 돌린다.

개념 확인 퀴즈

반응기에 촉매를 넣으면 평형에 대해 무엇이 바뀌나?

촉매는 정반응과 역반응을 같은 비율로 빠르게 한다(\(K = k_\mathrm f/k_\mathrm b\)는 그대로). \(\Delta_\mathrm rG^\circ\)는 상태 함수의 차이라 경로와 무관하다.

\(\ce{N2 + 3H2 <=> 2NH3}\)의 평형 상수가 \(K\)일 때, \(\ce{NH3 <=> 1/2N2 + 3/2H2}\)의 평형 상수는?

뒤집으면 역수, 계수를 ½배 하면 ½제곱이다. \(\Delta_\mathrm rG^\circ\)가 \(-\frac12\)배가 되기 때문이다.

엘링엄 도표에서 거의 모든 금속 산화물 선이 오른쪽 위로 올라가는(기울기가 양수인) 이유는?

기울기는 \(-\Delta S^\circ\)다. 기체 1 mol이 사라지는 엔트로피 손실(약 180 J/K)이 금속에 상관없이 비슷해 선들이 나란하다. 탄소가 CO가 되는 반응만 기체가 늘어나 기울기가 음수다.

600 °C에서 SiH₄ 분해 반응의 \(K\)는 \(10^6\)보다 크다. 그런데 LPCVD에서 온도를 550 °C에서 620 °C로 올리면 증착 속도가 몇 배 빨라진다. 이것은 무엇을 뜻하나?

\(K\)가 이미 엄청나게 커서 평형은 완전히 생성물 쪽이다(발열이라 \(K\)는 오히려 조금 줄어든다). 증착 속도는 아레니우스형 표면 반응(13·14장)이 정한다. 열역학은 방향과 상한, 속도론은 빠르기를 말한다.

\(\ce{CO + H2O <=> CO2 + H2}\) 평형 혼합물의 전체 압력을 10배로 올리면?

\(\Delta n = 0\)이므로 \(K_x = K(P/P^\circ)^{0} = K\)로 압력과 무관하다(이상 기체). 르샤틀리에 시뮬레이터에서 피스톤을 움직여도 조성이 그대로인 것을 확인할 수 있다.
