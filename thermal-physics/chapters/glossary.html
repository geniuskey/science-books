Appendix B

용어집과 종합 문제

1–17장 본문에서 처음 정의한 용어를 모았다. 설명은 본문의 정의를 한두 문장으로 정리한 것이며, 링크를 누르면 그 용어가 처음 나온 절로 이동한다. 검색창에 한국어나 영어를 넣거나 장을 골라 목록을 좁힐 수 있다. 뒤의 종합 문제는 장마다 4문제씩, 계산 문제와 선택형을 섞어 낸다. 대부분 LPCVD 튜브의 분압, 가스 실린더와 레귤레이터, 스크러버 발열, 웨이퍼 냉각과 크라이오펌프, 실레인·W CVD·TCS 평형, RTP 램프와 고온계, 스퍼터 챔버의 진공, 버블러와 클린룸 이슬점, 초순수 용존 산소, 잉곳 편석, 레지스트 PEB와 식각 라디칼, ALD·핵생성, 구리 도금과 CMP 후 부식, 도펀트 드라이브인과 열산화, 칩 접합 온도처럼 반도체 현장의 숫자로 묻는다. ‘종합’ 표시가 붙은 문제는 같은 부의 여러 장 또는 여러 절의 도구를 함께 써야 풀린다. 그다음 장을 넘나드는 반복 연습 두 개, 시험 직전 체크리스트, 각 장의 개념 퀴즈를 무작위로 섞어 내는 코너가 이어진다. 상수·자료표와 계산기는 부록 A에 있다.

10.0 L 실린더에 Ar 50.0 mol이 25 °C로 들어 있다. 판데르발스 식(\(a = 0.1355\) Pa·m⁶/mol², \(b = 3.201\times10^{-5}\) m³/mol)으로 압력(bar)과 압축 인자 \(Z\)를 구하라. 이상 기체 식으로는 몇 bar인가?

\(RT = 2479\) J/mol. \(RT/(V_\mathrm m - b) = 2479/1.680\times10^{-4} = 1.476\times10^7\) Pa, \(a/V_\mathrm m^2 = 3.39\times10^6\) Pa, \(P = 1.137\times10^7\ \text{Pa} = 114\ \text{bar}\). \(Z = 0.917\), 이상 기체라면 \(RT/V_\mathrm m = 124\ \text{bar}\). 거꾸로, 게이지가 114 bar를 가리킬 때 이상 기체 식으로 몰수를 세면 45.9 mol — 실제보다 8% 적게 잡는다. 잔량 계산에 \(n = PV/ZRT\)를 쓰는 이유다. → 1장 판데르발스 기체와 임계점

진동자 3개짜리 아인슈타인 고체 A와 B가 맞닿아 에너지 덩어리 6개를 나눈다. 전체 미시 상태 수와, 6개가 모두 A에 몰려 있을 확률은?

\(\Omega(N, q) = \binom{q + N - 1}{q}\). 전체는 진동자 6개에 덩어리 6개. 모든 미시 상태는 같은 확률이다.

(100) 실리콘의 1000 °C 건식 산화 계수는 \(B = 0.01044\) µm²/h, \(A = 0.2325\) µm이다. 산화막을 25 nm에서 50 nm로 키우는 데 걸리는 시간(분)과, 그동안 소모되는 실리콘 두께(nm)는?

\(x^2 + Ax = B(t + \tau)\)에서 \(t(x) = (x^2 + Ax)/B\)의 차이를 구한다. 산화막 두께 \(x\)당 Si 소모는 \(0.44x\).

\(t(0.050) = (0.0025 + 0.011625)/0.01044 = 1.353\) h, \(t(0.025) = (0.000625 + 0.005813)/0.01044 = 0.617\) h. 차이 \(0.736\ \text{h} = 44.2\ \text{min}\). Si 소모 \(0.44\times25 = 11.0\ \text{nm}\). 이 두께에서는 \(x \ll A\)라 거의 선형 영역(\(B/A = 0.045\) µm/h)이다 — 계면 반응이 속도를 정해 결정 방향과 온도에 민감하다. → 16장 딜–그로브 열산화 모형

공정 흐름에 1100 °C 10 s 스파이크 어닐과 800 °C 1시간 단계가 있다. 붕소(\(E_a\) = 3.46 eV)의 \(\sum D_it_i\)를 주로 정하는 것은? (램프 구간은 무시)

\(D(1100\ {}^\circ\mathrm C)/D(800\ {}^\circ\mathrm C) = \exp[(3.46/k)(1/1073 - 1/1373)] = 3.5\times10^3\). \(Dt\): \(1.52\times10^{-13}\times10 = 1.5\times10^{-12}\) cm² 대 \(4.3\times10^{-17}\times3600 = 1.5\times10^{-13}\) cm². 활성화 에너지가 큰 확산에서는 가장 뜨거운 단계가 열 예산을 거의 다 차지한다 — 짧은 스파이크라도 최고 온도를 낮추는 것이 얕은 접합의 열쇠다(실제로는 TED가 더해진다). → 16장 열 예산

17장 열전달과 비평형 현상본문 →

150 W 프로세서 다이(15 mm × 15 mm, 두께 775 µm, \(\kappa\) = 148 W/(m·K))가 두께 50 µm의 TIM(\(\kappa\) = 4.0 W/(m·K))으로 방열판(\(\theta_\mathrm{SA}\) = 0.30 K/W)에 붙어 있다. 열이 두께 방향 1차원으로 흐른다고 보고 TIM 열저항과 접합 온도를 구하라(주위 35 °C).

평판 \(R = L/\kappa A\), 직렬은 더한다. \(T_\mathrm J = T_\mathrm A + P\sum R\).

\(A = 2.25\times10^{-4}\) m². \(R_\text{TIM} = 50\times10^{-6}/(4.0\times2.25\times10^{-4}) = 0.0556\ \text{K/W}\), \(R_\text{Si} = 0.0233\) K/W. 합 \(0.379\) K/W, \(T_\mathrm J = 35 + 150\times0.379 = 91.8\ {}^\circ\text{C}\). 얇은 TIM이 실리콘 다이 전체보다 2.4배 큰 저항이다. 실제로는 핫스팟의 퍼짐 저항이 더해져 국소 온도가 이보다 높다. → 17장 열저항 회로와 칩 접합 온도

정전척 위 300 mm 웨이퍼(두께 775 µm, \(\rho\) = 2329 kg/m³, \(c\) = 712 J/(kg·K), \(\kappa\) = 148 W/(m·K))가 뒷면 He 기체로 척과 \(h = 500\) W/(m²·K)로 이어져 있다. 비오 수 \(hL/\kappa\), 열 시간 상수 \(\tau = \rho cL/h\), 플라스마가 1.0 W/cm²를 넣을 때 정상 상태 웨이퍼–척 온도 차를 구하라.

\(\mathrm{Bi}\ll1\)이면 웨이퍼 두께 방향 온도가 고르다(집중 용량). 정상 상태 \(\Delta T = q/h\).

\(\mathrm{Bi} = 500\times7.75\times10^{-4}/148 = 2.62\times10^{-3}\) — 웨이퍼는 한 덩어리로 데워진다. \(\tau = 2329\times712\times7.75\times10^{-4}/500 = 2.57\ \text{s}\). \(\Delta T = 10^4/500 = 20.0\ \text{K}\). He 압력을 올리면 \(h\)가 커져(분자류 영역에서 \(h\propto P\), 8장) 온도 차와 시간 상수가 함께 준다. 영역별 He 압력으로 웨이퍼 반경 방향 온도를 조절한다. → 17장 열 확산 방정식과 열 시간 상수

Bi₂Te₃ 계 재료(\(S\) = 210 µV/K, \(\sigma\) = 1.1×10⁵ S/m, \(\kappa\) = 1.4 W/(m·K))의 성능 지수 \(Z\)(10⁻³ K⁻¹ 단위)와 300 K의 \(ZT\)를 구하라. 뜨거운 면을 300 K로 둘 때 무부하 최대 온도 차 \(\Delta T_\text{max} = \tfrac12ZT_c^2\)는?

\(Z = S^2\sigma/\kappa\). \(T_h - T_c = \tfrac12ZT_c^2\)를 \(T_c\)에 대한 2차식으로 푼다.

\(Z = (210\times10^{-6})^2(1.1\times10^5)/1.4 = 3.47\times10^{-3}\ \text{K}^{-1}\), \(ZT = 1.04\). \(\tfrac12ZT_c^2 + T_c - 300 = 0\) → \(T_c = (-1 + \sqrt{1 + 2Z\cdot300})/Z = 217.8\) K, \(\Delta T_\text{max} = 82.2\ \text{K}\). 줄 열(\(\tfrac12I^2R\))과 역전도(\(K\Delta T\))가 펠티에 냉각(\(SIT_c\))과 맞서는 한계다. 열을 실어 나르면 온도 차는 이보다 작아지므로, 레이저 다이오드·센서 냉각에는 다단 모듈을 쓴다. → 17장 열전 효과와 열전 냉각

배선의 전자 이동 수명이 블랙 식 \(\mathrm{MTTF}\propto j^{-2}e^{E_a/kT}\)(\(E_a\) = 0.90 eV)를 따른다. 설계 변경으로 전류 밀도가 20% 늘고, 자기 가열로 배선 온도가 105 °C에서 115 °C로 올랐다. 새 수명은 처음의 몇 배인가?

전류 몫 \(1.2^{-2}\), 온도 몫 \(\exp[(E_a/k)(1/388.15 - 1/378.15)]\).

\(1.2^{-2} = 0.694\), 온도 몫 \(\exp[10\,444\times(-6.81\times10^{-5})] = e^{-0.711} = 0.491\). 곱 \(0.341\) — 수명이 약 3분의 1로 준다. 전류를 늘리면 줄 열로 온도까지 오르는 되먹임이 겹쳐, 수명 계산에는 늘 자기 가열 온도를 넣는다. → 17장 줄 가열과 자기 가열

시험 직전 체크리스트

아래 문장을 막힘없이 설명하고 식을 쓸 수 있으면 그 부를 정리한 것이다. 걸리는 줄이 있으면 링크한 절로 돌아가자.

제1부 열역학의 법칙

  • \(PV = nRT\)와 분압 \(P_i = x_iP\)로 sccm 유량에서 챔버 분압·수밀도를 구하고, 고압 실린더는 \(n = PV/ZRT\)로 센다.1장
  • \(\Delta U = Q + W\)(받은 일 양수)와 과정별 일: 등압 \(-P\Delta V\), 가역 등온 \(-nRT\ln(V_2/V_1)\), 단열 \(nC_V\Delta T\). 헤스·키르히호프로 반응열을 옮긴다.2장
  • 카르노 효율·COP, \(\Delta S\)는 가역 경로로 계산, \(S_\text{gen}\ge0\)과 잃어버린 일 \(T_0S_\text{gen}\).3장
  • \(\Delta G = \Delta H - T\Delta S\)의 부호표와 \(T^*\), 네 퍼텐셜의 미분형과 맥스웰 관계식, \(W'_\text{max} = -\Delta G = nFE\).4장

제2부 통계역학

  • 겹침수 \(\binom Nn\)·\(\binom{q+N-1}{q}\), \(S = k\ln\Omega\), \(1/T = \partial S/\partial U\)로 열이 흐르는 방향을 말한다.5장
  • \(Z = \sum g_ie^{-\beta E_i}\)에서 \(U\), \(C_V\), \(F\), \(S\)를 얻고, 등분배가 깨지는 조건(\(T\lesssim\theta\))과 \(e^{-E_a/kT}\) 열활성을 쓴다.6장
  • FD·BE 분포와 고전 극한 \(n\lambda^3\ll1\), \(N_c\)와 볼츠만 근사의 한계, 플랑크·빈·슈테판 법칙.7장
  • \(\bar v\), 플럭스 \(\tfrac14n\bar v\), \(\lambda = kT/\sqrt2\pi d^2P\)와 Kn, 분자류 컨덕턴스 직렬 합성과 \(P_\text{base} = Q/S_\text{eff}\).8장

제3부 상평형

  • \(\mu_\alpha = \mu_\beta\)와 클라페이롱·클라우지우스–클라페이롱 식, 버블러 유량 \(Q_cP_v/(P - P_v)\), 맥스웰 같은 넓이 규칙.9장
  • 라울·헨리 법칙, 활동도 \(a = \gamma x\), 정규 용액 \(\ln\gamma_\mathrm A = \Omega x_\mathrm B^2/RT\), 쌍봉선과 스피노달, 총괄성.10장
  • 상규칙 \(F = C - P + 1\)(압력 고정), 공통 접선, 지렛대 규칙, 공정 반응, 쇼이어 식과 \(k_\mathrm{eff}\).11장

제4부 화학 평형과 반응

  • \(\Delta_\mathrm rG^\circ = -RT\ln K\), 반응 진행도로 평형 조성 풀기, 반트호프 식, 르샤틀리에(압력·희석은 \(Q\)를 바꾼다), 엘링엄과 H₂O/H₂ 비.12장
  • 적분 속도식과 반감기, 아레니우스 두 온도 식과 온도 민감도 \(E_a/kT^2\), 정상 상태 근사, 촉매는 \(K\)를 바꾸지 않는다.13장
  • 영 식과 부착 일, 랭뮤어·BET, ALD 포화 시간, 핵생성 \(r^*\)·\(\Delta G^*\), 그로브 모형의 두 영역과 계단 피복.14장
  • \(E^\circ_\text{cell}\)과 \(\Delta G = -nFE\), 네른스트(10배당 59/n mV), 패러데이 두께, 타펠 기울기와 한계 전류, 갈바닉 넓이 효과.15장

제5부 수송과 비평형

  • \(\langle x^2\rangle = 2Dt\), 픽의 법칙, \(D = D_0e^{-E_a/kT}\), erfc·가우스 분포와 접합 깊이, 열 예산 \(\sum D_it_i\), 딜–그로브 두 영역.16장
  • 열저항 회로와 \(T_\mathrm J\), 비오 수와 집중 용량 \(\tau = \rho cL/h\), 복사 \(4\varepsilon\sigma\bar T^3\), 펠티에 냉각 한계와 \(ZT\), 존슨 잡음 \(4kTR\Delta f\).17장
