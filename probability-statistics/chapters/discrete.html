Chapter 04

이산 확률 변수

300 mm 웨이퍼 한 장에 결함이 몇 개 떨어질지, 그중 한 다이에는 몇 개가 들어갈지는 미리 알 수 없다. 그래도 웨이퍼 수백 장을 보면 "결함 0개인 다이가 대략 몇 %"라는 규칙이 뚜렷하다. 이 장은 그 규칙을 다루는 도구를 만든다. 실험 결과에 숫자를 붙이는 확률 변수, 각 값의 확률을 적은 표인 확률 질량 함수, 분포를 숫자 둘로 줄이는 기댓값과 분산을 정의한다. 그다음 공장에서 날마다 만나는 여섯 분포를 하나씩 만든다. 칩 n개 중 불량 수(이항), 첫 통과까지 재테스트 횟수(기하·음이항), 로트에서 비복원으로 뽑은 표본 속 불량 수(초기하), 다이당 결함 수(포아송)다. 마지막으로 분포 전체를 함수 하나에 담는 적률 생성 함수를 본다. 아래 웨이퍼에서는 결함이 계속 떨어지고, 오른쪽 히스토그램에 다이별 결함 수가 쌓이면서 포아송 분포(자주색)와 겹쳐진다. 웨이퍼를 누르면 결함이 한 덩어리로 떨어져 무작위 모형이 깨지는 모습도 볼 수 있다.

웨이퍼를 누르면 결함 덩어리가 떨어진다
  • 확률 변수를 표본 공간에서 실수로 가는 함수로 이해하고, 확률 질량 함수 \(p_X(x)\)와 누적 분포 함수 \(F_X(x)\)를 서로 바꾸어 구간 확률 \(P(a < X \le b) = F_X(b) - F_X(a)\)를 계산한다.
  • 기댓값(무게 중심)과 분산(회전 관성)을 표에서 계산하고, \(E[aX+b] = aE[X]+b\), \(\operatorname{Var}(aX+b) = a^2\operatorname{Var}(X)\), \(\operatorname{Var}(X) = E[X^2]-(E[X])^2\), 합의 기댓값의 선형성을 쓴다.
  • 베르누이·이항 분포의 조건을 확인하고 \(P(X=k) = \binom nk p^k(1-p)^{n-k}\), 평균 \(np\), 분산 \(np(1-p)\)를 쓴다.
  • 기하 분포의 무기억성을 설명하고, 음이항 분포를 기하 분포의 합으로 이해해 재테스트 횟수를 계산한다.
  • 초기하 분포로 로트 샘플링 검사의 합격 확률과 OC 곡선을 계산하고, 이항 근사가 맞는 조건(유한 모집단 수정)을 판단한다.
  • 포아송 분포로 다이당 결함 수와 수율 \(Y = e^{-D_0A}\)를 계산하고, 이항 분포의 포아송 근사가 맞는 범위를 수치로 확인한다.
  • 적률 생성 함수로 평균·분산을 구하고, 독립인 확률 변수 합의 분포(포아송+포아송 등)를 알아본다.

확률 변수와 확률 질량 함수

2장에서 표본 공간 \(\Omega\)와 사건에 확률을 매겼다. 칩 세 개를 검사하면 결과는 "양품·양품·불량"(GGD) 같은 글자 묶음이다. 그런데 엔지니어가 실제로 궁금한 것은 대개 숫자다. 불량이 몇 개인가, 몇 번 만에 통과했나, 결함이 몇 개 떨어졌나. 결과 하나하나에 숫자를 하나씩 붙이는 규칙을 확률 변수(random variable)라 한다. 이름과 달리 "변수"가 아니라 함수 \(X:\Omega\to\mathbb R\)다. 관례로 확률 변수는 대문자 \(X, Y\), 그 값은 소문자 \(x, y\)로 쓴다. \(\{X = 1\}\)은 "\(X\)가 1이 되는 결과들의 모임"이라는 사건이다.

값이 유한개이거나 0, 1, 2, …처럼 셀 수 있게 띄엄띄엄 놓이면 이산 확률 변수(discrete random variable)다. 불량 개수, 재시험 횟수, 결함 수가 모두 그렇다. 막두께나 문턱 전압처럼 구간 안의 모든 실수를 가질 수 있는 양은 5장의 연속 확률 변수다.

확률 질량 함수와 누적 분포 함수

이산 확률 변수 \(X\)의 확률 질량 함수(probability mass function, pmf)는 \(p_X(x) = P(X = x)\)이다. 모든 \(x\)에서 \(p_X(x)\ge 0\)이고 \(\sum_x p_X(x) = 1\)이다. 누적 분포 함수(cumulative distribution function, cdf)는 \(F_X(x) = P(X\le x) = \sum_{k\le x}p_X(k)\)이다.

pmf는 "각 값에 확률이 얼마씩 쌓였나"를, cdf는 "그 값까지 모두 합해 얼마인가"를 말한다. 이산 변수의 cdf는 값이 있는 자리에서만 \(p_X(k)\)만큼 뛰어오르는 계단이다. 계단은 왼쪽 끝 0에서 오른쪽 끝 1까지 줄지 않고 오르며, 뛰는 점에서는 위쪽 값을 갖는다(오른쪽 연속). 그래서 \(F_X(1.5) = F_X(1)\)이다. 정수 값을 갖는 변수에서는 다음 관계를 계속 쓴다.

$$P(a < X \le b) = F_X(b) - F_X(a),\qquad P(X = k) = F_X(k) - F_X(k-1),\qquad P(X \ge k) = 1 - F_X(k-1)$$
연속 변수와 달리 이산 변수에서는 부등호에 등호가 붙느냐가 답을 바꾼다. \(P(X\le 2)\)와 \(P(X<2)\)는 \(P(X=2)\)만큼 다르다.

칩 세 개를 검사한다. 각 칩이 불량일 확률은 0.1이고 칩끼리 독립이다. 불량 개수 \(X\)의 pmf와 cdf를 구하고, \(P(X\ge 1)\)과 \(F_X(1.5)\)를 구하라.

기댓값과 분산

pmf는 표 전체라 한눈에 비교하기 어렵다. 그래서 분포를 숫자 둘로 줄인다. 하나는 "어디쯤에 있나"(위치), 다른 하나는 "얼마나 퍼졌나"(산포)다. 1장에서 자료의 평균과 분산을 계산했다면, 여기서는 같은 일을 확률을 가중치로 삼아 한다.

기댓값

이산 확률 변수 \(X\)의 기댓값(expected value)은 \(\mu = E[X] = \sum_x x\,p_X(x)\)이다. 함수 \(g(X)\)의 기댓값은 \(g(X)\)의 분포를 따로 구하지 않고 \(E[g(X)] = \sum_x g(x)\,p_X(x)\)로 계산한다(무의식 통계학자의 법칙).

막대 높이를 무게로 보면 \(E[X]\)는 막대들이 수평으로 균형을 이루는 받침점, 곧 무게 중심이다. 그 자리에서 왼쪽 막대들의 회전력 \(\sum(x - \mu)p\)와 오른쪽 막대들의 회전력이 정확히 상쇄된다. 그래서 \(E[X]\)가 \(X\)가 실제로 가질 수 없는 값(예: 불량 0.75개)이어도 이상하지 않다. 또 하나의 해석은 장기 평균이다. 같은 실험을 많이 되풀이하면 결과의 평균이 \(E[X]\)에 다가간다(7장의 큰 수의 법칙).

분산과 표준 편차

분산(variance)은 평균에서 벗어난 거리 제곱의 기댓값 \(\sigma^2 = \operatorname{Var}(X) = E[(X-\mu)^2]\)이고, 표준 편차(standard deviation)는 \(\sigma = \sqrt{\operatorname{Var}(X)}\)이다. 계산에는 보통 \(\operatorname{Var}(X) = E[X^2] - \mu^2\)을 쓴다.

역학으로 보면 분산은 받침점을 축으로 한 회전 관성 \(\sum(x-\mu)^2p\)다. 무게가 축에서 멀리 있을수록 커진다. 받침점을 \(\mu\)가 아닌 \(c\)에 두면 \(E[(X-c)^2] = \sigma^2 + (\mu - c)^2\)이 되어(평행축 정리와 같은 꼴) 항상 더 커진다. 평균은 제곱 오차를 가장 작게 만드는 자리다.

pmf에서 \(x = 1\)에 있던 확률 0.1을 떼어 \(x = 8\)로 옮긴다. 평균 \(\mu\)는 얼마나 움직일까?

\(\mu = \sum xp\)에서 바뀐 항만 보면 \(-1(0.1) + 8(0.1) = +0.7\)이다. 확률이 작아도 멀리 옮기면 평균이 크게 움직인다. 분산은 거리 제곱이라 더 민감하다. 아래 저울에서 막대를 끌어 확인하라.

선형 변환과 합

측정값의 단위를 바꾸거나(nm → Å), 개수에 단가를 곱해 비용으로 바꾸는 일은 \(Y = aX + b\) 꼴이다. 이때 분포 전체를 다시 계산할 필요가 없다.

$$E[aX+b] = aE[X] + b,\qquad \operatorname{Var}(aX+b) = a^2\operatorname{Var}(X),\qquad \sigma_{aX+b} = |a|\,\sigma_X$$
\(b\)만큼 옮겨도 퍼짐은 그대로다. \(a\)배로 늘리면 거리가 \(|a|\)배가 되므로 분산은 \(a^2\)배다. \(a\)가 음수여도 분산은 줄지 않는다.

위 표의 결함 수 \(X\)(\(\mu = 0.75\), \(\sigma^2 = 0.7875\))에 대해 리뷰 비용을 \(Y = aX + b\)로 매긴다. \(a =\) 2.0, \(b =\) 1.0이면 \(E[Y] =\) , \(\operatorname{Var}(Y) =\) , \(\sigma_Y =\) 이다.

두 확률 변수를 더하면 어떨까? 기댓값은 언제나 더해진다: \(E[X + Y] = E[X] + E[Y]\). 두 변수가 서로 관계가 있든 없든 성립한다. 반면 분산은 \(X\)와 \(Y\)가 독립일 때만 \(\operatorname{Var}(X+Y) = \operatorname{Var}(X) + \operatorname{Var}(Y)\)다. 같이 움직이면(양의 상관) 더 퍼지고, 반대로 움직이면 서로 상쇄된다. 일반식은 6장에서 공분산으로 쓴다.

베르누이와 이항 분포

결과가 둘뿐인 시행 — 양품/불량, 통과/실패, 비트 오류 있음/없음 — 을 베르누이 시행(Bernoulli trial)이라 한다. "성공"(관심 있는 쪽, 공장에서는 흔히 불량)에 1, 실패에 0을 붙인 \(X\)는 \(P(X=1) = p\), \(P(X=0) = 1-p\)인 베르누이 분포를 따른다. \(E[X] = p\), \(E[X^2] = p\)이므로 \(\operatorname{Var}(X) = p - p^2 = p(1-p)\)다. 이런 0/1 변수를 사건의 지시 확률 변수(indicator random variable)라고도 한다.

같은 베르누이 시행을 \(n\)번 독립으로 되풀이해 성공 횟수를 센 것이 이항 확률 변수다. 칩 \(n\)개 중 불량 수, 비트 \(n\)개 중 오류 비트 수, 사이트 \(n\)개 중 접촉 불량 수가 모두 그렇다. 조건 네 가지를 기억하자. ① 시행 횟수 \(n\)이 정해져 있다. ② 결과는 둘뿐이다. ③ 성공 확률 \(p\)가 시행마다 같다. ④ 시행끼리 독립이다.

이항 분포 \(X\sim\mathrm{Bin}(n,p)\)

성공 확률 \(p\)인 독립 베르누이 시행 \(n\)번의 성공 횟수는 이항 분포(binomial distribution)를 따른다.

$$P(X = k) = \binom nk p^k(1-p)^{n-k},\quad k = 0,1,\dots,n,\qquad E[X] = np,\qquad \operatorname{Var}(X) = np(1-p)$$

평균과 분산은 합으로 보면 한 줄이다. \(X = I_1 + \cdots + I_n\)(시행마다의 지시 변수)이므로 선형성으로 \(E[X] = np\), 독립이므로 \(\operatorname{Var}(X) = np(1-p)\)다. pmf는 \(k\)가 늘 때 \(\frac{P(k+1)}{P(k)} = \frac{n-k}{k+1}\cdot\frac{p}{1-p}\)로 변하므로, 이 비가 1보다 큰 동안 오르다가 내려간다. 가장 자주 나오는 값(최빈값)은 \(\lfloor(n+1)p\rfloor\)다.

기하 분포와 음이항 분포

이항 분포는 시행 횟수를 정해 놓고 성공을 셌다. 거꾸로 "성공할 때까지 몇 번 걸리나"를 물을 수도 있다. 접촉이 불안정한 다이를 통과할 때까지 다시 시험하는 횟수, 첫 불량이 나올 때까지 검사한 칩 수, 첫 고장까지 사이클 수가 그렇다.

기하 분포 \(X\sim\mathrm{Geom}(p)\)

성공 확률 \(p\)인 독립 시행을 첫 성공이 나올 때까지 되풀이한 시행 횟수 \(X\)(마지막 성공 포함)는 기하 분포(geometric distribution)를 따른다.

$$P(X = k) = (1-p)^{k-1}p,\quad k = 1,2,\dots,\qquad P(X > k) = (1-p)^k,\qquad E[X] = \frac1p,\qquad \operatorname{Var}(X) = \frac{1-p}{p^2}$$

"처음 \(k-1\)번 실패하고 \(k\)번째 성공"이므로 pmf는 바로 나온다. \(P(X>k)\)는 "처음 \(k\)번이 모두 실패"라서 더 간단하다. 평균 \(1/p\)은 직관과 맞는다. 통과율 25%면 평균 4번 만에 통과한다. 교재에 따라 성공 전 실패 횟수 \(Y = X - 1\)(값 0, 1, 2, …)을 기하 분포라 부르기도 하니, 평균이 \(1/p\)인지 \((1-p)/p\)인지로 어느 정의인지 확인하자. 이 책은 시행 횟수 \(X\)를 쓴다.

기하 분포에는 특별한 성질이 있다. 이미 \(m\)번 실패했다는 정보가 앞으로 남은 횟수의 분포를 전혀 바꾸지 않는다.

$$P(X > m + n \mid X > m) = \frac{(1-p)^{m+n}}{(1-p)^m} = (1-p)^n = P(X > n)$$
이 성질을 무기억성(memorylessness)이라 한다. 이산 분포 가운데 무기억성을 가진 것은 기하 분포뿐이다(연속에서는 5장의 지수 분포).

첫 성공이 아니라 \(r\)번째 성공까지의 시행 횟수를 세면 음이항 분포가 된다. 마지막 \(k\)번째 시행이 \(r\)번째 성공이고, 그 앞 \(k-1\)번 가운데 \(r-1\)번이 성공이어야 한다.

음이항 분포 \(X\sim\mathrm{NB}(r,p)\)

\(r\)번째 성공까지의 시행 횟수는 음이항 분포(negative binomial distribution)를 따른다. 서로 독립인 \(\mathrm{Geom}(p)\) \(r\)개의 합과 같다.

$$P(X = k) = \binom{k-1}{r-1}p^r(1-p)^{k-r},\quad k = r, r+1,\dots,\qquad E[X] = \frac rp,\qquad \operatorname{Var}(X) = \frac{r(1-p)}{p^2}$$

접촉이 불안정한 다이가 시험마다 통과할 확률이 0.4다. 이미 3번 연속 실패했다. 지금부터 통과할 때까지 평균 몇 번 더 시험해야 할까?

시험이 독립이고 \(p\)가 일정하면 무기억성으로 남은 횟수는 다시 \(\mathrm{Geom}(0.4)\), 평균 \(1/0.4 = 2.5\)번이다. 넷째 보기는 실제 현장에서는 일리가 있다 — 다이마다 \(p\)가 다르면(정말 나쁜 다이가 섞이면) 실패가 쌓일수록 나쁜 다이일 가능성이 커진다. 그것은 \(p\)가 일정하다는 모형 가정이 깨진 경우다(3장의 베이즈 갱신).

초기하 분포와 로트 샘플링 검사

이항 분포는 시행마다 확률 \(p\)가 같다고 가정했다. 공정에서 칩을 하나씩 계속 만들 때는 맞지만, 이미 만들어진 로트(예: 칩 50개, 그중 불량 3개)에서 표본을 뽑아 돌려놓지 않으면 사정이 다르다. 첫 칩이 불량이면 남은 49개 중 불량은 2개뿐이라 두 번째 칩이 불량일 확률이 \(3/50\)에서 \(2/49\)로 바뀐다. 시행이 독립이 아니다.

초기하 분포 \(X\sim\mathrm{Hyp}(N,K,n)\)

불량 \(K\)개를 포함한 \(N\)개짜리 로트에서 \(n\)개를 비복원으로 뽑을 때 표본 속 불량 수는 초기하 분포(hypergeometric distribution)를 따른다. \(p = K/N\)이라 쓰면

$$P(X = k) = \frac{\binom Kk\binom{N-K}{n-k}}{\binom Nn},\qquad E[X] = np,\qquad \operatorname{Var}(X) = np(1-p)\cdot\frac{N-n}{N-1}$$

분모는 \(n\)개를 고르는 모든 방법, 분자는 불량 \(K\)개 중 \(k\)개와 양품 \(N-K\)개 중 \(n-k\)개를 고르는 방법이다. 평균은 이항과 같지만 분산에 \(\frac{N-n}{N-1}\)이 붙는다. 이 인수를 유한 모집단 수정(finite population correction)이라 한다. 표본이 로트의 상당 부분을 차지하면 표본이 로트를 잘 대표하게 되어 불량 수가 덜 흔들린다. 극단으로 로트 전체를 뽑으면(\(n = N\)) 불량 수는 늘 \(K\)이고 분산은 0이다. 반대로 \(n/N\)이 작으면(대략 0.1 이하) 인수가 1에 가까워 이항 \(\mathrm{Bin}(n, K/N)\)으로 근사해도 된다.

합격 판정 샘플링과 OC 곡선

포아송 분포와 포아송 근사

웨이퍼 위 결함은 정해진 횟수의 시행으로 생기지 않는다. 면적 곳곳에서 아주 드물게, 서로 상관없이 떨어진다. 이런 "드문 사건의 개수"가 따르는 분포가 포아송 분포다. 단위 면적당 평균 결함 수(결함 밀도) \(D_0\)와 면적 \(A\)만 알면 평균 개수 \(\lambda = D_0A\)가 정해지고, 개수의 분포 전체가 \(\lambda\) 하나로 정해진다.

포아송 분포 \(X\sim\mathrm{Poisson}(\lambda)\)

평균 \(\lambda > 0\)인 포아송 분포(Poisson distribution)의 pmf는

$$P(X = k) = e^{-\lambda}\frac{\lambda^k}{k!},\quad k = 0,1,2,\dots,\qquad E[X] = \operatorname{Var}(X) = \lambda$$

포아송 분포가 나오는 조건은 세 가지다. ① 서로 겹치지 않는 영역(또는 시간 구간)의 사건 수는 독립이다. ② 아주 작은 영역 \(\Delta A\)에 사건이 하나 생길 확률은 \(D_0\Delta A\)에 비례한다. ③ 같은 자리에 두 개가 동시에 생길 확률은 무시할 만하다. 이 조건으로 면적을 \(n\)칸으로 잘게 나누면 칸마다 결함이 있을 확률 \(\lambda/n\)인 이항 분포가 되고, \(n\to\infty\)로 보내면 포아송이 된다.

$$\binom nk\Big(\frac\lambda n\Big)^k\Big(1-\frac\lambda n\Big)^{n-k} = \underbrace{\frac{n(n-1)\cdots(n-k+1)}{n^k}}_{\to 1}\cdot\frac{\lambda^k}{k!}\cdot\underbrace{\Big(1-\frac\lambda n\Big)^{n}}_{\to e^{-\lambda}}\cdot\underbrace{\Big(1-\frac\lambda n\Big)^{-k}}_{\to 1}\;\longrightarrow\; e^{-\lambda}\frac{\lambda^k}{k!}$$
평균 \(np = \lambda\)를 고정한 채 \(n\to\infty\), \(p\to0\)으로 보낸 이항 분포의 극한이 포아송 분포다.

평균과 분산이 같다는 것이 포아송 분포의 지문이다. 다이별 결함 수 자료의 분산이 평균보다 뚜렷이 크면 결함이 독립적으로 떨어지지 않고 뭉쳤다는 뜻이다. 이를 과대 산포(overdispersion)라 한다. 결함이 뭉치면 결함 0개인 다이(양품)가 포아송 예측보다 많아진다 — 결함이 한 다이에 몰려 "같은 다이를 여러 번 죽이기" 때문이다.

적률 생성 함수

평균은 \(E[X]\), 분산은 \(E[X^2]\)에서 나왔다. 일반적으로 \(E[X^k]\)를 \(k\)차 적률(moment)이라 한다. 3차는 비대칭(왜도), 4차는 꼬리 두께(첨도)와 관계가 있다. 분포마다 적률을 하나씩 합으로 계산하는 대신, 적률을 한꺼번에 담은 함수를 만들 수 있다.

적률 생성 함수

확률 변수 \(X\)의 적률 생성 함수(moment generating function, mgf)는 0 근처의 \(t\)에서 \(M_X(t) = E[e^{tX}] = \sum_x e^{tx}p_X(x)\)이다. \(e^{tX} = 1 + tX + \frac{t^2X^2}{2!} + \cdots\)이므로

$$M_X(t) = 1 + E[X]\,t + E[X^2]\frac{t^2}{2!} + \cdots,\qquad M_X'(0) = E[X],\qquad M_X''(0) = E[X^2]$$

곧 \(t = 0\)에서 \(M_X\)의 기울기가 평균, 휘어짐(2차 도함수)이 2차 적률이다. 분산은 \(M''(0) - M'(0)^2\)이다. 그래프로 보면 mgf는 항상 \((0, 1)\)을 지나고(\(M(0) = E[1] = 1\)), 아래로 볼록하다.

$$M_{X+Y}(t) = M_X(t)\,M_Y(t)\qquad (X, Y \text{ 독립})$$

핵심 정리

  1. 확률 변수는 결과에 숫자를 붙이는 함수다. 이산 변수는 pmf \(p_X(x) = P(X=x)\)(합 1)와 계단 모양 cdf \(F_X(x) = P(X\le x)\)로 기술하고, \(P(a < X\le b) = F(b) - F(a)\), \(P(X\ge k) = 1 - F(k-1)\)이다. 이산 변수에서는 등호 여부가 답을 바꾼다.
  2. \(E[X] = \sum xp(x)\)는 무게 중심, \(\operatorname{Var}(X) = E[(X-\mu)^2] = E[X^2] - \mu^2\)은 회전 관성이다. \(E[aX+b] = aE[X]+b\), \(\operatorname{Var}(aX+b) = a^2\operatorname{Var}(X)\). 기댓값은 늘 더해지고, 분산은 독립일 때만 더해진다.
  3. \(\mathrm{Bin}(n,p)\): 고정된 \(n\)번 독립 시행의 성공 수, \(\binom nk p^k(1-p)^{n-k}\), 평균 \(np\), 분산 \(np(1-p)\). "하나라도"는 \(1 - (1-p)^n\)으로 계산한다.
  4. \(\mathrm{Geom}(p)\): 첫 성공까지 시행 수, \(P(X>k) = (1-p)^k\), 평균 \(1/p\), 분산 \((1-p)/p^2\), 무기억성. \(\mathrm{NB}(r,p)\)는 기하 \(r\)개의 합으로 평균 \(r/p\), 분산 \(r(1-p)/p^2\).
  5. \(\mathrm{Hyp}(N,K,n)\): 비복원 표본 속 불량 수, 평균 \(nK/N\), 분산은 이항에 \((N-n)/(N-1)\)을 곱한 값. \(n/N\lesssim 0.1\)이면 이항 근사. 샘플링 계획 \((n,c)\)의 OC 곡선 \(P_a(p) = P(X\le c)\)는 생산자 위험(AQL)과 소비자 위험(LTPD)을 함께 맞춰 고른다.
  6. \(\mathrm{Poisson}(\lambda)\): 드문 독립 사건 수, \(e^{-\lambda}\lambda^k/k!\), 평균 = 분산 = \(\lambda = D_0A\). 수율 \(Y = e^{-D_0A}\). 분산/평균 > 1이면 결함 군집(과대 산포). \(n\)이 크고 \(p\)가 작으면 \(\mathrm{Bin}(n,p)\approx\mathrm{Poisson}(np)\), 오차는 대략 \(p\)에 비례한다.
  7. mgf \(M_X(t) = E[e^{tX}]\)에서 \(M'(0) = E[X]\), \(M''(0) = E[X^2]\). mgf는 분포를 유일하게 정하고, 독립 합의 mgf는 곱이다 — 포아송 + 포아송 = 포아송, 같은 \(p\)의 이항 + 이항 = 이항, 기하 \(r\)개 = 음이항.

연습문제

따로 말이 없으면 시행·칩·결함은 서로 독립이다. 확률은 소수로 답한다. 답이 ±1% 이내면 정답이다.

확률 변수 \(X\)의 pmf가 \(x = 1, 2, 3, 4\)에서 \(p_X(x) = cx\)이고 그 밖에서는 0이다. 상수 \(c\)와 \(E[X]\)를 구하라.

확률의 합이 1이어야 한다: \(c(1+2+3+4) = 1\).

\(10c = 1\)에서 \(c = 0.1\). \(E[X] = \sum x\cdot0.1x = 0.1(1 + 4 + 9 + 16) = 3.0\).

값 0, 1, 2, 3을 갖는 \(X\)의 cdf가 \(F(0) = 0.50\), \(F(1) = 0.80\), \(F(2) = 0.95\), \(F(3) = 1\)이다. \(P(X = 2)\)와 \(P(X\ge2)\)를 구하라.

\(P(X=2) = F(2) - F(1) = 0.15\). \(P(X\ge2) = 1 - F(1) = 0.20\).

\(E[X] = 4\), \(\operatorname{Var}(X) = 2.25\)이다. \(Y = 3X - 5\)의 평균과 표준 편차를 구하라.

\(E[Y] = 3(4) - 5 = 7\). \(\operatorname{Var}(Y) = 9(2.25) = 20.25\), \(\sigma_Y = 4.5\)(\(= 3\times1.5\)). \(-5\)는 산포에 영향이 없다.

웨이퍼 한 장의 스크래치 수 \(X\)의 pmf가 \(P(0) = 0.4\), \(P(1) = 0.3\), \(P(2) = 0.2\), \(P(3) = 0.1\)이다. \(E[X]\)와 \(\operatorname{Var}(X)\)를 구하라.

\(E[X] = 0.3 + 0.4 + 0.3 = 1.0\). \(E[X^2] = 0.3 + 0.8 + 0.9 = 2.0\). \(\operatorname{Var}(X) = 2.0 - 1.0^2 = 1.0\).

불량률 5%인 공정에서 칩 20개를 뽑는다. 불량이 0개일 확률과 1개 이하일 확률을 구하라.

\(X\sim\mathrm{Bin}(20, 0.05)\). \(P(0) = 0.95^{20} = 0.3585\). \(P(1) = 20(0.05)(0.95)^{19} = 0.3774\). \(P(X\le1) = 0.7358\).

8개 사이트를 동시에 시험하는 프로브 카드에서 사이트마다 접촉 불량 확률이 2%다. 한 번 터치다운할 때 접촉 불량 사이트가 하나라도 있을 확률과 평균 접촉 불량 사이트 수를 구하라.

\(1 - 0.98^8 = 1 - 0.8508 = 0.149\). 평균 \(np = 8(0.02) = 0.16\)개. 확률(0.149)이 평균(0.16)보다 조금 작은 것은 두 개 이상 동시에 불량인 경우를 한 번으로 세기 때문이다.

재처리(rework) 한 번에 막두께가 규격에 들어올 확률이 0.25다. 규격에 들어올 때까지의 재처리 횟수 \(X\)의 평균과, 4번 이상 필요할 확률을 구하라.

\(P(X\ge4) = P(X>3)\)이다.

\(X\sim\mathrm{Geom}(0.25)\). \(E[X] = 1/0.25 = 4\). \(P(X\ge4) = P(X>3) = 0.75^3 = 0.422\).

시험마다 통과 확률이 같은 다이 A는 이미 5번 연속 실패했고, 다이 B는 처음 시험한다. 두 다이 모두 같은 \(p\)를 가진다고 할 때 옳은 것은?

기하 분포의 무기억성: \(P(X > 5 + n\mid X > 5) = P(X > n)\). 남은 횟수는 둘 다 \(\mathrm{Geom}(p)\)이다. \(1-(1-p)^6\)은 "처음부터 6번 안에 통과할 확률"이지 다음 시험의 통과 확률이 아니다(다음 시험은 그냥 \(p\)).

신뢰성 시험에서 소자 하나가 스트레스 1사이클에 고장 날 확률이 0.1이다. 같은 소자 하나를 사이클마다 독립으로 다룬다고 할 때, 네 번째 고장(고장 후 즉시 교체)이 나올 때까지의 사이클 수의 평균과 표준 편차를 구하라.

\(X\sim\mathrm{NB}(4, 0.1)\). \(E[X] = 4/0.1 = 40\). \(\operatorname{Var}(X) = 4(0.9)/0.01 = 360\), \(\sigma = 18.97\approx19.0\).

칩 20개 중 4개가 불량인 트레이에서 5개를 비복원으로 뽑는다. 불량이 정확히 1개일 확률과 불량 수의 기댓값을 구하라.

\(P(X=1) = \binom41\binom{16}4/\binom{20}5 = 4(1820)/15504 = 0.470\). \(E[X] = nK/N = 5(4)/20 = 1\).

칩 100개 로트에 불량이 5개 있다. 15개를 비복원으로 뽑아 불량이 1개 이하면 합격시킨다. 합격 확률을 초기하 분포로 정확히 구하고, 이항 근사 \(\mathrm{Bin}(15, 0.05)\)로도 구하라.

\(P(X=0) = \binom{95}{15}/\binom{100}{15}\), \(P(X=1) = 5\binom{95}{14}/\binom{100}{15}\).

초기하: \(P(0) = 0.4357\), \(P(1) = 0.4034\), \(P_a = 0.839\). 이항: \(0.95^{15} = 0.4633\), \(15(0.05)(0.95)^{14} = 0.3658\), \(P_a = 0.829\). \(n/N = 0.15\)라 차이가 0.01 남짓 난다. 비복원이 분산이 작아 \(c\) 근처에 더 몰리기 때문에 합격 확률이 조금 높다.

세정 후 웨이퍼 한 장의 0.1 µm 이상 파티클 수가 평균 3인 포아송 분포를 따른다. 파티클이 하나도 없을 확률과 2개 이하일 확률을 구하라.

\(P(0) = e^{-3} = 0.0498\). \(P(X\le2) = e^{-3}(1 + 3 + 4.5) = 8.5e^{-3} = 0.423\).

면적 0.5 cm²인 다이의 무작위 결함 수율이 90%다. 포아송 모형으로 결함 밀도 \(D_0\)를 구하고, 같은 공정에서 면적이 두 배(1.0 cm²)인 다이의 수율을 예측하라.

\(e^{-0.5D_0} = 0.9\)에서 \(D_0 = -\ln0.9/0.5 = 0.211\)/cm². 면적이 두 배면 \(Y = e^{-0.211} = 0.9^2 = 0.81\). 포아송 모형에서는 면적이 두 배일 때 수율이 제곱이 된다.

소자 500개를 번인하는데 소자마다 초기 고장 확률이 0.004다. 고장 소자가 1개 이하일 확률을 포아송 근사로 구하라.

\(\lambda = 500(0.004) = 2\). \(P(X\le1) \approx e^{-2}(1 + 2) = 0.406\). 이항 정확값은 0.4055로 거의 같다.

확률 변수 \(X\)의 mgf가 \(M_X(t) = e^{3(e^t - 1)}(0.6 + 0.4e^t)^2\)이다. \(X\)는 어떤 두 독립 변수의 합으로 볼 수 있나? \(E[X]\)와 \(\operatorname{Var}(X)\)를 구하라.

mgf의 곱은 독립 합이다. 각 인수를 표에서 찾아라.

\(e^{3(e^t-1)}\)은 \(\mathrm{Poisson}(3)\), \((0.6 + 0.4e^t)^2\)은 \(\mathrm{Bin}(2, 0.4)\)의 mgf다. 따라서 \(X = U + V\), \(U\sim\mathrm{Poisson}(3)\), \(V\sim\mathrm{Bin}(2, 0.4)\) 독립. \(E[X] = 3 + 0.8 = 3.8\), \(\operatorname{Var}(X) = 3 + 2(0.4)(0.6) = 3.48\).

칩 30개짜리 트레이에서 10개를 골라(돌려놓지 않고) 검사할 때 표본 속 불량 수의 분포로 가장 알맞은 것은?

유한한 로트에서 비복원으로 뽑으므로 초기하다. \(n/N = 1/3\)로 커서 이항 근사도 맞지 않는다.

개념 확인 퀴즈

다이당 결함 수의 기댓값이 0.75개라는 말의 뜻으로 가장 알맞은 것은?

기댓값은 pmf의 무게 중심이고 장기 평균이다. 실제로 가질 수 없는 값이어도 된다. 둘째 보기는 \(P(X\ge1)\)이고, 넷째는 중앙값에 대한 설명이다.

\(X\)와 \(Y\)가 독립이고 분산이 같다. \(\operatorname{Var}(2X)\)와 \(\operatorname{Var}(X+Y)\)의 관계는?

\(\operatorname{Var}(2X) = 4\sigma^2\), \(\operatorname{Var}(X+Y) = 2\sigma^2\). \(2X\)는 같은 값이 두 번 더해져 흔들림이 그대로 커지지만, 독립인 \(X\)와 \(Y\)는 서로 일부 상쇄된다. 평균을 낼수록 산포가 줄어드는 이유다.

다이별 결함 수 자료의 평균이 0.5, 분산이 1.4였다. 가장 그럴듯한 해석은?

포아송이면 분산 = 평균이다. 분산/평균 = 2.8이면 결함이 일부 다이에 몰렸다. 몰릴수록 결함 0인 다이가 늘어나 실제 수율이 \(e^{-0.5} = 0.61\)보다 높다. 음이항 수율 모형을 쓴다.

칩 수만 개짜리 로트에서 표본 50개를 비복원으로 뽑을 때 불량 수를 이항 분포로 계산해도 되는 이유는?

비복원이어도 로트가 크면 몇 개를 빼도 남은 로트의 불량률이 거의 그대로다. 그래서 초기하가 이항에 가까워진다.

두 확률 변수 \(X\), \(Y\)의 mgf가 0 근처의 모든 \(t\)에서 같다. 무엇을 결론 내릴 수 있나?

mgf의 유일성: 0 근방에서 mgf가 같으면 분포가 같다. 하지만 분포가 같다는 것이 두 변수가 같은 값을 갖는다는 뜻은 아니다(두 주사위는 분포가 같지만 눈은 다를 수 있다).
