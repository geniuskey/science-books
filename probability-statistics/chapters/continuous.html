Chapter 05

연속 확률 변수

4장의 확률 변수는 0, 1, 2, …처럼 셀 수 있는 값만 가졌다. 그런데 공장에서 재는 양은 대부분 연속이다. 게이트 선폭(CD)은 45.13 nm일 수도 45.1327 nm일 수도 있고, 소자가 고장 나는 시각도 1년과 1년 1초 사이 어디든 될 수 있다. 이런 양에서는 "정확히 45 nm일 확률"이 0이 되어 버려서, 확률을 값 하나가 아니라 구간의 넓이로 말해야 한다. 아래 그림은 CD 측정값을 하나씩 쌓은 히스토그램이다. 측정이 늘수록 막대를 잘게 쪼갤 수 있고, 막대 꼭대기는 매끈한 곡선 하나로 수렴한다. 이 곡선이 이 장의 주인공인 확률 밀도 함수다.

아래 막대의 흰 원을 끌어 측정 개수를 바꾼다 · 누르면 처음부터
  • 확률 밀도 함수 \(f_X\)와 누적 분포 함수 \(F_X\)의 관계(\(F' = f\), \(P(a<X\le b) = F(b) - F(a)\))를 설명하고, 밀도의 정규화 상수와 구간 확률을 적분으로 구한다.
  • 연속 확률 변수의 기댓값 \(E[X] = \int x f(x)\,dx\), \(E[g(X)]\), 분산, 중앙값·최빈값·분위수를 계산하고, 비대칭 분포에서 평균과 중앙값이 갈리는 이유를 말한다.
  • 균일 분포와 지수 분포를 쓰고, 지수 분포의 무기억성과 일정한 고장률, FIT와 MTTF의 관계를 계산한다.
  • 정규 분포를 표준화해 \(z\) 값과 \(\Phi(z)\)로 확률을 구하고, 거꾸로 확률에서 분위수 \(x = \mu + z\sigma\)를 찾으며, 스펙 밖 비율을 ppm으로 나타낸다.
  • 감마·베타·로그 정규·와이블 분포의 모양 모수와 척도 모수, 평균·중앙값·최빈값, 고장률 곡선을 비교하고 어떤 현상에 어떤 분포를 쓰는지 고른다.
  • 확률 변수의 변환 \(Y = g(X)\)의 분포를 누적 분포 함수법과 변수 변환 공식 \(f_Y(y) = f_X(x)\,|dx/dy|\)로 구하고, 역변환 \(X = F^{-1}(U)\)로 원하는 분포의 난수를 만든다.

확률 밀도 함수와 누적 분포 함수

4장에서 이산 확률 변수는 확률 질량 함수 \(p_X(x) = P(X = x)\)로 다 설명되었다. 연속인 양에서는 이 방식이 통하지 않는다. CD가 40–50 nm 사이 어느 값이든 될 수 있다면 가능한 값이 셀 수 없이 많아서, 값 하나하나에 양의 확률을 주면 합이 무한대가 된다. 그래서 값 하나의 확률은 0이고, 확률은 구간에만 붙는다.

히스토그램에서 출발하면 자연스럽다. 측정값 \(n\)개를 폭 \(w\)인 계급으로 나누고, 각 막대의 높이를 개수가 아니라 개수 ÷ (\(n\cdot w\))로 그리면 막대 넓이가 곧 상대 도수가 되고 넓이의 합은 1이다(1장의 밀도 히스토그램). 측정을 늘리며 계급 폭을 줄이면 막대 꼭대기가 한 곡선으로 다가가는데, 그 극한이 밀도다.

확률 밀도 함수

연속 확률 변수 \(X\)의 확률 밀도 함수(probability density function, pdf) \(f_X(x)\)는 모든 구간에 대해 \(P(a \le X \le b) = \int_a^b f_X(x)\,dx\)를 만족하는 함수다. 따라서 \(f_X(x) \ge 0\)이고 \(\int_{-\infty}^{\infty} f_X(x)\,dx = 1\)이다.

두 가지를 바로 얻는다. 첫째, 구간의 폭을 0으로 줄이면 넓이도 0이므로 \(P(X = a) = 0\)이다. 그래서 연속 확률 변수에서는 \(P(a < X < b) = P(a \le X \le b)\)로, 끝점을 넣든 빼든 같다(4장의 이산 변수에서는 달랐다). 둘째, \(f(x)\) 자체는 확률이 아니다. 아주 좁은 구간에서 \(P(x < X \le x + \Delta x) \approx f(x)\,\Delta x\)이므로 \(f\)는 "단위 길이당 확률"이고 단위가 \(x\) 단위의 역수(CD라면 1/nm)다. 그러니 1보다 커도 된다.

어떤 막의 두께 편차 \(X\)가 0–0.25 nm에서 고르게(균일하게) 퍼져 있다. \(0 < x < 0.25\)에서 밀도 \(f(x)\)의 값은?

넓이가 1이어야 하므로 높이 × 0.25 = 1, 높이는 4 nm⁻¹이다. 밀도는 확률이 아니라 확률÷길이라서 구간이 좁으면 얼마든지 커진다. 아래 미니 실험에서 폭을 줄여 보라.

누적 분포 함수

이산이든 연속이든 쓸 수 있는 공통 언어가 누적 분포 함수(cumulative distribution function, cdf) \(F_X(x) = P(X \le x)\)다. 연속 확률 변수에서는 밀도를 왼쪽 끝부터 \(x\)까지 쌓은 넓이다.

$$F_X(x) = \int_{-\infty}^{x} f_X(t)\,dt,\qquad f_X(x) = \frac{dF_X(x)}{dx},\qquad P(a < X \le b) = F_X(b) - F_X(a)$$
\(F\)는 0에서 1로 올라가는 연속 증가 함수다. 밀도가 큰 곳에서 \(F\)가 가파르게 오르고, 밀도가 0인 곳에서는 평평하다. 이산 변수의 \(F\)가 계단이었던 것과 달리 연속 변수의 \(F\)에는 점프가 없다.

아래 시뮬레이터에서 밀도 위의 두 끝점을 끌면 넓이(\(P(a < X < b)\))와 누적 분포 함수의 높이 차가 함께 바뀐다. 같은 분포에서 실제로 표본을 뽑아 구간에 들어간 비율을 세면 그 비율이 넓이로 다가간다.

기댓값·분산·분위수

4장에서 기댓값은 "값 × 확률"의 합이었다. 연속 확률 변수에서는 \(x\) 근처 폭 \(dx\)의 확률이 \(f(x)\,dx\)이므로 합이 적분이 된다. 밀도 곡선을 얇은 판으로 오려 내 손가락 위에 올려놓았을 때 균형이 잡히는 점, 곧 무게 중심이 기댓값이다.

$$E[X] = \mu = \int_{-\infty}^{\infty} x\,f(x)\,dx,\qquad E[g(X)] = \int_{-\infty}^{\infty} g(x)\,f(x)\,dx$$
둘째 식(무의식적 통계학자의 법칙(law of the unconscious statistician, LOTUS))은 \(Y = g(X)\)의 분포를 몰라도 \(E[Y]\)를 \(X\)의 밀도로 바로 구하게 해 준다. 적분이 수렴하지 않으면 기댓값이 없다(예: 코시 분포).
$$\operatorname{Var}(X) = \sigma^2 = E[(X-\mu)^2] = E[X^2] - \mu^2,\qquad E[aX + b] = aE[X] + b,\qquad \operatorname{Var}(aX + b) = a^2\operatorname{Var}(X)$$
성질은 4장의 이산 변수와 똑같다. 단위를 nm에서 Å으로 바꾸면(\(a = 10\)) 평균과 표준 편차는 10배, 분산은 100배가 된다. 측정값에 상수 오프셋을 더해도(\(b\)) 분산은 그대로다.

평균만으로는 분포의 "가운데"를 다 말할 수 없다. \(F(x_p) = p\)인 값 \(x_p\)를 분위수(quantile)라 하고(100\(p\) 백분위수), \(p = 0.5\)인 \(x_{0.5}\)가 중앙값(median)이다. 밀도가 가장 높은 점은 최빈값(mode)이다. 좌우 대칭이고 봉우리가 하나인 분포에서는 셋이 같지만, 오른쪽 꼬리가 긴 수명 분포에서는 대개 최빈값 < 중앙값 < 평균 순으로 벌어진다. 긴 꼬리가 무게 중심을 끌고 가기 때문이다.

균일 분포와 지수 분포

균일 분포

\(X\)가 구간 \([a, b]\) 어디에나 똑같이 떨어질 수 있으면 \(X \sim U(a, b)\), 곧 균일 분포(uniform distribution)를 따른다. 정보가 "이 범위 안"뿐일 때의 모형이고, 디지털 측정의 양자화 오차(분해능 \(\Delta\)이면 \(U(-\Delta/2, \Delta/2)\)), 회전하는 웨이퍼 노치의 각도, 컴퓨터 난수 \(U(0,1)\)이 대표적이다.

$$f(x) = \frac{1}{b-a}\ (a \le x \le b),\qquad F(x) = \frac{x-a}{b-a},\qquad E[X] = \frac{a+b}{2},\qquad \operatorname{Var}(X) = \frac{(b-a)^2}{12}$$
분산의 12는 \(\int_{-1/2}^{1/2}x^2\,dx = 1/12\)에서 온다. 분해능 1 nm인 측정기의 양자화 오차 표준 편차는 \(1/\sqrt{12} = 0.29\) nm다.

지수 분포와 포아송 과정

4장에서 단위 시간당 평균 \(\lambda\)번 일어나는 드문 사건의 개수는 포아송 분포를 따랐다(포아송 과정(Poisson process), 15장). 이제 반대로 "다음 사건까지 기다리는 시간" \(T\)를 보자. 시간 \(t\)까지 사건이 하나도 없을 확률은 포아송 분포에서 \(P(N(t) = 0) = e^{-\lambda t}\)이므로

$$P(T > t) = e^{-\lambda t},\qquad F(t) = 1 - e^{-\lambda t},\qquad f(t) = \lambda e^{-\lambda t}\ (t \ge 0),\qquad E[T] = \frac1\lambda,\ \ \operatorname{Var}(T) = \frac{1}{\lambda^2}$$
\(T \sim \mathrm{Exp}(\lambda)\)를 지수 분포(exponential distribution)라 한다. \(\lambda\)는 비율(1/시간), 평균은 \(1/\lambda\)이고 표준 편차도 평균과 같다. 장비에 파티클이 시간당 3개꼴로 떨어지면 30분 동안 하나도 안 떨어질 확률은 \(e^{-1.5} = 0.223\), 기다림의 중앙값은 \(\ln 2/3\) h = 13.9분이다.

무기억성

지수 분포에는 다른 연속 분포에 없는 성질이 있다. 이미 \(s\)시간 동안 고장 나지 않은 소자가 앞으로 \(t\)시간 더 버틸 확률은

$$P(T > s + t \mid T > s) = \frac{P(T > s+t)}{P(T > s)} = \frac{e^{-\lambda(s+t)}}{e^{-\lambda s}} = e^{-\lambda t} = P(T > t)$$
살아온 시간 \(s\)가 식에서 사라진다. 이것이 무기억성(memoryless property)이다. 연속 분포 가운데 무기억성을 가진 것은 지수 분포뿐이다(이산에서는 4장의 기하 분포).

무기억성은 고장률로 보면 더 분명하다. 시각 \(t\)까지 살아남은 것 가운데 다음 순간 고장 나는 비율, 곧 고장률(hazard rate, failure rate)은

$$h(t) = \lim_{\Delta t\to0}\frac{P(t < T \le t + \Delta t \mid T > t)}{\Delta t} = \frac{f(t)}{1 - F(t)} = \frac{f(t)}{R(t)}$$
\(R(t) = 1 - F(t) = P(T > t)\)를 신뢰도 함수(reliability function, survival function)라 한다. 지수 분포는 \(h(t) = \lambda e^{-\lambda t}/e^{-\lambda t} = \lambda\), 곧 고장률이 나이와 상관없이 일정하다. 늙지 않으니 기억할 것도 없다.

정규 분포와 표준화

CD, 막두께, 문턱 전압, 저항처럼 수많은 작은 요인이 더해져 생기는 양은 거의 언제나 종 모양으로 퍼진다. 7장의 중심 극한 정리가 그 이유를 설명한다. 이 종 모양이 정규 분포(normal distribution) \(X \sim N(\mu, \sigma^2)\)이다(가우스 분포라고도 한다).

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}}\exp\!\left[-\frac{(x-\mu)^2}{2\sigma^2}\right],\qquad -\infty < x < \infty,\qquad E[X] = \mu,\ \ \operatorname{Var}(X) = \sigma^2$$
\(\mu\)는 봉우리의 위치, \(\sigma\)는 봉우리에서 변곡점까지의 거리다(\(f''(\mu \pm \sigma) = 0\)). 봉우리 높이는 \(1/(\sigma\sqrt{2\pi}) \approx 0.399/\sigma\)라서 σ가 반이 되면 두 배로 솟는다. 표기 \(N(\mu, \sigma^2)\)의 둘째 자리는 분산이다.

정규 분포의 누적 분포 함수는 초등 함수로 적분되지 않는다. 그래서 모든 정규 분포를 하나로 바꿔 표 하나로 계산한다. 평균을 빼고 표준 편차로 나누는 표준화(standardization)다.

$$Z = \frac{X - \mu}{\sigma} \sim N(0, 1),\qquad P(X \le x) = \Phi\!\left(\frac{x-\mu}{\sigma}\right),\qquad \Phi(z) = \int_{-\infty}^{z}\frac{1}{\sqrt{2\pi}}e^{-t^2/2}\,dt$$
\(Z\)를 표준 정규 분포(standard normal distribution), \(z = (x-\mu)/\sigma\)를 z 값(z-score)이라 한다. z 값은 "평균에서 표준 편차 몇 개만큼 떨어졌는가"다. \(\phi(z)\)는 표준 정규 밀도. 대칭성으로 \(\Phi(-z) = 1 - \Phi(z)\)이다.

감마·베타·로그 정규·와이블 분포

정규 분포는 음수까지 퍼지고 좌우가 대칭이다. 수명, 기다림, 비율처럼 0 이상이거나 [0, 1] 안에 갇힌 양, 오른쪽 꼬리가 긴 양에는 다른 분포가 필요하다. 네 가족을 소개한다. 각 분포에는 모양을 정하는 모양 모수와 가로축 단위를 정하는 척도 모수가 있다. 척도 모수를 바꾸면 그래프가 가로로 늘거나 줄 뿐 모양은 그대로다.

감마 분포

포아송 과정에서 \(k\)번째 사건까지 기다리는 시간은 독립인 지수 분포 \(k\)개의 합이다. 이 분포를 일반화한 것이 감마 분포(gamma distribution) \(\mathrm{Gamma}(k, \theta)\)다(모양 \(k\), 척도 \(\theta = 1/\lambda\)). \(k\)가 정수이면 얼랑 분포라고도 한다.

$$f(x) = \frac{x^{k-1}e^{-x/\theta}}{\Gamma(k)\,\theta^k}\ (x > 0),\qquad E[X] = k\theta,\ \ \operatorname{Var}(X) = k\theta^2,\qquad \Gamma(k) = \int_0^\infty t^{k-1}e^{-t}dt$$
감마 함수는 계승의 연장이다: \(\Gamma(k) = (k-1)!\), \(\Gamma(1/2) = \sqrt\pi\). \(k = 1\)이면 지수 분포. \(k\)가 커지면 7장의 중심 극한 정리대로 정규 분포에 가까워진다. 카이제곱 분포 \(\chi^2_\nu\)는 \(\mathrm{Gamma}(\nu/2, 2)\)이다(8장).

베타 분포

0과 1 사이의 비율 — 수율, 커버리지, 불량률 그 자체의 불확실성 — 을 그릴 때는 베타 분포(beta distribution) \(\mathrm{Beta}(a, b)\)를 쓴다. 모양이 매우 유연해서 균일(\(a = b = 1\)), 종 모양, U자, 한쪽으로 몰린 모양을 다 만든다. 9장의 베이즈 추정에서 비율의 사전 분포로 다시 나온다.

$$f(x) = \frac{x^{a-1}(1-x)^{b-1}}{B(a,b)}\ (0 < x < 1),\qquad E[X] = \frac{a}{a+b},\qquad \operatorname{Var}(X) = \frac{ab}{(a+b)^2(a+b+1)},\qquad \text{최빈값} = \frac{a-1}{a+b-2}$$
\(B(a,b) = \Gamma(a)\Gamma(b)/\Gamma(a+b)\). 최빈값 식은 \(a, b > 1\)일 때. \(a + b\)가 클수록 평균 근처로 좁게 몰린다.

로그 정규 분포

\(\ln X\)가 정규 분포 \(N(\mu, \sigma^2)\)를 따르면 \(X\)는 로그 정규 분포(lognormal distribution)를 따른다. 정규 분포가 작은 요인의 합에서 나온다면, 로그 정규 분포는 작은 요인의 곱에서 나온다. 보이드가 자라는 속도, 결함 크기, 누설 전류처럼 비율로 흔들리는 양이 그렇다.

$$f(x) = \frac{1}{x\sigma\sqrt{2\pi}}\exp\!\left[-\frac{(\ln x-\mu)^2}{2\sigma^2}\right]\ (x > 0),\qquad \text{중앙값} = e^{\mu},\ \ E[X] = e^{\mu + \sigma^2/2},\ \ \text{최빈값} = e^{\mu-\sigma^2}$$
여기서 \(\mu, \sigma\)는 \(X\)가 아니라 \(\ln X\)의 평균과 표준 편차다. 신뢰성에서는 중앙 수명 \(t_{50} = e^\mu\)와 모양 \(\sigma\)로 말한다. \(P(X \le x) = \Phi\big((\ln x - \mu)/\sigma\big)\)이므로 정규 표로 계산한다.

와이블 분포

사슬은 가장 약한 고리에서 끊어진다. 산화막도 넓이 전체 가운데 가장 약한 한 점에서 뚫린다. 많은 독립 요소 중 가장 먼저 고장 나는 것의 시각을 그리는 분포가 와이블 분포(Weibull distribution) \(\mathrm{Weibull}(\beta, \eta)\)다.

$$F(t) = 1 - e^{-(t/\eta)^\beta},\qquad f(t) = \frac{\beta}{\eta}\left(\frac{t}{\eta}\right)^{\beta-1}e^{-(t/\eta)^\beta},\qquad h(t) = \frac{\beta}{\eta}\left(\frac{t}{\eta}\right)^{\beta-1},\qquad E[T] = \eta\,\Gamma(1 + 1/\beta)$$
\(\beta\)는 모양 모수, \(\eta\)는 척도 모수(특성 수명(characteristic life))다. \(t = \eta\)에서 언제나 \(F = 1 - e^{-1} = 63.2\%\)가 고장 난다. 고장률이 \(t^{\beta-1}\)에 비례하므로 β < 1은 초기 고장(감소), β = 1은 지수 분포(일정), β > 1은 마모(증가)다. 욕조 곡선의 세 구간을 β 하나로 그린다.

확률 변수의 변환과 역변환 표본 추출

공정 엔지니어는 선폭을 재지만 회로 설계자가 궁금한 것은 저항 \(R = \rho L/(WH)\)이다. 수명 \(T\)를 알면 \(\ln T\)의 분포가 궁금하다. \(X\)의 분포를 알 때 \(Y = g(X)\)의 분포는 어떻게 구할까?

누적 분포 함수법

가장 확실한 방법은 \(Y\)의 누적 분포 함수를 \(X\)의 사건으로 바꿔 쓰는 것이다. \(g\)가 증가 함수이면 \(\{Y \le y\} = \{X \le g^{-1}(y)\}\)이므로 \(F_Y(y) = F_X(g^{-1}(y))\)이고, 미분하면 밀도가 나온다. 예를 들어 \(X \sim U(0,1)\), \(Y = X^2\)이면 \(F_Y(y) = P(X \le \sqrt y) = \sqrt y\), \(f_Y(y) = 1/(2\sqrt y)\) (\(0 < y < 1\))다. 고른 \(X\)를 제곱하면 0 근처로 몰린다.

변수 변환 공식

\(g\)가 \(X\)의 범위에서 미분 가능한 단조 함수이면 \(Y = g(X)\)의 밀도는 \(f_Y(y) = f_X\big(g^{-1}(y)\big)\left|\dfrac{d}{dy}g^{-1}(y)\right|\)이다. 단조가 아니면(예: \(Y = X^2\), \(X\)가 음수도 가질 때) \(g(x) = y\)인 모든 \(x\)에 대해 이 항을 더한다.

선형 변환 \(Y = aX + b\)는 \(f_Y(y) = f_X\big((y-b)/a\big)/|a|\)로 모양을 그대로 둔 채 옮기고 늘인다. 표준화가 그 예다. 정규 분포를 선형 변환하면 다시 정규이므로 \(aX + b \sim N(a\mu + b, a^2\sigma^2)\)이다. 반면 비선형 변환은 모양을 바꾸고, 평균도 그대로 옮겨지지 않는다: 일반적으로 \(E[g(X)] \ne g(E[X])\)다(볼록 함수이면 \(E[g(X)] \ge g(E[X])\), 옌센 부등식).

핵심 정리

  1. 연속 확률 변수의 확률은 밀도 아래 넓이다: \(P(a < X \le b) = \int_a^b f(x)\,dx = F(b) - F(a)\). \(f \ge 0\), 전체 넓이 1, \(P(X = a) = 0\). 밀도는 확률÷길이라서 1보다 클 수 있고, \(F' = f\)이다.
  2. \(E[X] = \int x f\,dx\)(무게 중심), \(E[g(X)] = \int g f\,dx\), \(\operatorname{Var}(X) = E[X^2] - \mu^2\), \(\operatorname{Var}(aX+b) = a^2\operatorname{Var}(X)\). 분위수 \(x_p\)는 \(F(x_p) = p\)의 해, 중앙값은 \(x_{0.5}\). 오른쪽 꼬리가 길면 최빈값 < 중앙값 < 평균.
  3. \(U(a,b)\): 평균 \((a+b)/2\), 분산 \((b-a)^2/12\). \(\mathrm{Exp}(\lambda)\): \(R(t) = e^{-\lambda t}\), 평균·표준 편차 \(1/\lambda\), 고장률 \(h = f/R = \lambda\) 일정, 무기억성 \(P(T > s+t \mid T > s) = P(T > t)\). 1 FIT = \(10^{-9}\)/h, MTTF = \(1/\lambda\).
  4. \(N(\mu, \sigma^2)\)은 \(Z = (X-\mu)/\sigma\)로 표준화해 \(\Phi(z)\)로 계산한다. 68–95–99.7 규칙, \(z_{0.05} = 1.645\), \(z_{0.025} = 1.960\), \(z_{0.005} = 2.576\). 분위수 \(x_p = \mu + \sigma\Phi^{-1}(p)\). 스펙 밖 비율은 두 꼬리의 합이고, ±3σ 가운데이면 2700 ppm.
  5. 감마 \(\mathrm{Gamma}(k,\theta)\)(지수 \(k\)개의 합, 평균 \(k\theta\)), 베타 \(\mathrm{Beta}(a,b)\)([0,1]의 비율, 평균 \(a/(a+b)\)), 로그 정규(\(\ln X\)가 정규, 중앙값 \(e^\mu\), 평균 \(e^{\mu+\sigma^2/2}\)), 와이블 \(F = 1 - e^{-(t/\eta)^\beta}\)(가장 약한 고리, \(h \propto t^{\beta-1}\), \(F(\eta) = 63.2\%\), 넓이 환산 \(\eta \propto A^{-1/\beta}\)). TDDB는 와이블, EM은 로그 정규.
  6. 변환 \(Y = g(X)\): 누적 분포 함수법 \(F_Y(y) = P(g(X) \le y)\) 또는 단조 \(g\)에서 \(f_Y(y) = f_X(x)\,|dx/dy|\). 일반적으로 \(E[g(X)] \ne g(E[X])\)(옌센).
  7. \(F_X(X) \sim U(0,1)\)(확률 적분 변환), 거꾸로 \(X = F^{-1}(U)\)는 분포 \(F\)를 따른다(역변환 표본 추출): 지수 \(-\ln(1-U)/\lambda\), 와이블 \(\eta(-\ln(1-U))^{1/\beta}\), 결함 반지름 \(R_0\sqrt U\).

연습문제

표준 정규 분포 값은 부록 A의 표나 계산기를 쓴다. 표에서 z를 소수 둘째 자리로 반올림해 읽은 답도 정답으로 처리되도록 허용 오차를 잡았다. 따로 말이 없으면 답이 ±1% 이내면 정답이다.

\(X \sim U(2, 8)\)이다. \(P(3 < X < 5.5)\)와 \(X\)의 표준 편차는?

밀도는 \(1/6\)로 일정하다. 분산은 \((b-a)^2/12\).

\(P = (5.5 - 3)/6 = 0.417\). \(\sigma = (8-2)/\sqrt{12} = 1.73\).

\(f(x) = kx^3\) (\(0 \le x \le 2\)), 그 밖은 0인 밀도가 있다. \(k\)와 \(P(X > 1)\)은?

\(\int_0^2 x^3dx = 4\).

\(k\cdot4 = 1\)에서 \(k = 1/4\). \(F(x) = x^4/16\)이므로 \(P(X > 1) = 1 - 1/16 = 0.9375\).

계측 장비의 대기열에서 다음 로트가 도착하기까지의 시간이 평균 20분인 지수 분포를 따른다. 30분 넘게 기다릴 확률은?

\(\lambda = 1/20\)/분, \(P(T > 30) = e^{-30/20} = e^{-1.5} = 0.223\).

고장률이 500 FIT로 일정한 칩이 이미 3년을 고장 없이 동작했다. 앞으로 2년(17,520 h) 안에 고장 날 확률은?

무기억성: 지나온 3년은 상관없다.

\(\lambda = 5\times10^{-7}\)/h. \(P = 1 - e^{-5\times10^{-7}\times17520} = 1 - e^{-0.00876} = 0.00872\).

\(X \sim N(100, 15^2)\)이다. \(P(X < 120)\)과 \(P(85 < X < 130)\)은?

\(z = 20/15 = 1.33\), \(\Phi(1.33) = 0.909\). \(P(-1 < Z < 2) = 0.9772 - 0.1587 = 0.819\).

핀 CD가 \(N(32.0, 0.8^2)\) nm이고 스펙은 30–34 nm이다. 스펙 밖 비율을 ppm으로 구하라.

\(z = \pm2/0.8 = \pm2.5\). \(p = 2(1 - \Phi(2.5)) = 2(0.00621) = 0.01242\), 곧 12,400 ppm.

게이트 산화막 두께가 \(N(5.00, 0.08^2)\) nm이다. 두께가 가장 두꺼운 5%를 골라내는 경계값은?

\(x = \mu + z_{0.05}\sigma = 5.00 + 1.645(0.08) = 5.132\) nm.

스펙이 목표값 ±6 nm이고 공정 평균이 목표값에 있다. 스펙 밖 비율을 100 ppm 이하로 하려면 σ는 얼마 이하여야 하는가?

양쪽 꼬리가 각각 50 ppm = \(5\times10^{-5}\)이다.

\(z_{0.00005} = 3.891\). \(6/\sigma \ge 3.891\)이므로 \(\sigma \le 1.54\) nm.

수명이 \(\mathrm{Weibull}(\beta = 2, \eta = 1000\ \text{h})\)이다. 500 h까지 고장 날 확률과 중앙 수명은?

\(F(500) = 1 - e^{-0.5^2} = 1 - e^{-0.25} = 0.221\). \(t_{0.5} = 1000(\ln 2)^{1/2} = 833\) h.

신공정 로트의 수율 \(Y\)에 대한 엔지니어의 믿음을 \(\mathrm{Beta}(8, 2)\)로 나타냈다. 평균 수율과 \(P(Y < 0.6)\)은?

\(b = 2\)이면 \(f(y) = 72y^7(1-y)\)로 적분이 쉽다.

\(E[Y] = 8/10 = 0.8\). \(F(y) = \int_0^y 72t^7(1-t)\,dt = 9y^8 - 8y^9\), \(F(0.6) = 9(0.01680) - 8(0.01008) = 0.0705\).

EM 수명이 \(t_{50} = 1000\) h, \(\sigma = 0.8\)인 로그 정규 분포를 따른다. 300 h 안에 고장 날 확률과 평균 수명은?

\(z = \ln(300/1000)/0.8 = -1.505\), \(\Phi(-1.505) = 0.0662\). \(E[T] = 1000e^{0.8^2/2} = 1000e^{0.32} = 1377\) h.

장비 정비가 독립인 세 단계로 이루어지고, 각 단계의 소요 시간이 평균 2 h인 지수 분포다. 총 시간 \(T\)의 표준 편차와 \(P(T > 10\ \text{h})\)는?

\(T \sim \mathrm{Gamma}(3, 2)\). 얼랑 분포에서 \(P(T > t)\)는 "시간 \(t\) 동안 포아송 사건이 3개 미만"과 같다.

\(\operatorname{Var}(T) = 3\cdot2^2 = 12\), \(\sigma = 3.46\) h. 비율 \(\lambda = 0.5\)/h로 10 h 동안 사건 수는 \(\mathrm{Poisson}(5)\)이므로 \(P(T > 10) = P(N < 3) = e^{-5}(1 + 5 + 12.5) = 0.125\).

\(X \sim N(2, 0.5^2)\)이고 \(Y = e^X\)이다. \(P(Y > 10)\)과 \(E[Y]\)는? \(e^{E[X]}\)와 비교하라.

\(P(Y > 10) = P(X > \ln 10) = 1 - \Phi\big((2.303 - 2)/0.5\big) = 1 - \Phi(0.605) = 0.273\). \(Y\)는 로그 정규이므로 \(E[Y] = e^{2 + 0.125} = 8.37\), 반면 \(e^{E[X]} = e^2 = 7.39\)이다(옌센).

균일 난수 \(u\)로 (1) 밀도 \(f(x) = 2x\) (\(0 \le x \le 1\))인 난수를 만들 때 \(u = 0.36\)에서 나오는 값 \(x_1\), (2) \(\mathrm{Weibull}(\beta = 2, \eta = 100\ \text{h})\) 난수를 만들 때 \(u = 0.9\)에서 나오는 값 \(x_2\)를 구하라.

(1) \(F(x) = x^2 = u\)에서 \(x_1 = \sqrt{0.36} = 0.6\). (2) \(1 - e^{-(x/100)^2} = 0.9\)에서 \(x_2 = 100\sqrt{\ln 10} = 152\) h.

"이미 \(s\)시간을 버틴 것과 상관없이 앞으로 \(t\)시간 더 버틸 확률이 같다"는 성질을 가진 연속 분포는?

지수 분포만 무기억성을 가진다. 고장률이 일정하기 때문이다. 와이블 β = 2는 고장률이 \(t\)에 비례해 늘고, 균일 분포 \(U(0, b)\)는 \(b\)에 가까울수록 고장률이 무한대로 커진다.

연속 확률 변수 \(X\)의 밀도가 \(x = 3\)에서 \(f(3) = 2.5\)이다. 옳은 것은?

밀도는 확률÷길이다. 값이 큰 곳은 좁은 구간에 확률이 몰려 있다는 뜻일 뿐이고, 전체 넓이가 1이면 된다. \(P(2.995 < X < 3.005) \approx 2.5\times0.01 = 0.025\).

개념 확인 퀴즈

CD가 연속 확률 변수일 때 \(P(\text{CD} = 45.000\ \text{nm})\)는?

폭이 0인 구간의 넓이는 0이다. 실제 측정값은 분해능 Δ만큼의 구간 \([45 - \Delta/2, 45 + \Delta/2]\)에 들 확률 \(\approx f(45)\Delta\)로 해석해야 한다.

와이블 모양 모수 β = 0.6인 제품에 번인을 하면 출하 후 고장률은?

β < 1이면 \(h(t) \propto t^{\beta-1}\)이 시간에 따라 줄어든다. 번인으로 고장률이 높은 초기 구간을 공장에서 지나 보내면 고객은 낮은 고장률부터 쓴다. β > 1(마모)인 제품에 번인을 하면 오히려 수명을 깎는다.

스펙이 ±3인 두 공정 A(평균이 가운데, σ = 1)와 B(평균이 1만큼 치우침, σ = 0.75) 중 스펙 밖 비율이 더 큰 것은?

A: \(2(1 - \Phi(3)) = 0.0027\). B: 가까운 쪽 \(z = 2/0.75 = 2.67\), \(1 - \Phi(2.67) = 0.0038\), 먼 쪽 \(z = 5.33\)은 무시할 만하다. 불량을 정하는 것은 σ 자체가 아니라 가까운 경계까지의 z 값이다(16장의 \(C_{pk}\)).

\(\ln T\)의 평균이 \(\mu\)인 로그 정규 수명에서 \(e^\mu\)는 무엇인가?

\(P(T \le e^\mu) = P(\ln T \le \mu) = 0.5\). 지수 함수는 단조라 분위수를 그대로 옮기지만 평균은 옮기지 않는다. 평균은 \(e^{\mu+\sigma^2/2}\)로 더 크다.

균일 난수 \(U\)로 평균 \(1/\lambda\)인 지수 분포 난수를 만드는 식은?

\(F^{-1}(u) = -\ln(1-u)/\lambda\)이고, \(1 - U\)도 \(U(0,1)\)이므로 \(-\ln(U)/\lambda\)로 써도 같은 분포다. 넷째 보기는 밀도 식이다.
