Appendix B

용어집과 종합 문제

1–17장 본문에서 처음 정의한 용어를 모았다. 설명은 본문의 정의를 한두 문장으로 정리한 것이며, 링크를 누르면 그 용어가 처음 나온 절로 이동한다. 검색창에 한국어나 영어를 넣거나 장을 골라 목록을 좁힐 수 있다. 뒤의 종합 문제는 장마다 4문제씩, 계산 문제 셋과 선택형 하나를 섞어 낸다. 대부분 막두께 측정, 검사 장비의 과검출, 웨이퍼 결함 수와 다이 수율, 임계 치수 산포, 스플릿 로트, 검량선, 식각 실험, 장비 대기열, 관리도, 가속 수명 시험처럼 반도체 현장의 숫자로 묻는다. ‘종합’ 표시가 붙은 문제는 여러 장의 도구를 함께 써야 풀린다. 그다음 장을 넘나드는 반복 연습 두 개, 시험 직전 체크리스트, 각 장의 개념 퀴즈를 무작위로 섞어 내는 코너가 이어진다. 분포표와 공식은 부록 A에 있다.

웨이퍼 한 장에서 산화막 두께를 8점 쟀다(nm): 101.2, 99.8, 100.5, 102.1, 98.9, 100.0, 101.6, 99.3. 표본 평균, 표본 표준 편차, 변동 계수(CV)를 구하라.

\(s^2 = \sum(x_i - \bar x)^2/(n-1)\), \(\mathrm{CV} = s/\bar x\times100\%\). 100을 빼고 계산하면 편하다.

100을 뺀 값의 합이 \(3.4\)이므로 \(\bar x = 100.425\ \text{nm}\). 편차 제곱합 \(= 8.955\), \(s^2 = 8.955/7 = 1.279\), \(s = 1.131\ \text{nm}\). \(\mathrm{CV} = 1.131/100.425 = 1.13\%\). 공정 엔지니어는 이것을 “두께 균일도 1.1%(1σ)”라고 말한다. → 1장 퍼짐의 척도

같은 막을 장비 A에서 10장(평균 100.2 nm, 표준 편차 1.1 nm), 장비 B에서 15장(평균 99.6 nm, 표준 편차 1.4 nm) 쟀다. 원자료 없이, 25장 전체의 평균과 표본 표준 편차를 구하라.

전체 제곱합 = 묶음 안 제곱합 \(\sum(n_i-1)s_i^2\) + 묶음 사이 제곱합 \(\sum n_i(\bar x_i - \bar x)^2\). 14장 분산 분석의 분해와 같은 식이다.

\(\bar x = (10\cdot100.2 + 15\cdot99.6)/25 = 99.84\). 안: \(9(1.21) + 14(1.96) = 38.33\). 사이: \(10(0.36)^2 + 15(0.24)^2 = 2.16\). 합 \(40.49\), \(s = \sqrt{40.49/24} = 1.30\ \text{nm}\). 두 장비의 평균 차이가 전체 산포를 조금 키운다 — 장비를 섞어 관리하면 이 몫이 공정 능력을 깎는다. → 1장 분산과 표준 편차

트랜지스터 누설 전류 1000개를 모았더니 오른쪽 꼬리가 길게 늘어진 분포였다(몇 개는 중앙값의 100배). 이 자료에 대해 옳은 것은?

오른쪽 꼬리는 평균을 끌어올린다(양의 왜도, 평균 > 중앙값). 평균과 표준 편차는 극단값 몇 개에 크게 흔들리지만 중앙값과 IQR은 거의 움직이지 않는다. 누설 전류처럼 곱셈적으로 흔들리는 양은 로그를 취하면 대칭에 가까워진다(5장 로그 정규). → 1장 분포의 모양

금속막 다섯 장의 두께 \(x\)(nm)와 면저항 \(y\)(mΩ/□)가 (95, 21.3), (98, 20.5), (100, 20.1), (102, 19.4), (105, 19.0)이다. 표본 상관 계수를 구하라.

\(r = S_{xy}/\sqrt{S_{xx}S_{yy}}\). \(\bar x = 100\), \(\bar y = 20.06\).

\(S_{xx} = 25 + 4 + 0 + 4 + 25 = 58\), \(S_{yy} = 3.292\), \(S_{xy} = -5(1.24) - 2(0.44) + 0 + 2(-0.66) + 5(-1.06) = -13.7\). \(r = -13.7/\sqrt{58\cdot3.428} = -0.991\). 면저항 \(R_s = \rho/t\)이므로 두께가 늘면 줄어든다. 좁은 범위에서는 \(1/t\)도 거의 직선이라 \(|r|\)이 1에 가깝다. → 1장 산점도와 상관 계수

웨이퍼 25장 로트 중 3장이 금속 오염돼 있다. 4장을 무작위로(비복원) 골라 분석할 때, 오염 웨이퍼가 한 장 이상 들어 있을 확률은?

여사건: 4장 모두 깨끗한 경우의 수는 \(\binom{22}{4}\).

\(P = 1 - \binom{22}{4}/\binom{25}{4} = 1 - 7315/12650 = 0.422\). 4장 분석으로는 오염 로트의 절반 넘게를 놓친다. 이 계산이 4장의 초기하 분포다. → 2장 경우의 수

로트 15장에 각각 00–99 중 하나의 슬롯 번호를 무작위로(중복 허용, 같은 확률로) 붙인다. 두 장 이상이 같은 번호를 받을 확률은?

모두 다를 확률 \(\dfrac{100\cdot99\cdots86}{100^{15}}\)을 1에서 뺀다.

\(P(\text{모두 다름}) = \prod_{i=0}^{14}(100-i)/100 = 0.331\), 따라서 \(P = 0.669\). 100칸에 15개만 넣어도 충돌이 더 흔하다 — 쌍의 수가 \(\binom{15}{2} = 105\)이기 때문이다. 무작위 ID의 자릿수를 정할 때 이 계산을 한다. → 2장 생일 문제

검사에서 웨이퍼에 입자 결함이 있을 확률 0.08, 긁힘이 있을 확률 0.05, 둘 다 있을 확률 0.02이다. 둘 다 없을 확률과, 정확히 하나만 있을 확률은?

\(P(A\cup B) = P(A) + P(B) - P(A\cap B)\). 정확히 하나는 \(P(A) + P(B) - 2P(A\cap B)\).

\(P(A\cup B) = 0.08 + 0.05 - 0.02 = 0.11\), 둘 다 없음 \(= 0.89\). 정확히 하나 \(= 0.06 + 0.03 = 0.09\). 벤 다이어그램의 세 조각(0.06, 0.02, 0.03)을 그리면 한눈에 보인다. → 2장 확률의 공리와 기본 성질

불량률 5%로 안정된 공정에서 다이가 독립적으로 만들어진다. 테스터에서 연달아 불량 다이 4개가 나왔다. 다음 다이에 대한 판단으로 옳은 것은?

독립 시행에서는 과거가 다음 결과를 바꾸지 않는다. 대수의 법칙은 상대 도수가 긴 반복에서 0.05로 다가간다는 말이지, 앞의 편차를 갚는다는 뜻이 아니다. 한편 확률 \(0.05^4 = 6\times10^{-6}\)인 일이 실제로 일어났다면 공정이 안정·독립이라는 모형이 틀렸을 가능성(결함 군집, 장비 이상)을 먼저 본다 — 16장 관리도의 생각이다. → 2장 상대 도수와 대수의 법칙

3장 조건부 확률과 베이즈 정리본문 →

다이의 0.5%가 실제 불량이다. 광학 검사는 불량의 98%를 잡고(민감도), 양품의 3%를 불량으로 오검출한다. 검출된 다이가 실제 불량일 확률과, 통과한 다이가 실제 불량일 확률(ppm)은?

전확률: \(P(+) = 0.005(0.98) + 0.995(0.03)\). 통과는 \(P(-) = 1 - P(+)\), 그중 불량은 \(0.005\times0.02\).

\(P(+) = 0.0049 + 0.02985 = 0.03475\). \(P(D\mid+) = 0.0049/0.03475 = 0.141\) — 검출의 86%가 과검출이다(기저율 오류). \(P(D\mid-) = 0.0001/0.96525 = 1.04\times10^{-4} = 104\ \text{ppm}\). 검사가 불량 0.5%(5000 ppm)를 104 ppm으로 줄인다. → 3장 베이즈 정리와 기저율 오류

진공 계통이 신뢰도 0.9인 펌프 3대의 병렬(하나만 돌아도 됨)과 신뢰도 0.99인 제어기의 직렬로 이루어져 있다. 부품이 서로 독립일 때 계통 신뢰도를 소수 넷째 자리까지 구하라.

병렬: \(1 - (1-R)^3\). 직렬: 곱.

펌프 묶음 \(1 - 0.1^3 = 0.999\), 계통 \(0.99\times0.999 = 0.9890\). 이제 약한 고리는 제어기다 — 병렬 중복은 이미 충분하니 제어기를 이중화해야 효과가 크다. 17장 계통 신뢰도에서 수명 함수로 확장한다. → 3장 직렬·병렬 계통의 신뢰도

장비 A, B, C가 웨이퍼를 각각 50%, 30%, 20% 처리하고, 불량률은 1%, 2%, 3%이다. 무작위 웨이퍼가 불량일 확률과, 불량 웨이퍼가 장비 C에서 왔을 확률은?

확률 나무의 가지 곱을 더하면 전확률, 한 가지의 몫이 사후 확률.

\(P(D) = 0.005 + 0.006 + 0.006 = 0.017\). \(P(C\mid D) = 0.006/0.017 = 0.353\). 처리량은 20%뿐인 C가 불량의 35%를 낸다 — 커머낼리티 분석이 장비를 의심하는 근거가 이것이다. → 3장 확률 나무와 전확률 공식

사건 \(A\)(다이가 bin 3)와 \(B\)(다이가 bin 7)는 한 다이가 동시에 가질 수 없는 결과이며, \(P(A) = 0.04\), \(P(B) = 0.02\)이다. 옳은 것은?

배반이면 \(B\)가 일어났다는 사실이 \(A\)를 불가능하게 만든다: \(P(A\mid B) = 0\). 확률이 0이 아닌 두 배반 사건은 언제나 종속이다. 독립은 “서로 정보를 주지 않는다”, 배반은 “함께 일어날 수 없다”는 전혀 다른 말이다. → 3장 독립 사건

4장 이산 확률 변수본문 →

웨이퍼당 큰 결함 수가 평균 1.6개인 포아송 분포를 따른다. 결함이 하나도 없을 확률과 3개 이상일 확률은?

\(p(k) = e^{-\lambda}\lambda^k/k!\). \(P(X\ge3) = 1 - p(0) - p(1) - p(2)\).

\(p(0) = e^{-1.6} = 0.2019\), \(p(1) = 0.3230\), \(p(2) = 0.2584\). \(P(X\ge3) = 1 - 0.7834 = 0.217\). 결함이 다이에 고르게 떨어지면 이 \(p(0)\)이 17장의 포아송 수율과 같은 꼴이다. → 4장 포아송 분포

입고 로트에서 50개를 뽑아 불량이 1개 이하면 합격시킨다(로트가 커서 이항으로 본다). 로트 불량률이 2%일 때와 5%일 때 합격 확률은?

\(P(X\le1) = (1-p)^{50} + 50p(1-p)^{49}\).

\(p = 0.02\): \(0.3642 + 0.3716 = 0.736\). \(p = 0.05\): \(0.0769 + 0.2025 = 0.279\). 불량률에 따라 합격 확률을 그린 것이 16장의 OC 곡선이다. 불량 5% 로트도 네 번에 한 번은 통과한다. → 4장 이항 분포

100개 로트에 불량이 5개 있다. 10개를 비복원으로 뽑을 때 불량이 하나도 없을 확률을 초기하 분포로 정확히, 그리고 이항 근사(\(p = 0.05\))로 구하라.

초기하: \(\binom{95}{10}/\binom{100}{10}\). 이항: \(0.95^{10}\).

초기하 \(= \prod_{i=0}^{9}(95-i)/(100-i) = 0.584\), 이항 \(0.95^{10} = 0.599\). 뽑는 비율이 10%라 차이가 2.5% 난다. 비복원 추출은 뽑을수록 남은 불량 비율이 바뀌어 분산이 \((N-n)/(N-1)\)배 줄어든다. → 4장 초기하 분포와 로트 샘플링 검사

프로브 카드 교체 후 터치다운을 반복하는데, 매번 독립적으로 2% 확률로 접촉 불량이 난다. “첫 접촉 불량이 날 때까지의 터치다운 횟수”의 분포와 평균은?

“첫 성공(여기서는 불량)까지의 시행 횟수”가 기하 분포의 정의이고 \(E[X] = 1/p = 50\)이다. 무기억성 때문에 49번 무사했어도 앞으로 기다릴 평균 횟수는 여전히 50이다 — 연속판이 5장의 지수 분포다. → 4장 기하 분포

5장 연속 확률 변수본문 →

게이트 CD가 \(N(45, 1.2^2)\) nm를 따른다. 규격 43–47 nm 안에 들 확률과, 규격 밖 비율(ppm)은?

\(z = \pm2/1.2 = \pm1.667\). \(P = 2\Phi(1.667) - 1\).

\(\Phi(1.667) = 0.9522\), \(P = 0.904\). 규격 밖 \(0.0956 = 95\,600\ \text{ppm}\). 규격 폭이 \(\pm1.67\sigma\)뿐이니 공정 능력 \(C_p = 4/7.2 = 0.56\) — 16장 기준으로 한참 모자란다. → 5장 정규 분포와 표준화

펌프 부품의 수명이 평균 2000 h인 지수 분포를 따른다. 1000 h 동안 멀쩡했던 부품이 앞으로 500 h를 더 버틸 확률과, 수명의 중앙값은?

무기억성: \(P(T > s + t\mid T > s) = P(T > t) = e^{-\lambda t}\). 중앙값은 \(\ln2/\lambda\).

\(e^{-500/2000} = 0.779\) — 이미 쓴 1000 h와 무관하다. 중앙값 \(2000\ln2 = 1386\ \text{h}\)로 평균보다 짧다(오른쪽 꼬리). 지수 수명은 고장률이 일정한 우발 고장 구간의 모형이다. → 5장 지수 분포

배선의 수명이 \(\mathrm{Weibull}(\beta = 2, \eta = 10\,000\ \text{h})\)를 따른다. 5000 h 신뢰도와, 10%가 고장 나는 시간 B10은?

\(R(t) = \exp[-(t/\eta)^\beta]\). \(R(t_{10}) = 0.9\)를 풀면 \(t_{10} = \eta(-\ln0.9)^{1/\beta}\).

\(R(5000) = e^{-0.25} = 0.779\). \(t_{10} = 10\,000\sqrt{0.10536} = 3246\ \text{h}\). 같은 0.779가 앞 문제에도 나왔지만 뜻은 다르다: \(\beta = 2\)이면 고장률 \(h(t) = 2t/\eta^2\)이 커지는 마모 고장이라, 오래 버틴 부품일수록 위험하다. → 5장 와이블 분포

\(U\sim\mathrm{Uniform}(0,1)\)일 때 \(X = -\ln(U)/\lambda\)가 따르는 분포는?

\(P(X > x) = P(-\ln U > \lambda x) = P(U < e^{-\lambda x}) = e^{-\lambda x}\) — 지수 분포의 생존 함수다. \(1-U\)도 균일하므로 \(F^{-1}(U) = -\ln(1-U)/\lambda\)와 같은 분포다. 수명 몬테카를로의 기본 재료다. → 5장 역변환 표본 추출

6장 결합 분포본문 →

두 층을 연속 증착했다. 아래층 두께의 표준 편차는 1.5 nm, 위층은 2.0 nm이고 웨이퍼 사이 상관 계수는 0.4이다(같은 챔버 온도의 영향). 총두께와 두께 차이(위 − 아래)의 표준 편차는?

\(\operatorname{Var}(X\pm Y) = \sigma_X^2 + \sigma_Y^2 \pm 2\rho\sigma_X\sigma_Y\).

합: \(\sqrt{2.25 + 4 + 2.4} = \sqrt{8.65} = 2.94\ \text{nm}\). 차: \(\sqrt{2.25 + 4 - 2.4} = \sqrt{3.85} = 1.96\ \text{nm}\). 독립이라면 둘 다 \(2.5\) nm였을 것이다. 양의 상관은 합을 더 흔들고 차를 덜 흔든다 — 짝지은 비교(11장 대응 검정)가 강한 이유다. → 6장 선형 결합의 평균과 분산

면저항을 \(R_s = \rho/t\)로 계산한다. 비저항 \(\rho\)의 상대 표준 편차는 2%, 두께 \(t\)는 3%이다. \(R_s\)의 상대 표준 편차를 (가) \(\rho\)와 \(t\)가 독립일 때, (나) 상관 계수가 \(+1\)일 때 구하라.

곱·몫의 1차 전파: \((\sigma_R/R)^2 = (\sigma_\rho/\rho)^2 + (\sigma_t/t)^2 - 2\rho_{\rho t}(\sigma_\rho/\rho)(\sigma_t/t)\). 몫이라 상관 항의 부호가 음이다.

(가) \(\sqrt{0.02^2 + 0.03^2} = 3.61\%\). (나) \(\sqrt{0.0004 + 0.0009 - 2(0.0006)} = |0.03 - 0.02| = 1.00\%\). 두꺼운 막의 비저항이 함께 커지는 공정이라면 둘이 서로 상쇄해 면저항이 오히려 안정해진다. → 6장 오차 전파

문턱 전압 \(V_t\sim N(0.40, 0.02^2)\) V와 \(Y = \log_{10}I_{\text{off}}\sim N(-9, 0.3^2)\)가 상관 계수 \(-0.8\)인 이변량 정규 분포를 따른다. \(V_t = 0.37\ \text{V}\)인 소자의 \(Y\)의 조건부 평균과 조건부 표준 편차는?

\(E[Y\mid x] = \mu_Y + \rho(\sigma_Y/\sigma_X)(x - \mu_X)\), \(\sigma_{Y\mid x} = \sigma_Y\sqrt{1-\rho^2}\).

\(E = -9 + (-0.8)(15)(-0.03) = -8.64\) — 누설이 \(10^{0.36} = 2.3\)배 크다. \(\sigma = 0.3\times0.6 = 0.18\). \(V_t\)를 알면 \(\log I_{\text{off}}\)의 산포가 \(1-\rho^2 = 36\%\)만 남는다. 13장 회귀선이 바로 이 조건부 평균이다. → 6장 이변량 정규 분포

\(X\sim N(0,1)\)이고 \(Y = X^2\)이다. 옳은 것은?

\(\operatorname{Cov}(X, X^2) = E[X^3] - E[X]E[X^2] = 0\). 상관 계수는 직선 관계의 세기만 잰다. “상관 0 ⇒ 독립”은 \((X,Y)\)가 함께 이변량 정규일 때만 성립하는데, \(X^2\)은 정규가 아니다(자유도 1 카이제곱). 산점도를 먼저 보는 이유다. → 6장 공분산과 상관 계수

7장 극한 정리와 시뮬레이션본문 →

개별 측정값의 분포는 치우쳐 있지만 평균 50 nm, 표준 편차 3 nm이다. 36점의 평균 \(\bar X\)가 51 nm를 넘을 확률과, \(\bar X\)의 99% 분위수를 근사로 구하라.

\(\bar X\approx N(50, (3/6)^2)\). \(z_{0.01} = 2.326\).

\(z = (51-50)/0.5 = 2\), \(P = 1 - \Phi(2) = 0.0228\). 99% 분위수 \(50 + 2.326(0.5) = 51.16\ \text{nm}\). 원자료가 정규가 아니어도 36개의 평균은 정규에 가깝다 — 이것이 X̄ 관리도의 3σ 한계가 잘 듣는 이유다. → 7장 중심 극한 정리

다이 400개, 각 불량 확률 0.05(독립)이다. 불량이 15개 이하일 확률을 연속성 수정을 한 정규 근사로 구하고, 이항 분포로 정확히 계산한 값과 비교하라.

\(\mu = 20\), \(\sigma = \sqrt{400(0.05)(0.95)} = 4.359\). \(P(X\le15)\approx\Phi((15.5 - 20)/4.359)\).

\(z = -1.032\), \(\Phi(-1.032) = 0.151\). 정확한 이항 값은 \(0.150\)이다. 수정 없이 \(\Phi(-5/4.359) = 0.126\)으로 하면 17% 작게 나온다 — 이산 분포의 막대 하나가 폭 1을 차지하기 때문이다. → 7장 연속성 수정

웨이퍼당 결함 수(평균 2, 오른쪽으로 치우침)를 날마다 25장씩 모은다. 중심 극한 정리가 보장하는 것은?

CLT는 합이나 평균의 분포에 관한 정리다. 원자료의 분포는 표본을 아무리 늘려도 그대로(치우친 포아송꼴)이고, 표본이 많아질수록 히스토그램이 그 원래 모양을 더 정확히 그릴 뿐이다. 평균의 퍼짐은 \(\sigma/\sqrt n\)으로 준다. → 7장 중심 극한 정리

변동성 시뮬레이션으로 회로 수율(약 0.9)을 추정한다. 수율 추정의 표준 오차를 0.001 이하로 만들려면 표본이 몇 개 필요한가? 또 \(10^4\)개로 돌리면 표준 오차는?

성공·실패 표본의 비율이므로 \(\mathrm{SE} = \sqrt{p(1-p)/N}\).

\(N = 0.09/10^{-6} = 90\,000\). \(N = 10^4\)이면 \(\sqrt{0.09/10^4} = 0.003\). 정밀도를 10배 높이려면 표본이 100배 든다(\(1/\sqrt N\) 법칙). 수율이 0.9999처럼 1에 가까우면 실패가 드물어 중요도 표본 추출 같은 기법이 필요하다. → 7장 몬테카를로 적분과 오차

8장 표본 분포본문 →

웨이퍼 안 두께의 표준 편차가 2 nm이다. 9점 평균의 표준 오차는? 표준 오차를 0.25 nm 이하로 줄이려면 몇 점을 재야 하나?

\(\mathrm{SE} = \sigma/\sqrt n\). \(n \ge (\sigma/\mathrm{SE})^2\).

\(2/3 = 0.667\ \text{nm}\). \(n \ge (2/0.25)^2 = 64\)점. 오차를 \(1/2.7\)로 줄이는 데 측정이 7배 넘게 늘어난다. 계측 시간과 정밀도를 맞바꾸는 계산이다. → 8장 표본 평균의 분포와 표준 오차

정규 공정(\(\sigma^2 = 4\ \text{nm}^2\))에서 10점을 재어 \(S^2\)를 계산한다. \(S^2 > 7.5\)일 확률과, \(S^2\)가 95% 확률로 넘지 않는 값은?

\((n-1)S^2/\sigma^2\sim\chi^2_{9}\). \(\chi^2_{0.05,9} = 16.92\).

\(9(7.5)/4 = 16.875\), \(P(\chi^2_9 > 16.875) = 0.0507\). 상한 \(4(16.92)/9 = 7.52\ \text{nm}^2\). 공정이 그대로여도 10점 분산은 참값의 1.9배까지 흔들린다 — 분산 비교에 표본이 많이 드는 이유다. → 8장 카이제곱 분포와 표본 분산

X̄ 관리도(3σ 한계, 부분군 \(n = 4\))를 매 부분군마다 하는 가설 검정으로 보자. 공정이 그대로일 때 거짓 경보까지의 평균 부분군 수 ARL₀와, 평균이 \(1\sigma\) 이동했을 때 경보까지의 평균 부분군 수 ARL₁은?

초기 고장이 \(\mathrm{Weibull}(\beta = 0.5, \eta = 10^7\ \text{h})\)를 따른다. 사용 첫 1000 h 안에 고장 날 확률을 (가) 번인 없이, (나) 가속 계수 50인 조건에서 48 h 번인(사용 2400 h에 해당)을 통과한 칩에 대해 구하라.

제1부 자료와 확률

  • 확률 나무로 전확률을 만들고 베이즈 정리로 뒤집는다 — 기저율이 작으면 양성 예측도가 낮다.3장

제2부 확률 변수와 분포

  • 상황에서 분포를 고른다: 정해진 시행의 성공 수(이항), 비복원(초기하), 첫 성공까지(기하), 면적·시간당 사건 수(포아송).4장

  • \(\operatorname{Var}(aX + bY) = a^2\sigma_X^2 + b^2\sigma_Y^2 + 2ab\operatorname{Cov}(X,Y)\)와 곱·몫의 상대 오차 전파.6장

제3부 통계적 추론

  • \(\chi^2\), \(t\), \(F\) 분포가 각각 무엇에서 나오는지(표본 분산, 표준화한 평균, 분산 비) 말할 수 있다.8장
