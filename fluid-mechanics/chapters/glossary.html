이상 기체 상태 방정식ideal-gas equation of state

기체의 압력·밀도·온도 관계 \(p = \rho RT\)(공기 \(R = 287\) J/(kg·K)). 대부분의 공학 조건에서 성립한다.

01장 유체의 성질 →

임계 상태critical state

압축성 유동에서 Ma = 1인(실제 또는 가상의) 단면 상태. 상태량에 별표(*)를 붙이며 목 넓이 \(A^*\)가 기준이 된다.

11장 압축성 유동 입문 →

임계 수심critical depth

주어진 유량에서 비에너지가 최소가 되는 수심 \(y_c\)(직사각형 \(y_c = (q^2/g)^{1/3}\)). 이때 Fr = 1이다.

10장 개수로 유동 →

임펠러impeller

원심 펌프나 팬에서 회전하며 유체에 각운동량을 주는 날개 바퀴(로터).

12장 터보 기계 →

입구 길이entrance length

관 입구에서 경계층이 자라 속도 분포가 완전 발달할 때까지의 거리 \(L_h\). 층류 \(L_h \approx 0.05\,Re\,D\), 난류 \(L_h \approx 1.359\,Re^{1/4}D\)이다.

입자 영상 유속계PIV

유동에 뿌린 입자를 짧은 간격으로 두 번 찍어 변위로 순간 속도장을 얻는 측정법(PIV). 오일러 속도장을 직접 준다.

04장 유체 운동학 →

ㅈ

자유 분류free jet

고체 벽 없이 대기 속을 나아가는 분류. 둘레 압력이 대기압이므로 분류 속의 압력도 대기압이다.

03장 베르누이 방정식 →

자유 표면free surface

액체가 대기와 맞닿은 경계면. 그 위의 압력은 대기압이다.

10장 개수로 유동 →

자유류free stream

물체에서 멀리 떨어져 교란되지 않은 흐름과 그 속도 \(U\).

작동 원판actuator disk

로터를 얇은 원판으로 보고 그 앞뒤의 압력 차와 운동량 변화만 다루는 모델. 풍력 터빈의 베츠 한계를 유도한다.

12장 터보 기계 →

작동점operating point

펌프 성능 곡선과 관로의 시스템 곡선이 만나는 점. 실제로 운전되는 유량과 양정이다.

12장 터보 기계 →

장field

위치와 시간의 함수로 주어진 상태량(field). 속도장, 압력장, 온도장 등이 있다.

전단 농화shear-thickening, dilatant

변형률이 커질수록 겉보기 점성이 커지는 비뉴턴 유체(dilatant, 멱법칙 \(n > 1\)). 옥수수 전분 물이 예다.

01장 유체의 성질 →

전단 박화shear-thinning, pseudoplastic

변형률이 커질수록 겉보기 점성이 작아지는 비뉴턴 유체(pseudoplastic, 멱법칙 \(n < 1\)). 페인트, 혈액, 케첩이 예다.

01장 유체의 성질 →

전단 변형률shear strain rate

유체 요소의 처음 직각이던 두 변 사이의 각이 줄어드는 비율의 절반 \(\tfrac12(\partial u/\partial y + \partial v/\partial x)\).

전수두total head

압력·속도·위치 수두의 합 \(H = p/\rho g + V^2/2g + z\). 베르누이 식에서는 유선을 따라 일정하다.

03장 베르누이 방정식 →

전압total pressure

정압, 동압, 정수압 항을 모두 더한 압력 \(p + \tfrac12\rho V^2 + \rho gz\). 베르누이 식에서는 유선을 따라 일정하다.

03장 베르누이 방정식 →

전양정net head

펌프가 유체에 준 단위 무게당 에너지 \(H\), 곧 출구와 입구의 전수두 차이.

12장 터보 기계 →

절대 속도absolute velocity

정지한 관찰자가 보는 유체 속도 \(\vec V = \vec W + \vec U\)(상대 속도 + 날개 속도).

12장 터보 기계 →

절대 압력absolute pressure

완전 진공(압력 0)을 기준으로 잰 압력. 계기 압력에 대기압을 더한 값이다.

02장 유체 정역학 →

점성 계수dynamic viscosity

뉴턴 유체에서 전단 응력과 변형률의 비례 상수 \(\mu\)(Pa·s). 액체는 온도가 오르면 줄고 기체는 커진다.

01장 유체의 성질 →

점성 저층viscous sublayer

난류 경계층에서 벽 바로 위의 아주 얇은 층(\(y^+ < 5\)). 점성이 지배해 \(u^+ = y^+\)이다.

점착 조건no-slip condition

벽과 닿은 유체의 속도가 벽의 속도와 같다는 조건(no-slip). 경계층과 점성 마찰의 근원이다.

01장 유체의 성질 →

접촉각contact angle

액체가 고체 벽과 만나는 선에서 액체 표면이 벽과 이루는 각. 90°보다 작으면 액체가 벽을 적셔 모세관에서 올라간다.

01장 유체의 성질 →

정상 유동steady flow

어느 점에서도 상태량이 시간에 따라 변하지 않는 유동(\(\partial/\partial t = 0\)). 유선, 유적선, 유맥선이 일치한다.

04장 유체 운동학 →

정압static pressure

유체와 함께 움직이는 계측기가 느낄 압력 \(p\). 흐름에 나란한 벽의 작은 구멍으로 잰다.

03장 베르누이 방정식 →

정체 상태stagnation state

유동을 단열·등엔트로피적으로 정지시켰을 때 얻는 상태. 상태량에 아래첨자 0을 붙인다(\(p_0\), \(T_0\), \(\rho_0\)).

11장 압축성 유동 입문 →

정체 온도stagnation temperature

흐름을 단열적으로 정지시켰을 때의 온도 \(T_0 = T + V^2/2c_p\). 단열 유동이면 충격파가 있어도 일정하다.

11장 압축성 유동 입문 →

정체압stagnation pressure

흐름을 마찰 없이 정지시킨 점의 압력 \(p_0 = p + \tfrac12\rho V^2\). 피토관이 이 값을 잰다.

03장 베르누이 방정식 →

정체점stagnation point

흐름이 물체에 부딪혀 속도가 0이 되는 점. 압력이 가장 높다.

03장 베르누이 방정식 →

제동 동력brake horsepower, bhp

모터가 펌프 축에 넣은 동력(bhp, 축 동력) \(T\omega\). 수동력을 이것으로 나눈 것이 펌프 효율이다.

12장 터보 기계 →

종단 속도terminal velocity

떨어지는 물체의 무게가 항력과 부력의 합과 같아져 더 이상 가속하지 않는 속력. 스토크스 영역에서는 \(V_t = (\rho_s - \rho)gD^2/(18\mu)\)이다.

09장 외부 유동: 경계층, 항력, 양력 →

종량 상태량extensive property

질량, 운동량, 에너지처럼 계의 양에 비례하는 상태량 \(B\).

04장 유체 운동학 →

주기 유동periodic flow

상태량이 일정한 주기로 되풀이해 변하는 비정상 유동. 원기둥 뒤의 카르만 와류열, 왕복 펌프의 흐름이 예다.

04장 유체 운동학 →

주축principal axes

전단 변형률이 0이 되어 유체 요소가 늘고 줄기만 하는 방향의 좌표축. 변형률 텐서를 대각화하는 축이다.

04장 유체 운동학 →

준정상quasi-steady

유동이 천천히 변할 때 매 순간을 정상 유동으로 보고 정상 식(예: 토리첼리 식)을 적용하는 근사.

03장 베르누이 방정식 →

증기압vapor pressure

액체와 그 증기가 평형을 이룰 때 증기의 압력 \(p_v\). 온도만의 함수이며, 주위 압력이 이 값까지 떨어지면 끓음이나 공동 현상이 일어난다.

01장 유체의 성질 →

진공 압력vacuum pressure

대기압보다 낮은 압력을 대기압과의 차이 \(p_\text{atm} - p_\text{abs}\)로 나타낸 양수 값.

02장 유체 정역학 →

질량 유량mass flow rate

단면을 단위 시간에 지나는 질량 \(\dot m = \int\rho V_n\,dA = \rho VA\)(kg/s).

ㅊ

차압 유량계differential-pressure flowmeter

관을 일부러 좁혀 만든 압력 차로 유량을 재는 장치. 오리피스, 노즐, 벤투리 유량계가 있다.

유동을 묘사하는 데 필요한 공간 좌표의 수(dimensionality). 속도장이 좌표 몇 개에 의존하는지로 1차원·2차원·3차원 유동을 나눈다.

물리 법칙을 나타내는 식의 모든 항이 같은 차원을 가져야 한다는 원리. 차원 해석의 출발점이다.

차원 행렬dimensional matrix

각 변수의 기본 차원 지수를 열로 늘어놓은 행렬. 그 계수(rank)가 Π 정리의 \(j\)다.

척도 높이scale height

등온 대기에서 압력이 \(1/e\)로 줄어드는 높이 \(H = RT_0/g\)(288 K에서 약 8.4 km).

천음속transonic

마하 수 약 0.8–1.2의 유동 영역. 날개 윗면 등에 국소적인 초음속 영역과 약한 충격파가 생긴다.

천이transitional flow

층류에서 난류로 바뀌는 과정이나 그 중간 영역. 원형 관에서는 대략 \(2300 \lesssim Re \lesssim 4000\)이며 난류 덩어리가 간헐적으로 지나간다.

체적 유량volume flow rate

단면을 단위 시간에 지나는 부피 \(Q = \int V_n\,dA = VA\)(m³/s).

체절 양정shutoff head

펌프의 토출 밸브를 완전히 닫아 유량이 0일 때의 양정. 성능 곡선이 세로축과 만나는 점이다.

12장 터보 기계 →

초음속supersonic

마하 수가 1보다 큰 유동. 교란이 상류로 전파되지 못하고 충격파와 팽창파가 생긴다.

11장 압축성 유동 입문 →

초크choking

흐름이 더 이상 유량을 늘리거나 조건 변화를 상류로 전하지 못하는 상태. 개수로에서는 장애물 위에서 비에너지가 최소(임계)에 이르는 것, 노즐에서는 목에서 Ma = 1에 이르는 것이다.

10장 개수로 유동 →

최고 효율점best efficiency point, BEP

펌프 성능 곡선에서 효율이 가장 높은 점(BEP). 펌프의 정격값은 보통 이 점의 유량·양정·동력이다.

12장 터보 기계 →

최대 유량free delivery

펌프 양정이 0일 때의 유량(free delivery). 성능 곡선이 가로축과 만나는 점이다.

12장 터보 기계 →

최적 수리 단면best hydraulic cross section

주어진 단면적에서 윤변이 가장 짧아 같은 경사·거칠기로 가장 많은 유량을 흘리는 단면. 직사각형은 \(b = 2y\), 사다리꼴은 정육각형의 절반이다.

추력thrust

추진 기관이 유체의 운동량을 바꾼 반작용으로 받는 힘. 검사 체적의 선운동량 방정식으로 구한다.

축 유도 계수axial induction factor

축류 수축부vena contracta

오리피스나 노즐에서 나온 분류가 가장 좁아지고 유선이 나란해지는 단면(vena contracta).

축일shaft work

회전축을 통해 검사 체적과 주고받는 일. 펌프는 유체에 축일을 주고 터빈은 빼낸다.

층류laminar flow

유체가 서로 섞이지 않는 매끈한 층을 이루며 흐르는 유동. 원형 관에서는 \(Re \lesssim 2300\)이다.

카르만 와류열Kármán vortex street

원주 같은 뭉툭한 물체 뒤에서 위아래로 번갈아 소용돌이가 떨어져 나가 생기는 와류의 줄. 방출 진동수는 \(\mathrm{St} \approx 0.2\)로 거의 일정하다.

07장 차원 해석과 상사 →

캠버선camber line

에어포일의 위·아래 면 가운데를 이은 곡선. 캠버가 있으면 받음각 0에서도 양력이 생긴다.

임의의 연속체에 성립하는 미분형 운동량 방정식 \(\rho\,D\vec V/Dt = \rho\vec g + \nabla\cdot\sigma_{ij}\). 구성 방정식이 있어야 풀 수 있다.

06장 미분 해석과 퍼텐셜 유동 →

콜브룩 식Colebrook equation

난류 관 마찰 계수의 음함수식 \(1/\sqrt f = -2\log_{10}[(\varepsilon/D)/3.7 + 2.51/(Re\sqrt f)]\). 무디 선도의 바탕이다.

쿠에트 유동Couette flow

쿠타 조건Kutta condition

날카로운 뒷전에서 흐름이 매끄럽게 떠나야 한다는 조건. 날개 주위 순환 \(\Gamma\)의 크기를 정한다.

2차원 물체가 받는 단위 길이당 양력이 \(L' = \rho U\Gamma\)라는 정리. 모양과 무관하게 순환 \(\Gamma\)만으로 정해진다.

크누센 수Knudsen number

분자 평균 자유 행로와 대표 길이의 비 \(\mathrm{Kn} = \lambda/L\). \(\mathrm{Kn} \ll 1\)이면 연속체 가정이 성립한다.

ㅌ

터보 기계turbomachine

넓이 0.2 m²인 평판이 두께 0.5 mm의 기름막(\(\mu = 0.29\ \text{Pa·s}\)) 위를 1.5 m/s로 미끄러진다. 막 안의 속도 분포가 선형일 때 판을 끄는 데 필요한 힘은?

\(\tau = \mu V/h = 0.29(1.5)/(0.5\times10^{-3}) = 870\ \text{Pa}\), \(F = \tau A = 870(0.2) = 174\ \text{N}\).

안지름 1 mm인 깨끗한 유리관을 20 °C 물(\(\rho = 998\ \text{kg/m}^3\), \(\sigma = 0.0728\ \text{N/m}\), 접촉각 0°)에 세웠다. 모세관 상승 높이는?

둘레에 작용하는 표면 장력의 수직 성분 \(\pi d\sigma\cos\theta\)가 올라간 물기둥의 무게 \(\rho g h\,\pi d^2/4\)를 받친다.

\(h = \dfrac{4\sigma\cos\theta}{\rho g d} = \dfrac{4(0.0728)}{998(9.81)(0.001)} = 0.0297\ \text{m} = 29.7\ \text{mm}\).

깊이 4000 m 해저에서의 계기 압력과, 해면에서 그곳까지 내려간 바닷물 덩어리의 부피 감소율을 구하라. 바닷물 \(\rho = 1025\ \text{kg/m}^3\)(일정하다고 근사), 체적 탄성 계수 \(E_v = 2.34\ \text{GPa}\).

정수압 \(p = \rho g h\)(2장), 그다음 \(\Delta V/V = -\Delta p/E_v\)(1장).

\(p = 1025(9.81)(4000) = 4.02\times10^7\ \text{Pa} = 40.2\ \text{MPa}\). \(|\Delta V|/V = 40.2\times10^6/2.34\times10^9 = 0.0172 = 1.72\%\). 밀도도 그만큼(약 1.7%) 커지므로 \(\rho\) 일정 근사의 오차는 1% 정도다.

4장 유체 운동학본문 →

정상 2차원 속도장 \(u = 1 + 2.5x + y\), \(v = -0.5 - 1.5x - 2.5y\)(m/s, x·y는 m)에서 점 (2 m, 3 m)의 유체 입자 가속도 성분을 구하라.

정상 유동이므로 \(a_x = u\,\partial u/\partial x + v\,\partial u/\partial y\), \(a_y = u\,\partial v/\partial x + v\,\partial v/\partial y\).

점에서 \(u = 9\), \(v = -11\). \(a_x = 9(2.5) + (-11)(1) = 11.5\ \text{m/s}^2\), \(a_y = 9(-1.5) + (-11)(-2.5) = 14.0\ \text{m/s}^2\). 정상 유동이라도 대류 가속도는 0이 아니다.

위 문제의 속도장에서 와도의 z 성분 \(\zeta_z\)는? (부호 포함)

\(\zeta_z = \partial v/\partial x - \partial u/\partial y = -1.5 - 1 = -2.5\ \text{s}^{-1}\). 0이 아니므로 회전 유동이며, 유체 요소는 각속도 \(\zeta_z/2 = -1.25\ \text{rad/s}\)(시계 방향)로 돈다. 한편 \(\partial u/\partial x + \partial v/\partial y = 0\)이라 비압축 연속 조건은 만족한다.

속도장이 시간에 따라 변하지 않으면 한 점을 지난 입자들이 모두 같은 길을 따라가므로 세 선이 겹친다. 비정상 유동에서는 일반적으로 다르다.

간격 4 mm인 고정된 두 평행 평판 사이로 기름(\(\mu = 0.4\ \text{Pa·s}\))이 압력 구배 \(dp/dx = -2000\ \text{Pa/m}\)에 의해 층류로 흐른다. 최대 속도와 폭 1 m당 유량은?

완전 발달 유동의 정확해 \(u(y) = \dfrac{1}{2\mu}\left(-\dfrac{dp}{dx}\right)y(b - y)\).

\(u_{max} = \dfrac{(-dp/dx)b^2}{8\mu} = \dfrac{2000(0.004)^2}{8(0.4)} = 0.0100\ \text{m/s}\), \(q = \dfrac{(-dp/dx)b^3}{12\mu} = \dfrac{2000(0.004)^3}{12(0.4)} = 2.67\times10^{-5}\ \text{m}^2/\text{s}\) (평균 속도 = \(\tfrac23u_{max}\)).

유동 함수 \(\psi = 3xy\ (\text{m}^2/\text{s})\)인 2차원 비압축 유동에서 (가) 점 (1 m, 2 m)의 속력, (나) 유선 \(\psi = 2\)와 \(\psi = 5\) 사이를 지나는 단위 폭당 유량을 구하라.

\(u = \partial\psi/\partial y\), \(v = -\partial\psi/\partial x\). 두 유선 사이 유량은 \(\psi\)의 차.

\(u = 3x = 3\), \(v = -3y = -6\) → \(|V| = \sqrt{9 + 36} = 6.71\ \text{m/s}\). \(q = \psi_2 - \psi_1 = 5 - 2 = 3.00\ \text{m}^2/\text{s}\). (모서리 근처 정체점 유동이다.)

균일 유동 \(U = 10\ \text{m/s}\)(공기 \(\rho = 1.2\ \text{kg/m}^3\)) 속의 원주를 퍼텐셜 유동으로 본다. (가) 순환이 없을 때 앞 정체점에서 60° 떨어진 표면의 압력 계수, (나) 원주를 돌려 순환 \(\Gamma = 20\ \text{m}^2/\text{s}\)를 줄 때 단위 길이당 양력을 구하라.

표면 속도 \(2U\sin\theta\) → \(C_p = 1 - 4\sin^2\theta\). 쿠타–주코프스키: \(L' = \rho U\Gamma\).

(가) \(C_p = 1 - 4(\sin60°)^2 = 1 - 3 = -2.00\). (나) \(L' = 1.2(10)(20) = 240\ \text{N/m}\). 원주 반지름은 양력에 들어가지 않는다.

7장 차원 해석과 상사본문 →

관 유동의 압력 강하 \(\Delta p\)가 평균 속도 \(V\), 지름 \(D\), 밀도 \(\rho\), 점성 계수 \(\mu\), 벽 거칠기 \(\varepsilon\)에 달려 있다. 관 길이는 고정이다. 독립인 무차원 Π 그룹은 몇 개인가?

변수 \(n = 6\)(\(\Delta p, V, D, \rho, \mu, \varepsilon\)), 기본 차원 \(j = 3\)(M, L, T) → \(k = n - j = 3\): 예컨대 \(Eu = \Delta p/(\rho V^2)\), \(Re = \rho VD/\mu\), \(\varepsilon/D\).

배를 1:25 모형으로 수조에서 시험한다. 실물 속력은 10 m/s이다. 조파 저항이 지배적이라 프루드 수를 맞출 때 (가) 모형 속력은? (나) 모형의 저항이 20 N이면 실물 저항은? (같은 물을 쓴다.)

\(Fr = V/\sqrt{gL}\) 일치 → \(V_m/V_p = \sqrt{L_m/L_p}\). 힘은 \(\rho V^2L^2\)에 비례.

(가) \(V_m = 10/\sqrt{25} = 2.00\ \text{m/s}\). (나) \(F_p/F_m = (V_p/V_m)^2(L_p/L_m)^2 = 25(625) = 25^3\) → \(F_p = 20(15625) = 3.13\times10^5\ \text{N} = 313\ \text{kN}\).

길이 4 m의 자동차가 공기(\(\rho = 1.2\ \text{kg/m}^3\), \(\nu = 1.5\times10^{-5}\ \text{m}^2/\text{s}\)) 속을 25 m/s로 달릴 때의 항력을 1:5 모형으로 수조(\(\rho = 1000\ \text{kg/m}^3\), \(\nu = 1.0\times10^{-6}\ \text{m}^2/\text{s}\))에서 구하려 한다. (가) 레이놀즈 수를 맞추려면 모형 유속은? (나) 그때 모형 항력이 600 N이면 실물 항력은?

\(Re\)가 같으면 항력 계수 \(C_D = F_D/(\tfrac12\rho V^2A)\)도 같다(9장).

(가) \(V_m = V_p\dfrac{L_p}{L_m}\dfrac{\nu_m}{\nu_p} = 25(5)\dfrac{1.0\times10^{-6}}{1.5\times10^{-5}} = 8.33\ \text{m/s}\). (나) \(F_p = F_m\dfrac{\rho_p}{\rho_m}\left(\dfrac{V_p}{V_m}\right)^2\left(\dfrac{L_p}{L_m}\right)^2 = 600(0.0012)(9)(25) = 162\ \text{N}\). 물속 모형이 훨씬 큰 힘을 받아 측정이 쉽다.

8장 관 내 점성 유동본문 →

기름(\(\rho = 900\ \text{kg/m}^3\), \(\nu = 1.0\times10^{-4}\ \text{m}^2/\text{s}\))이 지름 2 cm, 길이 10 m인 수평관을 평균 1 m/s로 흐른다. 수두 손실과 압력 강하는?

먼저 \(Re\)로 층류인지 확인하고 \(f = 64/Re\).

\(Re = VD/\nu = 1(0.02)/10^{-4} = 200\)(층류), \(f = 0.32\). \(h_L = f\dfrac{L}{D}\dfrac{V^2}{2g} = 0.32(500)\dfrac{1}{19.62} = 8.15\ \text{m}\), \(\Delta p = \rho g h_L = 900(9.81)(8.15) = 72.0\ \text{kPa}\).

20 °C 물(\(\nu = 1.0\times10^{-6}\ \text{m}^2/\text{s}\))이 지름 0.1 m, 길이 100 m의 상업용 강관(\(\varepsilon = 0.045\ \text{mm}\))을 0.02 m³/s로 흐른다. 콜브룩 식으로 마찰 계수와 수두 손실을 구하라.

\(V = 2.55\ \text{m/s}\), \(Re = 2.55\times10^5\), \(\varepsilon/D = 4.5\times10^{-4}\). \(1/\sqrt f = -2\log_{10}\!\left(\dfrac{\varepsilon/D}{3.7} + \dfrac{2.51}{Re\sqrt f}\right)\)을 반복한다.

반복하면 \(f = 0.0182\). \(h_L = 0.0182\dfrac{100}{0.1}\dfrac{(2.55)^2}{19.62} = 6.00\ \text{m}\).

펌프가 아래 저수지의 물(\(\rho = 1000\ \text{kg/m}^3\))을 수면이 20 m 높은 위 저수지로 0.015 m³/s 올린다. 관은 지름 0.1 m, 길이 200 m, \(f = 0.02\)이고 부차 손실 계수의 합(입구·밸브·엘보·출구)은 \(\sum K = 3\)이다. 필요한 펌프 수두와, 효율 75%일 때의 축 동력은?

두 수면 사이 에너지 식(5장): \(h_p = \Delta z + \left(f\dfrac{L}{D} + \sum K\right)\dfrac{V^2}{2g}\). 두 수면 모두 대기압·속도 0.

\(V = 0.015/(\tfrac\pi4\,0.1^2) = 1.91\ \text{m/s}\), \(V^2/2g = 0.186\ \text{m}\). \(h_p = 20 + (40 + 3)(0.186) = 28.0\ \text{m}\). \(P = \rho g Q h_p/\eta = 9810(0.015)(28.0)/0.75 = 5.49\ \text{kW}\). 이 값이 12장의 시스템 곡선 위 한 점이다.

9장 외부 유동: 경계층, 항력, 양력본문 →

길이 1 m, 폭 0.5 m인 매끈한 평판에 공기(\(\rho = 1.2\ \text{kg/m}^3\), \(\nu = 1.5\times10^{-5}\ \text{m}^2/\text{s}\))가 5 m/s로 나란히 흐른다. 뒷전에서의 경계층 두께와 한쪽 면의 마찰 항력을 구하라(천이 \(Re_{cr} = 5\times10^5\)).

\(Re_L\)이 임계값보다 작으면 전체가 층류: \(\delta = 4.91x/\sqrt{Re_x}\), \(C_f = 1.328/\sqrt{Re_L}\).

\(Re_L = 5(1)/1.5\times10^{-5} = 3.33\times10^5\)(층류). \(\delta = 4.91(1)/\sqrt{3.33\times10^5} = 8.50\ \text{mm}\). \(C_f = 1.328/577 = 0.00230\), \(F_D = C_f\tfrac12\rho U^2 A = 0.00230(0.5)(1.2)(25)(0.5) = 0.0173\ \text{N}\).

지름 0.1 mm의 모래알(\(\rho_s = 2650\ \text{kg/m}^3\))이 물(\(\rho = 1000\ \text{kg/m}^3\), \(\mu = 1.0\times10^{-3}\ \text{Pa·s}\)) 속에서 가라앉는 종단 속도는? 스토크스 법칙을 쓰고 \(Re\)로 타당성을 확인하라.

무게 − 부력 = \(3\pi\mu V D\).

\(V_t = \dfrac{(\rho_s - \rho)gD^2}{18\mu} = \dfrac{1650(9.81)(10^{-4})^2}{18(10^{-3})} = 8.99\times10^{-3}\ \text{m/s}\). \(Re = \rho V D/\mu = 0.90 \lesssim 1\)이므로 스토크스 영역으로 볼 수 있다.

장비를 포함한 질량 90 kg의 낙하산병이 투영 넓이 40 m², \(C_D = 1.3\)인 낙하산을 펴고 내려온다. 공기 \(\rho = 1.2\ \text{kg/m}^3\)일 때 종단 속도는? (부력 무시)

\(mg = C_D\tfrac12\rho V^2A\) → \(V = \sqrt{\dfrac{2mg}{\rho C_D A}} = \sqrt{\dfrac{2(90)(9.81)}{1.2(1.3)(40)}} = 5.32\ \text{m/s}\) — 약 1.4 m 높이에서 뛰어내린 것과 같은 착지 속도.

10장 개수로 유동본문 →

폭 3 m인 직사각형 수로에 6 m³/s가 흐른다. (가) 임계 수심, (나) 수심 0.5 m일 때의 프루드 수를 구하라.

\(q = 2\ \text{m}^2/\text{s}\), \(y_c = (q^2/g)^{1/3} = (4/9.81)^{1/3} = 0.742\ \text{m}\). \(V = q/y = 4\ \text{m/s}\), \(Fr = V/\sqrt{gy} = 4/\sqrt{4.905} = 1.81\) — 사류.

넓은 직사각형 수로에서 수심 0.5 m, 유속 8 m/s의 흐름이 수력 도약을 일으킨다. 도약 뒤 수심과 도약에서의 수두 손실은?

\(y_2/y_1 = \tfrac12\left(\sqrt{1 + 8Fr_1^2} - 1\right)\), \(h_L = (y_2 - y_1)^3/(4y_1y_2)\).

\(Fr_1 = 8/\sqrt{9.81(0.5)} = 3.61\). \(y_2 = 0.25\left(\sqrt{1 + 8(3.61)^2} - 1\right) = 2.32\ \text{m}\). \(h_L = (1.82)^3/(4\cdot0.5\cdot2.32) = 1.29\ \text{m}\) — 도약 전 비에너지 \(0.5 + 3.26 = 3.76\ \text{m}\)의 약 34%.

폭 4 m인 콘크리트 직사각형 수로(\(n = 0.013\))가 경사 0.001로 놓여 있고 등류 수심이 1.5 m이다. 유량은? (SI 매닝 식)

\(A = 6\ \text{m}^2\), \(P = 4 + 2(1.5) = 7\ \text{m}\), \(R_h = 0.857\ \text{m}\). \(Q = \dfrac1n A R_h^{2/3}S_0^{1/2} = \dfrac{1}{0.013}(6)(0.902)(0.0316) = 13.2\ \text{m}^3/\text{s}\).

11장 압축성 유동 입문본문 →

여객기가 기온 223 K인 고도에서 250 m/s로 난다. 공기 \(k = 1.4\), \(R = 287\ \text{J/(kg·K)}\). 마하 수와, 기수 정체점의 온도(정체 온도)는?

\(c = \sqrt{kRT} = \sqrt{1.4(287)(223)} = 299\ \text{m/s}\), \(Ma = 250/299 = 0.835\). \(T_0 = T\left(1 + \tfrac{k-1}{2}Ma^2\right) = 223(1.139) = 254\ \text{K}\).

정체 압력 500 kPa, 정체 온도 300 K인 탱크의 공기가 목 넓이 5 cm²인 수렴 노즐로 충분히 낮은 배압 속에 분출된다(초크). 질량 유량은?

\(\dot m = A^*p_0\sqrt{\dfrac{k}{RT_0}}\left(\dfrac{2}{k+1}\right)^{(k+1)/[2(k-1)]}\) — \(k = 1.4\)이면 \(\dot m = 0.6847\,A^*p_0/\sqrt{RT_0}\).

\(\dot m = 0.6847\dfrac{(5\times10^{-4})(5\times10^5)}{\sqrt{287(300)}} = 0.6847\dfrac{250}{293.4} = 0.583\ \text{kg/s}\). 배압을 더 낮춰도 이 값은 변하지 않는다.

\(Ma_1 = 2.0\)인 공기(\(k = 1.4\)) 흐름에 수직 충격파가 선다. 충격파 뒤의 마하 수와 정압비는?

\(Ma_2^2 = \dfrac{1 + 0.2Ma_1^2}{1.4Ma_1^2 - 0.2} = \dfrac{1.8}{5.4} = 0.333\) → \(Ma_2 = 0.577\). \(p_2/p_1 = 1 + \dfrac{2k}{k+1}(Ma_1^2 - 1) = 1 + 1.1667(3) = 4.50\).

12장 터보 기계본문 →

원심 펌프 임펠러의 바깥 반지름이 0.15 m, 회전수가 1750 rpm이다. 입구에서 선회 성분이 없고 출구 절대 속도의 접선 성분이 \(V_{t2} = 20\ \text{m/s}\)이다. 이론 수두와, 물(\(\rho = 1000\ \text{kg/m}^3\)) 0.05 m³/s를 보낼 때 유체에 주는 동력은?

\(gH = U_2V_{t2} - U_1V_{t1}\), \(U_2 = \omega r_2\).

\(U_2 = 1750(2\pi/60)(0.15) = 27.5\ \text{m/s}\). \(H = U_2V_{t2}/g = 27.5(20)/9.81 = 56.0\ \text{m}\). \(P = \rho Q U_2 V_{t2} = 1000(0.05)(27.5)(20) = 27.5\ \text{kW}\).

어떤 펌프가 1450 rpm에서 0.1 m³/s, 양정 30 m, 축 동력 40 kW로 운전된다. 같은 펌프를 1750 rpm으로 돌리면 상사점의 양정과 축 동력은?

\(H \propto N^2\): \(30(1750/1450)^2 = 43.7\ \text{m}\). \(P \propto N^3\): \(40(1750/1450)^3 = 70.3\ \text{kW}\). (유량은 \(N\)에 비례해 0.121 m³/s.)

펌프가 대기(101.325 kPa)에 열린 탱크에서 20 °C 물(\(\rho = 998\ \text{kg/m}^3\), 증기압 2.339 kPa)을 빨아올린다. 탱크 수면은 펌프 입구보다 3 m 아래이고 흡입관의 수두 손실은 0.5 m이다. 유효 흡입 수두 NPSHa는?

\(\text{NPSH}_a = \dfrac{p_{atm} - p_v}{\rho g} - z_s - h_{L,s}\) — 증기압(1장)과 정수압(2장)이 모두 들어간다.

\(\dfrac{101325 - 2339}{998(9.81)} = 10.11\ \text{m}\), \(\text{NPSH}_a = 10.11 - 3 - 0.5 = 6.61\ \text{m}\). 펌프의 NPSHr이 이보다 작아야 공동 현상이 생기지 않는다.
