미분 해석과 퍼텐셜 유동

5장의 검사 체적 해석은 노즐에 걸리는 힘이나 관을 지나는 유량처럼 전체에 관한 답을 준다. 그러나 날개 표면의 압력이 어디서 가장 낮은지, 베어링의 기름막 속 속도가 어떻게 분포하는지 알려면 질량·운동량 보존을 무한히 작은 유체 덩어리에 적용해 미분 방정식을 세워야 한다. 그 결과가 연속 방정식과 나비에–스토크스 방정식이다. 점성을 빼고 회전도 없다고 하면 방정식은 선형인 라플라스 방정식이 되고, 간단한 해들을 더하기만 해서 물체 주위의 흐름을 만들 수 있다. 아래 화면의 원천·흡입·와류를 끌어 보자.

미분형 연속 방정식

5장에서는 크기가 정해진 검사 체적에 질량 보존을 적용했다. 이제 그 검사 체적을 한 점 \((x, y, z)\) 주위의 무한소 상자 \(dx\,dy\,dz\)로 줄인다. 상자에 들어오고 나가는 질량 유량의 차이는 상자 안 질량이 줄어드는 비율과 같아야 한다. 각 면의 질량 유속 \(\rho u\)를 상자 중심의 값에서 테일러 전개해 일차 항까지 쓰면 된다.

이렇게 얻은 연속 방정식(continuity equation)은 좌표계와 무관한 벡터 꼴로 쓸 수 있다.

$$\frac{\partial\rho}{\partial t} + \nabla\cdot(\rho\vec V) = 0 \quad\Longleftrightarrow\quad \frac{\partial\rho}{\partial t} + \frac{\partial(\rho u)}{\partial x} + \frac{\partial(\rho v)}{\partial y} + \frac{\partial(\rho w)}{\partial z} = 0$$
물질 도함수(4장)를 쓰면 \(\dfrac{1}{\rho}\dfrac{D\rho}{Dt} + \nabla\cdot\vec V = 0\). 즉 \(\nabla\cdot\vec V\)는 유체 입자의 체적 팽창률이고, 입자가 부풀면 밀도가 줄어든다.

액체 대부분과 마하 수 0.3 이하의 기체 흐름은 비압축성(incompressible)으로 다룬다. 밀도가 일정하면 연속 방정식은 시간 미분이 사라져 정상·비정상 유동 모두에 성립하는 간단한 꼴이 된다.

비압축 연속 방정식

$$\nabla\cdot\vec V = \frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} + \frac{\partial w}{\partial z} = 0$$ 어떤 유체 덩어리든 모양은 바뀌어도 체적은 바뀌지 않는다. 한 방향으로 늘어나면 다른 방향으로 반드시 줄어든다.

유동 함수

2차원 비압축 유동에서는 두 속도 성분을 함수 하나로 묶을 수 있다. 유동 함수(stream function) \(\psi(x, y)\)를 다음과 같이 정의하면

$$u = \frac{\partial\psi}{\partial y}, \qquad v = -\frac{\partial\psi}{\partial x} \qquad\Big(\text{원통 좌표: } u_r = \frac{1}{r}\frac{\partial\psi}{\partial\theta},\ \ u_\theta = -\frac{\partial\psi}{\partial r}\Big)$$
\(\partial u/\partial x + \partial v/\partial y = \psi_{yx} - \psi_{xy} = 0\): 어떤 매끄러운 \(\psi\)를 골라도 연속 방정식이 저절로 만족된다. 단위는 m²/s(단위 깊이당 유량).

\(\psi\)가 일정한 곡선을 따라가면 \(d\psi = \psi_x dx + \psi_y dy = -v\,dx + u\,dy = 0\), 즉 \(dy/dx = v/u\)이다. 이것은 유선의 방정식이다. 따라서

운동량 방정식: 오일러와 나비에–스토크스

무한소 유체 덩어리에 뉴턴 제2법칙을 적용하자. 단위 체적당 (질량 × 가속도) = (체적력) + (표면력)이고, 가속도는 4장의 물질 도함수 \(D\vec V/Dt\)이다. 표면력은 각 면에 작용하는 응력(stress)이 위치에 따라 달라서 생긴다. 응력 성분 \(\sigma_{ij}\)는 법선이 \(i\) 방향인 면에 작용하는 \(j\) 방향 성분이다.

x 방향 성분을 쓰면 코시 운동 방정식(Cauchy equation)이다. 이 식은 어떤 연속체에도 성립하지만, 응력과 속도의 관계(구성 방정식(constitutive equation))를 알기 전에는 풀 수 없다.

$$\rho\frac{Du}{Dt} = \rho g_x + \frac{\partial\sigma_{xx}}{\partial x} + \frac{\partial\tau_{yx}}{\partial y} + \frac{\partial\tau_{zx}}{\partial z}, \qquad \sigma_{ij} = -p\,\delta_{ij} + \mu\Big(\frac{\partial u_i}{\partial x_j} + \frac{\partial u_j}{\partial x_i}\Big)$$
오른쪽 식이 비압축 뉴턴 유체의 구성 관계다. 1장의 \(\tau = \mu\,du/dy\)를 3차원 변형률(4장)로 일반화한 것이다.

구성 관계를 코시 방정식에 넣고 연속 방정식 \(\nabla\cdot\vec V = 0\)을 쓰면, 점성 항이 \(\mu\nabla^2\vec V\)로 깔끔하게 정리된다. 이것이 유체역학의 기본 방정식인 나비에–스토크스 방정식(Navier–Stokes equation)이다.

$$\rho\Big(\frac{\partial\vec V}{\partial t} + (\vec V\cdot\nabla)\vec V\Big) = -\nabla p + \rho\vec g + \mu\nabla^2\vec V$$
비압축 뉴턴 유체, 일정한 \(\mu\). 미지수 \(u, v, w, p\) 네 개에 방정식 네 개(운동량 3 + 연속 1). 왼쪽의 대류 항이 비선형이라 일반해가 없다.
성분별로 펼친 꼴 (직교 좌표, x 성분)

$$\rho\Big(\frac{\partial u}{\partial t} + u\frac{\partial u}{\partial x} + v\frac{\partial u}{\partial y} + w\frac{\partial u}{\partial z}\Big) = -\frac{\partial p}{\partial x} + \rho g_x + \mu\Big(\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} + \frac{\partial^2 u}{\partial z^2}\Big)$$ y, z 성분은 \(u \to v, w\), \(x \to y, z\)로 바꾼다. 유도: \(\partial\sigma_{xx}/\partial x + \partial\tau_{yx}/\partial y + \partial\tau_{zx}/\partial z = -\partial p/\partial x + \mu\nabla^2 u + \mu\,\partial(\nabla\cdot\vec V)/\partial x\)이고 마지막 항이 연속 방정식 때문에 0이다. 원통 좌표의 축 방향 성분은 관 유동(8장)에서 쓴다: \(\mu\nabla^2 u_z = \mu\big[\frac1r\frac{\partial}{\partial r}\big(r\frac{\partial u_z}{\partial r}\big) + \frac{1}{r^2}\frac{\partial^2u_z}{\partial\theta^2} + \frac{\partial^2u_z}{\partial z^2}\big]\).

점성을 무시한 \(\mu = 0\)의 특수한 경우가 오일러 방정식(Euler equation)이다. 레이놀즈 수가 큰 흐름에서 벽에서 떨어진 영역에 잘 맞는다. 유선을 따라 적분하면 3장의 베르누이 식이 나온다.

$$\rho\frac{D\vec V}{Dt} = -\nabla p + \rho\vec g \qquad(\text{오일러, 비점성})$$

경계 조건

미분 방정식은 경계 조건이 있어야 해가 하나로 정해진다. 점성 유동에서 가장 중요한 것은 점착 조건(no-slip condition)이다. 벽에 닿은 유체는 벽과 같은 속도로 움직인다. 고정 벽에서는 \(\vec V = 0\), 속도 \(U\)로 미끄러지는 판에서는 \(u = U\)이다. 그 밖에 자유 표면에서는 \(p = p_\text{atm}\)이고 전단 응력이 0(공기의 전단은 무시)이며, 두 유체의 경계면에서는 속도와 전단 응력이 연속이다. 점성을 버린 오일러 방정식은 미분 차수가 낮아 점착 조건을 걸 수 없고, 벽을 뚫지 않는다(\(V_n = 0\))는 조건만 쓴다. 비점성 해가 벽에서 미끄러지는 이유이고, 9장의 경계층이 그 간극을 메운다.

수평면에서 물(ρ = 1000 kg/m³)이 \(u = ax,\ v = -ay\), \(a = 2.0\) s⁻¹로 흐른다. 이 유동이 나비에–스토크스 방정식을 만족함을 보이고, 정체점(원점)과 점 (1.5, 2.0) m 사이의 압력 차를 구하라. 중력은 수직 방향이라 수평면 안의 압력 분포에는 영향이 없다.

검토 그 점의 속력은 \(V = a\sqrt{x^2 + y^2} = 5.0\) m/s, \(\tfrac12\rho V^2 = 12.5\) kPa로 베르누이 식과 같다. \(\partial^2 p/\partial x\partial y\)가 두 식에서 똑같이 0이어야 압력이 존재하는데, 이 검사가 바로 '주어진 속도장이 물리적으로 가능한가'의 판정이다.

나비에–스토크스 방정식의 정확해

비선형 방정식이지만, 기하가 단순하면 대류 항이 정확히 사라져 손으로 풀 수 있다. 두 평판 사이나 긴 관 속의 완전 발달 유동(fully developed flow)에서는 속도가 흐름 방향으로 변하지 않으므로(\(\partial u/\partial x = 0\)), 연속 방정식에서 \(v = 0\)이 되고 대류 항 \(u\,\partial u/\partial x + v\,\partial u/\partial y\)가 0이 된다. 남는 것은 압력 구배와 점성의 평형뿐이다.

$$0 = -\frac{dp}{dx} + \mu\frac{d^2u}{dy^2} \quad\Longrightarrow\quad u(y) = \frac{1}{2\mu}\frac{dp}{dx}\,y^2 + C_1 y + C_2$$
y 운동량 식에서 \(\partial p/\partial y = -\rho g\)(정수압)이므로 \(dp/dx\)는 \(y\)와 무관한 상수다. \(C_1, C_2\)는 두 벽의 점착 조건으로 정한다.

쿠에트 유동 (dp/dx = 0)

\(u(0) = 0,\ u(h) = U\) → \(u = U\,y/h\). 전단 응력은 어디서나 같은 \(\tau = \mu U/h\). 저널 베어링의 얇은 기름막, 점도계(1장)가 이 흐름이다.

평판 푸아죄유 유동 (U = 0)

\(u = \dfrac{1}{2\mu}\Big(-\dfrac{dp}{dx}\Big)y(h - y)\). \(u_\text{max} = \dfrac{h^2}{8\mu}\Big(-\dfrac{dp}{dx}\Big)\), 단위 폭 유량 \(q = \dfrac{h^3}{12\mu}\Big(-\dfrac{dp}{dx}\Big)\), 평균 속도 \(V = \tfrac23 u_\text{max}\), 벽 전단 \(\tau_w = \dfrac h2\Big(-\dfrac{dp}{dx}\Big)\).

판을 갑자기 움직이면 정상 상태의 직선 분포가 즉시 생기지 않는다. 벽의 운동량은 점성에 의해 확산되어 퍼지고, 그 시간 규모는 \(h^2/\nu\)이다. 이번에는 비정상 항 \(\partial u/\partial t\)를 살려 둔 식 \(\partial u/\partial t = \nu\,\partial^2u/\partial y^2 - (1/\rho)\,dp/dx\)를 수치로 풀어 보자.

두 판 사이의 간격 \(h\)를 두 배로 늘리면, 윗판을 출발시킨 뒤 정상 상태에 가까워지는 데 걸리는 시간은?

비회전 유동과 퍼텐셜 유동의 중첩

레이놀즈 수가 큰 흐름에서 물체 앞쪽과 경계층 바깥은 점성 효과가 작고, 균일한 흐름에서 출발한 유체는 회전(와도, 4장)을 얻지 못한다. 이런 비회전 유동(irrotational flow)에서는 \(\nabla\times\vec V = 0\)이므로 속도를 스칼라 함수의 기울기로 쓸 수 있다. 이 함수가 속도 퍼텐셜(velocity potential) \(\phi\)다.

$$\vec V = \nabla\phi \ \ \Big(u = \frac{\partial\phi}{\partial x},\ v = \frac{\partial\phi}{\partial y}\Big), \qquad \nabla\cdot\vec V = 0 \ \Rightarrow\ \nabla^2\phi = \frac{\partial^2\phi}{\partial x^2} + \frac{\partial^2\phi}{\partial y^2} = 0$$
2차원에서는 비회전 조건 \(\partial v/\partial x - \partial u/\partial y = 0\)에서 \(\nabla^2\psi = 0\)도 성립한다. \(\phi\)와 \(\psi\)는 둘 다 라플라스 방정식(Laplace equation)을 만족하고, \(\phi\) 등고선과 \(\psi\) 등고선(유선)은 어디서나 직교한다.

라플라스 방정식은 선형이다. 해 두 개를 더한 것도 해이므로, 몇 가지 기본 해를 중첩하면 복잡한 흐름을 만들 수 있다. 압력은 속도를 구한 뒤 베르누이 식 \(p + \tfrac12\rho V^2 = \)일정(비회전이면 유동장 전체에서 같은 상수)으로 얻는다. 이렇게 운동학(φ 또는 ψ)과 압력 계산을 분리할 수 있다는 것이 퍼텐셜 유동의 힘이다.

반무한 물체: 균일류 + 원천

원점의 원천 \(q\)에 균일류 \(U\)를 더하면 \(\psi = U r\sin\theta + \dfrac{q}{2\pi}\theta\)이다. 원천에서 나온 유체는 균일류에 떠밀려 하류로 가고, 균일류는 원천의 유체를 피해 돌아간다. 두 유체를 나누는 유선 \(\psi = q/2\)를 단단한 벽으로 바꿔도 흐름은 그대로이므로, 이것이 앞이 둥근 반무한 물체 주위의 흐름이다.

$$\text{정체점: } x = -b,\ \ b = \frac{q}{2\pi U}, \qquad \text{물체 표면: } r = \frac{b(\pi - \theta)}{\sin\theta}, \qquad \text{하류의 폭: } 2\pi b = \frac{q}{U}$$

랭킨 타원과 중첩 빌더

원천 \(q\)를 \(x = -a\)에, 같은 세기의 흡입을 \(x = +a\)에 두고 균일류를 더하면 원천에서 나온 유체가 모두 흡입으로 들어가 닫힌 물체가 생긴다. 이것이 랭킨 타원(Rankine oval)이다. x축 위에서 \(u = U - \dfrac{qa/\pi}{x^2 - a^2} = 0\)을 풀면 앞뒤 정체점의 위치가 나온다.

$$\frac{\ell}{a} = \sqrt{1 + \frac{q}{\pi U a}}, \qquad \text{반두께 } h:\ \ \psi(0, h) = Uh - \frac{q}{\pi}\tan^{-1}\frac{a}{h} = 0$$
\(q/(\pi Ua)\)가 클수록 뭉툭해지고, 작을수록 납작해진다. \(a \to 0\)이면서 \(qa\)를 일정하게 두면 쌍극자가 되고 원주가 된다.

원주 주위 유동과 양력

균일류에 원점의 쌍극자 \(K = Ua^2\)를 더하면 \(r = a\)인 원이 유선 \(\psi = 0\)이 된다. 원 밖의 흐름이 반지름 \(a\)인 원주 주위의 비점성 유동이다.

$$\psi = U\sin\theta\Big(r - \frac{a^2}{r}\Big), \qquad u_r = U\cos\theta\Big(1 - \frac{a^2}{r^2}\Big), \qquad u_\theta = -U\sin\theta\Big(1 + \frac{a^2}{r^2}\Big)$$
표면 \(r = a\)에서 \(u_r = 0\)(뚫지 않음), \(u_\theta = -2U\sin\theta\)(미끄러짐). \(\theta\)는 하류 방향 x축에서 반시계로 잰 각이다(뒤 정체점 θ = 0, 앞 정체점 θ = 180°).

표면 속력 \(V_s = 2U|\sin\theta|\)를 베르누이 식에 넣으면 표면 압력 계수(pressure coefficient)가 나온다.

$$C_p = \frac{p_s - p_\infty}{\tfrac12\rho U^2} = 1 - \Big(\frac{V_s}{U}\Big)^2 = 1 - 4\sin^2\theta$$
정체점(θ = 0°, 180°)에서 \(C_p = 1\), 꼭대기와 바닥(θ = ±90°)에서 \(C_p = -3\)(속력 2U), θ = 30°, 150°에서 \(C_p = 0\).
달랑베르 역설

비점성·비회전 이론에서는 원주뿐 아니라 어떤 모양의 물체도 정상 유동에서 항력이 0이다(1752). 실제 원주는 \(C_D \approx 1.2\)의 큰 항력을 받는다. 원인은 점성이다. 표면의 얇은 경계층은 뒤쪽의 압력 상승(역압력 구배)을 이기지 못해 θ ≈ 100° 부근에서 박리되고, 뒤쪽에 압력이 회복되지 않은 후류가 남는다. 앞면은 높은 압력, 뒷면은 낮은 압력 — 이것이 압력 항력이다(9장). 쿠에트–푸아죄유 시뮬레이터에서 역압력 구배가 벽 근처 유체를 뒤로 밀던 것과 같은 현상이다.

순환이 있는 원주: 쿠타–주콥스키 양력

원주 중심에 자유 와류(순환 Γ)를 더해도 원은 여전히 유선이다(와류의 유선이 원이므로). \(\psi = U\sin\theta\,(r - a^2/r) - \dfrac{\Gamma}{2\pi}\ln\dfrac ra\)이고, 표면 속도는 \(u_\theta = -2U\sin\theta + \dfrac{\Gamma}{2\pi a}\)이다.

$$\sin\theta_s = \frac{\Gamma}{4\pi U a}, \qquad C_p = 1 - \Big(2\sin\theta - \frac{\Gamma}{2\pi a U}\Big)^2, \qquad L' = -\rho U\Gamma, \qquad D' = 0$$
\(L'\)은 단위 길이당 양력(위쪽 +), Γ는 반시계 +. 시계 방향 순환(Γ < 0)이면 윗면이 빨라져 위로 양력이 생긴다. \(|\Gamma| > 4\pi Ua\)이면 정체점이 표면을 떠나 유동 속으로 나간다. 크기만 쓰면 쿠타–주콥스키 정리(Kutta–Joukowski theorem) \(L' = \rho U|\Gamma|\)이며, 모양과 상관없이 모든 2차원 물체에 성립한다.

회전하는 원주나 공은 점성으로 주변 유체를 끌고 돌아 순환을 만든다. 이것이 마그누스 효과(Magnus effect)다. 탑스핀을 건 탁구공이 뚝 떨어지고, 축구의 감아 차기가 휘며, 야구의 커브볼이 꺾이는 이유다. 돛 대신 회전 원통을 단 플레트너 로터 배도 있다. 이상적으로는 표면 속도가 유체 속도와 같다고 보고 \(\Gamma = 2\pi a^2\omega\)로 어림하지만, 실제 순환과 양력은 이보다 작다.

순환이 없는 원주(정체점이 앞뒤 정중앙)에 시계 방향 순환을 조금 더했다. 정체점 두 개는 어떻게 움직일까?

\(\sin\theta_s = \Gamma/(4\pi Ua) < 0\): 두 정체점이 모두 아랫면으로 내려가 서로 가까워지고, \(|\Gamma| = 4\pi Ua\)에서 바닥에서 만난다. 아래에서 정체점을 직접 끌어 보라.

핵심 정리

  1. 미분형 연속 방정식 \(\partial\rho/\partial t + \nabla\cdot(\rho\vec V) = 0\). 비압축이면 \(\nabla\cdot\vec V = 0\)(원통 좌표: \(\frac1r\partial(ru_r)/\partial r + \frac1r\partial u_\theta/\partial\theta + \partial u_z/\partial z = 0\))이고, 모르는 속도 성분을 적분과 경계 조건으로 구한다.
  2. 2차원 비압축 유동의 유동 함수: \(u = \partial\psi/\partial y,\ v = -\partial\psi/\partial x\). \(\psi = \)일정이 유선이고, 두 유선 사이 단위 깊이당 유량은 \(\psi_2 - \psi_1\).
  3. 비압축 뉴턴 유체의 나비에–스토크스 방정식 \(\rho D\vec V/Dt = -\nabla p + \rho\vec g + \mu\nabla^2\vec V\). 국소·대류 가속 = 압력 + 중력 + 점성. \(\mu = 0\)이면 오일러 방정식.
  4. 점성 유동의 벽 경계 조건은 점착(유체 속도 = 벽 속도). 비점성 해는 벽을 뚫지 않는다는 조건만 만족한다.
  5. 완전 발달 유동의 정확해: 쿠에트 \(u = Uy/h\), 평판 푸아죄유 \(q = h^3(-dp/dx)/12\mu\), 결합 유동 \(u/U = \eta + P\eta(1-\eta)\)(P < −1이면 역류), 하겐–푸아죄유 \(Q = \pi D^4\Delta p/128\mu L\).
  6. 비회전 유동은 \(\vec V = \nabla\phi\), \(\nabla^2\phi = 0\). 선형이므로 균일류·원천·흡입·와류·쌍극자를 중첩해 반무한 물체(\(b = q/2\pi U\)), 랭킨 타원, 원주(\(K = Ua^2\))를 만든다.
  7. 원주 표면 \(C_p = 1 - 4\sin^2\theta\)는 대칭이라 항력 0(달랑베르 역설, 실제로는 박리 때문에 항력). 순환을 더하면 \(\sin\theta_s = \Gamma/4\pi Ua\), 양력 \(L' = \rho U|\Gamma|\)(쿠타–주콥스키, 마그누스 효과).

연습문제

특별한 말이 없으면 비압축 유동이고 \(g = 9.81\) m/s²이다. 속도장의 좌표는 m, 속도는 m/s 단위다. 답이 ±1% 이내면 정답이다.

2차원 비압축 유동에서 \(u = 3x^2 - 2y\)이다. \(y = 0\)에서 \(v = 0\)일 때 점 (1, 2)에서 \(v\)는?

\(\partial v/\partial y = -\partial u/\partial x = -6x\).

\(v = -6xy + f(x)\), \(f = 0\). \(v(1, 2) = -12\) m/s. \(u\)의 \(-2y\) 항은 \(\partial u/\partial x\)에 기여하지 않는다.

다음 2차원 속도장 중 비압축 연속 방정식을 만족하지 않는 것은?

\(\partial u/\partial x + \partial v/\partial y\): ① \(2 - 2 = 0\), ② \(0 + 0 = 0\), ③ \(2x - 2x = 0\), ④ \(y + x \ne 0\).

2차원 비압축 유동의 원주 방향 속도가 \(u_\theta = -U\sin\theta\,(1 + a^2/r^2)\)이고, \(r = a\)에서 \(u_r = 0\)이다. \(U = 5.0\) m/s, \(a = 0.10\) m일 때 \(r = 0.20\) m, \(\theta = 30^\circ\)에서 \(u_r\)은?

\(\partial(ru_r)/\partial r = -\partial u_\theta/\partial\theta = U\cos\theta\,(1 + a^2/r^2)\)를 \(r\)로 적분한다.

\(ru_r = U\cos\theta\,(r - a^2/r) + f(\theta)\), \(r = a\)에서 0이므로 \(f = 0\). \(u_r = U\cos\theta\,(1 - a^2/r^2) = 5.0\cos30^\circ(1 - 0.25) = 3.25\) m/s. (원주 주위 유동이다.)

유동 함수가 \(\psi = 3x^2y - y^3\) (m²/s)이다. 점 (1, 2)에서 속력은?

\(u = \partial\psi/\partial y = 3x^2 - 3y^2 = -9\), \(v = -\partial\psi/\partial x = -6xy = -12\). \(|V| = \sqrt{81 + 144} = 15.0\) m/s.

유동 함수가 \(\psi = 4xy\) (m²/s)인 모서리 유동이다. 점 (1, 1)과 (2, 3)을 지나는 두 유선 사이를 흐르는 체적 유량은? 깊이(종이에 수직)는 0.50 m이다.

\(\psi_1 = 4\), \(\psi_2 = 24\) → 단위 깊이당 20 m²/s, \(Q = 20\times0.50 = 10.0\) m³/s.

위 문제의 유동(\(\psi = 4xy\))은 비회전이다. 속도 퍼텐셜 \(\phi\)를 구하고 \(\phi(3, 1) - \phi(1, 1)\)을 계산하라.

\(u = \partial\psi/\partial y = 4x = \partial\phi/\partial x\), \(v = -4y = \partial\phi/\partial y\).

\(\phi = 2x^2 - 2y^2\). \(\phi(3, 1) - \phi(1, 1) = 16 - 0 = 16.0\) m²/s. \(\phi\)와 \(\psi\)의 등고선(쌍곡선)은 서로 직교한다.

0.40 m × 0.40 m 판이 두께 0.80 mm의 SAE 30 오일막(μ = 0.29 Pa·s) 위를 1.5 m/s로 미끄러진다. 판을 끄는 힘과 동력은?

\(\tau = \mu U/h = 0.29\times1.5/0.0008 = 544\) Pa, \(F = \tau A = 544\times0.16 = 87.0\) N, \(\dot W = FU = 130.5\) W.

간격 1.00 mm인 두 고정 평판 사이로 20 °C 물(μ = 1.002×10⁻³ Pa·s)이 흐르고 \(dp/dx = -2.00\) kPa/m이다. 단위 폭 유량과 최대 속도는?

\(q = h^3(-dp/dx)/(12\mu) = (10^{-9})(2000)/(0.012024) = 1.66\times10^{-4}\) m²/s, \(u_\text{max} = h^2(-dp/dx)/(8\mu) = (10^{-6})(2000)/(8.016\times10^{-3}) = 0.250\) m/s.

간격 2.0 mm의 SAE 30 오일막(μ = 0.29 Pa·s)에서 윗판이 2.0 m/s로 움직인다. 아랫벽의 전단 응력이 0이 되는(역류가 막 시작되는) 압력 구배 \(dp/dx\)와, 그때의 단위 폭 유량을 구하라.

아랫벽에서 \(\partial u/\partial y = (U/h)(1 + P) = 0\) → \(P = -1\).

\(P = -1\) → \(dp/dx = 2\mu U/h^2 = 2(0.29)(2.0)/(4\times10^{-6}) = 2.90\times10^5\) Pa/m (역압력 구배). \(q = Uh(1/2 - 1/6) = Uh/3 = 1.33\times10^{-3}\) m²/s.

지름 1.0 cm, 길이 2.0 m인 관으로 SAE 30 오일(μ = 0.29 Pa·s, ρ = 891 kg/m³)을 압력 차 30 kPa로 보낸다. 체적 유량은? (층류인지도 확인하라.)

\(Q = \pi D^4\Delta p/(128\mu L) = \pi(0.01)^4(30000)/(128\times0.29\times2.0) = 1.27\times10^{-5}\) m³/s (0.762 L/min). \(V = 0.162\) m/s, \(Re = 891\times0.162\times0.01/0.29 = 5.0\) → 층류.

균일류 \(U = 10\) m/s에 세기 \(q = 6.0\) m²/s의 원천을 더했다. 원천에서 앞 정체점까지 거리 \(b\)와 하류의 물체 폭은?

\(b = q/(2\pi U) = 6.0/(20\pi) = 0.0955\) m, 폭 \(= q/U = 0.600\) m.

반무한 물체 표면에서 원천 바로 위(θ = 90°)인 점의 압력 계수는? (U와 q에 무관함을 보여라.)

표면 방정식 \(r = b(\pi - \theta)/\sin\theta\)에서 θ = 90°이면 \(r = \pi b/2\).

원천 속도 \(q/(2\pi r) = q/(\pi^2 b) = 2U/\pi\)(위쪽), 균일류 \(U\)(오른쪽). \(V^2/U^2 = 1 + 4/\pi^2\), \(C_p = -4/\pi^2 = -0.405\).

순환 없는 원주 주위 비점성 유동에서, 앞 정체점에서 잰 각으로 표면 압력이 자유류 압력과 같아지는 첫 위치는? 또 U = 20 m/s 공기(ρ = 1.2 kg/m³)일 때 표면의 최저 계기 압력은?

\(1 - 4\sin^2\theta = 0\) → \(\sin\theta = 1/2\) → 30°. 최저는 θ = 90°의 \(C_p = -3\): \(p - p_\infty = -3\times\tfrac12(1.2)(20)^2 = -720\) Pa.

지름 1.0 m, 높이 10 m의 회전 원통(플레트너 로터)이 8.0 m/s의 바람(ρ = 1.2 kg/m³)을 받는다. 두 정체점이 표면의 한 점에서 막 만나도록 회전시킬 때, 필요한 순환의 크기와 퍼텐셜 이론의 양력은?

두 정체점이 만나는 조건은 \(|\sin\theta_s| = 1\), 즉 \(|\Gamma| = 4\pi Ua\).

\(|\Gamma| = 4\pi(8.0)(0.50) = 50.3\) m²/s. \(L = \rho U|\Gamma|\,b = 1.2\times8.0\times50.3\times10 = 4.83\times10^3\) N. 이상적 회전수 \(\omega = \Gamma/(2\pi a^2) = 32\) rad/s(306 rpm).

퍼텐셜 유동 이론이 예측하는 원주의 항력이 실제와 크게 다른 가장 중요한 이유는?

이상 유동에서는 뒤쪽 표면의 압력이 앞쪽과 똑같이 회복되어 항력이 0이다. 실제로는 역압력 구배에서 경계층이 박리되어 후류의 압력이 낮게 남는다.

균일류 \(U = 5.0\) m/s에 세기 \(q = 10\) m²/s의 원천을 \(x = -1.0\) m에, 같은 세기의 흡입을 \(x = +1.0\) m에 두었다. 랭킨 타원의 반길이 \(\ell\)(원점에서 정체점까지)은?

x축 위에서 \(u = U + \dfrac{q}{2\pi}\Big(\dfrac{1}{x + a} - \dfrac{1}{x - a}\Big) = 0\).

\(u = U - \dfrac{qa/\pi}{x^2 - a^2} = 0\) → \(\ell = a\sqrt{1 + q/(\pi Ua)} = \sqrt{1 + 10/(5\pi)} = 1.28\) m. 중첩 빌더에서 U = 1, q = 2(같은 \(q/U\))로 확인해 보라.

개념 확인 퀴즈

유동 함수 ψ를 정의할 수 있는 유동은?

\(\psi\)는 2차원 연속 방정식을 자동으로 만족시키려고 도입한 함수다. 회전·점성과는 관계없다. 비회전 조건이 필요한 것은 속도 퍼텐셜 φ다.

두 평판 사이의 완전 발달 층류에서 나비에–스토크스 방정식의 어느 항이 정확히 0인가?

\(\partial u/\partial x = 0\)이고 연속 방정식에서 \(v = 0\)이므로 \(u\,\partial u/\partial x + v\,\partial u/\partial y = 0\). 압력 구배와 점성이 평형을 이룬다.

쿠에트–푸아죄유 유동(윗판 +x로 이동)에서 아랫벽 근처에 역류가 생기는 조건은?

\(P = (h^2/2\mu U)(-dp/dx) < -1\), 즉 \(dp/dx > 2\mu U/h^2\). 점성이 클수록 판이 끄는 힘이 강해져 역류가 어려워진다.

왼쪽에서 오른쪽으로 부는 바람 속의 원통이 시계 방향으로 회전한다. 양력의 방향은?

시계 방향이면 윗면이 바람과 같은 방향(+x)으로 움직여 윗면 유속이 빨라지고 압력이 낮아진다. Γ < 0이므로 \(L' = -\rho U\Gamma > 0\).

순환이 없는 원주 표면에서 속력이 가장 큰 곳과 그 값은?

\(V_s = 2U|\sin\theta|\). 꼭대기에서 2U, \(C_p = -3\). θ = 30°에서는 \(V_s = U\), \(C_p = 0\)이다.
