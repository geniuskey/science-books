유체 물성과 자료

본문의 예제와 연습문제에 필요한 수치를 한곳에 모았다. 표는 그대로 찾아 쓰고, 표 사이 값은 각 절의 계산기에서 바로 읽는다. 특별한 말이 없으면 \(g = 9.81\ \text{m/s}^2\), 공기 \(R = 287\ \text{J/(kg}\cdot\text{K)}\), \(k = 1.4\), 표준 대기압 \(p_{\text{atm}} = 101.325\ \text{kPa}\)를 쓴다.

물의 성질 (1 atm, 0–100 °C)

물의 밀도는 0–100 °C에서 4%밖에 변하지 않지만, 점성 계수(dynamic viscosity) \(\mu\)는 6배 넘게 줄어든다. 그래서 같은 관과 같은 유속이라도 뜨거운 물의 레이놀즈 수가 훨씬 크다. 동점성 계수(kinematic viscosity)는 \(\nu = \mu/\rho\), 비중량은 \(\gamma = \rho g\)이다. 증기압 \(p_v\)는 공동 현상(1장, 12장), 표면 장력 \(\sigma\)는 모세관 현상(1장)에 쓴다.

공기의 성질 (1 atm)

공기는 이상 기체로 다룬다. 밀도는 압력에 비례하고 절대 온도에 반비례한다. 기체의 점성 계수는 액체와 반대로 온도가 오르면 커진다(분자 운동량 교환이 활발해진다). 압력에는 거의 무관하므로, 동점성 계수 \(\nu = \mu/\rho\)는 압력에 반비례한다. 아래 표와 계산기는 서덜랜드 식을 쓴다.

$$\rho = \frac{p}{RT},\qquad \mu = \mu_0\left(\frac{T}{T_0}\right)^{3/2}\frac{T_0 + S}{T + S},\qquad c = \sqrt{kRT}$$
\(\mu_0 = 1.716\times10^{-5}\ \text{Pa}\cdot\text{s}\), \(T_0 = 273.15\ \text{K}\), \(S = 110.4\ \text{K}\), \(R = 287\ \text{J/(kg}\cdot\text{K)}\), \(k = 1.4\). T는 절대 온도(K).

표준 대기 (ISA, 0–20 km)

국제 표준 대기는 해면에서 \(T_0 = 288.15\ \text{K}\), \(p_0 = 101.325\ \text{kPa}\), \(\rho_0 = 1.225\ \text{kg/m}^3\)로 시작한다. 대류권(0–11 km)에서는 온도가 일정한 비율 \(B = 0.0065\ \text{K/m}\)로 떨어지고, 11–20 km(성층권 하부)에서는 216.65 K로 일정하다. 정수압 식 \(dp/dz = -\rho g\)에 이상 기체 식을 넣어 적분한 결과다(2장).

$$0\le z\le 11\ \text{km}:\ T = T_0 - Bz,\ \ p = p_0\left(1 - \frac{Bz}{T_0}\right)^{g/RB};\qquad 11\text{–}20\ \text{km}:\ p = p_{11}\,e^{-g(z - 11\,\text{km})/RT_{11}}$$
\(g/RB = 5.256\), \(p_{11} = 22.63\ \text{kPa}\), \(T_{11} = 216.65\ \text{K}\). 표준 대기 정의는 \(g = 9.80665\), \(R = 287.05\)를 쓴다.

관 마찰과 부차 손실 자료

다르시–바이스바흐 식 \(h_L = f\,(L/D)\,V^2/2g\)의 마찰 계수 \(f\)는 레이놀즈 수와 상대 거칠기 \(\varepsilon/D\)로 정해진다(8장). 층류(Re < 2300)는 \(f = 64/Re\), 난류는 콜브룩 식이나 그 근사식을 쓴다.

$$\text{콜브룩: }\ \frac{1}{\sqrt f} = -2.0\log\left(\frac{\varepsilon/D}{3.7} + \frac{2.51}{Re\sqrt f}\right)$$$$\text{해일란드: }\ \frac{1}{\sqrt f} \approx -1.8\log\left[\frac{6.9}{Re} + \left(\frac{\varepsilon/D}{3.7}\right)^{1.11}\right],\qquad \text{스와미–제인: }\ f \approx \frac{0.25}{\left[\log\left(\frac{\varepsilon/D}{3.7} + \frac{5.74}{Re^{0.9}}\right)\right]^2}$$

표 읽기 확인 문제

이 부록의 표와 계산기만으로 풀 수 있다. g = 9.81 m/s².

40 °C 물의 동점성 계수를 표의 ρ와 μ로 계산하라.

\(\nu = \mu/\rho\). 표에서 μ = 0.653 × 10⁻³ Pa·s, ρ = 992.2 kg/m³.

\(\nu = 0.653\times10^{-3}/992.2 = 6.58\times10^{-7}\ \text{m}^2/\text{s}\). 20 °C(1.00 × 10⁻⁶)의 약 2/3이다.

50 °C, 1 atm 공기의 밀도는?

\(\rho = p/RT = 101\,325/(287\times323.15) = 1.09\ \text{kg/m}^3\). 공기 표의 50 °C 행과 같다.

엔진 오일(SAE 30, 20 °C)의 μ = 0.29 Pa·s, ρ = 891 kg/m³이다. 점성 계수를 cP로, 동점성 계수를 cSt로 나타내라.

1 cP = 10⁻³ Pa·s, 1 cSt = 10⁻⁶ m²/s.

\(\mu = 0.29/10^{-3} = 290\ \text{cP}\). \(\nu = 0.29/891 = 3.25\times10^{-4}\ \text{m}^2/\text{s} = 325\ \text{cSt}\).

게이지 압력 250 kPa를 물(998 kg/m³) 기둥과 수은(13 550 kg/m³) 기둥의 높이로 나타내라.

\(h = p/\rho g\): 물 \(250\,000/(998\times9.81) = 25.5\ \text{m}\), 수은 \(250\,000/(13\,550\times9.81) = 1.88\ \text{m}\).

표준 대기에서 고도 8 km의 압력과 밀도는?

\(T = 288.15 - 0.0065\times8000 = 236.15\ \text{K}\), \(p = 101.325\,(236.15/288.15)^{5.256} = 35.6\ \text{kPa}\), \(\rho = p/RT = 35\,600/(287.05\times236.15) = 0.525\ \text{kg/m}^3\).

Re = 10⁵, ε/D = 0.001인 관의 마찰 계수를 콜브룩 식(또는 무디 선도)으로 구하라.

해일란드 식으로 시작값 \(1/\sqrt f = -1.8\log[6.9/10^5 + (0.001/3.7)^{1.11}]\)을 구한 뒤 콜브룩 식에 한두 번 대입한다.

해일란드: \(f_0 = 0.0220\). 콜브룩 반복: \(1/\sqrt f = -2\log(0.001/3.7 + 2.51\times6.74/10^5) = 6.716\) → \(f = 0.0222\). 무디 시뮬레이터에서 점을 (10⁵, 0.001)에 놓아 확인하라.

공기(k = 1.4)가 M = 2로 등엔트로피 유동할 때 p/p₀와 A/A*는?

\(T_0/T = 1 + 0.2\times4 = 1.8\), \(p/p_0 = 1.8^{-3.5} = 0.128\), \(A/A^* = \tfrac12(1.8/1.2)^{3} = 1.69\).

M₁ = 2, p₁ = 50 kPa, T₁ = 250 K인 공기 흐름에 수직 충격파가 선다. 충격파 뒤의 마하 수, 압력, 온도는?

표의 M₁ = 2 행: M₂ = 0.5774, p₂/p₁ = 4.5, T₂/T₁ = 1.6875. 따라서 p₂ = 225 kPa, T₂ = 250 × 1.6875 = 422 K.

반지름 0.5 m인 원형 수문이 연직 벽에 있고, 도심이 수면 아래 3 m에 있다(물 1000 kg/m³). 수문에 작용하는 힘과, 압력 중심이 도심보다 얼마나 아래에 있는지 구하라.

\(A = \pi(0.5)^2 = 0.785\ \text{m}^2\), \(F = \rho g h_c A = 1000\times9.81\times3\times0.785 = 23.1\ \text{kN}\). \(I_{xc} = \pi R^4/4 = 0.0491\ \text{m}^4\), \(y_R - y_c = 0.0491/(3\times0.785) = 0.0208\ \text{m}\).

배의 조파 저항(파도를 만드는 데 드는 저항)을 축소 모형으로 시험할 때 모형과 원형에서 같게 맞춰야 하는 무차원 수는?

자유 표면파는 중력과 관성의 균형으로 생기므로 프루드 수 \(V/\sqrt{gL}\)를 맞춘다(7장, 10장).
