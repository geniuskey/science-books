Appendix A

고체 물성 자료

본문의 예제와 연습문제에 필요한 물성값을 한곳에 모았다. 표는 머리글을 눌러 정렬하고, 위쪽 검색 칸에 물질 이름을 넣어 걸러 본다. 값은 특별한 말이 없으면 300 K의 대표값이다. 같은 양도 교재마다 마지막 자리가 다르다. 그래서 이 책의 계산 엔진(Solid.*, Q.*)이 쓰는 값은 그대로 싣고, 문헌값과 다를 때는 둘 다 적은 뒤 출처를 밝혔다. 문제를 풀 때는 문제에 주어진 값을 먼저 쓰고, 없을 때 이 표를 쓴다.

  • 반도체·금속·절연막 표에서 필요한 값을 찾고, 어떤 정의의 값(상태 밀도 질량, 전도도 질량, 정적·광학 유전율)인지 확인한다.
  • 에너지(eV·meV·cm⁻¹·THz·K), 길이, 농도 단위를 계산기로 바로 바꾼다.
  • 온도에 따른 \(E_g\)·\(n_i\)·이동도와, 실리콘 도핑 농도 ↔ 비저항을 계산기로 읽는다.
  • 격자 상수–띠 간격 지도에서 격자 정합 에피층을 고르고, \(\rho_0\lambda\)로 배선 금속을 비교한다.

고체물리는 한 양을 여러 단위로 쓴다. 포논 에너지는 라만 분광에서 cm⁻¹, 중성자 산란에서 meV나 THz, 열 문제에서는 \(\hbar\omega/k_B\)(K)로 적는다. 길이는 결정학에서 Å, 소자에서 nm, 농도는 소자에서 cm⁻³, 물리 식에서 m⁻³다.

질량은 mₑ의 배수다. ml/mt는 전도대 골짜기의 세로·가로 질량, mhh/mlh는 무거운·가벼운 정공 질량이다. 상태 밀도 유효 질량(density-of-states effective mass) mdos는 Nc·Nv와 캐리어 농도에, 전도도 유효 질량(conductivity effective mass) mc는 이동도와 플라스마 진동수에 쓴다. Si: \(m_{dos,e} = 6^{2/3}(m_lm_t^2)^{1/3} = 1.08\), \(m_{c,e} = 3/(1/m_l + 2/m_t) = 0.26\)(Solid.mDOS, Solid.mCond; 8장). μ는 도핑이 낮을 때의 이동도(cm²/(V·s))다. Si의 1414/471은 Solid.mobParams의 μmax(마세티형 맞춤)다. 문헌에서는 1350–1450 / 450–500을 쓴다. 화합물의 μ와 vsat은 고순도 결정의 상한(Ioffe NSM)이다. GaAs·InP·GaN의 vsat은 속도가 최고점을 지난 뒤의 고전기장 값이다(최고 속도는 2–2.5 × 10⁷ cm/s).

Si의 Nc·Nv·ni는 출처가 둘이다

표의 값 \(N_c = 2.8\times10^{19}\), \(N_v = 1.04\times10^{19}\), \(n_i = 1.0\times10^{10}\ \text{cm}^{-3}\)은 Q.materials(Sze 2판 표값)다. Solid.semis는 서로 맞춰 쓰도록 만든 Green(1990) 값 \(N_c = 2.86\times10^{19}\), \(N_v = 3.10\times10^{19}\), \(E_g = 1.124\) eV를 쓴다. 이 값으로 \(\sqrt{N_cN_v}\,e^{-E_g/2k_BT}\)를 계산하면 \(n_i = 1.07\times10^{10}\ \text{cm}^{-3}\)다. 아래 계산기들이 이 값을 쓴다. 실측 \(n_i\)는 \(9.65\times10^9\)(Altermatt 2003, Sze & Ng 3판)에서 \(1.5\times10^{10}\)(옛 교재)까지 퍼져 있다. Nv가 세 배나 차이 나는 것은 300 K 정공 상태 밀도 질량을 0.81로 잡느냐 1.15(비포물선·온도 효과 포함)로 잡느냐의 차이다. Ge·GaAs도 같다. GaAs의 \(N_v\)는 Q.materials 7.0 × 10¹⁸, Solid.semis 9.0 × 10¹⁸(Sze & Ng)이다. 같은 계산 안에서는 한 출처의 값끼리만 섞어 쓴다.

두 결정을 이어 기를 때(에피택시) 격자 상수가 같으면 결함 없이 두껍게 쌓을 수 있다. 이것을 격자 정합(lattice matching)이라 한다. 혼정 \(A_{1-x}B_x\)의 격자 상수는 베가드 법칙(Vegard's law)대로 조성에 거의 정비례하고, 띠 간격은 직선에서 아래로 휜다. 휜 정도를 나타내는 계수가 휨 매개변수(bowing parameter) \(b\)다.

$$a(x) = (1-x)\,a_A + x\,a_B,\qquad E_g(x) = (1-x)\,E_{g,A} + x\,E_{g,B} - b\,x(1-x)$$
InxGa1−xAs: \(b = 0.477\) eV(Vurgaftman 2001). AlxGa1−xAs(Casey–Panish): 직접 \(1.424 + 1.247x\), 간접(X) \(1.900 + 0.125x + 0.143x^2\) eV. 약 x = 0.45에서 간접으로 바뀐다. Si1−xGex: 격자 상수는 Solid.aSiGe(데즈뮤크스 2차식), 무변형 띠 간격은 x < 0.85에서 \(1.12 - 0.41x + 0.008x^2\) eV(Si 같은 X 골짜기)로 근사하고, 그 위는 Ge의 L 골짜기 값 0.66 eV까지 직선으로 이었다(개략).

표 찾아 쓰기 연습

필요한 값은 모두 이 부록의 표와 계산기에 있다. 문제에 값이 주어지면 그 값을 쓴다.

표의 격자 상수로 (가) Si 기판 위 Ge 층, (나) Ge 기판 위 GaAs 층의 격자 불일치 \(f = (a_{\text{층}} - a_{\text{기판}})/a_{\text{기판}}\)를 %로 구하라.

Si 0.54310, Ge 0.56579, GaAs 0.56533 nm.

(가) \((0.56579 - 0.54310)/0.54310 = +4.18\%\)(층이 크다 → 압축 변형). (나) \((0.56533 - 0.56579)/0.56579 = -0.081\%\). Ge 위 GaAs는 거의 정합하여, 우주용 다중 접합 태양 전지가 Ge 기판에서 출발한다.

1 cm⁻¹ = 0.123 984 meV = 0.029 979 THz.

\(520.7\times0.123984 = 64.6\ \text{meV}\), \(520.7\times0.0299792 = 15.6\ \text{THz}\). 온도로는 \(64.56/0.086173 = 749\) K이므로 300 K에서는 점유수가 \(1/(e^{2.50}-1) = 0.09\)로 작다.

InP(a = 0.58687 nm)에 격자 정합하는 InxGa1−xAs의 조성 x와 300 K 띠 간격을 구하라. GaAs a = 0.56533 nm, Eg = 1.424 eV; InAs a = 0.60583 nm, Eg = 0.354 eV; 휨 매개변수 b = 0.477 eV.

\(x = (a_{\text{InP}} - a_{\text{GaAs}})/(a_{\text{InAs}} - a_{\text{GaAs}})\).

\(x = 0.02154/0.04050 = 0.532\). \(E_g = 0.468\times1.424 + 0.532\times0.354 - 0.477\times0.532\times0.468 = 0.6665 + 0.1883 - 0.1188 = 0.736\ \text{eV}\). 흡수 끝은 \(1239.84/0.736 = 1684\) nm라 1.55 μm 빛을 흡수한다. 에피 지도의 과녁과 같다.

P를 \(1.0\times10^{16}\ \text{cm}^{-3}\) 도핑한 n형 Si의 300 K 비저항을 구하라. 이동도는 Solid.mobility 맞춤식 값(1184 cm²/(V·s))을 쓰고, 소수 캐리어 기여는 무시한다.

\(\rho = 1/(qn\mu_n)\), \(n \approx N_d\).

\(\rho = 1/(1.602\times10^{-19}\times10^{16}\times1184) = 0.527\ \Omega\cdot\text{cm}\). 비저항 계산기에 1e16을 넣어도 같은 값이 나온다. 어빈 곡선에서 읽는 0.5 Ω·cm와 맞는다.

붕소의 진성 확산 계수 \(D = 0.76\,\exp(-3.46\ \text{eV}/k_BT)\) cm²/s로 1000 °C에서의 D와 1시간 확산 길이 \(\sqrt{Dt}\)를 구하라.

\(k_BT = 8.617\times10^{-5}\times1273.15 = 0.10971\) eV, \(D = 0.76\,e^{-31.54} = 1.53\times10^{-14}\ \text{cm}^2/\text{s}\). \(\sqrt{Dt} = \sqrt{1.53\times10^{-14}\times3600} = 7.42\times10^{-6}\ \text{cm} = 74\ \text{nm}\). 도펀트 표의 값과 같다.

금속 표의 ρ0와 λ로 Cu와 Ru의 ρ0λ 곱의 비를 구하라. 얇은 선폭 극한에서 어느 쪽이 유리한가?

Cu \(1.68\times39.9 = 67.0\), Ru \(7.1\times6.6 = 46.9\)(단위 μΩ·cm·nm = 10⁻¹⁷ Ω·m²). 비는 \(67.0/46.9 = 1.43\)이다. 선폭이 λ보다 훨씬 좁으면 \(\rho \propto \rho_0\lambda/w\)이므로 Ru가 유리하다. 벌크 비저항만 보면 Cu가 4배 낮다.

격자간 Fe의 주개 준위 Ev + 0.38 eV는 Si의 진성 준위 Ei에서 얼마나 떨어져 있는가? \(E_i - E_v = E_g/2 + (k_BT/2)\ln(N_v/N_c)\)에 Solid.semis 값(Eg = 1.1245 eV, Nc = 2.86 × 10¹⁹, Nv = 3.10 × 10¹⁹ cm⁻³)을 쓴다.

\(E_i - E_v = 0.5622 + 0.012926\times\ln(1.084) = 0.5622 + 0.0010 = 0.563\) eV. \(E_t - E_i = 0.38 - 0.563 = -0.183\) eV. 중간 띠에서 7 kBT 떨어져 있지만 정공 포획 단면적이 작아(σn/σp ≈ 600) p형에서는 강한 재결합 중심이 된다(12장).

1550 nm 광통신 빛을 띠 간 흡수로 검출할 수 있는 물질은?

흡수하려면 \(E_g < 1239.84/1550 = 0.80\) eV여야 한다. Si 1.12, GaAs 1.424, InP 1.344 eV는 모두 크고, In0.53Ga0.47As(0.74 eV, λg ≈ 1.68 μm)만 흡수한다. Ge(0.66 eV)도 흡수하므로 Si 위에 Ge 광검출기를 붙이는 실리콘 포토닉스가 있다.
