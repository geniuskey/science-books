용어집과 종합 문제

1–16장과 부록 A 본문에서 처음 정의한 용어를 모았다. 설명은 본문의 정의를 한두 문장으로 정리한 것이며, 링크를 누르면 그 용어가 처음 나온 절로 이동한다. 검색창에 한국어나 영어를 넣거나 장을 골라 목록을 좁힐 수 있다. 뒤의 종합 문제는 장마다 계산 문제를 3–4개씩 내고, 대부분 웨이퍼 방위, XRD, 확산, 구리 배선, 홀 측정, 도핑과 면저항, 수명, 접합, high-k, MRAM, 나노시트 채널처럼 반도체 현장의 숫자로 묻는다. ‘종합’ 표시가 붙은 문제는 여러 장의 도구를 함께 써야 풀린다. 마지막에는 각 장의 개념 퀴즈를 무작위로 섞어 낸다. 상수는 CODATA 2018 값, \(\hbar^2/2m_e = 0.0381\ \text{eV}\cdot\text{nm}^2\), 300 K에서 \(k_BT = 25.85\ \text{meV}\)를 쓴다.

Cu Kα1(\(\lambda = 0.15406\ \text{nm}\))로 (001) 실리콘 웨이퍼의 (004) 반사를 잰다. 회절 각 \(2\theta\)는?

입방정의 면 간격 \(d_{hkl} = a/\sqrt{h^2 + k^2 + l^2}\), \(\lambda = 2d\sin\theta\).

\(d_{004} = 0.5431/4 = 0.13578\ \text{nm}\), \(\sin\theta = 0.15406/0.27155 = 0.5673\) → \(\theta = 34.56°\), \(2\theta = 69.13°\). 고분해능 XRD의 SiGe 로킹 곡선이 이 기판 봉우리를 기준으로 잡힌다.

다이아몬드 구조의 구조 인자는 \(F = f\,S_{FCC}\,(1 + e^{i\pi(h+k+l)/2})\)이고 \(S_{FCC} = 4\)(지수가 모두 홀수이거나 모두 짝수일 때)이다. 원자 산란 인자 \(f\)를 같게 둘 때 \(|F_{220}|^2/|F_{111}|^2\)는? (200)은 어떻게 되는가?

\(h + k + l = 3\): \(1 + e^{i3\pi/2} = 1 - i\). \(h + k + l = 4\): \(1 + e^{i2\pi} = 2\).

\(|F_{111}|^2 = 16f^2|1 - i|^2 = 32f^2\), \(|F_{220}|^2 = 16f^2\cdot4 = 64f^2\) → 비 = 2. (200)은 \(h + k + l = 2\)에서 \(1 + e^{i\pi} = 0\)이라 금지 반사다. 실제 세기는 \(f\)의 각도 의존, 다중도, 로런츠–편광 인자가 더 바꾼다.

다결정 박막의 회절 봉우리가 \(2\theta = 38.2°\)에서 반치폭 0.40°(장비 넓어짐을 뺀 값)로 넓어져 있다. Cu Kα1, \(K = 0.9\)로 결정립 크기를 어림하라.

\(L = K\lambda/(\beta\cos\theta)\), \(\beta\)는 라디안의 \(2\theta\) 반치폭, \(\theta = 19.1°\).

\(\beta = 0.40°\times\pi/180 = 6.98\times10^{-3}\), \(\cos 19.1° = 0.9449\). \(L = 0.9(0.15406)/(6.98\times10^{-3}\times0.9449) = 21.0\ \text{nm}\). 미세 변형도 봉우리를 넓히므로 셰러 값은 결정립 크기의 하한으로 읽는다.

Si(001) 기판 위 Si0.75Ge0.25 층이 면 안에서 기판에 완전히 맞춰 자랐다. 베가드 법칙(\(a_{Si} = 0.5431\), \(a_{Ge} = 0.5658\ \text{nm}\))으로 완화 격자 상수를 구하고, \(\varepsilon_\parallel = (a_{Si} - a)/a\), \(\varepsilon_\perp = -2(C_{12}/C_{11})\varepsilon_\parallel\)(\(C_{12}/C_{11} = 0.39\))로 두께 방향 변형과 \(a_\perp\)를 구하라.

면 안으로 눌리면(\(\varepsilon_\parallel < 0\)) 두께 방향으로 늘어난다(푸아송 효과).

\(a = 0.5431 + 0.25(0.0227) = 0.54878\ \text{nm}\). \(\varepsilon_\parallel = (0.5431 - 0.54878)/0.54878 = -1.034\%\), \(\varepsilon_\perp = -2(0.39)(-1.034\%) = +0.807\%\), \(a_\perp = 0.54878(1.00807) = 0.5532\ \text{nm}\). (004) 봉우리는 기판보다 작은 각으로 갈라져 나오고, 그 간격에서 조성과 변형을 함께 거꾸로 읽는다.

3장 결합과 탄성본문 →

FCC 아르곤 결정의 원자당 에너지는 \(U = 2\epsilon[12.13(\sigma/R)^{12} - 14.45(\sigma/R)^6]\)이다(\(R\)은 최근접 거리). \(\sigma = 0.340\ \text{nm}\), \(\epsilon = 10.4\ \text{meV}\)일 때 평형 거리와 원자당 응집 에너지의 크기는?

\(R_0/\sigma = (1.6789)^{1/6} = 1.090\) → \(R_0 = 0.371\ \text{nm}\)(측정 0.376). \(U_0 = -8.61\epsilon = -89.5\ \text{meV}\)(측정 −80 meV, 차이는 영점 운동). 공유 결합 실리콘의 4.6 eV보다 50배 약하다.

실리콘의 탄성 상수는 \(C_{11} = 165.7\), \(C_{12} = 63.9\), \(C_{44} = 79.6\ \text{GPa}\)이다. [100]과 [110] 방향의 영률을 구하라. 방향 여현 \(l, m, n\)에 대해 \(1/E = S_{11} - 2(S_{11} - S_{12} - \tfrac12S_{44})(l^2m^2 + m^2n^2 + n^2l^2)\).

\(S_{11} = \dfrac{C_{11} + C_{12}}{(C_{11} - C_{12})(C_{11} + 2C_{12})}\), \(S_{12} = \dfrac{-C_{12}}{(C_{11} - C_{12})(C_{11} + 2C_{12})}\), \(S_{44} = 1/C_{44}\).

\(S_{11} = 7.68\times10^{-3}\), \(S_{12} = -2.14\times10^{-3}\), \(S_{44} = 12.56\times10^{-3}\ \text{GPa}^{-1}\). [100]: \(E = 1/S_{11} = 130\ \text{GPa}\). [110]: \(l^2m^2 = 1/4\) → \(1/E = S_{11} - \tfrac12(S_{11} - S_{12} - \tfrac12S_{44}) = 5.91\times10^{-3}\) → \(E = 169\ \text{GPa}\). [111]은 188 GPa. (100) 웨이퍼의 노치 방향 ⟨110⟩이 가장 단단하다.

5장 격자 진동과 포논본문 →

질량 28 u의 원자가 간격 0.25 nm로 늘어선 사슬이 용수철 상수 \(C = 50\ \text{N/m}\)로 이웃과 이어져 있다. 분산 \(\omega = 2\sqrt{C/M}\,|\sin(ka/2)|\)의 최대 진동수 \(\nu_{max}\)와 장파장 음속은?

영역 경계 \(k = \pi/a\)에서 최대 \(\omega_{max} = 2\sqrt{C/M}\). 작은 \(k\)에서 \(\omega \approx a\sqrt{C/M}\,k\).

\(\sqrt{C/M} = \sqrt{50/(28\times1.6605\times10^{-27})} = 3.279\times10^{13}\ \text{s}^{-1}\). \(\nu_{max} = 2(3.279\times10^{13})/2\pi = 10.4\ \text{THz}\). \(v_s = 0.25\times10^{-9}\times3.279\times10^{13} = 8.20\ \text{km/s}\) — 실리콘의 종파 음속(8.4 km/s)과 비슷하다.

Ga(69.72 u)와 As(74.92 u)가 번갈아 놓인 1차원 사슬(\(C = 35\ \text{N/m}\))에서 광학 가지의 \(k = 0\) 진동수와, 영역 경계에서 음향 가지의 최대·광학 가지의 최소 진동수는?

\(\omega_O(0) = \sqrt{2C(1/M_1 + 1/M_2)}\), 경계에서 \(\sqrt{2C/M_{무거운}}\)(음향)과 \(\sqrt{2C/M_{가벼운}}\)(광학).

\(\omega_O(0)/2\pi = 5.44\ \text{THz}\), 경계의 음향 최대 \(\sqrt{2C/M_{As}}/2\pi = 3.78\ \text{THz}\), 광학 최소 \(\sqrt{2C/M_{Ga}}/2\pi = 3.91\ \text{THz}\). 두 질량이 비슷해 경계의 간격(0.14 THz)이 좁다. 질량이 같으면 간격이 닫혀 다이아몬드 구조의 두 가지가 X점에서 만난다.

\(\hbar\omega = hc\tilde\nu\), \(hc = 1239.84\ \text{eV}\cdot\text{nm}\). \(\langle n\rangle = 1/(e^{\hbar\omega/k_BT} - 1)\).

\(\hbar\omega = 1239.84\times520\times10^{-7} = 0.0645\ \text{eV}\). \(\hbar\omega/k_BT = 2.494\) → \(\langle n\rangle = 0.0900\). 스토크스/반스토크스 세기비 \(\approx (\langle n\rangle + 1)/\langle n\rangle\)로 국소 온도를 잴 수 있다. 응력은 이 봉우리를 cm⁻¹ 단위로 옮긴다.

\(x = 4.40\): \(x^2e^x/(e^x - 1)^2 = 19.36(81.45)/(80.45)^2 = 0.244\). 아인슈타인이 1907년 다이아몬드의 작은 비열을 설명한 계산이다(측정 약 0.25).

9장 결정 속 전자의 운동본문 →

격자 상수 0.50 nm의 결정에 \(10^5\ \text{V/cm}\)의 전기장을 건다. 블로흐 진동의 주기는? 실리콘의 운동량 완화 시간(약 0.1 ps)과 비교하라.

GaAs 전자(\(m^* = 0.067m_e\))의 1.0 T 사이클로트론 공명 진동수는?

두께 500 µm의 n형 실리콘 막대에 전류 1.00 mA, 자기장 0.500 T를 걸었더니 홀 전압이 2.50 mV였다. 비저항이 1.90 Ω·cm일 때 전자 농도와 홀 이동도는? (홀 인자는 1로 둔다.)

\(V_H = IB/(nqt)\), \(\mu_H = 1/(qn\rho)\).

\(B = n_sh/(\nu e) = 3\times10^{15}(6.626\times10^{-34})/(2\times1.602\times10^{-19}) = 6.20\ \text{T}\). \(R_{xy} = 25812.8/2 = 12906\ \Omega\) — 시료와 무관한 저항 표준이다.
